# NDC 同场景状态变化

实际使用 Photoshop MCP 前按需读取 [全局 PS 队列](../ndc-photoshop-queue/SKILL.md)。同任务当前图须保存、完成技术及真实视觉检查并核对当前hash；未审完不得推进下一张。PASS可推进相应依赖；FAIL缺陷已记录且预算耗尽或用户要求封存时，保留候选和累计次数，仅继续独立资产；安全保存可恢复文件和固定审阅快照后，可按队列协议挂起释放给其他独立任务。释放不是PASS，不解除原图及依赖的阻断、不重置预算；命令在途或结果未知时不得自行交棒。纯准备、生图等待和离线审阅不长期占用桥接，未授权的PS操作不会因排队而获得授权。

交付同一已批准场景的指定状态，保持固定镜头、空间拓扑和受保护内容。大范围状态变化先建立连贯整体，再修局部瑕疵；它不属于 MJ 新底图交付，也不应靠许多小补丁拼成主状态。

## 查验与锁定

先依项目来源顺序查验同场景、同机位、目标状态是否已有正式资产，核对批准依据与本次用途。满足要求时按 [production-record.md](references/production-record.md) 验证源图/父图、当前字节、要求与拒收状态后精确复用；只缺少某状态才制作该项。明确重画指令优先。

打开实际批准底图，记录当前与目标状态、来源/批准关系、原始画布与镜头、固定地标及连接关系、允许变化区域、必须像素保护的区域、允许改变表面但不得改变身份/位置的区域。空间身份保护和像素保护须明确区分。新状态的光源、时间、天气或事件条件从当前需求取得，不自行添加剧情事实、人物或证物。

使用 [ndc-visual-description](../ndc-visual-description/SKILL.md) 在方案形成前明确实际可见变化，最终提示/参考/裁切组装后核对同一份输入。沿用主记录，不额外审批。未明确授权变化的区域继续保护；整体重绘需求不能隐式授权改变受保护镜头、建筑身份或关键地标。

## 生产与累计预算

按 [production-record.md](references/production-record.md) 建立同一场景/底图/目标状态的稳定 job，在项目 `工作过程文件` 下保留全部输入、候选、变换和审核。默认最多 **3 次实际图像生成，含首次**；整图、各语义区域、重试以及调用局部修图时的新增生成都共用此总额，拆区域/换阶段/恢复任务不能重新计数。比如两个区域各生成一次，合计已用 2 次，仅剩 1 次。确定性对齐、合法合成或已授权 PS 修正不占生成次数、不赠额度。

每次提交前保留尝试，返回后记录真实输入和实际保存结果；不确定是否已提交时先核对结果。预算耗尽即停止生成，保留当前候选及失败原因，不能用收尾阶段或换文件名领取新额度。继承上游更严格剩余额度；仅明确追加授权可变更预算。

1. **建立整体状态**：优先一次参考锁定的完整状态编辑；工具限制或保护区需要时，用最少量可在剩余额度内完成的大语义区域，每区包含完整建筑关系与足够重叠上下文。避免沿门框、柜体或光束边缘切碎。每区共享同一镜头/身份、状态、整体光照和风格约束，只改变本区允许变化内容。
2. **先看整体，再看局部**：先确认还是同一地点、状态一致且整体光照/材质变化合理；明显整体失败的候选记录拒收原因即可，不为它补做无意义的完整细纹理批准。进入接受链的候选仍须实际整图和所有适用原像素局部检查；不能拿整体粗筛当正式通过。
3. **恢复准确画布并合成**：记录所有缩放、裁切、平移、重叠与混合；禁止非等比拉伸。候选长宽比明显不符时拒收，不通过隐蔽裁切掩盖机位变化。大区域交接先对齐多个受保护地标/透视线，再检查整体光照和边界；像素锁定区域必须从原图精确保留并验证零漂移。
4. **最后局部收尾**：整体已成立才把小接缝、局部重复、关键细结构或边缘缺陷交给 [ndc-coordinate-image-edit](../ndc-coordinate-image-edit/SKILL.md)。它使用当前接受图作为局部源，但沿用本 job 剩余生成预算；局部修补的蒙版/并集零漂移证据追加回同一接受依赖链。语义/整体状态失败回本阶段，不能用许多局部补丁掩盖。

图像工具、参考和 Photoshop 操作遵守当前项目授权。生成画布两边为 16 的倍数，每边不超过 3840、长宽比不超过 3:1、总像素 655,360–8,294,400；不能为满足工具限制改掉交付镜头。工具支持下可记录等比输入/输出映射；仍须保护原始画布身份与明确的像素保护区。需要 Photoshop 的变换/Alpha/导出按项目 MCP 路线与全局队列执行：同任务当前图未审完不推进下一张，PASS才推进相应依赖，FAIL按全局队列有据封存后仅继续独立资产；跨任务可安全挂起释放；不以本 Skill 为替代工具授权或解除同场景接受依赖。

## 验收与交付

当前接受链及最终文件须通过：原画布/模式；同镜头和空间拓扑；受保护地标身份与位置；目标状态及共同光照/材质响应；无直线拼接、矩形明暗孤岛、重复结构或局部风格孤岛；未授权内容没有增加；像素保护区确实零漂移。只在当前需求涉及事件时检查其方向/时间/强弱因果，不把破坏或爆炸强行套入普通灯光/天气变化。

风格验收沿用场景原图全覆盖标准：先完整画面，再原像素重叠分块，所有适用局部不得用少量代表裁图替代；使用已安装场景提示 Skill 的[分块工具](../ndc-scene-to-mj-prompt/scripts/make_style_review_tiles.py)与[场景风格协议](../ndc-scene-to-mj-prompt/references/style-analysis-protocol.md)。阶段视觉记录绑定真实输入输出、哈希、要求、实际看过的整图/局部及各项结论，并运行项目既有 `validate-ndc-stage-visual-self-check.py --record <record> --artifact <output>` 阶段校验器。技术/哈希不自动产生艺术 PASS。空间身份审查与像素保护检查各自报告，不能用局部零漂移宣称整体状态正确，也不能用整体合理豁免被锁像素。

选择/复制/发布仅在生产记录的当前字节、父图、用途、要求、审核和无拒收绑定有效时复用既有审阅；变化只使受影响记录及依赖失效。历史失败候选保留，不要求其全部 PASS。把通过的请求状态 PNG 放入用户授权交付位置，记录来源、状态关系、实际变换、生成次数及当前审核；未通过则留在过程目录并明确缺项，不以新建审批环节拖住已获授权的交付。

需要理解整图状态与局部修图区别时，可读 [Morrison 历史案例](../ndc-coordinate-image-edit/references/morrison-explosion-state-conversion.md)。其具体爆炸源、物件、损坏比例和提示文本只是单案例证据，不是默认场景事实、通用风格或本 Skill 的预算/权限来源。
