# 细节控制

版本：2.0，2026-09-07。将原有纹理治理扩展为内容、轮廓、体积、对比、空间层次与表面纹理的联合控制。跨项目使用，不预设 NDC 配色、特定构图、唯一焦点或平滑画风。

## 边界与风格权威

- 保留用户当前要求、批准参考、身份与必要结构、准确文字、交互线索、既定镜头及编辑区域。细节减少不能掩盖结构、接触或信息缺失。
- 根据批准参考确定可接受的概括程度。保留原生笔触、颗粒、磨损、硬软边和材质语言；“更干净”不能补偿风格漂移。平顺大笔触仅适用于参考支持或用户明确要求的分支。
- 允许在当前创作授权内归并非必要的重复刻画、次级轮廓与表面细节；它们即使具有合理语义，也不必逐一展开。必须区分可选陈设与任务必需物件，不自行删除后者。
- 逐字锁定的提示词仍逐字保留。本 Skill 的通用接入不自动授权重写它们；必要时给出定位明确的最小修改建议，沿用项目已有修改权限。
- 本 Skill 不生成图像、不操作 Photoshop、不自动去噪、不改模型参数或重试上限，不自动批准正式资产。没有看过图片时，只能进行文字审查。
- 使用者可只安装本文件夹；没有其他 Skill 或项目脚本也能完成提示准备与人工视觉审查。主生产流程存在时，沿用其工具、格式、资产目录和验收责任。

## 介入时机

1. **视觉方案形成时**：需求、用途和参考明确后，布局与刻画方案定稿前，确定保留信息及概括权限。简单任务直接思考并写提示，不强制额外表单。
2. **实际提交前**：检查最终提示、实际参考职责与顺序、裁切和编辑范围。避免后续拼装重新引入“每处极致细节”“所有材质清晰”等冲突。编译成主工具可用的简短具体要求，不把整份 Skill 复制给图像模型。
3. **候选审核时**：复用主流程已经查看的整图和局部证据，先诊断失败类别，再修正对应变量。不要重复生成相同报告。
4. **实质变化时**：镜头、资产用途、可见内容、风格参考或编辑范围改变后，只更新受影响项。纯复制与批准资产复用不重新启动创作，但主流程要求的交付检查仍保留。

## 先判断六类问题

| 类别 | 可观察的问题 | 对应处理 |
| --- | --- | --- |
| 内容密度 | 可选物件挤占空间、无安静区域 | 收敛可选陈设，组织聚散与间隔，保留必要内容 |
| 轮廓复杂度 | 连续小尖峰、云瓣、锯齿、同尺度转折 | 保留关键走势与识别点，合并次级起伏 |
| 体积分割 | 大形由大量各自受光的小球、小褶、小亮暗块拼接 | 小形共享整体光照，以共同色面和暗面归并 |
| 对比分布 | 到处亮边、黑缝与碎高光 | 对比服从焦点/交互任务，高光与阴影成组 |
| 空间层次 | 近远信息同密、远景只是变淡但小结构仍完整 | 按实际视距省略信息；外景/大空间适用空气透视，普通室内加强遮挡与光照关系 |
| 表面纹理 | 杂点、断裂笔触、重复纹样、尺度跳变 | 约束方向、尺度、连续性和密度，保护原生材质特征 |

同一候选可以有多个问题。没有表面噪点不等于不碎；轮廓简洁也不等于材质正确。

## 刻画安排

为实际需要控制的区域明确：**区域/用途 → 必须保留 → 允许省略或归并 → 目标形态 → 对比/边缘 → 检查位置**。

- 焦点明确到部位，不能把整座建筑或全身全部默认为精细区。探索场景可有多个必要可读区域，不强制唯一焦点。
- 近处不自动精细，远处不自动模糊；用途决定重点，投影视距限制实际可表现的信息。若必要文字必须看清，依照主流程准备详情图，不擅自改变镜头。
- 细节归并以任务与参考为依据，不使用通用“减半细节”、固定物件数量、固定云数或强制留白比例。
- 可归并不等于可改设计：角色脸型、必要服装结构、证据符号、建筑身份和承托关系不属于可选碎细节。

## 按当前画面选分支

读 [分支与边界](references/branches.md) 中对应小节：普通室内、外景/大纵深、角色与物件、坐标锁定局部编辑。一个画面只组合实际需要的分支。

需要可复制提示时，读 [提示组装](references/prompt-templates.md)，产出一份填好具体对象、去重且无冲突的完整提示。用户要求完整版本时，不只交付增补段落；用户要求跨场景模板时同时说明应填字段，不把单案例配置固化成默认。

需要判断结果或返工时，读 [审阅与返工](references/review.md)。缩略图看层级，正常展示尺寸看轮廓/体积/空间，原像素看材质；最后回到整体。

## 协作输出

简单任务：完整可复制提示＋少量必要保持项。复杂任务：将刻画安排、最终输入对应关系、适用分支及审查结论并入主流程原有记录。

审核必须指出具体区域、可见现象、比较依据及返工方向，区分 `PASS`、`FAIL`、`NOT_CHECKED`；不适用项写明原因。提示审查通过不等于图片通过。

不要求新建通用 JSON，不改变主流程既有风格/纹理/技术验证器。可将补充判断写入原记录允许的说明字段或旁附人读审阅，不向固定 schema 塞入未支持字段。通用清晰度、边缘密度或哈希不能自动给艺术 PASS。

## 已知证据边界

方法来自连续外景提示迭代与室内差异分析。外景观察支持“内容收敛后仍可能轮廓繁碎、体积分割、远景信息过密”；它不是控制了随机性和参考状态的对照试验。室内及其他风格分支仍需真实任务验证，不能宣传普遍有效或保证消除杂点。
