# 审阅、返工与证据

## 三个观察尺度

复用主流程的原图与审阅证据，不额外强制生产一套图表。

1. **缩略图/整体**：主次是否符合用途；是否有聚散与间隔；必要交互区域是否仍可读；亮点是否无目的地分散。不能据缩略图批准微纹理。
2. **正常展示尺寸**：忽略表面纹理后，轮廓是否仍繁碎；大体积是否被独立小亮暗块切开；空间层次是否合理；重复元素是否形成节奏。不要把前景失焦当作概括成功。
3. **原像素局部**：纹理方向、连续性、尺度、重复伪影、杂点与必要结构。主流程要求完整覆盖时继续执行，不以几张代表裁图替代。最后返回整图核对风格和整体关系。

## 记录什么

在主流程已有审核中记录六类问题的适用性、具体位置、可见现象、参考/需求依据、结论与返工出口。`PASS` 需实际看图；没有对应观察为 `NOT_CHECKED`；不适用项写理由，不编造观察。历史通过记录不证明当前输出通过，沿用主流程当前文件哈希绑定。

示例：
- 不充分：“纹理 PASS，无问题。”
- 可执行：“右后山体仍可辨认密集树冠与岩缝，内部对比接近中景；需求要求远景仅保留山势，空间层次 FAIL。减少该区域内部结构及轮廓转折，重核空气透视。”
- 室内：“右侧普通书架每本书均有亮边，形成连续亮线；必要证据书脊已列为保护项。对其余书本归并共同阴影，保持证据文字与柜体结构。”

风格与必要内容必须独立保持。更平滑但丢失批准干笔、皱纹或必要信息不能通过。新审阅补充项并入主流程支持的字段；固定 schema 不支持时用旁附说明关联同一资产，不更名现有门禁、不伪造验证器通过。

## 按原因返工

| 问题 | 最小可解释修正 |
| --- | --- |
| 可选内容过密 | 重组聚散、减少可选陈设，保护任务必需物件 |
| 轮廓繁碎 | 保留识别走势，归并次级转折；不是统一羽化边缘 |
| 体积破碎 | 统一共同受光和暗面，减少独立高光单元 |
| 对比散乱 | 调整对比分配，保护批准光照和必要可读区 |
| 空间信息同密 | 按分支调整信息省略与实际空气透视；普通室内不默认加雾 |
| 局部杂点/纹理错误 | 从冻结批准源进行授权区域修复，检查边界与上下文 |
| 输入相互冲突 | 修正最终提示与参考职责，保留未受影响的有效约束 |
| 后期引入问题 | 返回对应后处理步骤，不重生原本正确的资产 |

全图组织失败且已授权新图生成时，从原始需求与批准参考重生；不要把失败候选不断当成下一轮风格源。若当前只授权局部修改，不扩大范围。采用主流程既有工具、重试预算和停止条件，不新增无限重试或自动换模型。

反复失败时核对真实提交文本、参考图是否持续提供相反细节倾向，以及生成后是否经锐化/放大等处理。不宣称已证明模型内部机制。将每轮有用改变整合成一份完整简洁提示，不积累相互矛盾的长排除清单。

## 验证方法的适用范围

Skill 语法验证只能证明文件格式，不证明画面改善。图像质量分数、边缘数量、锐度、哈希和文件存在性不能自动审批艺术质量。

实际跨场景验证应保留需求、参考职责、真正提交的输入、模型/参数中已知项、候选及逐项判断；条件允许时对比原版与修订版，并覆盖外景、普通室内、角色/物件及不同原生笔触。控制能控制的变量，记录未控制的随机性与上下文差异，不把一次漂亮结果当作普遍有效。

检查两条结果是否同时成立：碎细节减少且层级更清楚；风格、身份、结构与必要信息仍被保留。未经授权不为测试自行消耗生成额度或修改正式资产。
