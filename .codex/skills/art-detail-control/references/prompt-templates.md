# 提示组装

## 先分析，再编译

沿用主工具原生提示语法、图片职责、画幅和参数。填写画面内容、风格依据、镜头、光照、焦点/多交互区域、必须保留、可概括区域与具体表现。选择与当前画面有关的规则，不复制无关分支或不断叠加旧版本。

完整提示通常按“内容与镜头 → 批准风格 → 主次与具体刻画安排 → 适用空间分支 → 保持项和有限排除”组织；也可沿用主流程的有效顺序。风格名不替代参考证据；没有看过参考时注明依据仅为文字。

检查“全图极致细节/满幅颗粒/每处锐利”与概括要求冲突。未锁定且属于当前修改范围的词可改为局部要求；逐字锁定词给出最小修订建议，不自动替换。不要因为一个案例成功就添加通用模型参数。

## 通用核心（将括号替换成具体内容）

```text
创作【内容与镜头】，遵循【批准风格/参考职责】，光照为【来源与氛围】。

准确保留【身份、必要结构、可见信息及不可修改项】。主要刻画集中于【具体部位或必要可读区域】；【次要区域】保留【轮廓/体积/少量特征】，省略【明确可省略项】，用【具体归并方式】表达；【安静区域】保持连续的大色面和参考支持的材质。

以完整大形、成组明暗与连贯笔触组织画面。次级轮廓保留关键走势和识别转折，减少连续等尺度的小凸起与凹口。小形体共享整体明暗，不各自重复高光与暗部。重复元素形成有大小、疏密和间隔的组，不均匀铺满画面。

材质通过整体色泽、反光宽窄、边缘特性和少量代表性纹理体现。保留指定风格必要的笔触、颗粒和磨损，控制随机杂点、断裂纹理与重复伪影。通过省略、归并和选择性刻画形成主次，不用全局模糊、磨皮或压黑掩盖问题。
```

## 普通室内分支（按场景填好后并入完整提示）

```text
先建立墙、地、顶与主要家具的完整体块，保持透视、厚度、连接、遮挡、接触和投影。【具体墙面/柜面/桌面】作为连续低细节区域，用大明暗与少量材质线索表达。

【重复陈设】归并为几组有疏密变化的色块，仅展开【代表性/任务必要物件】，其余省略【内部细节】。同一区域物件共享光照，次要暗部适当合并，不逐物亮边、逐缝加黑。

通过遮挡、尺度、透视和光照分区建立层次。空气透视仅使用实际距离和环境支持的强度，不默认加雾、远墙褪色或背景失焦。必要空间、行动区域和任务信息保持可读。
```

## 外景/大空间分支

```text
依照【实际视距、天气与空气色】建立空间层次。近处选择性保留材质，中景保留主要结构，远景主动省略单个小物件和内部纹理，极远处以淡薄色形交代空间。远处受光面与阴影面共同向空气色靠拢，局部对比、内部边缘与轮廓转折逐渐减少。

【山体/树群/城市背景】先形成连续的大走势，保留【必要主峰/地标】，归并次级小轮廓。云雾若存在，以共同受光的大体积表现；小起伏从属于宽大亮暗面，不逐个形成亮圈。依据构图形成主群、弱呼应和完整间隔，保留自然形态，避免均匀碎块与满幅碎亮边。
```

## 局部编辑保持项

```text
只处理【授权对象与区域】中的【已观察到的问题】。以原图为结构、光照、笔触和纹理尺度依据，保留【具体必要细节】。修改区域与周围连续，区域外不重新解释或增加内容。概括不改变身份、承托、边界与既定构图。
```

用户需要可复用模板时可保留字段并说明用法；用户需要直接复制提交时必须填完，删除不适用段落与分析性说明。若需完整版本，重新整合整个提示，不只提供增补。不要声称仅靠提示能保证像素保持或稳定生图效果。
