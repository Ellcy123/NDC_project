# NDC 场景完整风格分析协议

当任务涉及场景风格参考分析、场景风格自检、生成结果风格比较或正式场景验收时，必须先看完整画面，再以原图无遗漏网格逐块复检；不得只看缩小整图或挑选少量“代表性局部”。

## 执行方法

1. 整图记录构图、空间层级、色彩、明暗、线条密度、材质分区和整体可读性。
2. 运行 `scripts/make_style_review_tiles.py`。默认局部块最大 720×720，重叠 72 像素；四块检查页固定为 1600×1600，清单必须证明每个源像素至少被一个块覆盖，且查看时不发生二次缩小。
3. 从左上到右下检查全部块，包括边缘、天空、纯墙面、地面、最暗暗部和最亮高光；4K/8K 不得以缩略预览代替。
4. 每块检查线宽与收笔、笔触方向和尺度、硬软边、颗粒/纸纹、材质差异、重复纹理、锐度不一致、拼接或生成瑕疵。
5. 局部检查后回到整图，判断观察属于整组稳定共性、特定场景/材质分支、少数样本特征，还是压缩与生成噪点。
6. 完全相同 SHA-256 的文件可只检查一次，但必须记录它们在不同 Skill 中承担的角色。

## 场景专用观察维度

- 建筑轮廓与室内构造线是否真的采用书法式粗细变化，还是只在主体边缘加统一黑边；
- 笔触是否按墙、木、石、金属、玻璃、天空、云雨和光束分别组织；
- 远中近景是否通过边缘硬度、对比度和细节频率分层，而不只是景深模糊；
- 光照是否以成组色块和图形化暗面构成，是否出现无结构空气刷渐变；
- 大面积平面是否保留受控数字绘画纹理，还是平滑 3D 材质或均匀噪声贴图；
- 边缘和留白是否存在可延展连续性、重复生成纹理或裁切接缝。

## 归纳与输出

将结论标为 `稳定共性`、`场景/材质分支共性`、`少数样本特征` 或 `异常噪点`。报告原图条目数、去重数、局部块数、覆盖状态、支持样本和反例；明确哪些判断区别于既有记录，哪些旧判断被削弱。正式通过必须同时记录 `whole_image_checked: true`（整图已检查）和 `local_tile_coverage_complete: true`（原图局部覆盖已完成）；覆盖未完成时只能给临时结论。
