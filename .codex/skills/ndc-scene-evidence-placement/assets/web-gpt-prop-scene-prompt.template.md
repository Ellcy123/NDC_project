# NDC 道具场景／容器／环境叙事：网页版 GPT 通用提示词

来源：ndc-scene-evidence-placement/assets/web-gpt-prop-scene-prompt.template.md
版本：2026-09-13；用户侧副本必须与本模板一致，只有【】可改。

此提示词只用于现行 NDC Skill 明确允许的网页例外：场景证据、容器二级菜单或环境叙事 Big。它不授权普通独立道具母版、普通 Big 或 Icon 使用网页生成；这些仍走各自现行 Skill 的指定生产路径。

请在未经修改的原场景／菜单基础上，完成唯一冻结的场景证据或容器／环境叙事画面：

- 场景／容器：【SCENE_OR_CONTAINER_ID】；revision：【REVISION】；目标角色：【scene_evidence_OR_container_menu_OR_environmental_narrative_big】。
- 物品／状态与取得语义：【ITEM_STATE_AND_ACQUISITION_FACTS】。
- 精确承托、落点、透视、遮挡、动线和可见关系：【FROZEN_PLACEMENT_AND_CARRIER_CONTRACT】。
- 若为环境叙事 Big，语义母图与场景派生关系：【SEMANTIC_MASTER_TO_SCENE_DERIVATION】。
- 若为容器，生成第一人称完整二级菜单画面；不要露出场景人物或人体，不把内容物半露在基础场景。
- 不要添加未经冻结的文字、人物、UI、玩法结论、物品、背景或叙事事实。不得改变机位、基础场景或已通过的上游 Big／母图。
- 保留与 NDC 既有场景一致的画风、透视、光照和像素层级；交付后会独立处理热区、Map、XY、Icon 与 Alpha。
