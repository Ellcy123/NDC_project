# 按遮挡层次分批生产角色层

白模顺序：初次生成时包括隐藏部位的完整人体，保留未裁剪母层；随后按真实遮挡关系裁剪派生层或制作蒙版，审核裁剪后的场景参考。正常裁剪不算缺失，不要求补回场景中本应被遮住的像素；小瑕疵容错不取消初始完整生成。正式角色同样先生成完整母层再应用遮挡。

白模阶段以 [白模放行与正式完整性](whitebox-acceptance.md) 为准：位置、比例、头身比、动作和演绎可准确判断时，小型遮挡、局部缺失和细节可放行，不为此强制补全、PS返修或再生成。下文完整母层要求在正式生产仍适用；白模只须提供足以判断核心目标的独立及联合参考。

用户 2026-09-07 明确调整：按远景到近景、图层由下往上分批生产；一批可有多名角色，不强制逐人生成。目的为获得可独立使用 Photoshop MCP 调整位置与尺度的角色层。该规则优先于旧文档中可能被理解为先生成一张全员合并图、再从遮挡片段提取角色的顺序。

## 分批先于生成

从同一时间线快照的真实遮挡关系建立顺序，不按角色名单、头顶或脚底的屏幕 Y 坐标机械排序。先明确完整角色母层，再明确源场景遮挡物与交互物所在层位。

- 同层或不存在相互遮挡依赖的多人可以同批生成，保留各自的支撑深度与比例，不将“同批”误解为同一距离或相同像素高度。
- 每个角色须能从该批结果中完整分离，保持独立的头、身体、手、腿、脚与角色归属物，不带其他角色或固定家具。批内发生遮挡且无法取得完整独立层时，只拆分冲突组，不把整个项目降为强制逐人生成。
- 先远后近生产与审查。已确认的下层作为注册与比例参考，不在后续批次重新生成。近景角色覆盖远景角色的最终效果只在组合图里表现，不能永久擦掉远景母层。
- 一个完整角色可由生成图中的独立区域分离为图层；不要求图像模型原生输出多层 PSD，也不能宣称一张含多人的平面图已经有独立图层。

## 完整母层与场景预览是不同用途

角色层以同一固定相机、支持深度、姿势与注册画布生成。可使用简单中性背景，明确每人颜色和完整轮廓；不要把会遮住腿脚的床、柜或其他人物烘焙进母层。直接输出透明仅在工具确实支持且 Alpha 实测有效时采用，否则按已批准图像流程分离，不能把棋盘格 RGB 当透明。

完整母层用于单独调整与人体核查；组合预览将这些相同母层、同一变换放回批准场景，重新叠加准确的源图遮挡物。最终不应可见的腿脚仍保留于未破坏的母层中，不为展示它们而改变场景镜头。固定家具像素仍来自原图，软被单等交互部分按最小授权组件处理。场景缺少支撑上下文时可保留单独支撑参考，不能以空白背景替代真实接触验证。

对于卧躺、倚靠等软物接触，人体与枕头/靠垫/被褥的受力关系应一起设计、生成或局部调整，交付仍保留完整人体母层与独立软物响应层。独立图层不等于可以独立破坏接触：头、颈、肩与枕头的承托，肩背与被褥起伏均在同一组合中检查。不要把需要压陷的原枕头当作固定结构冻结；床架、床栏等固定结构继续使用原像素。

局部孔洞、漏遮挡、残边先查选区与层序，再复用匹配的现有承托／被褥片。保留软物可用表面，让最终人体自然遮挡；不要把另一次生成的人体轮廓当成最终枕头／被褥的永久扣洞模板。需要补片时保留供体来源、原始层和当前完整母层，不能把拼合后的可见碎片当作完整角色。

## 整场生图先于抠图

远近批次只决定正式生图顺序，不允许把同一场景改成“生成一个角色，立即抠图去背景，再生成下一个角色”。每个角色／状态的网页结果回收后，先完成身份、动作、完整人体、服装、风格、来源与文件完整性的提取前审核，保存原始下载、来源回执与冻结 SHA-256，然后继续本场下一角色／状态。此时不得对任何正式角色执行 Remove Background、Select Subject、Alpha／蒙版、角色注册、接触合成或最终场景合成。

冻结 scope 中全部 `case / snapshot / actor_pose_id` 均已有通过提取前审核的生成结果，或已有当前规则允许的正式复用源后，建立全场生成冻结清单并登记 `SCENE_CAST_GENERATION_GATE: PASS`，再统一进入 PS 提取阶段。清单逐项绑定角色／状态、生成或复用来源、原始文件、回执、审核结论和 SHA-256；缺失、失败、待回收、结果未知或未冻结任一项都保持 FAIL。某角色受阻不妨碍继续生成本场其它角色，但阻断本场全部新提取；不同完整场景仍可独立推进。

旧任务已经产生的局部提取结果只读保留，不删除、不覆盖；若本场仍有角色／状态未完成生成，从当前节点起暂停新的提取，先补齐全场生成冻结门禁。参考白模和生图输入准备所需的已授权 PS 工作不属于本节所称正式角色抠图，不受误伤。

## PS MCP 调整与锁定

实际PS操作通过原生 MCP；本机同一时刻仅由一个任务操作，保存检查点且无在途或未知命令后才交棒。全场由同一任务统筹，以下批次不拆为不同任务按角色跨阶段推进；跨任务释放仅服务其他真正独立任务，不解除同场联合白模、遮挡、支撑或全场验收依赖。

给角色保留独立图层/蒙版及来源哈希；移动、统一缩放只作用于该角色和明确归属的组件。先确认真实支撑与姿势成立，再围绕脚底、坐骨或卧躺支撑点调整；远近深度变化时重算尺度，而不是只拖到一个好看的屏幕位置。每次调整后检查头身比、人体连续性、承托、相互接触与遮挡；人体与软物响应层联动更新，不能自动让已接触的两个人或人和枕头独立位移而断开接触。完整人体检查与最终遮挡预览使用同一变换。

用户显式锁定的坐标、尺度或姿势继续保留，不把这项纠偏能力视为任意修改锁定资产的授权。上述“调整后检查”在同一张图连续处理完成时合并执行，采用 [production-cadence.md](production-cadence.md) 的里程碑与证据复用规则，不把每次移动或保存拆成一轮全流程。

同任务按主流程完成当前图保存、技术和整图/局部真实视觉检查并核对hash，未审完不把该角色计入整场生成冻结清单；先完成全部角色／状态的提取前 PASS，再统一推进正式提取依赖。若 Photoshop MCP 已实际导出可打开但不完整或低置信度的非生成 RGBA，则在保留提取前原图、尝试件、恢复证据和缺陷后标记 `PROVISIONAL_EXTRACTION_PENDING_USER_REVIEW`，继续明确标记的 provisional 注册、遮挡、接触、合成、XY、重建与待用户审核包；同场正式前置及发布仍阻断。其它 FAIL 按共享规则只继续独立资产。安全保存可恢复文件和固定审阅快照后可交棒，当前未通过状态及依赖不变。全场生成门禁通过后，才按已确认层次进入提取、注册和合成；每个正式角色仍以自身身份卡和批准白模为约束，不能让同批身份串用。正式角色姿势和支撑已成立时，允许 PS 统一缩放或平移纠正注册/尺度偏差并更新相关合同；不得以任意变形补救解剖、朝向或动作语义错误。

## 白模阶段看得清什么，就检查什么

白模硬检查：可判断位置与动作的独立人体参考、头身尺度、主要动作轮廓、头部/躯干的大方向、可见手臂动作或自然休息状态、承重与支撑、实体接触、当前组合中的遮挡和 UI。动作符合剧情与全身是否僵硬分别判断：检查承重链和肩肘腕是否无故绷紧，不强迫每只手承担任务，不以全员错步、歪肩或大手势换取所谓自然。明显背向要求却变正面、面朝错误交互侧等结构偏差仍需修正。

眼球视线的小角度、细微神态及白模分辨率/材质无法清楚表达的差别是观察项，不作为白模硬门禁。记录其目标与 deferred-to-character-stage，不写虚假的 PASS，不用它单独否决白模或触发再生成。在 ndc-stage-visual-self-check/v1 中标为 applicable:false 并注明负责的正式角色检查阶段；在整体 posePerformance 中仅判断白模可辨识的大方向和动作。正式角色和最终图的可见视线/表情仍按剧情、镜头及最终门禁核验。

## 预算与失败范围

生成前写明批次 ID、包含角色、完整母层范围和组成顺序。每个预先声明的批次最多三次有效生成及三轮可行的 PS 修复；白模阶段的首个可用候选出现可修缺陷即可按 [PS优先修复](ps-first-repair.md) 转 PS，不必先用满生成次数。正式角色阶段先完成整场生成冻结门禁，之后才执行本场各角色的 PS 修复／提取；某层失败只返修该层，不重画已通过下层。必须保留全任务总提交次数、每批重试数和工具失败数。无返回图像的工具拦截单列，不能谎称已得到白模或已完成艺术检查。不得通过重命名同一失败批次无限刷新预算；真实新对话任务开始时自动，按 production-cadence.md 另立计数并保留来源关系；旧测试计数保留于历史，不扣减或同步进新测试。仅换目录、日期、批次名或普通续作仍累计原次数。
