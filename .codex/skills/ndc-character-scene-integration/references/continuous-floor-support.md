# 连续地面与固定支撑线

先识别支撑依据，再选择检测方式。单幅图中，连续地面没有对所有横坐标唯一的落脚高度；两个前后错步的脚也不必位于同一深度截线。不要把自拟站位线的偏差自动命名为物理浮空，也不要用当前脚点反画一条“独立”线求通过。

先从空场景确认可站立空间及脚点深度，再推定这个深度的人体尺度。暂定消失点、家具尺寸和地面投影可作为待验证假设；多个数值共用这些假设时，彼此接近不增加独立可信度。记录其不确定性，并以实际家具落地关系、透视和全场观感复核；不能把数值自洽当成可靠支撑。

本页的支撑记录并入 [production-cadence.md](production-cadence.md) 的相应里程碑；同图连续技术操作完成后统一审核，不因每次保存、复制或参数派生重跑全图流程。

- 固定床面/椅面、可辨识台阶或有有效外部依据的落脚线：沿用原 `fixed-support-line`（缺省）检查及原容差。卧躺仍须床面、枕头、床尾和完整人体包络；本分支不改变它们。
- 连续平地：可用 `continuous-floor-region`，但必须同时通过独立场景/深度地面区域、当前足底观测和实际物理视觉审核。区域覆盖只证明脚点落在允许地面投影范围，**不声称测出了悬空或下陷的像素数**。完整人体、体重与鞋底接触、地面透视、结构余量、遮挡和环境响应均不可省略。
- 原生角色/白模的前后鞋必须分别辨认，不能把同一只鞋的鞋尖和鞋跟填成左右脚。自身遮挡的不可见关节不得虚构精确测量；完整母层、已锁定姿势与可见接触证据仍须共同支持判断。
- 在正式图阶段，实际接触阴影仍归入必检项；白模阶段仅审核该材质与分辨率能可靠体现的结构。不能用白模对细节不可见的说明豁免明显离地、穿插、悬空被褥或错误承重。
- 被床、柜或前景人物挡住腿脚时，使用同一完整母层和同一变换切换“无遮挡人体”与“最终遮挡”查看：前者检查足底、腿、骨盆与地面，后者检查可见身体与家具的空间关系。只切换遮挡可见性，不暗中改变尺度或位移。两种观察合并进既有支撑审核；最终看不到脚，不代表支撑可以免检。

## 地板透视与隐藏足点的最小核验

1. 在原分辨率空场景记录可见地板缝、床架或建筑线段的端点，按实际世界方向分组，回画到原图检查；曲线、阴影、纹理边不冒充平行结构。区分直接观测、依据结构推断和暂定尺寸。
2. 同一方向的多条线只能支持一个消失点。地平线需要第二个独立的地面方向，或有依据的相机姿态／垂直方向约束。采用水平地平线假设时说明依据与有效范围；不能把一个消失点的 y 坐标直接称为已精确求出的地平线。重采样线段估计的稳定性也不是绝对相机精度。
3. 被家具挡住的足点先依据家具落地、可通行空间和远近关系给出合理范围，不先选头顶再倒推脚点。记录仍不可见的地面，不把遮挡图当实际看到了脚。
4. 对会改变站位决策的地平线／足点／家具实际尺寸，比较合理上下界的尺度结果与完整人物场景对照。差异足以改变支撑、头部关系或UI可读性时，先补几何依据，或选取同剧情功能且地面更明确的位置。没有唯一解时保留范围，不能制造单像素精度。
5. 在同平地、直立人物且水平地平线近似成立的情况下，h_target / h_ref 约为 (H_target / H_ref) × (y_target - y_horizon) / (y_ref - y_horizon)。它只用于该假设内的敏感性比较；不适用于斜地面、不同支撑平面或未经方向校正的横向物体。假设不足时不用此式输出精确站高。
6. 选定候选后，从原始完整人体层直接进行所需变换；保留完整／遮挡同源对照。缩放改善观感不自动证明隐藏足点和绝对尺度通过。

单视图度量的几何前提参考 [Oxford VGG: Single View Metrology](https://www.robots.ox.ac.uk/~vgg/publications/2000/Criminisi00a/)。数值工具检查输入与运算；场景依据和接触仍需真实视觉判断。

## 合同

在 supportSurfaces 中，仅对确属连续平地的项设置：

```json
{
  "id": "floor-front",
  "referenceKind": "continuous-floor-region",
  "planeType": "floor",
  "evidence": "具体场景与地面关系的说明",
  "occupancy": {"status": "clear", "evidence": "通道无实体障碍的依据"},
  "contacts": [{"regions": ["leftFoot", "rightFoot"]}],
  "supportPolygon": [[0, 600], [1000, 600], [1000, 1000], [0, 1000]],
  "geometryEvidence": {
    "basis": "fixed-scene-and-depth",
    "derivedFromActorJoints": false,
    "method": "由原场景墙脚、家具落地关系和已审核深度图确定；遮挡内区域写明推断边界",
    "sourceScene": {"path": "scene.png", "sha256": "..."},
    "depthReference": {"path": "depth.png", "sha256": "..."}
  }
}
```

示例坐标不是任何项目的默认站位。区域必须依据本场原图与深度独立确定，排除墙体、立柱和不可占用家具；无法可靠判断的关键区域仍阻断，不能把整个画布当成地面。

placement.target 新增两个带path/sha256的引用：`supportVisualReview` 与 `supportReviewArtifact`。前者沿用 `ndc-stage-visual-self-check/v1`，后者为实际检查的当前白模或正式图。视觉记录除原必需项外包含：

- `poseSha256`：当前整个pose对象的规范化JSON哈希；
- `supportSurfaceSha256`：按surface id索引的当前支撑surface规范化哈希；
- `reviewedContacts`：实际查阅的左右足点；
- 必检criteria：`weightAndSoleContact`、`floorDepthAndPerspective`、`structuralClearance`、`environmentResponse`，均须applicable:true、PASS及具体finding。

规范化哈希使用 `floor_support_review.digest`。哈希只能绑定审阅内容，不能制造视觉通过。必须先看原图与当前全图/200%局部，记录观察，再绑定哈希并运行原 `validate-support-contact`；之后仍运行项目阶段视觉记录验证器及完整生产台账。输入图、姿势、脚点、地面区域或输出图变化均使旧审阅失效。

报告保留原schema，在连续地面项明确 `referenceKind`，`expectedSupportY`、`verticalDeltaPx`和`tolerancePx`为null；`condition`报告区域覆盖结果。只有区域与当前视觉证据都通过，支撑报告才可pass。缺失、失败、过期或不适用的物理审核拒绝放行。旧固定线失败报告保留为历史，不能覆盖成新模式的结果。

实现复用项目原有点在多边形内部检测，并增加边界覆盖。调研参考：Shapely covers的几何含义是覆盖区域与边界，不等同于物理支撑证明：[官方实现与说明](https://github.com/shapely/shapely/blob/main/docs/manual.rst)。不引入新依赖。
