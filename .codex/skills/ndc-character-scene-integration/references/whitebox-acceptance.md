# 白模放行与正式角色完整性

2026-09-09 用户明确调整并补充：白模首次生成时隐藏部位也要完整，随后按真实遮挡关系裁剪。本规则优先于旧文档中要求裁剪后重新补出全部隐藏部位、每处小缺失均修复后才能放行的表述；不免除初始完整生成，也不降低正式角色完整性要求。

- 顺序固定为：首次生成完整白模 → 保留未裁剪母层 → 按场景遮挡关系制作裁剪层/蒙版 → 检查裁剪后的场景参考。裁剪可以实际删除派生副本的被遮挡像素，也可用蒙版隐藏；原始完整白模保持可恢复。完整母层与裁剪结果使用同一姿势、位置和变换。
- 初始白模须包含头至脚及隐藏身体；不能把本规则解释为允许初次只生成可见身体碎片。后续按遮挡关系裁去的部位属于正常处理，不是待修复缺陷，不要求在最终场景预览重新显示。正式生图同时明确完整母层职责和遮挡参考职责，生成完整角色后再按场景关系裁剪/遮挡。

- 白模主要控制角色位置、场景比例、头身比、动作与演绎。支撑、主要身体方向、多人关系和关键动作可读性用于判断这些目标是否成立。
- 小型遮挡、局部缺失、边缘小瑕疵和细节不精确，在不影响上述判断时可直接放行。不为这些问题单独启动 PS 修复、再次生图或退回参考阶段；不要求先补出每一处隐藏身体像素。
- 不能仅凭缺失面积小就放行：若它使位置、比例、头身比、动作或演绎无法判断，或遮住决定动作含义的关键手势/接触，则仍需解决影响判断的部分。无需修复无关细节。
- 保留各角色初始完整母层、按遮挡裁剪的独立参考及同源联合快照。裁剪参考允许正确遮挡及上述小瑕疵；“完整场景包”表示角色、状态、母层来源与检查范围齐全，不表示裁剪后的画面仍展示全部身体。不得把正常裁剪夸大为缺失，也不得用无完整来源的大段残片替代初始白模。
- 真实检查当前白模，记录小缺失的位置、为何不影响核心判断，以及交给正式生图补全的要求。核心项通过时可给白模 PASS；不虚称白模解剖像素完整。仅对不属于白模门禁的细节使用现有观察项或 applicable:false，注明 deferred-to-character-stage，不将位置、比例、头身比、动作、演绎标为不适用。旧 FAIL 保留历史，按新规则实际复核后追加当前结论。
- 正式生图输入明确区分参考职责：白模约束位置、比例、头身比、动作与演绎；小缺失或遮挡不是断肢、裁切或缺损设计。提示词必须要求在同一姿势、相机与尺度下生成头至脚完整角色，补全白模缺失/被挡部位，留出足够画布，不把前景遮挡烘焙进唯一角色母层。
- 正式结果须实际核验完整人体和独立可用母层，尤其检查交接列出的缺失处；提示词写了“完整”不等于生成已完整。场景遮挡放回组合预览，正式完整性不通过时在生产阶段按既有流程处理，不能把白模细节豁免带入最终交付。
