- 顺序固定为：首次生成完整白模 → 保留未裁剪母层 → 按场景遮挡关系制作裁剪层/蒙版 → 检查裁剪后的场景参考。裁剪可以实际删除派生副本的被遮挡像素，也可用蒙版隐藏；原始完整白模保持可恢复。完整母层与裁剪结果使用同一姿势、位置和变换。
- 初始白模须包含头至脚及隐藏身体；不能把本规则解释为允许初次只生成可见身体碎片。后续按遮挡关系裁去的部位属于正常处理，不是待修复缺陷，不要求在最终场景预览重新显示。正式生图同时明确完整母层职责和遮挡参考职责，生成完整角色后再按场景关系裁剪/遮挡。

- 白模硬判定只控制角色/状态、头身比、动作大类、主要身体朝向、承托类型、粗略景深，以及足以证明头到脚完整母版范围的画布。多人关系和关键动作可读性用于判断这些目标是否成立；精确表情、手指、衣纹、边缘和最终像素位置留给正式阶段。
- 小型遮挡、局部缺失、边缘小瑕疵和细节不精确，在不影响上述判断时可直接放行。不为这些问题单独启动 PS 修复、再次生图或退回参考阶段；不要求先补出每一处隐藏身体像素。
- Halo、matte edge、衣纹、手指、面部精修、小型局部遗漏、精确 XY 或精确最终尺寸均不能单独触发再生成。可在正确承托锚点上以统一平移、等比缩放和必要旋转修正白模并重跑受影响检查；不得非等比拉伸或扭曲错误姿势。
- 不能仅凭缺失面积小就放行：若它使头身比、动作大类、主要朝向、承托、粗略深度或完整母版范围无法判断，或遮住决定动作含义的关键手势/接触，则仍需解决影响判断的部分。只有动作前提、主朝向、承托类型、粗略深度错误或解剖不可用才返回生成；无需修复无关细节。
- 保留各角色初始完整母层、按遮挡裁剪的独立参考及同源联合快照。裁剪参考允许正确遮挡及上述小瑕疵；“完整场景包”表示角色、状态、母层来源与检查范围齐全，不表示裁剪后的画面仍展示全部身体。不得把正常裁剪夸大为缺失，也不得用无完整来源的大段残片替代初始白模。
