# 场景：镜头、空间与状态

## 描述设计

先确定本次资产是新场景、既有场景状态变化还是局部编辑；沿用主 Skill 的机位、空场景范围、允许物件、画幅与修改边界。本 Skill 不自行重选镜头或增加可交互内容。

按需要交代：
- 镜头所在位置、朝向、视高、可见墙面/入口及画面边界；
- 前中后景的大体积关系、通道与家具依附关系；
- 当前可见状态，如门关闭、床铺空置、墙面完好；
- 可见光源或有来源依据的受光方向、阴影及材质表现；
- 只在当前画面内成立的必要环境细节。

## 剧情信息转译

“凶手刚逃走”“这间屋子隐藏秘密”“这里见证了一场背叛”本身没有唯一视觉答案。保留为上下文；依据已有美术/剧情事实选取可见状态。没有证据时，不自行加入血迹、脚印、破门、凶器或关键纸张。

“刚发生争执”与“家具倒地、杯子打碎”不是自动等价。若后两者有明确来源，则直接描述倒下家具的朝向、破碎物所在表面；若没有，则报告该剧情未提供可见痕迹，必要时提出可选择的视觉方案。

“压抑、安静、危险”等氛围可作为简短辅助说明，但需要当前授权的构图、空旷程度、色调、光照或表面状态承载。已锁定画风/光照时，不能借氛围提示改成另一套风格或昼夜。

## 典型冲突

- 固定门口视点却要求看到墙后房间、桌背铭牌或柜内文件；
- 空场景却保留“侦探站在窗边凝视”等人物动作；
- 远景全房间却要求小纸条文字像特写一样完整清楚；
- 保持房间身份却为表现剧情重新摆墙、移门或移动固定家具；
- 一个单帧同时表现事件前、发生中和事件后，未指定多格/多状态。

按主 Skill 的空间与资产范围消解：延后道具就从当前正向提示中排除；独立状态就在分别的画面描述中表达。用户要求本身冲突时保留两项及依据，交回主流程决定，不静默改变。

## 检查点

镜头能否同时看见所要求的面？通道与支撑是否合理？场景状态是否只对应当前一帧？有没有模型为了讲故事添加的无依据人物/证物？参考图是否被误用为布局权威？已批准画面允许的遮挡无需因“信息完整”而消除。
