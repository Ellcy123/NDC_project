# 生产介入设计

## 目标与边界

把错误尽量挡在第一次生成之前，并让每次重试有可解释的修正目标。提示词只能提高控制概率，不能保证精确姿势/几何；精确性仍依赖合适的结构参考、实际工具能力和主流程验收。不要宣称文字检查能证明图片正确。

不在用户刚说出剧情时就机械删除故事，也不等生图失败多轮才检查语言。先由主流程保留事实、解析资产用途、确定来源权威，再做视觉设计；图像模型提交之前再检查实际输入是否忠实执行了设计。

## 检查点 A：视觉设计先于布局和白模

输入是当前事实与用途、批准参考及主流程硬约束。产出一份轻量“本帧可见意图”，可直接放在主流程现有记录：

- 本帧对象、状态与镜头；
- 必须可见的动作/面/空间关系及来源；
- 合理不可见内容与另需取得的独立证据；
- 允许变化、必须保持、仍有冲突的项；
- 供后续坐标/白模/提示组织使用的观察条件。

角色站位坐标应从已经一致的机位、表演与支撑方案推导；场景布局应能从镜头看见要求的区域；道具摆位应让实际需要的物理面自然可见。不要先随意画两个脚点，再以“必须对齐”为理由改写动作。

这不是取消主流程的尺度/坐标门禁。用户锁定的坐标、引擎硬约束、来源几何仍保留；与新意图冲突时必须定位并解决，不静默放宽。

## 检查点 B：审查真正提交给模型的整体输入

主流程完成最终提示拼装后，检查以下实际存在的内容：

1. 最终正向提示中的朝向、动作、可见部位、状态是否一致；剧情原文是否被意外重新拼入；每一个必需画面要求是否仍被表达，防止过度删减。
2. 图片的真实内容、排列顺序和职责是否与文字一致。身份/风格参考不自动成为机位或动作权威；主流程有固定参考顺序则沿用它，不额外创造另一套顺序。
3. 局部裁切是否容纳动作与必要接触；镜头关系是否仍可理解；背景保持项及蒙版是否保护了固定家具/实体边界。需要改裁切/范围时交主流程执行，不自行扩权。
4. 负向约束及工具参数是否与正向目标冲突；保留主流程专门语法和画幅规则，不伪造通用姿态锁参数。不要用一串被禁止的表情细节替代明确背影视角。
5. 验收项是否由同一意图和有效来源导出，是否误把自拟构图点或不可见内容升成硬门槛。

已有来源明确的锁定文本不能直接改写；输出差异让主流程按原权限处理。当前用户明确要求新姿态等变更时，按其实际授权范围更新，不能因“过去曾锁定”而多问一次无必要的确认。

主流程提交的文本/参考/裁切如果与检查版本发生实质变化，检查相应变化后再提交。已有 prompt 文件/manifest 则沿用其路径、版本/哈希；简单单图可直接检查即将提交的文本，不强制另造版本系统。

## 不同生产类型的插入位置

| 生产链 | 检查点 A | 检查点 B | 出图后重点 |
| --- | --- | --- | --- |
| 场景提示与 MJ | 需求/空间来源解析后，机位与布局方案定稿前 | 原生 MJ handoff 的提示、参考、画幅组装后；执行端沿用已检查版本 | 是否为“讲故事”新增人物/证物，是否为显示隐藏内容改变空间 |
| 道具与证据 | 来源、用途、闭/开/详情状态明确后，承托与摆位定稿前 | 场景局部/Big/Type7 各自提示与参考、裁切就绪后 | 可见面、承托、透视、信息量；不得用详情可读性要求场景 Map |
| 新角色/角色卡 | 身份和用途明确后，每个视图动作/朝向定稿前 | 每个视图或面板提示、身份/风格参考组装后 | 是否为表现脸/服装转身；多视图要求是否串到同一面板 |
| 人物入景 | 引擎时间线、场景身份、实际 UI 等上游事实明确后，联合白模与站位合同定稿前 | 白模生成输入提交前；白模通过后的局部角色替换提示组装后，各检查一次对应输入 | 朝向/动作、支撑、联合遮挡、同源完整人体证据；合理遮挡不等于证据豁免 |
| 表情/UI 肖像 | 确认需新生成及当前肖像视角/裁切后，表情/动作定稿前 | 该表情/母图的最终提示与参考就绪后 | 可见面部变化是否符合任务，身份与锁定光照是否保持 |
| 坐标锁定局部编辑 | 修改对象及授权区域确定后，局部变化方案前 | 最终局部提示、蒙版与裁切就绪后 | 编辑目标是否改变不可见面/构图；零漂移继续由主流程检查 |

同一素材的链条不重复把 A 当成新创作。例如场景提示 Skill 已完成 A，MJ 执行 Skill 只需确认 handoff 仍对应原意图及 B 的实际输入，不能另起一套视觉方案。

## 偏差诊断与下一步

| 证据指向 | 应做什么 | 不应做什么 |
| --- | --- | --- |
| 意图与机位/状态互相矛盾 | 回到 A，保留事实与硬约束，解决视觉方案 | 一次又一次强化冲突的两端 |
| 意图正确，最终词句或参考引入冲突 | 回到 B，最小修订对应词句/参考职责 | 把模型输出当作唯一故障来源 |
| 输入一致，但模型偏离明确目标 | 复用主流程的定向重试；可用时加强同机位结构参考 | 保证提示词必然精确执行；擅自增加生成预算 |
| 生成正确，后期裁切/变换造成偏差 | 返回相应后处理阶段 | 重新生成整个资产或修改剧情 |
| 验收采用无来源或不适用的假设 | 更正验收依据并留痕，重核相关合同 | 把候选自动转正，抹去其他实际缺陷或历史报告 |
| 缺失人体/内部等独立证据 | 按主流程补足所需证据/组件 | 为让它在最终图可见而改变镜头，或直接写 PASS |

重试由主流程计数。一次仅改变能够定位的问题变量；语义冲突解决后依然需要技术与视觉检查。没有实际审阅原始提交输入时，只能把冲突当成待核对的原因，不能断言已经证明是模型转身的唯一原因。
