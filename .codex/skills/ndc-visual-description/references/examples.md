# 正反案例

这些案例用于理解判断方式，不是每次生成都应追加的要求。

## 角色：Emma 背影问候

需求：Emma 背对镜头，向床上人物问候。
冲突稿：背对镜头，露出温柔微笑，双眼关切地看着病人。
修订稿：Emma 背对镜头站在床旁，头部朝向床上人物，肩背略向床边倾，一侧手臂轻抬作问候。
解释：用背部和手臂承载问候；不要求直接可见的眼睛和嘴部，也不自行让她回头。具体手势若没有来源，作为可调整的表现方案。
验收：背面朝向成立；动作对象清楚；不因未露正脸而拒收。

## 角色：侧视陪护与脚距

需求：侧面可见的静止陪护，稳定站立。
错误验收：没有在画面横向分开150像素，因此姿势失败。
修正：若150像素仅为自拟占位，先检查其是否与侧视投影相容；检查足底支撑与承重，不强迫画面横向展开。若150像素来自明确锁定的工程或用户要求，保留冲突并请求解决，不能自行删去。

## 场景：固定机位的“可疑办公室”

需求：从门口看向办公桌，空场景；故事说此处藏有犯罪秘密。
冲突稿：画出桌背面的秘密铭牌、抽屉内的证据，侦探紧张地寻找线索。
修订方向：保留门口机位和原有桌柜、可见通道、表面与光照；未获准出镜的角色、隐藏内容及新证据不加入正向画面描述。犯罪秘密保留为上下文，不自行设计污渍/破坏来“说明”它。

## 道具：封闭戒指盒

需求：桌上的闭合木盒，内装戒指；本帧只显示关闭状态。
冲突稿：闭合不透明木盒，清楚展示盒内刻字戒指。
修订稿：桌面上的闭合木盒，按镜头展示顶面、侧面与金属锁扣，盒底与桌面接触；表面特征沿用批准参考。
解释：内部戒指留在状态说明；获准的打开详情另行描述，不改为透明盒，也不自动掀盖。

## 保留例外，避免过度删词

- 正面表情头像需要微笑、眉眼状态：保留可见面部要求。
- 用户明确要求背影在镜中露脸：分别描述实体背面与镜中脸，不把镜面作为未经授权的补救。
- 玩法依赖报纸上的某行文字：保留有来源的准确文字与可用尺度，不因它包含剧情就删除。
- 主 Skill 要求遮挡后的完整人体证据：本帧遮挡合理也不能豁免独立证据；不为了显露证据移动床或改变镜头。
- 已批准逐字提示存在“背影+可见微笑”冲突：只输出修订建议与冲突记录，原锁定文本保持不动。
