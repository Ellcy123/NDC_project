# 角色：朝向、可见表演与投影

## 描述设计

先确定全身/半身/头像、背面/侧面/正面、镜头视点和人物朝向，再选择可见的身体描述。以“靠床的一侧”“靠镜头的一侧”“朝门的一侧”等场景关系减少左右混淆；解剖左右确实重要时明确“角色自身左/右”，不要与画面左右混用。

按当前任务选用以下信息，不要求每张图填满：
- 主要动作与静止/运动状态；
- 胸口、骨盆、头部各自朝向及是否允许转头；
- 承重方式、脚与地面的接触、双脚前后/横向关系；
- 躯干从何处倾斜、肩背状态；
- 可见手的动作、接触对象或自然休息状态，不要求每只手都有任务；
- 可见脸部表情或视线目标；
- 合理遮挡与必要的独立完整身体证据。

## 视角决定表达载体

| 视角/用途 | 可优先描述 | 需避免的冲突 |
| --- | --- | --- |
| 纯背面，脸不入画 | 后脑朝向、肩背、手臂、与交互对象的距离 | 同时要求看清眼神、微笑、眉头或脸部轮廓 |
| 侧面/斜侧面 | 可见侧脸、头与躯干关系、近远肢体和接触 | 自动转成正面以展示双眼/两侧服装；强迫双腿横向展开 |
| 正面肖像/表情 | 可见眼睑、眉、嘴角、脸部肌肉及批准身份 | 因“避免剧情式描述”而删掉表情资产的核心要求 |
| 多视图角色卡 | 每个面板独立规定朝向与可见部位 | 把所有视图要求混成一个人物同时满足的句子 |

反射、回头或特殊镜头只有任务明确需要时才可作为例外：如果已要求背面人物同时在镜中露出脸，应分清背影实体和镜中像的观察方向与表情。不得为了补足表情自行增加镜子或转头。

## 情绪与动作

把“关切地问候”落实为当前视角能看到的微前倾、停顿或轻抬手臂；不要自动加出镜脸部。“一手捂腹 + 弯腰 + 低头”可能读成腹痛，应核对是否符合意图；无剧情依据时，不把病态解释当作必需动作。动作建议注明来源或作为可调整的设计选择。

全身重心和足底接触属于需要检查的物理关系；文本“自然、稳定”不能替代检查。侧视时脚可能重叠，不能把它直接判成并脚或双腿缺失。若剧情要求某只脚迈出或某只手接触人/物，保留具体动作；若只是自拟占位点，先判断本镜头是否需要那种展开。

**动作符合剧情与身体自然度分别判断。** 从脚或家具承重点看骨盆、躯干、肩、肘、腕的连贯关系；避免各关节只为满足坐标而摆放，也避免肩臂和手指同时无故绷紧。安静不等于僵直，自然下垂的手臂或放松的手可以成立；不能强求每只手都握物、握腕、贴腹或悬停，也不能机械地给全员加错步、歪肩、扭腰和大手势。

多人画面先用完整预演检查“谁在说明、谁在听、谁在观察、谁在休息”等实际可见区别。全员低头、双手收拢或整齐叠放可能产生仪式或哀悼意味，须按本段剧情判断，不能靠给每个人追加“自然、关切”来修复。角色动作建议是可调整的设计，不能从一次病房案例推导所有场景都禁止某种手势。

## 支撑与软物交互

人物位置先依据空场景中的可用空间和真实支撑深度，再确定该深度的尺度。脚点在允许地面区域内只证明投影覆盖；多个数值共用暂定透视或家具尺寸也只证明自洽，不证明落地。将不确定性反馈主 Skill，用真实家具关系与全场图判断，不能从描述辅助 Skill 声称推得精确三维位置。

卧躺时把后脑、颈、肩与枕头/被褥写成一个接触整体：后脑在哪处被承托、颈肩如何放松、软物在哪处压陷包覆、邻近布料如何随身体起伏。不能只写“头在枕头上”，也不能用接触阴影掩盖错误头颈结构。人体保持独立完整母层，受力软物另存最小交互层；它们可分层编辑，但变换后必须一起重新检查接触。床架、床栏等固定结构仍保留原像素，原枕头若没有所需受力状态则不能冻结复用。

## 参考与验收

角色融入场景采用分层批次时，先区分“完整角色母层”与“最终带遮挡组合”：母层保留完整身体供 PS 单独调整，组合才应用前景家具/人物遮挡；两种检查使用同一母层、同一变换，只切换遮挡可见性，既看完整足腿骨盆，也看最终上半身与家具的关系。同批允许多人，但不可相互盖掉唯一完整身体。白模中不能可靠辨认的眼球小角度、细微表情只作观察并移交正式角色阶段，不升为白模硬失败；明显的头/躯干反向、僵硬的主要动作轮廓或承重错误仍可在白模阶段判定。此处跟随主 Skill 的用户批准分层流程，不修改最终角色的可见视线要求。

身份卡只约束适用的身份、服装和比例；姿势图约束动作与机位。既有头像/表情的锁定光照、裁切和像素继承仍由对应主 Skill 决定，不用本 Skill 扩大修改范围。

本帧要求看不到脸时，“脸部不可辨识”不是失败；人物身份可通过批准的后脑发型、衣着和体型继承。上游全脸身份锚的要求仍保留在其自己的资产/证据阶段，不混成本帧展示条件。若主 Skill 已要求同姿态完整人体白模，遮挡部位仍须有独立证据。

验收描述写成“背部朝镜头，面部未直接入画；手臂动作与床上人物发生关系”等可观察条件，避免仅写“问候正确”“神态合理”。
