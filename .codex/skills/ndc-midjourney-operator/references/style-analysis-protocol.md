# NDC 场景出图完整风格复检

正式判断场景风格前，先检查完整候选，再对候选原图进行无遗漏分块复检。使用 `ndc-scene-to-mj-prompt/scripts/make_style_review_tiles.py`，默认最大 720×720、重叠 72 像素，四块检查页固定为 1600×1600；清单必须证明每个源像素都被覆盖，且查看时不发生二次缩小。4K/8K 整图预览不能替代局部检查。

逐块检查建筑与物件线宽、起收笔、笔触方向和尺度、硬软边、图形化暗面、材质差异、颗粒/纸纹、重复纹理、局部锐化或模糊、生成粘连与边缘接缝。天空、墙面、地面、暗部、高光和左右延展边缘均不得跳过。

局部结论必须返回整图复核，并标为 `稳定共性`、`场景/材质分支共性`、`少数样本特征` 或 `异常噪点`。正式候选只有在 `whole_image_checked: true`（整图已检查）和 `local_tile_coverage_complete: true`（原图局部覆盖已完成）同时成立时才能通过风格项；否则只能标记为临时或待复检。
