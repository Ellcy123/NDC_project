## 横向视觉总结

13张示例均保留暗暖棕/炭黑的场景背景；人物以块面明暗、结构转折和成组暗部呈现，皮肤非现代照片质感，背景明显弱化，脸部占主要视觉面积。服装、发型、种族、性别、年龄各不相同：不能从风格参考或某一示例复制这些身份特征。

big 显示更多肩颈与背景，small 对脸部裁切更紧。Frank 的帽子、其他高发型存在顶部截断，支持正文的允许超框说明。示例背景不同，不应把同一房间作为跨角色通用背景。部分历史表情和精确对齐存在差异；示例用于横向比较，不覆盖本轮原文的中性正视和辅助线要求，也不触发对旧资产的擅自重制。

## 明文要求与工程解释

- **明确要求**：上游角色卡+通用肖像；三图顺序；身体15°/头正面/中性直视；职业背景；3:4完整胸像母图；从同母图分别裁切缩放位移；big/small分目录；222×240及106×120；按眼睛下巴线对齐；帽发允许超框。
- **测量值**：辅助线颜色行区间与中点见 `profiles-and-tools.md`。左上0坐标；中点可为半像素，不能当成原文手写数值。
- **工程默认**：PNG/RGB来自全部现有样本；`<stem>_big/small`来自现有命名；单次缩采样、禁止放大、输出不覆盖和哈希绑定用于质量与来源保护。若未来有明确的新规格则单独记为新任务合同，不能更改旧样本。
- **冲突处理**：职业背景优先于风格段白底尾词；画风参考不继承其侧脸；母图完整肩膀和最终紧裁切不冲突；UI独立生成不修改通用肖像“不补肩”规则。
- **未作推断**：Unit1未提供small、Unit2未提供big不等于这些角色缺资产，也不构成当前任务的补产清单；本次只整理Skill，没有调用生成模型。
