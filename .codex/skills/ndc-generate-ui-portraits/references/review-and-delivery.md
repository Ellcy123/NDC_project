# 自检、返工与交付

## 分阶段检查

| 阶段 | 必检项目 | 失败处理 |
|---|---|---|
| 历史复用前置 | 检索早于目标章节的同角色UI；记录来源章节、身份依据、两版路径/hash及复用或新制作决定 | 未查先查；占位图不算本人资产；缺版先补查配套，不自动整对重制 |
| U0来源 | 人物映射、批准依据、身份链、三图次序、策划职业证据 | 补齐/澄清上游；不生成 |
| U1母图 | 同人身份，年龄/服装/配饰；身转15°且头正面；中性直视；完整肩臂/轮廓；3:4；职业场景成立；人物插画和背景照片风格分离 | 从冻结三图修改失败项重生 |
| U1画风与纹理 | 块面、线重、暗部、低饱和棕黑、原生笔触；脸/头发/衣物纹理连续，背景安静；无散乱噪点或新高光 | 局部或整体按责任源返工，不能抹平或锐化遮掩 |
| U2每版 | 尺寸/RGB/PNG；同母图hash；独立裁切；无上采样/越界；无拉伸、锐化或补边 | 重新标注或从母图重裁 |
| U3每版 | 原尺寸认得出同一人；中性正视；实际眼/下巴对线；头顶软参考正确处理；与同Profile实例横向一致；无导线、字样、黑边或接缝 | 技术错返U2；艺术错返U1 |
| U3完整交付 | 每个要求角色有big和small；分目录；文件名映射；每步真实视觉记录当前hash有效；主图可追溯 | 缺项保留过程件，不能只报告总PASS |

不得用“同样年轻、同样胡须、同样西服”代替身份通过；逐项比脸型、双眼、鼻、口、颌线、发际线。不得从纯黑帽檐阴影推断缺脸，也不得因“小图仍能看出是人”忽略具体人物漂移。现有示例是横向风格参照，不能成为新脸部身份源。

## 记录与门禁

`REUSE_EXISTING` 分支跳过新生成的 U1/U2 及其母图纹理门禁，不补造历史执行记录。对本次复用核验／复制单独记录实际来源、身份、PNG规格、当前hash和已查看结果；字节相同副本以复制前后hash证明沿用。下文 U1/U2 与母图检查适用于本次新制作分支，最终包同时列清复用与新制作的各角色及缺项。

每个实际输出对应一份 `ndc-stage-visual-self-check/v1` 记录，含：`stage_id`、实际 `reviewer/reviewed_at`、输入文件引用数组、单个输出路径/SHA-256、`required_criteria`、每项 `status/finding`、`visual_check_status`、整图 `whole_100` 和 `local_200_or_tiles` 的文件/坐标/缩放/哈希证据。失败写明责任阶段，技术脚本不准填视觉PASS。

对全部生成图还需独立的 `STYLE_LOCK_GATE`、`TEXTURE_COHERENCE_GATE`；母图按全图原像素块覆盖，不能仅看眼睛小块。完整字段按工程 `production/art_pipeline/validator_contracts.md`，不复制一个可能过时的精简假回执。

从工程根运行已有验证器：

```text
python -B scripts/art_pipeline/validate_stage_visual_self_check.py --record <逐张视觉记录> --artifact <当前输出>
python -B scripts/art_pipeline/validate_texture_gate.py --record <纹理视觉记录>
python -B scripts/art_pipeline/validate_final_visual_record_presence.py --formal-dir <待归档的big-small目录> --record-root <全部实际过程记录根>
```

最后一个命令仅查“当前每张PNG有有效记录”，不能证明阶段链完整；另逐项枚举 U0、U1、实际修复、U2-big、U2-small、包装的执行与记录。任一漏项、错误输出hash、未查看或FAIL均阻断。不要把历史样本的分析记录写成新生产资产的批准。

## 重试边界

每次失败记录具体原因和提示词/裁切变更，始终从冻结来源重来。尊重当次已定预算；未定预算时同一母图问题最多三次有效生成尝试作为本 Skill 的成本默认，第三次仍失败暂停该角色并汇报候选与缺陷，可继续其他独立角色。该默认不是源Word规则，也不将失败最优图转正式。文件、权限或工具错误不计为一次有效生成。

## 归档

最终图片只含 `big` 与 `small` 两类PNG，按当前项目类别/Unit结构放入角色的UI肖像子类（本机可用 `最终交付/角色/Unit<n>/UI肖像_<中文名>/big|small`）。工程资料库已有 `美术资产交付/角色UI肖像/Unit<n>` 分类，只有用户要求转入时才向该路径复制批准范围的成品，并保持两个规格分目录。源目录中的说明与辅助线保留不动。

母图、标注、技术/视觉记录、对比图和被拒历史都留在工作过程目录。可复用高清母图在受管任务清理前另存长期主档并校验，不能只保存低分辨率双图便删除唯一母版。正式放行、用户具体版本选择、工程复制是不同状态，依当前项目授权继续，不伪造任一状态。
