# 人工补全肖像来源与返回

通用肖像可以截肩。仅当当前 UI 母图需要来源尚未提供的肩胸、服装或主体外轮廓时，设置 `WAITING_FOR_MANUAL_PORTRAIT_COMPLETION`；不要把通用肖像原交付判成不合格，也不要让 UI 生图承担猜补缺失结构的工作。完整来源生成 UI 母图仍按 U1 进行；候选意外裁掉已有结构时，从完整冻结来源按原预算返工，不从失败候选扩图。

人工交接记录放入任务的生产记录：角色身份、原肖像和角色卡路径/哈希、已确认用途、缺失的具体部位、所需完整轮廓与裁切余量/清晰度、须保持的脸部/视角/服装/光照，以及约定返回文件。保留来源，不写回只读资产目录。此等待不消耗 U1 三次有效生成预算，可以继续其他独立角色。

人工说明已完成并指定返回源后，核对身份映射、人工确认、用途范围、肩胸与服装结构、视角/光照、分辨率及实际源哈希。完成记录分别保存原源和返回源的路径/哈希；哈希变化只表示版本变化，不证明视觉通过。核验未通过则列出具体返修项继续人工等待，不调用自动补全。

通过后更新受影响的 U0 来源锁定，记录人工来源与本次实际检查，从首个失效阶段继续 U1/U2。保留其他角色及无依赖的已批准历史 UI 资产。不要填造 Codex 补全提示、生成次数或 PASS；也不要把这次人工源补全充当表情 E5/E6 的手工 Alpha 操作或回执。PS 抠图试验授权不扩展到补肩。
