# 道具人工回流与机械导出合同

## 1. 权威输入

本分支的输入是用户已经人工定稿、并明确要求按现状导出的道具 PSD 或活动 Photoshop 文档。用户指定的层名、层级、图层效果、位置和输出用途优先于旧过程记录；旧记录只用于识别需要被替换的名称或文件，不能覆盖用户当前修改。

磁盘 PSD、活动文档和截图必须区分：截图能证明用户意图，不能证明磁盘 PSD 已保存。磁盘解码只绑定当前文件 SHA-256；如果活动文档更新而文件哈希未变，禁止从旧磁盘状态导出并声称是回流结果。用户未授权保存源文件时，保持 PSD 不变。

## 2. 输出角色

- `type6`：场景中的容器入口或可操作承载体。使用实际视觉左上角，文件名带精确 XY。
- `type7`：打开后的二级视图。完整保留用户已经定稿的边框、描边和其它图层效果；可沿用不带 XY 后缀的运行时文件名，但仍登记全场景 XY。
- `map`：独立可点击层。保留所有用户已定稿的 Alpha 岛、可见像素和位置，文件名带精确 XY。
- `scene_carrier`：用户明确指定的场景承载层；可作为另一 Map 的父级，文件名带精确 XY。
- `carrier_child_map`：承载层中的独立子项；必须记录 `parent_id`，同时保留自己的全场景 XY。
- `big`、`icon`：只在用户明确指定现有图层或允许从定稿层作确定性派生时导出，默认不写 XY。已有明确 Profile／目标尺寸时在 manifest 记录 `final_profile` 与 `target_size`；字段用于复现与自检，不构成单独门禁。

父子关系是配置关系，不改变坐标系。子项即使位于 Type7 或同一 PSD 组内，也登记原场景画布坐标；需要局部坐标的运行时另行从父级左上角计算，不能用局部坐标覆盖交付 XY。

## 3. 视觉范围与像素

`raw_layer` 取指定层的实际 Alpha 范围。`visual_layer_with_effects` 取图层加已定稿效果后的完整视觉范围；描边向外扩展时，XY 使用扩展后的左上角。不得因为原始像素边界较小而裁掉边框，也不得从全场合成图裁一个矩形来混入兄弟层、背景或调试内容。

导出后允许将 Alpha 0 的 RGB 清零；这不改变可见像素。Alpha 大于 0 的 RGB／Alpha、图层效果、尺寸和位置必须与用户定稿源一致。任何会改变可见轮廓、内容、文字、光影或关系的处理都不是机械导出，应离开本 Skill。

Big 是规格例外：用户人工定稿的是内容和构图，但回流后发现画布不符合既有最终 Profile 时，就在本支线顺手完成技术归一化，不新增审批或门禁。普通 Big 的当前固定框为竖版 `571x1000`、方形 `818x818` 或横版 `1000x571`；线索宝丽来为 `620x620`；环境 Big 使用需求明确的环境 Profile；Icon 为 `130x130`。优先仅扩展透明画布并居中，不缩放已合格内容；必须缩放时保持比例、只做一次高质量采样并用透明留边补足，禁止非等比拉伸。目标尺寸先取本项已锁定需求，其次取本批同类正式 Profile；记录实际采用值并继续，不把回流源尺寸错误变成停工理由。

Big 规格调整后重新核对输出尺寸、Alpha、主体与文字完整性，并使依赖该 Big 的 Icon 重新绑定当前字节。这个技术归一化不调用生图，也不改变 `ndc-prop-master-production` 的职责。

层名或旧文件名中的 `__XY` 只是注释。它与当前图层视觉边界冲突时，以当前画布真实左上角为准，同时更新目标文件名和 `XYposition.txt`，并在 manifest 中保留旧注释差异。

## 4. XY 与命名

交付 `XYposition.txt` 每行固定为：

```text
<文件名stem>\t【x,y】
```

顺序服从 manifest。每个 `coordinate_bearing=true` 的输出只出现一次；每个 `coordinate_bearing=false` 的 Big／Icon 不出现。Map 与 Type6 的 `embed_xy_in_filename` 必须为 true，stem 末尾坐标与 `xy` 完全一致。Type7 可为 false，但仍必须有 `xy`。

同一场景内存在多个 Map 时，名称必须能稳定区分并与配置键一致。用户已经指定 `map1`、`map2` 等名称时原样沿用，不把该场约定泛化成所有场景的强制编号。

## 5. 覆盖、候选与状态

只有当前任务明确授权的文件可覆盖。覆盖前先确认新输出已经形成；若旧文件是唯一可恢复版本，则在 `{WORK_ROOT}` 保存必要历史。若根目录已有同字节的目标，不再重复备份。

本人工回流分支不建立额外 `交付候选` 文件夹，也不运行 candidate registry。机械校验成功只写 `MECHANICAL_EXPORT_COMPLETE`；正式 PASS、发布与 Unity 接入仍由各自流程决定。

## 6. 最小阻断

只在以下情况阻断对应输出：

- 源 PSD／活动文档打不开；
- 人工修改尚未保存，而活动文档不能直接忠实导出；
- 必需层不存在或同名层无法唯一映射；
- 图层效果无法按当前能力完整渲染；
- 目标已存在但本次没有覆盖授权；
- 坐标、文件名与 XY 文本无法一致。

一个输出受阻不撤回同场已可靠导出的其他独立输出，也不触发生成预算或全批返工。
