# U1 L5 最终凶手选择｜章节接入策划案

版本：v0.1，2026-09-18。状态：按本次已确认玩法整理的初稿；对白、State、正式配置及 Unity 尚未迁移。

通用规则见 [最终凶手选择](../docs/游戏系统/核心玩法/最终凶手选择.md)。本文件只维护 U1 的候选、材料依据、剧情转换及交接差异。

## 1. 本次改变什么

U1 / EPI01 的最后一轮为 L5。调查、搜证、疑点保持原设计，最终对抗先选凶手：选 James 进入三轮证物指证；选 Tommy 进入纯对白对抗，说着说着发现指错了人，随后返回选择。L1—L4 的指证模式不变。

| 环节 | 原方案 | 新方案 |
|---|---|---|
| 最终调查 | 收集 L5 材料并完成两项主线疑点 | 保留 |
| 提交判断 | 选 Tommy 或 James，再进入对应证物指证 | 选择人物，点击确认即提交本次判断 |
| Tommy 路线 | 出示故障枪击破一次，再坦白、进入坏结局 | Zack 施压，Tommy 说出既有隐瞒；对白表现指控碰壁，无玩家证物提交 |
| James 路线 | 三轮出示证物、逐轮击破 | 保留三轮证物指证和各轮错误重试，完成后接真相与尾声 |
| 错误返回 | 原设计的黑屏时间耗尽等结局之后回选人 | 对白结束后短淡出，显示“这次指控未能成立”及“返回指认前”，回未选中的候选界面 |
| 正确收束 | 真相还原、争辩、后巷及固定尾声 | 保留既定故事方向与衔接，按新对白出口接入 |

本次错误反馈不再要求制作“时间耗尽、未救 Vivian”等额外坏结局段；这些旧内容列为后续迁移时停用，不直接删除当前对白或 State。

## 2. 选人前玩家具备什么

候选为 Tommy（105）、James（107）。题面“你认为谁是凶手？”；James 为正确路线。编号用于后续对照，不在界面上显示。

沿用本轮两项主线疑点，不新增第三项疑点、不新增故障枪分析或详情已读门槛。

| 疑点／来源 | 触发材料 | 在新玩法中的用途 |
|---|---|---|
| L5 1501：他所说的停留时段，对应哪段演出？ | 实际节目单1590＋Tommy取枪自述1055001 | 触发本轮疑点，并供判断行动时段；节目单为 James 第一轮指证用，取枪自述用于触发疑点／前置调查 |
| L5 1502：这句话为什么听起来似曾相识？ | L4 Vivian隔门声音1064001＋L5 James厨房喊话1075001 | 触发本轮疑点，供玩家辨认声音表达的联系；两条证词为 James 第二轮指证用 |
| L4 1404（继承，不计入本轮分母） | 离室目击1124001＋故障枪1601 | 目击用于调查判断；故障枪为 James 第三轮指证用，在 Tommy 路线仅作对白依据 |

James 路线保留原有三轮指证材料与疑点归属。Tommy 路线取消玩家出示操作，已有材料可在对白中被引用。

判断边界：

- 节目单给出23:00—23:10的演出窗口；音量资料仍是环境信息，不能把节目单单独写成定凶证明。
- 23:18离室不构成 Tommy 整晚不在场证明；三分钟来自其自述，不能升级成已证实的约23:15入室。
- 故障枪“未见所述试枪痕迹”支持质疑 Tommy 的试枪说辞，不能单独证明他见尸或开枪杀人。
- “故障后未击发”与“未见试枪痕迹”不是同一句事实，James 的走火辩解与 Tommy 的说辞必须分别对应。
- 正确路线中的新退守、供述和动机不能成为选人前唯一缺失的证据。

接入前需沿真实玩家路径核查一次“直接选 James”的依据。尤其音量表为可选查看的环境信息：未看过时，不能让 Zack 假装已读；应核对现有文本能否在不新增门槛的情况下维持公平判断。本项是信息覆盖核查，不授权添加新线索或隐藏必读条件。

## 3. Tommy 错误路线的叙事设计

### 界面表现（2026-09-18 用户补充确认）

选 Tommy 后照常进入现有指证上下分屏界面，沿用人物展示和对白推进交互。玩家起初面对的是一次正常对抗，随着对话展开才逐渐发现指错了人；失败提示在对白结束后出现。Tommy 路线全程只有对白推进；James 路线在同一类上下分屏界面保留道具指证交互。四分图中的人物画面仅作流程示意，实际布局采用现有界面。

### 3.1 体验目标

玩家带着判断选择 Tommy，Zack 随之展开有压力的指控。Tommy 被逼出真话，但这些真话暴露的是他隐瞒、保护和自保的行为，不能完成“他就是射手”的证明。让玩家经历“以为问中了 → 确实问出隐瞒 → 核心指控仍站不住”的转折。

不先弹错答案提示，不让 Emma 当裁判直接报出 James，不靠 Tommy 单说一句“不是我”就结束。

### 3.2 段落职责（不作为最终台词）

1. 进入指证上下分屏界面，Zack 将怀疑指向 Tommy，追问已有说法中的矛盾。仍可在对白中引用已有枪械事实，但不暂停要求玩家出示。
2. Tommy 从辩护转为承认既有设计中的隐瞒：见尸取枪、误认 Vivian、未修枪及保护／自保等。具体坦白顺序由对白阶段编排，不新增事实。
3. Zack 试图把这些承认推进到杀人指控，Tommy 则守住“隐瞒不等于开枪”的区别，形成压力反转。
4. Zack 无法完成这次指控，收住结论；通过停顿、退让和收束让玩家感到判断碰壁。
5. 对白正常结束，进入失败反馈。不得从该段直接跳到 James 对抗。

Tommy 被勒索、身份承诺无望等既有内容可按原信息边界使用；照片另一人仍留既定尾声揭晓。不得为使错误更明显而新增真凶线索或宣称 Tommy 已被全部排除。

### 3.3 返回方式

```text
Tommy 对白收束
  → 短淡出
  → 这次指控未能成立
  → 同界面出现：返回指认前
     辅助说明：保留调查成果，无需重新搜证
  → 玩家点击
  → 恢复指认前状态，回候选人界面，无预选
```

采用[已确认四分示意](../docs/游戏系统/核心玩法/最终凶手选择_交互示意.png)。第二、第三格为同一界面，不增加一个额外确认页面。

保留指认前物品、证词、分析状态、疑点与探索成果；恢复错误路线的场景／人物／剧情完成状态。错误坦白不新增可带回的证词卡或道具。正确路线不记得错误路线谈话；玩家本人得到提示是允许重试的体验代价。

## 4. James 正确路线的转换

选 James 后进入既定厨房对抗，保留三轮指证。嫌疑人提出说法，玩家选择并提交对应材料；选对进入下一段，选错材料按现有规则重试本轮。

对抗采用现有指证上下分屏界面，沿用人物展示、对白推进及证物提交交互。

| 指证阶段 | 玩家提交与对抗推进 | 必须保留的限制 |
|---|---|---|
| 第一轮：小酒保替 James 辩护，质疑听不见枪声 | 玩家出示实际节目单1590，结合已有音量信息反驳，推进下一轮 | 小酒保不是新增嫌疑人；不把节目单单独当作定凶证明 |
| 第二轮：James否认进入会客室、否认门内声音 | 玩家提交1064001、1075001两条声音证词，推动James退守 | 不自动假定玩家已听过错误路线坦白 |
| 第三轮：James以争枪走火解释 | 玩家出示故障枪1601，以故障后未击发的事实反驳走火说法 | 不新增维修资料或枪检，不把证明范围扩大成未曾存在的物证事实 |

后续保留真相还原与争辩，再接后巷、医院、大厅和办公室的既定收束。厨房负责案件对抗，家庭动机按既有后巷揭示时机处理；家庭动机继续按原时机揭示。

英语练习书仍可选；未取得不播放依靠该书字形作出的指认。正确路线应独立完整，不要求先错选 Tommy。

## 6. U1 专项验收

- L5 两项主线疑点按现有来源完成，开放 Tommy／James 选择；其他探索不被改成新线性链。
- 点候选只是选中，确认才提交；未选中不能提交，错误返回无默认选中。
- 选 Tommy：无证物出示环节，坦白未被当成杀人定案，结果页与返回流程完整。
- 返回后可再次选 Tommy 或 James，无新证词／道具复制，无错误路线标记残留。
- 直接选 James 和先错选再选 James，正确对白内容都自洽，不继承错误坦白。
- James 路线三轮均可出示证物，选错材料可以重试，完成三轮后进入真相与尾声。
- 有书／无书两种既有调查状态均能完成正确路线，引用内容符合实际持有材料。
- 读档能恢复选人、路线对白或结果页；从错误路线返回时调查成果完整。
- 最终仍以五轮结束，不误接旧第六轮；L1—L4 的原指证不受影响。
