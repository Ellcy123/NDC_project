|---|---|---|
| 每轮开篇 | 连续锁定演出，结束后开放探索 | 按实际场景制作或复用 |

### 3.1 固定人物与独立人物

| 情况 | 交付方式 |
|---|---|
| 锁定 AVG 段落从头到尾在场 | 人物合入专用 AVG 场景图 |
| 同段中途进场或离场 | 独立透明人物层，底图补全其身后的空间 |
| 部分角色固定，部分进出 | 固定角色合底图，进出角色拆层 |
| 同一人物按条件切换状态 | 对应状态互斥显示，如 Morrison 正常／淋湿 |
| 指证后的普通交代 | 无背景正反打；无需 AVG 整图 |
| 全体随场景切换出现或消失 | 整图切换；无需仅为转场补步行层 |
| 强动作、证物特写 | 漫画承载；明确前后 AVG 状态，避免回到错误姿势或人员状态 |

固定人物的生产源仍可逐人保留透明层，最终交给 AVG 的显示图按上表合成。这样便于返修，但不把源文件层数冒充引擎需要的角色层数。独立层图与底图采用同一机位和光照，保留遮挡关系；吧台、桌椅等前景必要时另留遮挡层。

### 3.2 命名与工程接口

工作前缀 `U1_avg_`。背景输出带 `_bg` 或 `_bg_状态`，人物输出带角色名／状态名。正式路径和配置挂点在接入阶段确定，不擅自用新工作名替换现有资源。

每组交付：场景 PNG、所列独立 RGBA PNG、可编辑源文件、各可见状态合成预览；独立层附画布尺寸、坐标、脚位、层级和必要阴影。场景尺寸继承批准背景与工程显示方式，不能仅因制作方便统一裁成新比例。

工程实际已存在脚本 13 进场、14 退场及 8 场景切换的用法；只作为接入能力参照。新段落先挂事件名，待对白定稿再补 Talk ID／脚本参数。正文资源检查未等于运行时二进制字段全面对账。

### 3.3 构图与制作验收

- 按当前人物档案锁定身高、身份和服装。最终足点、人物大小由同景深门、床、桌台等实际尺度及透视推导；像素坐标在底图定稿后填写。
- 固定镜头与既有家具位置。坐姿必须有批准背景中的座椅支撑，接触床沿、吧台、地面的部位保持正确遮挡与接触阴影。
- 同段人物形成可理解的对话朝向、视线和距离；优先选稳定的关键交谈姿态，动作特写不压进长期驻留图。
- 用最终 TalkPanel 左右侧检查人物与关键信息可读性。面板方向取实际对白设置；当前不虚填安全矩形或最终脚位。
- 身份母版、医院背景、厨房窗口版尚需逐项绑定。小酒保、Isabel 的形象来源在正式生产前确认；病房来电通知人物为 Tommy，沿用其批准的身份参考，新作病房姿态。本文不擅定身高。
- 混合图的独立人物后续走 AVG-layer 人物入景流程；完整尺寸、比例、Alpha 与合成预览均验收，技术通过不代替用户视觉确认。
