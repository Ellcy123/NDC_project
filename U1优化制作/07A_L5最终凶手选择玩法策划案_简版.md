# U1 L5 最终凶手选择｜简版

2026-09-18 · 策划初稿，待制作。[详细版](07_L5最终凶手选择玩法策划案.md) · [通用玩法简版](../docs/游戏系统/核心玩法/最终凶手选择_简版.md)

## 这轮怎么玩

玩家照常搜证、完成两个主线疑点，然后在 **Tommy 和 James** 之间选择凶手。选 James 进入三轮道具指证；选 Tommy 只推进对白，逐渐发现指错了人。L1—L4 继续使用现有指证玩法。

**选 Tommy 或 James，都会进入现有指证的上下分屏界面**，沿用人物展示和对白推进交互。选错的感觉随着对抗逐渐出现，结果提示放在这段对白结束之后。

选人依据来自已有调查：节目单与 Tommy 的取枪自述、Vivian 听到的门内声音与 James 的喊话，以及前一轮取得的目击信息和故障枪。

## 选 Tommy：逼出隐瞒，指控碰壁

1. 进入指证上下分屏界面，Zack 带着怀疑向 Tommy 施压。
2. Tommy 顶住杀人指控，却逐渐承认见尸取枪、保护 Vivian 等既有隐瞒。
3. Zack 试图追到“谁开的枪”，发现这些坦白仍然撑不起自己的结论。
4. 玩家在这一来一回的对话中逐渐发现指错了人，随后对抗收住。

随后画面淡出，显示 **“这次指控未能成立”**，同一界面出现 **“返回指认前”** 按钮。

点击后回到 Tommy、James 的选择界面。调查材料和疑点进度保留，剧情恢复到指认前，玩家重新选择。Tommy 这次坦白只属于这次尝试；James 路线从选择前的人物认知继续。

## 选 James：对白对抗，进入结尾

保留原来的三轮指证，玩家逐轮选择材料、提交并击破谎言：

| 段落 | 内容 |
|---|---|
| 小酒保辩护 | 小酒保质疑枪声为何没人听见；玩家出示实际节目单，结合演出音量信息推进指证 |
| James 否认 | James 否认进入会客室；玩家提交 Vivian 与 James 的两条声音证词 |
| James 退守 | James 改称争枪走火；玩家出示故障枪反驳 |

接着播放真相还原，再进入后巷、医院、大厅和办公室的既定结尾。James 的家庭动机仍在后巷揭晓；英语练习书相关内容按玩家是否取得播放。

## 要改哪些内容

| 部分 | 要做的事 |
|---|---|
| 对白 | Tommy 通过连续对白写出选错后的挫败感；James 保留三轮指证对白 |
| 交互 | 制作候选人选择、确认、失败反馈和返回功能 |
| 对抗界面 | 两条路线均用上下分屏；Tommy 只推进对白，James 保留道具指证 |
| 流程配置 | Tommy 的提交节点改为连续对白；James 保留原证物提交，接好两条出口 |
| 存读档 | 保存当前路线和返回点，重选时完整保留调查成果 |
