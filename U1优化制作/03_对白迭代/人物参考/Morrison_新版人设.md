# Harold Morrison｜U1 五轮版完整人设

> 2026-09-17。本档用于新版五轮对白，已整合基础气质、当前经历与揭示边界，可独立使用。人物事实以新版已确认设计为准；表达建议不构成新增剧情。

## 身份与生活底色

Harold Morrison，NPC 104，约45岁，从警约二十年，白人，177厘米，身材魁梧。本案辖区警察，现行自报单位为二十二分局。他是蓝月亮的熟客，喝酒、看报，也关注赛马。警徽、压低的帽檐及枪套构成他的职业外观；紧张时摩挲枪套的习惯可沿用。外形、年龄及资历来自基础档，当前新版没有改动。

他看起来散漫、疲倦、满腹牢骚，实际上仍有经验和判断力。不要把他写成真的看不懂现场，也不把每一次迟钝都演成精密伪装。他习惯省事、回避麻烦，利益受威胁时会立即恢复警察的控制力。酒和赛马是已知生活内容，没有依据补充其他爱好。

目前确认：他因赌马欠债，Whale 替他处理债务，交换条件是尽快以 Vivian 为凶手收队。旧档的五千美元、具体赌场、债主及案前三周等细节未在新版重新锁定，本档不把这些数字和姓名当作对白可用事实。旧档有妻子及家人安全压力，但新版没有展开其家庭事件，不据此新增妻子受威胁的戏。

## 欲望、弱点与责任

他想把案子收在能交差的位置，也想保住自己的饭碗和生活。他会抱怨自己倒霉，却不主动承认受害者为他的省事付出了什么。这种自我解释使他能一边熟练勘验，一边压住不利于结案的信息。

核心弱点是债务和受制于人的羞耻。L3 听见赛马场就迁怒小酒保，是把真心求职听成挖苦；这不是提前向玩家解释债务的借口。小酒保后来同情他，只说明人可以对狼狈者心软，不意味着辱骂、受收买与强押因此免责。

五轮版的弧光是从令人厌烦的老警察，露出能强行结束调查的一面，再在尾声显出受人摆布的窘迫。新版没有清算他的完整审判结局，不恢复旧 L6 指证、签字认罪和落网解脱。

## 声音与冲突姿态

平时话松、牢骚具体，常用工作麻烦、酒和眼前琐事岔开。他可以不耐烦、挤兑人，L3 也确实会骂小酒保，不能机械执行旧档“从不发火”的禁令。这里的火气短促、针对痛处，不把所有场景都写成咆哮。

真正动用权力时，话反而少而硬。他不必解释每一步推理，而是限定时间、宣布处置、催人离开。L4 看见弹壳的停顿和降温比长篇威胁有效；表达可以克制，强押行动必须真实发生。面对 Zack 的事实追问，他用程序与结果截断；面对 Emma 挡路，他把阻拦变成可以拘捕她的理由。

和小酒保的区别：小酒保认真、慢半拍、实诚；Morrison 的散漫里有职业判断和自保。他不是两人的同款喜剧搭档。尾声可以狼狈，但笑点只围绕淋水、请酒与狐疑，不拿 James 的死亡和 Anna 的遭遇取乐。

| 阶段 | 本场表现与信息边界 |

| L1 会客室 | 维持命案现场的权威，提供胸口中枪身亡的基础勘验。Rosa 指控被部分击破后，面对 Webb 委托与仍有疑问的现场，给 Zack 72 小时；这不是已判 Vivian 无罪，也不是正式雇用 Zack |
| L2 | 无新增独立人物转折，不为了维持存在感追加赌债暗示或插场 |

| L4 开篇 | 让 Zack 调酒又嫌难喝，随即告知 Vivian 认罪和核查期限；不再安排赌马闲谈 |
| L4 收尾 | 大厅听核查结果、看弹壳后态度变冷；再到歌舞厅强押 Vivian。Emma 阻拦，他警告并伸手抓她；Zack 挡在两人之间愿承担风险。Vivian 主动随行，才让冲突收束，救人仍失败 |
| L5 尾声 | 承认 Whale 的人送来 James 的枪并要求放人，自己已经照办；抱怨 Whale 又追索此前处理的赌债。依据可选恶作剧状态呈淋湿或正常，不替未发生的支线补笑话 |

## 关系落地

对 Zack 是试探、限制与相互不信任，不是善意长辈。他给核查机会，也会在触及利益时关门。尾声埋怨 Zack 竟让 Whale 来要求自己放人，表现权力链反过来压到自己身上，不当场完成道德悔改。

对 Emma 起初可轻视其记者身份，L4 则因她阻拦而动用强制手段。Zack 的保护不是身份豁免，Morrison 退开是因为 Vivian 愿意随行、阻拦解除。

对 Vivian 没有已确认的私人仇恨；她是他被要求交出的案件答案。面对无罪方向的证据仍要带走她，正是他的责任所在。对小酒保则是熟客与服务人员的关系，他愿意使唤，却不认真对待对方求职的需要；尾声对请酒的狐疑引出 Vivian 留下员工的决定。

对 Whale 是被债务抓住的执行者。U1 可以揭示债务交换和放人指令，不能让他解释 Whale 的真实身份、完整布局，或认定他掌握了所有幕后动机。

## 作者知识与禁用旧内容

L1 不说出弹道、弹壳口径和幕后交易；L3 的赛马失态不解释金额、债主；L4 变脸不能直接说明 Whale 与自己关系。口径相同也不等于已证明致命弹壳来自他的配枪。L5 送枪消息建立在已完成的调查之上，不宣称一把没有来历的枪独自证明全案。

禁用旧版 L6 警局／住所调查、搜赌债物证、Morrison 三轮指证和签字结局。住址、车程、具体赌场债主等未复核细节不作为新增台词素材。
