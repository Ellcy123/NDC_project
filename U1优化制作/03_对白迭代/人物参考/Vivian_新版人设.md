# Vivian Gray｜U1 五轮新版人设

版本：2026-09-17。适用于 Unit1／EPI01 五轮新版。本文完整提供写作所需人物口径；作者真相按分轮边界使用，不将旧六轮桥段直接移入新版。

## 身份与生活

Vivian 约27岁，169厘米，混血，蓝月亮酒吧头牌歌女，化妆间兼私人住所。舞台身段、精致冷艳，浓妆下有疲惫；习惯透过镜子观察来人，距离感是一种防御。唱歌既是谋生手艺，也是仍能属于她自己的表达；不因职业替她增加未经确认的曲目偏好、收藏或其他爱好。

她是Webb的恋人、受其利用的勒索工具，也是遗嘱中的继承人。保留Webb所赠Colt Vest Pocket Model 1908小手枪（.25 ACP）；旧档“三年关系”与另一处“五年被利用”的起算关系不明，当前不锁定相处或受利用的精确年限。枪号384216与购枪收据对应，收据不能显示赠枪日期。她保存旧合影，撕毁的巴黎船票仍在，但物件不替她直接宣告仍爱Webb，也不展开旧退款往事。

## 性格与情绪

冷淡、克制，自尊强，熟悉被观看和被利用的处境。讽刺和反问用于把来人挡在外面，不是为了表演聪明。正常说话有舞台训练后的分寸，痛处被碰到时先冷硬、停顿、改口；不一受关心便诉苦，也不用连续眼泪替代抵抗。

她对Webb有爱、有恨，也无法轻易承认自己仍记得温情。赠枪之事被揭穿，迫使她面对关系中的矛盾，不等于证据证明Webb爱她。她对自己的杀人归罪带有自毁倾向：记得杀意、持枪、尸体和枪声，却没有清晰的扣扳机记忆，逐渐接受最坏解释。她并非明知无辜而有计划地替别人顶罪。

她的转变是从放弃未来，到愿意查明真相，最后主动决定如何生活。每一步由当下经历推动；不能L1就清醒认罪，不能L4刚被救出认知困境就宣布经营酒吧。

## 关系与真实责任

- Webb：真实感情与利用并存。继承他的财产不等于原谅，也不能将其死后安排解释成洗清全部伤害。她不知道所有幕后盘算。
- Tommy：他曾照应她；她受Webb安排接近他，参与制造勒索照片，伤害了一个有妻女的人。两人没有实际亲密关系。她知道自己有责任，不确信他原谅自己；她将他后来配合计划理解为共同怨恨Webb。复杂关系不写成恋情。
- Zack：起初拒斥追问，随后被证据迫使重新看待经历；被押走时主动请求继续查明真相，尾声愿意履约开柜。信任通过行动建立，不突然依赖或亲昵。
- Emma：两个有判断力的女人保留距离。Emma要求回应证据、冒险阻拦带人，提供信任的实际基础；不要将她写成天然闺蜜或知晓全部私事的人。
- Rita：继承人面对推动收购与遣散的股东代表。提及恋人身份会触动她，但她对员工去留的回应来自自己的选择；不将Rita当成凶手或让两人进行额外指证。
- Morrison：她切身承受错误结案与强押。认罪解释被推翻后仍被带走，她配合离开是为了结束眼前冲突，不再等同于认命有罪。
- 员工与Anna：留下经营首先回应员工生计；对Anna提供有限照护，不许诺解决全部医疗、育儿或身份困难。

## 案前与当晚：仅供作者掌握

她提出杀Webb的计划，请Tommy安排演出，Tommy知情配合；她不知道他私下归还故障枪、后来取枪藏枪。换曲是杀人准备，不再只是无意掩护凶手的浪漫共舞请求。

1928年11月3日22:00—23:00持续在台上表演，23:00离台后由乐队独奏强奏曲，不能在22:55安排休息。23:05持枪到会客室门外，敲门后听到门内喊话而离开，没有进屋；23:30再进入，看见Webb已经倒下，随后听到来自头顶二楼的枪声。她不知道门内说话者就是James，不能在回忆里直接确认。

## 五轮表现

| 阶段 | 本轮状态与交付 | 不得提前落定 |
|---|---|---|
| L1 | 酒醉、失语、断片，面对尸体只给碎片反应 | 不给完整自认杀人的陈述，不说Tommy计划与门内真相 |
| L2 | 对她处境的关心可由相关人物流露；不照搬旧版新增她的认罪场景 | 不提前铺完L4自认与指证 |
| L3 | 化妆间短谈，消沉、对遗产与收购放任；可谈为自己唱歌与Webb保管习惯 | 放任不等于已签出售协议；保管习惯不确认柜内具体物件 |
| L4自由探索 | 歌舞厅固定驻场；枪源询问谎称自己购买，与Webb无关；提供本轮允许的案发自述 | 不先讲换曲计划、Tommy经手和保护理由 |
| L4指证 | 第一轮承认Webb赠枪；继而承认杀人准备，却否认Tommy经手；申请击破后承认经手，仍独自归罪；最后接受小枪未造成致命射击 | 不把第二轮退守提前做成自由问话答案 |
| L4指证后 | 先交代23:05隔门经历与23:30所见所闻，再说只有Tommy知计划、有旧怨，开始怀疑他栽赃；强押时主动托付查明真相 | 怀疑不是犯罪证据；不知故障枪，不讲照片设局 |
| L5尾声 | 获释后邀两人返店；大厅下楼接住小酒保工作话题，决定不去巴黎、接手经营、留下员工；办公室私谈后开柜 | 不把经营决定前移到L4阻遣散；不自动继承Tommy错误分支坦白 |

开柜前，她修正对Tommy的栽赃怀疑，但不因此获知其全部保护动机。开柜后发现两人的勒索照片，她才简短承认Webb安排、自己参与，不用长篇回忆消解责任，不要求立即和好。她掌握实际密码并自行开柜；不恢复玩家查日期、输入1304的旧流程。
