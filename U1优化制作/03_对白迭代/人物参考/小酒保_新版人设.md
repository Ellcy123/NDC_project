# 小酒保｜五轮版完整人设

> 2026-09-17。汇总已确认情节与本次用户确认的人物方向，供新版对白使用。未补造姓名、年龄、家庭、籍贯或爱好；工作称呼为小酒保／Bartender。

## 人物核心（用户确认）

呆憨、慢半拍、有喜剧感，待人实诚。与 Zack 在相处中逐渐建立较好的关系，是值得信任的信息来源。

“呆”主要体现在理解话外音和应对场面上，不等于工作失能或观察不可靠。他可能认真地按字面理解别人的话，也会因没跟上暗示而问得很直白；不能每句话都误解，更不能为了笑点把关键证词说乱。

职业为蓝月亮酒吧酒保，担心遣散后失去工作与落脚处。现有资料未给出姓名、准确年龄、族裔、家庭或独立住所；“小酒保”不是未成年证明，不由写手随意定年龄。L3 吧台有其私藏的《禁酒法详解》假书，挖空藏扁酒壶，是已定环境趣味；不扩写为酗酒、嗜赌或偷盗的长期人设。

## 表达与喜剧方式

- 笑点来自认真、慢半拍和处境反差，不靠连续抖机灵、卖弄俏皮话或故意扮傻。
- 说话具体、直白，先关心眼前的工作、工资和自己遇到的麻烦。不使用固定口头禅强行制造人物标记。
- 对自己没弄懂的事可以追问；对亲眼看见的事可以清楚作答。不把所有回答都写成结巴、迟疑和记忆混乱。
- 被羞辱会委屈、生气，也会有幼稚的报复念头；知道对方的困境后又会心软。他有自己的情绪，不是任人取笑的工具。
- 严肃取证时自然收住笑点，准确交付人物、时刻、地点与观察范围。提供信息后不替玩家推导幕后真相。

## 与 Zack 的关系

关系逐步建立，不能在 L1 初见时就表现成多年老友。开门时仍履行自己的工作职责；之后通过 Zack 的实际帮助、解围与认真倾听逐渐亲近，愿意向他讲见闻、商量小事。

两人可以拌嘴，Zack 的反应可以干脆、带一点幽默，但不以刻薄羞辱小酒保为乐。小酒保可以信任 Zack 的判断，却不能因此顺着他的提问编造答案或认领没看见的事情。

玩家对他的信任来自两方面：相处中看见他的实诚，以及取证中看见他能分清“亲眼看见”“听人说”“自己猜的”。不靠其他角色直接宣布“他绝不可能说错”来替代可信度。

## 与其他人的关系

James 是熟悉的厨师同事；L5 真相还原后，他会不信、动摇并试图替 James 辩护。这是舍不得接受熟人犯罪的情绪，不是作伪证，也不把对 James 的好感改写成知道并参与计划。Emma 指出受害者与孩子的代价后，不能由他继续替 James 抹消责任。

Morrison 是熟客和辖区警察，起初求其介绍工作，遭辱后生气，后来知其困境又心软；不是原本知道赌债而故意挖苦。Tommy 是讨薪时要找的人，没见到便扑空；不因打碎假艺术品就新增工资抵偿剧情。Vivian 决定经营后留下员工，收束工作去留；他在此前不能预知她会作这个决定。对 Rita 的不满来自眼前遣散压力，不知道其真正替谁寻物。

## 可靠信息的边界（作者侧）

- 23:18：工作中处于正常移动状态，能看见会客室门；亲眼看见 Tommy 出来，并看过店内钟。不把“未离岗”写成整晚站着不动。
- 未见 Tommy 进入，不知道停留时长，没看清携带物，也没见房内杀人或当时 Webb 的生死。不得用“我一直盯着”补强证词。
- 不知道 Vivian 的杀人计划；演出见闻不等于知道演出安排的犯罪用途。
- 不提供保险柜保管习惯、密码或柜内信息；相应材料由既定角色和搜证节点承担。
- L3 不知道 Morrison 赌债原因；到 L5 听见抱怨后才能理解。若玩家跳过恶作剧，尾声仍可同情、请酒，但不能对未发生的泼水感到愧疚。
- 与 Zack 关系好不等于主动交付后轮信息，证词仍按 State 的节点取得。
- L2 的“22:00—24:00 在吧台未离岗”按岗位范围理解，允许正常移动；不是跨到会客室内部的见闻保证，也不能借此替所有其他人提供全时段不在场证明。
