# Zack Brennan｜五轮版完整人设

> 2026-09-17。新版对白的独立人物入口。基本气质经旧档核对保留，案件经历与关系采用已确认五轮方案；旧档只供追溯，不是写作必读补丁。

## 基础身份与生活

约 30—35 岁，180 cm，爱尔兰裔，私家侦探，曾在 Kirkland 律所任律师。体格健壮，长期失眠，眼神敏锐，外观比实际年龄疲倦。在艾斯弗德独居，与旧有亲友维持距离；母亲 Margaret 在南区经营鞋坊。三年前离开律所是既有背景，具体创伤经过不在本章自行扩写。

随身有糖罐、棒棒糖和 Webb 签署的遗嘱执行委托协议。嗜甜、靠咖啡和糖撑精神，咖啡加五块糖可作日常细节；不是每次思考都必须掏糖。没有另外确认的新爱好。

## 性格、需要与缺点

善于观察、试探和抓住说法中的矛盾，有律师训练留下的语言精确性。疲倦、克制，不擅长说软话，但会实际帮助别人。职业承诺是他进入案件的理由，不能据此把前期写成对人毫无关心：L2 借款、L3 面对 Rosa 的顾虑已经体现责任感。

他习惯掌握信息与决定权，容易先替别人作决定，再要求对方接受。对 Emma 擅借身份、套消息、扣留调查成果，是关系中的真实问题。成长通过主动求助、分享、担责和共同承诺表现，不靠一次表态解决所有问题。

幽默偏干、带一点得意或自嘲。与小酒保相处可以被对方的认真逗笑，也会帮其解围；不将呆憨当成可以羞辱或诱导假证词的理由。

## 说话与情绪

- 通常简洁具体，问一个明确问题，听对方回答再推进。指证中的准确不等于句句法律术语。
- 不愿承认需要帮助时，可以嘴硬、停顿或转换话题；被实际困难卡住后仍会开口求助，不为硬汉形象拒绝合理合作。
- 关心落在借钱、挡在别人前面、亲口告知坏消息、交还欠条等行动上。强忍情绪不等于对痛苦冷漠。
- 不能替玩家提前连好证据链。调查期指出可见矛盾即可；正式击破后的既定还原按节点进行。
- 不机械继承旧档“绝不使用感叹号”等排版式性格规则，不用网络语或大段说教替代人物表达。

## 五轮经历与关系进展

| 阶段 | 当前经历与人物状态 |
|---|---|
| L1 | 持 Webb 委托来访，秘密入口无人接应；Emma 帮助进门，合作条件未谈拢。案发后擅称记者助手周旋。一次击破只削弱持枪指认，再争取 72 小时调查机会，未证明 Vivian 完全无辜 |
| L2 | 与 Emma 暂时分开；以委托阻止 Rita 仓促接管，借 James 20 美元、收下欠条。小包厢套出 Emma 的调查方向，随后搬柜受阻，不得不请她协助。指证 Tommy 后尚未自动共享所有成果 |
| L3 | 查勘验与医院线，在清洁间开箱后发现 Emma 跟踪，默许同行。Rosa 被击破后，Emma 主动保密使他修正对她的看法；并非交换材料才答应保护母女 |
| L4 | 主动分享勒索线索，分工调查。与 Emma 向 Morrison 交涉；对方要抓挡路的 Emma 时，将她拉到身后并伸手等铐。Vivian 主动随警察走、托付继续查案，冲突才收束，救人尚未成功 |
| L5 开篇 | 接 Whale 电话，由玩家组织判断与密码线索筹码争取机会。挂断后完整说明交易条件，主动邀请 Emma 一起查到底；交换姓名是正式结伴仪式，不是首次获知名字 |
| L5 调查与结尾 | 与 Emma 共同查凶、追赶 James，仍想让其活着承担责任。后巷救人失败后，医院亲口告知 Anna 死讯、交还欠条并免债；在其崩溃后承诺两人共同追查。随后回店取材料、听唱片，家人危机引向下一章 |

## 主要关系与称呼

- Emma：从互相利用和较劲到主动选择合作。L3 默许随行不等于正式结伴。L5 电话后 Emma 开始称他 Zack，他仍称 O’Malley 小姐，体现对亲近慢半拍；不能在医院再演一次劝退与争取留下。
- 小酒保：L1 初识仍有工作上的阻拦；在后续帮助、询问和商量中建立亲近。认真听他提供的见闻，不因熟络而替他扩大观察范围。
- Webb：签约雇主，遗嘱安排保障的是 Vivian 继承。查明勒索后仍履行委托，但协议不赋予无限搜查权；不把 Webb 对报复的担心说成已预知具体死法。
- Vivian：核查其行为和认罪，争取清白机会；既不能因同情提前排除嫌疑，也不能把她带枪、准备杀人等同于实际射杀。
- James、Anna：帮助是真实的，后来发现犯罪也不使借款变成诱饵。对 James 追究杀人、嫁祸、胁迫责任；免除 Anna 的债务、支持她不等于替 James 洗白。
- Morrison：初期仍能核实勘验、争取时间，后续面对反证强押造成矛盾升级；不从 L1 就知道其被 Whale 收买。
- Whale：L5 电话时尚不知其真实身份，也没听唱片；尾声确认其履约，但仍不理解为何用逼死 James 的方式帮助放人。

## 作者控制与排除的旧设定

案发日为 1928 年 11 月 3 日；调查时长 72 小时，但未确定每轮日历与精确起算时刻，不把五轮写成五天。L1 不再采用“两次指证失败”；不存在新版 L6 去 Morrison 家、警局清算或结尾第二通 Whale 电话。唱片在 L5 末正式取得并保留，不能沿用旧档“不入背包”的限制。

母亲危机按残缺录音呈现，U1 不揭露 Whale 的真实姓名与完整组织计划，也不新增律所离职、未婚妻或父亲往事的现时对白。旧档有关这些背景的冲突性解释不作本轮定稿。
