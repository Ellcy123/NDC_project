# Rosa Martinez｜U1 五轮版完整人设

> 2026-09-17。本档为五轮版独立人物依据，整合仍成立的基础资料与新版医院、伪证情节。作者知识不能直接变成当轮台词。

## 身份与生活底色

Rosa Martinez，NPC 103，约38岁，154厘米，拉丁裔移民，尚未取得合法居留身份。蓝月亮清洁工，单亲母亲；女儿 Isabel 约8岁，生病并在圣心医院住院。基础档中的酒吧地下室储藏室兼住所、瘦弱体态、带清洁水渍的制服与粗糙双手可以沿用。

她的生活被工作、女儿与不稳定身份挤满。紧张时搓手、低头，先看对方会不会逼自己做什么，再决定回答多少。没有已确认的个人爱好，不补造宗教、饮食或收藏习惯来填空。女儿相关物件是牵挂，不是每次登场必须摸一下的表演道具。

她害怕得罪有权力的人，却不是没有判断力。她知道自己在作伪证，也知道这样会害 Vivian；最终交出弹壳，是明白代价后作出的小而实际的选择，不能把她写成随便问几句就失控的证据发放者。

## 当前事实与动机

她收到威胁女儿的纸条，被迫把 Vivian 塑造成杀害 Webb 的人。她不知道写纸条的是 James。作者知道 James 案前因陪 Anna 住院，已了解 Isabel 病房信息；这是胁迫为何能奏效的幕后因果，不新增 Rosa 提供的线索。

L1 她把看见 Vivian 持枪直接说成刚刚杀人，同时坚持23:30枪响、紧接玻璃破裂、当时只有 Vivian 在内的叙述。她确实在23:20到侧巷倒垃圾，放下垃圾袋后返回走廊；这条普通证词到 L3 才取得。她当晚从会客室捡走一枚弹壳，留作自保，L3 医院指证结束后亲手交给 Zack。不能擅自给拾弹壳动作新增精确分钟。

她的矛盾不是不知道事实，而是不敢承担说实话可能给女儿带来的危险。对 Vivian 的愧疚与对女儿的保护同时在场，不能用母爱把伪证造成的伤害抹掉，也不能因她撒谎就写成冷酷算计者。

## 情绪与表达习惯

基本声音低、谨慎，先缩小自己的身份和责任，再回答眼前问题。话短不等于每句结巴；对熟悉的清洁工作、行走位置与时间，她应能清楚交代。恐惧更多体现为说完立刻收口、回避延伸、压低音量，避免让所有事实都在改口中漂移。

旧档的随意改报时间、L1 主动求玩家去别处调查等样张不直接继承。现行关键时间是精确谜题材料，不能为了显得紧张把九点、十点乱换；没有授权的信息也不能靠恳求时脱口而出。中文保持自然，不以畸形语序表演族裔口音。

被逼近时，她会重复已讲过的说法，试图让话题停下；接近胁迫核心时，防守由坚持事实变成阻止对方再问。L3 揭穿后仍怕隔墙有耳，疲惫、低声，允许手抖和停顿，不突然变得健谈。信任建立后，她仍担忧未来，不能一交物件就如释重负。

## 分轮经历

| 阶段 | 行为与情绪任务 |
|---|---|
| L1 会客室 | 作为现场证人接受普通询问。持枪等于刚开枪的指控被一次实际击破，她仍退守23:30说法；玩家只知道其推断不成立，不得到威胁真相 |
| L2 | 不新增她的独立剧情与供述；女儿、纸条及弹壳不提前移入本轮 |
| L3 医院调查 | 她在 Isabel 病房陪女儿。普通询问交代23:20倒垃圾，不先供出胁迫；病房的吊坠提供生日信息，医疗单仍在酒吧清洁间箱外 |
| L3 医院指证 | 两次出示依次打破23:30死亡枪响、无人胁迫两层防线。她承认威胁后交出弹壳，要求保密只是人物愿望，不额外限制玩家取证或出示 |
| L4 | 已取得弹壳供调查回用；不追加 Rosa 目睹强押、被 Morrison 再次警告等旧版段落 |
| L5 | James 对其女儿的胁迫在后续对抗中被揭示；Rosa 没有因此自动获得场外信息。结尾员工得以留下不等于她已经取得合法身份、女儿痊愈 |

新版弧光到 L3 是从被迫害人到愿意交出自己藏下的事实。后续调查不必让她反复登场证明“已经改好”；保持她和女儿仍有现实生活需要处理。

## 关系与信任

Isabel 是她决定轻重的中心。照片、生日吊坠和医疗资料让牵挂具体可见；清洁箱密码线索来自吊坠内盖“我的天使 · 0915”，不让她直接告诉玩家密码。病房是女儿的病房，不能把她本人写成住院患者。

对 Zack，L1 是戒备、害怕问话带来惩罚；到 L3 才通过实际调查和面对胁迫建立谨慎信任。她交出弹壳代表愿意把部分风险交给他，不表示已经相信 Zack 能保证女儿绝对安全。

对 Vivian，是自己知道却难以出口的亏欠。不要在 L1 就用公开道歉泄露伪证；也不补写旧 L6 两人沉默和解作为已经发生的情节。对 James，调查早期不知道其胁迫者身份；不能因为同在医院而让她无依据地害怕他、暗示他的笔迹。James 是否真会伤害 Isabel 未定，Rosa 更无从替他担保。

对 Morrison，她面对的是有处置权的警察，天然不敢随意说话；但新版没有确认她掌握赌债和幕后交易，也不自动保留旧版末轮举报其警告的证词。

## 作者边界与已排除内容

L1 不出现储藏间搜照片、医疗单或威胁纸条的旧安排。本轮不是“两轮连败”，而是一次成功击破后仍留下待核事实。L3 致命射击早于23:20，不进一步替玩家锁定23:00—23:10强奏段；纸条字形在早轮只是可见内容，不提示 J/T 对应人物。枪械口径来自后续检查，不让她作为清洁工主动完成弹道鉴定。

Isabel 的具体病名、治疗方案与费用没有在本档定死；不能以重病为由新增医学结论。她的合法身份、后续居住与母女生活结局尚无完整解决方案，不填成圆满结局。
