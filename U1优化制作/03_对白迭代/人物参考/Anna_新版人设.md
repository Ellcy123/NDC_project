# Anna O'Sullivan｜U1 五轮版完整人设

> 2026-09-17。供五轮新版对白独立使用。当前事实、关系与情绪经过已整合，不需回读旧档补剧情；未确认内容不据旧情节自行填补。

## 基础身份与生活

Anna O'Sullivan，NPC 108，约23—26岁，158厘米，爱尔兰裔，James 的妻子，怀孕、孩子尚未出生。无固定工作，曾接零散清洁活；衣物旧而干净，动作轻，面对陌生人容易警惕。这些基础身份与外形来自人物原档，新版未改动。孕周、预产期、确切病情及医疗费用尚未完整锁定，不根据外形推定孕期。

当前 James 与 Anna 的移民身份都已经办妥，幕后由 Whale 完成。她在 L3 会真诚地为身份落实而高兴，觉得终于能安心检查、待产；这是她当下生活改善的感受，不代表她知道背后的犯罪交易。也不能把本作人物对正规医院的说法推广成现实年代的普遍医疗规定。

她此前长期处在不稳定身份和经济压力中，获得文件不等于立刻不再怕陌生人。但新版初见发生在医院走廊，James 在身边，又知道 Zack 借过应急款，不能搬用旧版住宅门缝里把来访者当移民局的开场。

## 性格、情感与愿望

她信任丈夫，愿意与他一起期待孩子和以后的生活。她的感激与还钱意愿都是真实的，不把善意演成诱导侦探同情的策略。日常不擅长长篇表达，倾向从家用、看病、工作和孩子这些具体事说起；陌生人问得太深时会谨慎，得到实际帮助后能自然交谈。

她有自己的生活判断，并非只供 James 展示动机的背景。丈夫死后，她先急着安排能够安排的事，企图给无法接受的生活找出下一步；这种勉力冷静，是爱和恐惧都来不及消化的状态，不是对丈夫无情。

没有明确记载的爱好、宗教习惯或特殊口头禅，不另造。可以从她认真记挂欠款、担心孩子照护、考虑工作这些既有行动写出人，而不是补一段无来源的童年故事。

## 已确认的经历

L2 她不在酒吧追款现场，但孕检情况不好、需要医疗费用，促使 James 向 Rita 追讨 Webb 欠付的跑腿报酬。追款未果后，Zack 借给 James 二十美元应急，James 写欠条。跑腿报酬、这笔应急借款、Whale 的交易利益是三件不同的事；二十美元不是已经付清全部医疗费。

L3 她与 James 固定在医院走廊，共用可重复交谈入口。她感谢 Zack，谈身份办妥的喜悦，两人帮助看医疗单、指出 Isabel 病房路线。她提供的是生活和问路信息，不发放一份用于证明丈夫罪行的身份文件。

L5 James 指证后逃跑，Whale 的车经过，Anna 在车里受到控制；James 看见她后退路被截断，在胁迫下自杀。她随后被送回医院，接送留在转场中。不能把她写成已经掌握厨房指证经过、听完后巷全部自白的人，也不新增她目睹死亡的精确视角。

## 医院情绪经过

她刚从昏迷中苏醒，首先会问 James 在哪。Zack 明确告诉她丈夫已经死了，并简短交代他杀了 Webb、看到她受控制后在胁迫下自杀。此前她不知道丈夫杀人、嫁祸或威胁 Rosa，关于这些事的困惑必须发生在获得基本事实之后。

她没有马上大哭，而是问恢复后能否工作、孩子由谁照顾、房租与吃饭怎么办，甚至询问临时机构照护以及以后能否探望、接回。说话看似务实，却可以没等回答又接下一件事、反复确认同一项开支，让吃力显出来。她尚未办理送养或托养，不把这些问题写成已经决定放弃孩子。

她想到欠 Zack 的钱，认真提出日后工作偿还。Zack 才拿出二十美元欠条交回，表示不必还。她看见 James 的名字，停住、攥紧纸，终于哭出来。情绪触发点是丈夫的字迹和不可挽回的缺席，不是免债带来的感动。

崩溃时允许断裂、重复，讲被绑走时的恐惧，问为什么丈夫杀了人、又为何一定要死。她不是替玩家总结案情，也不负责用痛苦为 James 免责。Emma 先靠近陪伴，Zack 等最强烈的一阵过去，再承诺两人继续追究幕后责任。她不会听完承诺立刻振作。

欠条留在她手里，不收回、不撕毁。陪伴之后，两人帮助询问照护事务，只得到有限信息与待核事项；不保证机构一定接收、孩子一定能随时接回。Tommy 到病房传达 Vivian 获释和返店邀请，发生在安慰与照护之后，不能打断她的崩溃。

## 关系与分轮状态

| 对象／阶段 | 关系落点 |
|---|---|
| James | 丈夫与即将共同养育孩子的人。她不知道其犯罪，不用“早有预感”冲淡新事实的冲击；即使知道罪行，失去亲人的痛也不会自动消失 |
| Zack | L3 已知其应急帮助并表达感谢，L5 是亲口带来死讯、交还欠条且愿意继续负责的人。感激不是无条件信任其能解决一切 |
| Emma | 医院悲剧中愿意靠近并接住她的人；接触顺序按实际同行状态，不让 Anna 假装 Emma 必然参加过此前每次谈话 |
| Vivian | 新版照护帮助由回酒吧后的私谈提出；Anna 留在医院，未在场听见，不恢复旧 L6 两人同室和解，也不提前收到尚未提出的承诺 |
| L1—L2 | 无独立出场，L2 从 James 的医疗需求认识她的存在 |
| L3 | 喜悦、感激与家庭期待；不露出预知惨剧的可疑停顿 |
| L4 | 无新增个人调查入口，不补写住宅搜查 |
| L5 | 受控制、昏迷后苏醒、得知死讯、勉力安排生活、攥欠条崩溃、获得有限陪伴。悲伤保持开放，不以一次安慰解决 |

## 声音与知识边界

她说话朴素，重点在眼前生活；不强制口音、倒装或每句省略号。平静时有完整回答的能力，悲痛时才随情绪破碎。旧档“永远不会情绪失控”不适用于新版欠条崩溃，但也不能从入病房开始就连续哭喊。

她不能说出保险柜密码、James 枪声安排、Whale 的真实身份，不能确认是谁为身份办理出面。旧“Anna 获批、James 配偶资格仍待审”已失效；住宅三件证物、私人物品许可、住宅作为调查通道均不再使用。原详细住址没有新版用途，不让她以此解锁已取消的场景。
