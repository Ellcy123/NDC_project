# Emma O'Malley｜五轮版完整人设

> 2026-09-17。独立适用于五轮版对白。基础身份与性格保留有据部分，关系进度、在场经历及揭示范围已改用新版。

## 基础身份与日常

约 25 岁，170 cm，爱尔兰裔，《艾斯弗德先驱报》记者。目光直接，追问时习惯向前探身，职业装束；随身记者证、笔记本、钢笔和蓝月亮会员卡。熟悉采访与摄影相关工作。没有足够来源的新私人爱好、家庭构成或住址，不自行补齐。

案前已经独立追查 Webb 数月，开篇有自己的调查目的。曾受到 Miller 基金资助，是理解 Rosa 困境的个人背景，L4 开篇按已定节点说明；不凭此扩写她的童年、资助缘由或与集团内部人物的亲属关系。

## 性格与内在张力

敏锐、直率，想要真相和好报道，愿意承认自己的职业追求。善于捕捉反常细节，常主动提出办法，不甘心只当 Zack 的陪衬。她也急躁，容易抓住疑点就希望对方立即回应，将追问推成争执；发现得准不意味着应对总成熟。

她重视具体的人，有保密和不伤害当事人的底线。Rosa 处境危险时能收起记录，放弃即时报道收益。对亲历死亡和遗属崩溃会害怕、无措，需要同伴支持；这与敢追问、敢挡路是同一个人的不同处境。

## 表达与行动

- 比 Zack 更外露，接话快、追问直接，发现被套话会不满，不必永远温柔理解。
- 可以调侃 Zack 的糖和不肯求助，回扣真实发生的合作经历；不凭空增添亲密回忆或默认恋爱关系。
- 情绪通过具体行动表达：收笔记、帮忙搬柜、挡路、靠近 Anna 陪伴。不是随时替玩家总结心情的旁白。
- 面对伤者先听对方说话，不把哭泣当成采访机会，也不急着用案件解释终止悲伤。
- 不继承旧档“前四轮从不争主导”“只能自愿退居次位”的限制；新版明确保留她的调查主动性与急躁。

## 五轮经历

| 阶段 | 所做之事与关系位置 |
|---|---|
| L1 | 帮 Zack 进入酒吧，提出合作但未谈成；尚不交代自己追查勒索的完整方向。现场被 Zack 擅借记者身份，临时配合不等于事先同意 |
| L2 | 对被利用不满，分开调查。小包厢被 Zack 套出调查方向，随后在搬柜时掌握主动、要求他配合。没有参加大厅借款，没有出钱，也未自动得知 Tommy 指证全部结果 |
| L3 | Zack 先到医院认识 James、Anna，自己不在初访现场；清洁间开箱后跟踪现身，争取并获准同行。Rosa 指证后主动保密，信任由此建立，尚未正式结伴 |
| L4 | Zack 主动分享后，说明帮助 Rosa 出于自身经历与同情，不是换线索。独立查 Rita，在办公室质疑私搜；可向 Zack 低声转述调查见闻。后续强押中急于要求 Morrison 回应而挡路，Zack 替她承担风险；Vivian 仍被带走 |
| L5 开篇 | 与 Zack 听 Whale 电话，不替玩家回答推理题。挂断后接受其正式邀请，回扣搬柜经历，交换姓名后称他 Zack；对方仍称 O’Malley 小姐，形成轻快回报 |
| L5 后续 | 随队调查、在合适节点提供观察。James 还原后的争辩中关注被牵连者及胁迫孩子的代价。后巷追赶失败后，在医院门外说出担忧，接受 Zack 支持；入病房陪 Anna 承受死讯，接下共同追查责任，再一起返店听唱片 |

## 关系与记忆范围

- Zack：能需要、支持他，也能反对他替自己做决定。L5 正式结伴后不再重复以扣留必要信息制造同一种矛盾；医院不是首次争取留下的节点。
- Rosa、Isabel：不以独家报道换取信任。答应保密属于人物承诺，不限制既定弹壳使用或另设取证条件。
- Rita：已搜集的点酒不喝、盯走廊、接触主顾来自对在场者的调查；不能改成亲眼见到其接受 Whale 指令。L4 的怀疑仍须玩家在 L5 电话中联系材料。
- Vivian：尊重其处境而不迎合错误认罪，强押时要求事实得到回应。末段由 Vivian 主动决定经营和提供有限照护，不能替她提前宣布。
- James、Anna：知道借款与家庭的时间依实际交谈而定，不把不在场的 L2、L3 初访说成共同经历。关注 Anna 的痛苦不消除 James 的责任。
- Morrison：会以职业身份周旋，更会因其不回应反证而急躁阻拦；媒体身份不自动赋予搜查权或阻止逮捕的特权。

## 作者边界与旧版清理

不安排 L6 Morrison 住所、警局或第二通 Whale 电话；不恢复已删除的分手信作为人物理解来源。L5 医院不写去 James 家、不写“你退出／我不走”重新确立搭档。Whale 真身、Lawson 亲属真相、完整唱片内容都不在 U1 由她揭晓。

小酒保呆憨喜剧方向不能转成所有角色持续讲笑话。Emma 在不同阶段的轻快、急躁、担忧与坚定必须跟随事件，不能只剩“总能接住 Zack 的完美搭档”。
