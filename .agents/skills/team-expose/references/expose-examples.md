# 指证案例：提炼优点与证明边界

2026-09-09 按现行 AVG、State 及道具表抽查整理。以下是局部设计参考，不是整场逻辑验收，也不代表已验证 Unity 当前运行效果。来源更新后按新原文复核；引用路径均相对仓库根。

## 第四章 L2 惠特菲尔德：三个问题各有证明任务

来源：`AVG/EPI04/Expose/L2_expose_whitfield.json`、`剧情设计/Unit4/state/loop2_state.yaml`；道具 `4702 / 4219 / 4703 / 4214`。

| 轮次 | 待反驳说法 | 主要证明材料 |
|---|---|---|
| R1 | Rosa 在十三日规定用药外多打了一整针 | 药瓶实际消耗量，结合规定剂量等已知前提 |
| R2 | Isabel 是唯一一例特殊事故 | 五年七例儿童死亡病例对照 |
| R3 | 药物异常在家庭保存期间形成，与医院发放品质无关 | 医院官方留样化验与采购发放对应记录 |

可提炼：后轮事实与前轮谎言可以同时成立，因而不能直接替代答案。其他孩子死亡、药物存在风险，都不能直接证明 Rosa 没有额外加量；药物有风险也不等于已发生多起同类死亡。每次退守保住的是另一项仍未被排除的解释。

边界与待修：
- 用量材料只能支持其具体测量结论，不应扩大成排除微量偏差、换瓶或所有误用。
- 若 R3 泛称所有异常都在家庭手中形成，医院留样单件已可能反驳，采购记录便有冗余风险。只有题面及已知信息使“留样与 Isabel 用药的联系”成为必要环节，双件才有分工。
- 检查道具全部可读内容：留样美术需求本身已有批号，不能只看正文而假定必须另一份记录才能建立关联。
- 七份病例不能自动证明七人同批次、同配方或同一死因；现行成功对白存在扩大概括，不能照搬。

## 第三章 L1 Morrison：把后轮证据拿到前轮试交

来源：`AVG/EPI03/Expose/Expose_L1_morrison.json`，R1 错误分支 `317001、310010—310013`；R2 断言 `310046`。

R1 坚称 Thomas 自己跳楼。提前出示 R2 的女性脚印时，NPC 回应：“就算有个女人上去过，也证明不了他不是自己跳下去的！”R2 改称“根本没有其他人留下的痕迹”后，脚印才反驳这条具体断言。

可提炼：失败理由说明“有人到过”和“没有主动跳楼”之间缺少因果联系。玩家可以理解同一材料为什么此时无效、稍后有效。把这种跨轮试交纳入设计自检，但无需为每张无关卡都制作专属失败演出。

边界与待修：R1 成功对白声称主动跳楼必然向外抛、不能贴墙留下抓痕，论证过满；R2 痕迹时间及人物归属也需真实材料支持。失败反馈写得合理，不等于标准答案已经充分。

## 第三章 L5 Bernard：同一个载体，两个不同事实

来源：`AVG/EPI03/Expose/Expose_L5_bernard.json`、`剧情设计/Unit3/state/loop5_state.yaml`；道具 `3570 / 3502`。交叉试交见 `357301、350026—350030` 与 `357401、350047—350052`。

| 材料 | 支持的有限事实 | 不能直接证明 |
|---|---|---|
| Thomas 标注报纸与垫板压痕比对 | 那份报纸在 Bernard 桌上写成 | Bernard 教唆杀妻、存在另一位访客 |
| 花形手链压痕 | 戴这种手链的人与桌面发生接触，提示其他到访者 | Thomas 的笔迹由谁指导、来访者具体咨询内容 |

可提炼：两轮不必更换道具类型。关键是物理特征对应不同事实，前后互换时都能明确指出证明缺口。

边界与待修：现行 R1 把书写地点推成主动教唆，超出了比对报告；R2 的“没有其他人来问过这种处理方式”也比手链接触痕迹更具体。NPC 随后承认的咨询内容是新供述，不能倒填成玩家提交前已知的前提。此案例只用于学习材料分工和跨轮试打。

## 第一章 L4 Vivian：情感递进不等于谜题独立

来源：`AVG/EPI01/Expose/Loop4_vivian.json`，`106904005、106904014`；`剧情设计/Unit1/U1_指证唯一性专项审查_20260905.md` 第 6 节。

R1：“我和 Webb 不是恋人。我只是他勒索别人的工具。”R2：“就算关系没有结束，我们之间也早就没有爱了。”

R2 用 Webb 的信与委托材料反驳“没有爱”。按本场接受的书证效力，那封信也能提前攻击 R1 的“只是工具”。不能前轮否认它的意义，后轮又把同一意义当作决定性证明。

可提炼：先区分可验证的关系事实、表达行为与内心状态。情感层层深入可能适合演出，但不自动支持拆成多道提交题。材料若总能同时解决前后两题，考虑合并，情绪推进留在连续对白里。

边界：信件与遗产安排可证明写过、表达过、安排过什么，不排他证明双方当下仍相爱；未寄分手信不排除通过其他方式分手。

## 如何使用案例

为新题写出真实断言与材料正文，再逐格试打。不要把“用量 → 个例 → 保存”“地点 → 到访者”复制成固定轮序，也不要为了复刻案例而新增剧情事实。需要更完整的交叉多解、子集多解和材料池判定方法时，读取上述 Unit1 专项审查第 2、9 节；其历史工程核查结论应对照本次实际版本验证。
