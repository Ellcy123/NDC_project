# 五 Loop 试验版 L1 制作合同

本次制作属于 Unit6 / EPI06 的试验版。依据《U1_五Loop场景与对话删改详细方案》第 0、2 节以及用户已经确认的对白要求：英文人名、中文口语、不写动作括注，整轮完成并接入原 avg_editor_v2 统一表。正式 Unit1 不修改；L2 已有对白不重写。

## 本轮因果与人物

Zack 应 Webb 的信约而来，尚未见到本人、也未取得正式协议。Emma 刚在门外接近他；线人给过她口令，她正在调查 Webb，需要接近知情人的机会。两人在大堂谈妥初步合作；随后听见 23:30 的枪声，到会客室看见 Webb 倒地、Vivian 持枪，Rosa 已经在场，Morrison 随后到达并宣布 Webb 死亡。

Emma 与 Zack 从陌生到临时合作，始终称姓或先生／小姐，不写成老搭档。Morrison 不新增与 Zack 的旧交故事，也不泄露保护伞、债务或幕后人物。他可以抱怨，但会维护现场和自己的办案决定。Rosa 怕承担责任，抓着眼前所见不肯退；不主动解释胁迫和女儿。Vivian 恍惚、难以集中注意力，但能说短句；不反复用失忆打发每个问题，不给清晰扣扳机记忆。她确实想杀 Webb 的设定保留，L1 不展开其计划、私情或完整动机。

语气以当前 L2 最近一轮自然衔接的写法为校准。不要强行让每句话互怼、每段都有讽刺；下一句必须接住上一句。人物界限靠选择、拒绝和措辞表现，不新增身世段落。未命名门卫只标“门卫”。

## 场景包与运行连接

1. 门外 `entrance`：门卫挡住 Zack，Emma 说出口令带人进去。口令使用既有的 “King Oliver from Ashford sent us.”，不能推成二人真的认识 King Oliver。
2. 大堂前置交谈：`lobby_intro` 后交还主题选择，Emma 仅有 `emma_connections`、`emma_terms` 两题，分别是进门门路／主动帮忙与合作条件。两题都回同一个菜单；“结束交谈，去找 Webb”进入 `cooperation_close`，不增加第三题。固定收口无论前面选过哪题，都明确临时合作与基本界限，并交代委托信提到遗产事务、受益人为 Vivian Gray、正式协议尚待取得。不能把某个可跳过的主题当作所有玩家已听过的前提。
3. `gunshot` → `discovery`：固定枪声与发现现场，期间无普通分支。用简短人物台词承载枪声、来源方向、时间、持枪与死者，不加动作文字。到场时只见结果，不让任何人补出亲见扣扳机。Morrison 让 Vivian 把枪留在桌上，确认其身份与死亡，允许 Zack 在现场查看物件、问话，不能先当场给出枪检答案。进入会客室自由调查。
4. 会客室：Rosa、Vivian、Morrison 各两题，任意先后，初访和复访回各自同一个菜单。Emma 随行，只参与取物或固定段，没有新菜单。可查看原枪、检查原枪、取得委托协议。原枪检查是物品分析；不是问 NPC 自动交付检查结论。
5. `expose_open` → `expose_lie` → 唯一一次选证 → `expose_success` → `negotiation` → `ending`。`expose_wrong` 独立预览并返回本题，不替玩家指出正确卡。只有 `ending` 最末句执行 loop_end；枪检通过后不再出现第二次答题。

本地网页仍是原有配置与对白预览，不在此任务中补一套独立玩法引擎。场景分段、主题回流、分析关联和选证配置必须明确挂在统一表，不靠单独网页文件隐藏实现。

## 指证与 L2 接缝

唯一谎言与 rosa_claim 完全同义，最好逐字相同；不得变成“她不可能无辜”“我亲眼看见她开枪”等更宽论点。唯一提交 gun_check。枪管、枪膛、弹匣的检查描述沿用项目已设结果，不添加现代化检验设备、新化学程序或第二份临时报告。

正确提交后，Rosa 退守“我看见她拿着枪，枪声也响了”；Morrison 接受对这把枪的检查，仍要问清真正枪击及其他可能。不能说“没有别的枪”，不能从一把枪没击发推出 Vivian 没杀意、没有参与、没有换枪。即使谈到换枪，也只作尚未排除的可能，不增加实际证据。

negotiation 使用已经调查取得的协议说明 Zack 的来意，依靠枪检暴露的缺口与需要补查的事实争取 72 小时。不能讲委托书给予免捕权、能阻止警方讯问，不能替未知幕后动机下结论。Morrison 允许继续调查，同时保留对 Vivian、Rosa 的问话。

ending 留在酒吧内收束：Morrison 单独问话，Vivian 仍被警方占用；Zack 和 Emma 转去查 Webb 的生意。接 L2 街角开头的“又在问 Gray 小姐”，而非 Vivian 已获释或已被带离酒吧。不得让下一轮 NPC 提前登场，也不出现 Lawson、Whale、Tommy/Vivian 私情、Rosa 胁迫原因。
