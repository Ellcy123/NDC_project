## L3 银行贵宾室：破产银行的战利品墙

类型：环境道具 / 可点击 OS  
场景：银行贵宾室，或 Moore 办公室 / 档案室边缘  
状态：新增需求。

时代背景依据：
1920 年代美国银行危机并不是 1929 年才突然发生。1921、1926、1928 前后已有大量银行停业。Moore 可以被塑造成“在银行尸堆里活下来的银行家”，不是单纯的地方银行反派。

道具内容：
- Moore 办公室或贵宾室墙上挂几块旧铜牌。
- 它们不是荣誉奖牌，而是被他收购、吞并或清算的小银行名牌。

建议铜牌名称：
- South Ward Savings
- Ashford Mutual Building & Loan
- St. Casimir Loan Society
- Workers' Home Trust

叙事功能：
- 补充 Moore 的银行家人设。
- 让玩家意识到 Moore 不是只压迫 Frank 的个体恶人，而是擅长在金融崩塌中吞吃残骸的人。
- 与 L3 掠夺性贷款、双重机构、投资公司马甲形成同一组金融恐怖感。

## L2 / L3 / L5 银行大厅：月度纪律公告板

类型：环境道具  
场景：湖滨信托银行大厅  
状态：新增需求。

道具内容：
- 银行内部公告板。
- 上面贴有“本月岗位调整”“纪律处分”“账户误差追责”等公告。
- 几名员工名字被红线划掉。
- Leonard 的名字在“贷款部绩效榜”上排中间偏后。
- Bernard 也在榜上，排名靠前。

叙事功能：
- 补充 Leonard 的动机和恐惧。
- 让玩家直观看见 Moore 银行内部也是一套高压淘汰系统。
- 让 Leonard 后续对职位、体面、升迁的执念有更早的环境伏笔。

挂载建议：
- L2 玩家首次进入银行大厅时可作为背景道具出现，但不宜过度解释。
- L3 持令状进入银行时最适合点击，玩家已经开始关注银行内部制度。
- L5 若仍回银行，可作为重复出现的压迫性背景。

## L2 / L3 / L5 银行贵宾室：被开除员工工牌盒

类型：环境道具  
场景：银行贵宾室 / Moore 管理区域  
状态：新增需求。

道具内容：
- 一个旧铁盒里整齐收着被回收的员工工牌、柜员名牌、抽屉钥匙牌、工位小铭牌。
- 每枚牌子贴着小纸条，理由冷冰冰：
  - 账目误差
  - 流程违规
  - 不适任
  - 泄露客户信息
  - 试用未通过

叙事功能：
- 补充 Moore 把“人”当成可替换编号的管理方式。
- 与月度纪律公告板一起，让 Leonard 的恐惧不是口头解释，而是空间里已经存在的制度。
- 也呼应 Moore 后续把 Leonard 当作可丢弃执行人的态度。

## L2 / L6 Silver Moon 赌场：TideWater 低价租赁文件

类型：证物 / 宏观阴影线索  
状态：原表写作 L5 “低价租赁回执”；按后续已确认设计，调整为 L2 未签草案 + L6 正式交接，L5 不再放置。

L2 版本：
- 放在 Silver Moon 角落小桌或抽屉夹层。
- 不是正式回执，而是未签的 TideWater 低价租赁草案 / 意向书。
- 抬头为 `Tidewater Development Co.`
- 内容写得干净：北区办公楼部分楼层，办公室、附属活动场地、仓储。
- 承租方未正式签名，只留下模糊的 `W.` 或“等 W. 点头”。
- 页角有脏活暗示：场务人手另算，不走租赁账。

L2 信息边界：
- Tony 看起来仍像“不知道 Whale 是谁”的酒保。
- 他只知道上面有人安排合法壳，不知道全局。
- 这一步让玩家意识到 Silver Moon 被 TideWater 这种地产公司接入，但不解释全貌。

## L6 Leonard 家：Miller 慈善舞会座位牌

类型：环境道具 / 可点击 OS  
场景：Leonard 家  
状态：新增需求。

道具内容：
- 一张 Miller 慈善舞会座位牌。
- 原本印着 `Mrs. Leonard Ross`。
- Edith 用带香槟金粉的化妆笔把 `Leonard Ross` 划掉，在旁边改写成 `Edith Whitfield`。

美术描述：
- 厚卡纸边缘烫金，印刷字体端正。
- `Mrs. Leonard Ross` 中的 `Leonard Ross` 被香槟金手写痕迹划去。
- 旁边补上 `Edith Whitfield`。
- 牌角有一点香槟渍和细亮粉，像是晚宴后随手塞进包里带回来的。

叙事功能：
- 补充 Edith 对 Leonard 的长期不满。
- 让她的阶层焦虑和“把 Leonard 当成通往体面的工具”更早具象化。
- 与 L6 她在 Leonard 快崩溃时优先考虑离婚、资产和社交名声形成闭环。

## L6 Leonard 家：被清洗失败的昂贵西服

类型：环境道具 / 证据气氛强化  
场景：Leonard 家衣柜  
状态：新增需求，可与终局指证中 Edith 提到“沾血西服”的突发事件互相呼应。

道具内容：
- 衣柜最里面挂着一套深灰西服。
- 内侧绣着高级定制品牌 `Maison Valette`。
- 剪裁克制而昂贵，像专为银行办公室和董事晚宴准备。
- 胸前羊毛被反复清洗到发毛，仍残着一片洗不净的暗褐色血迹。

叙事功能：
- 提前让玩家在 Leonard 家搜证时看到他试图处理痕迹。
- 与终局指证中“货物箱凹陷 + 西装纤维 + Edith 揭穿沾血西服”形成视觉闭环。
- 强化 Leonard 的体面崩塌：他最重视的阶层外壳，最终留下了犯罪痕迹，但因为舍不得舍弃，只能尽力清洗，却仍然无法洗掉那一片血迹。
