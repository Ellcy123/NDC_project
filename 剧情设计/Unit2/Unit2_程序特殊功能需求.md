## 2. 新增通用功能：对白、门和物品中出示道具

### 2.1 需求

新增统一的“出示 / 使用道具”交互界面。系统可以由以下两类入口调用：

1. **对白入口**：某句对白要求玩家出示许可、证据或工具。
2. **场景入口**：玩家点击门、容器或其他交互物后，选择背包道具进行使用。

### 2.2 主流程需要的能力

- 打开玩家背包中的可出示道具列表。
- 配置一个或多个正确道具 ID。
- 支持取消；取消后回到原对白节点或原场景，不改变状态。
- 选错后播放配置的提示或短对白，再回到出示界面或原交互点。
- 选对后把结果返回给调用方：
  - 对白继续到指定 Talk 节点；
  - 门或场景交互物进入已解锁 / 已使用状态；
  - 按配置决定道具保留还是消耗；
  - 按配置决定是否发放新物品、显示新物品或解锁新场景。
- 成功状态需要保存；读档后不得要求玩家重复出示，也不得让已开启的门重新锁上。
- 同一界面同时服务“出示证件”和“对物体使用工具”，不为每扇门或每件工具制作独立面板。

### 2.3 Unit2 使用点

| Loop | 使用点 | 预期行为 |
|---|---|---|
| L3 | 向银行相关人员出示合法许可 / 调查文件 | 正确文件继续对白或开放调查范围 |
| L4 | 对地下室门出示 2308 钥匙 | 门永久解锁，钥匙默认保留 |
| L4 | 对 2409 枯玫瑰使用 2410 水杯 | 进入玫瑰互动玩法 |
| L6 | 出示 2607 搜查令 | 开放 Leonard 住所或对应搜查范围 |
| L6 | 对柜面缝隙使用 2603 镊子 | 进入镊子取镜片互动并获得 2605 |

### 2.4 验收底线

- 正确、错误、取消三条路径都能回到明确状态。
- 错选和取消不消耗道具。
- 成功结果只能提交一次。
- 对白入口完成后能够准确续接原 Talk 链；场景入口完成后能够准确刷新门或物品状态。
- 存档 / 读档后，已完成状态与背包结果一致。

## 3. 新增功能：L1 可配置限时搜证

### 3.1 需求边界

- 倒计时时长必须由配置决定，不得在程序中写死；U2 L1 当前实例配置为 300 秒。
- 同一套功能应允许其他事件配置不同的限时时长。
- 鞋坊两个搜证区域共用同一份倒计时配置和剩余时间。
- 仅玩家处于可操作的搜证状态时计时；对白、全屏演出、设置界面、程序失焦和切场加载期间暂停。
- 必需证据收集齐后允许提前完成，不必强制等到五分钟结束。
- 超时但必需证据未齐时，从限时搜证开始前的检查点重试，不永久移走尸体，不造成证据缺失软锁。
- 倒计时成功或超时结算只能提交一次。

### 3.2 配置内容

每个限时搜证事件至少需要配置：

- 限时时长；
- 共用计时的场景范围；
- 必需证据列表；
- 成功后的 Talk / 场景或阶段；
- 超时后的 Talk / 场景或重试检查点。

调整限时时长时，不应修改代码或重新制作玩法界面。

### 3.3 存档

程序需在以下两种方案中选定一种并保持一致：

- 保存剩余时间、已取得证据和当前搜证阶段；或
- 限时搜证中禁止常规存档，退出后从开始检查点重来。

不可出现读档后尸体已移走、必需证据却尚未获得的状态。

## 4. 小玩法与互动玩法接入约定

Unit2 小玩法均由程序单独处理，玩法规则见对应文档。主流程只要求统一的接入结果：

- 能从物品分析、场景物品、普通 Talk 或 Expose Talk 启动指定玩法。
- 启动后暂时锁定原界面输入。
- 玩法完成时返回成功结果，并续接指定 Talk、发放物品或改变场景状态。
- 玩家取消或玩法失败时返回明确入口，不得把主流程推进到成功节点。
- 一次性奖励必须幂等；重复进入不得重复发放。

### 4.1 Expose 内嵌互动

诱导招供发生在 Leonard 指证流程内部。Expose 需要支持：

- 暂停在当前指证节点并启动互动 Overlay；
- 成功后续接指定下一节点；
- 取消 / 失败后回到当前轮的入口或重试点；
- 互动期间屏蔽底层指证按钮；
- 不重复发放物品，不提前提交本轮指证成功。

玩法内部规则由各玩法文档定义，不在本文展开。

## 5. 不需要新增程序的内容

### 5.1 L2 银行大厅偷听

采用纯 AVG 方案：

- Scene 2211 首次进入时自动播放 `207002001`；
- Danny、Leonard、Zack 的出现和离开由 Talk 说话人、立绘和动作表现完成；
- 不要求 Danny 成为银行探索场景中的常驻可点击 NPC；
- 偷听结束后切入 Leonard 的正常问话；再次点击 Leonard 不重播偷听。

当前正式配置仍是“点击 Leonard 才开始”，并且通往贵宾室的门可绕过偷听。这属于配表修正，不是新增程序系统。

### 5.2 L2 Tony 调酒问答

- 选错：Tony 阴阳或挖苦两句，然后 `next` 回到原分支节点。
- 选对：继续正确链。
- 不需要答题系统、失败状态或新 UI。

### 5.3 L5 律师坏结局

- 选择律师路线后播放完整演出。
- 演出结束回到原选择点，让玩家重新选择律师 / 侦探路线。
- 回选时不重播开盒，不回滚已获得或已移除物品，不重置一次性事件。
- 普通 Talk 分支和全屏视频回调能够表达该流程；资源完成后配表。

## 6. 已裁定：L6 镜片三方比较

### 6.1 剧情含义

当前剧情含义：

1. 2605 是鞋坊现场取得的左眼烟熏色旧镜片碎片。
2. 2610 维修单记录 Leonard 在案发次日更换了破失的左眼旧片，右眼旧片没有更换。
3. Leonard 当前佩戴的右眼旧片，与现场碎片在材质、颜色和磨损上属于同一副镜片。

该步骤不产生新物品，作用是证明 2605 属于 Leonard，使他从“碎片不是我的”退守到“我去过，但只是和平拜访”。

### 6.2 表现方案

- 采用当前线性 Talk。
- Zack 展示 2610 维修单，并在对白中说明“左眼破失记录、现场左眼碎片、右眼同副旧片”的对应关系。
- 玩家不进行拖拽、热点点击或额外选择。
- 对白结束后按现有指证链进入 R3“和平拜访”的退守。

该段不新增 UI 或玩法程序，不计入独立玩法开发量。
