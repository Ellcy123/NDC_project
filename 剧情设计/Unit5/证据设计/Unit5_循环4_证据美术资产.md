## 证据详细卡片

### 5401 倒下的 E-12 酒杯 / clue_e12_fallen_glass

- 类型：Clue（拍照取得；L4 洗清 Emma 的输入）
- 位置：SC5022 后台录音室，Emma 失去行动能力的起点。
- 推理用途：锁定只有 Emma 使用的 E-12 残液检出足以使人失去行动能力的安眠药痕迹；不判断投药者。
- 美术需求：
  - 酒杯必须倒在录音室地面，杯号 `E-12` 清楚可辨；杯号采用何种标签或刻记方式需与宴会杯具设定统一。
  - 杯中保留少量残液，但画面不能直接画出药粉、药片或投药动作。
  - 场景原物保留；背包证据表现为现场勘验照片或等价调查画面。
  - 与 5402 的拖痕起点保持同一空间位置，不能把 E-12 移到舞台侧翼或 Mary 房间。
- 美术参考：1920 年代宴会玻璃杯、案发后散乱但未被清理的录音室地面；重点是杯号与倒伏位置，不用夸张毒液色。

### 5402 录音室至舞台的跨血拖痕 / clue_recording_room_drag_trail

- 类型：Clue（拍照取得；L4 洗清 Emma 的输入）
- 位置：从 SC5022 后台录音室延伸，经舞台后台到舞台正面。
- 推理用途：证明昏迷的 Emma 在致命喷溅形成后才被从杯旁拖到尸体附近；不指认拖行者或投药者。
- 美术需求：
  - 拖痕起点紧邻 5401，宽度、连续擦抹纹理和残留礼服纤维须与 L1 的 Emma 礼服背面血迹一致。
  - 路径要明确跨过已经形成的致命喷溅血区，再延伸向舞台正面。
  - 不绘制从舞台正面返回录音室的反向痕迹，也不增加第二条拖痕。
  - 建议准备路线全景和关键交叉点近照；最终构图应让玩家读出先后关系，而不是用箭头直接写出结论。
- 美术参考：木地板／后台地面上的连续织物拖擦痕、局部纤维和干湿层次；血迹色调、干燥程度须与 L1 现场统一。

### 5403 心脏病药剂盒 / item_heart_medicine_package

- 类型：Item（关键，L4 R1 正常药物外观）
- 位置：SC5023 护士站。
- 推理用途：与 5404 对照，证明老 Charles 当晚吐出的整剂不是平时服用的药。
- 美术需求：
  - 包装图像中的正常药片必须清楚表现为蓝色。
  - 包装文字不得直接写“蓝色药片”，颜色判断必须来自图像。
  - 药品名称、厂牌、剂量、盒体尺寸和完整英文说明尚未锁定，不能自行编出影响剧情的医学信息。
  - 包装形式保持 1920 年代药品感，避免现代铝塑泡罩、条形码和现代警示图标。
- 美术参考：旧式纸盒或药房包装标签、有限印色、医学图示；蓝色药片图像是唯一必须高辨识的颜色锚点。

### 5404 手帕中的两片紫色药物 / item_two_purple_tablets

- 类型：Item（关键，L4 R1 实际弃药）
- 位置：SC5021 老 Charles 书房，5455 废纸篓深处。
- 推理用途：两片紫药与正常蓝药不一致；本轮不能确认药性或与 E-12 同源。
- 美术需求：
  - 一块被揉拢或包裹过的手帕中放着两片近乎完整的紫色药物，数量必须固定为两片。
  - 两片均不能画成明显被吞服、溶解或严重碎裂的状态；可有轻微表面磨损，但不改变“近乎完整”。
  - 紫色与 5403 的蓝色必须在游戏实际显示尺寸下仍能明确区分。
  - 不出现“安眠药”“毒药”或成分标签，不以图形暗示其药性。
  - 手帕与老 Charles 弃置行为相容，但花纹、姓名绣字和归属均未锁定。
- 美术参考：旧式压片药、素色织物手帕、废纸间被隐藏的小体积物件；重点是数量、颜色和完整程度。

### 5405 TideWater 毒杀文件 / item_tidewater_poisoning_order

- 类型：Item（1928 年南区投毒安排原件）
- 位置：SC5019 夹层文件柜区域。
- 推理用途：调查期把 1928 年投毒安排与 TideWater 相连；终幕法庭才证明签名实际为小 Charles 仿写。
- 美术需求：
  - 这是后续法庭继续使用的同一份原件，不制作第二份“真正版本”。
  - 文面必须能够辨认 `1928`、TideWater 归属、南区投毒安排，以及一处看似属于老 Charles Miller 的签名。
  - 调查期签名必须自然可信，不能预先画出红圈、笔画异常、伪造批注或双重署名。
  - 纸张、折痕、归档孔和旧污渍保持一致，后续法庭鉴定只能在这张原件上叠加比对材料。
  - 完整命令正文、具体日期、地址、剂量、编号和签名式样均待文字设计锁定。
- 美术参考：1920 年代公司内部打字文件、钢笔签名、归档章与长期封存痕迹；整体看上去应像一份可被误读为老 Charles 签发的正式文件。
