## 证据详细卡片

### 5101 Emma礼服背部的擦抹血迹 / clue_emma_dress_smeared_blood · L4

- 类型：Clue（现场记录，可收集；L4复用）
- 位置：SC5005舞台正面，复核案发开篇的衣物记录；Emma本人已经移至客房。
- 推理用途：本轮只留下“背部血迹不是站立飞溅”的异常，L4才与拖痕和餐刀握姿一起说明她被移动、摆放。
- 美术需求：
  - 画面主体是Emma礼服背面局部，血迹呈连续擦抹和织物受压后的拖曳方向，不画成放射状飞溅。
  - 记录图应保留礼服布料纹理，使“擦过表面”可读，但不能出现拖行者、拖行路线或凶手影像。
  - 本轮描述不锁定礼服颜色、材质、血迹面积和精确方向；须跟Emma正式服装设定统一，未冻结前不得自行定数值。
- 美术参考：法证衣物局部记录照；光线中性、尺度克制，重点落在血迹边缘与布料被抹开的形态。

### 5102 礼堂唯一正常入口勘验页 / item_auditorium_entrance_survey · L2

- 类型：Item（纸质勘验记录，可收集；L2复核）
- 位置：SC5009礼堂入口走廊，正式勘验夹内。
- 推理用途：固定礼堂的正常出入只经过该廊道和一扇门，发现时门从内部上闩；它不能证明不存在尚未发现的暗道。
- 美术需求：
  - 一页案发现场勘验记录，图示只表达“廊道—礼堂正门—礼堂内部”的正常通行关系。
  - 正文需清楚读出“唯一正常入口”和“发现时内部上闩”两项事实。
  - 不画隐藏夹层、A位顶板、暗门或任何未知出口；不能把“正常入口”排版成“唯一入口”。
  - 页面尺寸、纸张规格、记录机构抬头和签名人均未锁定，待配置阶段统一。
- 美术参考：1920年代现场勘验夹页，铅笔简图与打字/手写记录并存，纸张有使用痕迹但不遮挡关键词。

### 5103 巡逻警员右侧口袋里的手卷烟草 / item_patrolman_right_pocket_tobacco

- 类型：Item（可收集，L1指证R1关键）
- 位置：SC5012安保室；必须先完成巡逻警员普通问话，再调查其制服右侧口袋及取烟动作。
- 推理用途：与巡逻警员自然使用右手相互印证；镜中看起来像“左手抽烟”的人其实可以是右手取烟的巡逻警员。
- 美术需求：
  - 场景状态必须让烟草明确位于制服右袋，人物动作明确为右手从右袋取出。
  - 背包特写表现手卷烟草本身及来自右袋的调查语境；不要在物件上写“Morrison”或制造亡者归属。
  - 包装品牌、纸袋尺寸、烟丝颜色等未锁定，以符合年代的无品牌或弱品牌烟草包处理，最终样式待美术确认。
- 美术参考：朴素纸包手卷烟草、制服口袋日常磨损；动作自然，不做“关键证据发光”式强调。

### 5104 Pierce巡更打点纸带 / item_pierce_patrol_punch_tape

- 类型：Item（纸带记录，可收集；L1指证R3关键）
- 位置：SC5012安保室，巡更打点机内/旁。
- 推理用途：固定Pierce唯一一次低头签字打点共十四秒，再与镜后路程口供比较。
- 美术需求：
  - 窄幅连续纸带或与巡更机匹配的记录载体，清楚保留一处可核算为十四秒的签字/打点区段。
  - “十四秒”必须可读，但不得额外新增具体钟点、其他异常停顿或第二段离岗记录。
  - 打点机结构、纸带宽度和印记格式未锁定；先保证与安保室载体一致，再由美术确定年代化细节。
- 美术参考：机械巡更钟纸带、墨点/压印与短促手写签名；纸张细长、边缘有卷曲。

### 5105 Lawson所持监印照片 / clue_lawson_seal_photo · 后续监印链

- 类型：Clue（拍照收集；实体不转移）
- 位置：SC5006圆桌会议室；Lawson展示实体后立即收回，玩家只保存照片。
- 推理用途：记录随TideWater档案责任交接而来的监印及表面纹样。本轮不知道它对应哪里，不能称钥匙或入口。
- 美术需求：
  - 证据画面必须明确是对实体监印的现场照片，而非玩家取得原物。
  - 监印正面纹样需要稳定、可在后续同物回收时一致；外轮廓和比例一经定稿不得跨Loop漂移。
  - 不加入钥匙齿、房号、箭头、门形符号或“档案室/套间”文字等用途提示。
  - 具体材质、尺寸、颜色和纹样尚未由来源锁定；必须先与后续监印链统一设计，再制作本照片。
- 美术参考：低调的旧式实体印记工具/监印物件证物照；桌面临时拍摄感，纹样清楚但用途不可猜定。

### 5106 湖滨信托夜间止付密电 / item_lakeside_trust_stop_payment_wire · L3

- 类型：Item（通信文件，可收集；L3复用）
- 位置：SC5013安保与通讯室，通信台碳写发送联。
- 推理用途：证明21:38已经有人把老Charles登记为死亡并要求冻结当夜交易；本轮只留下夜间授权号M-7，L3才确认授权人。
- 美术需求：
  - 碳写发送联需清楚显示收件方“湖滨信托”、发送时间“21:38”、冻结当夜交易、老Charles已死亡以及授权号“M-7”。
  - 纸面可表现复写压力不均和通信台夹痕，但关键内容必须可读。
  - 不出现Moore姓名、签名、职位或可直接对应M-7身份的标识；线路中断也不能改写成“发送失败”。
  - 表格抬头、精确纸张尺寸和非关键正文未锁定，禁止擅自补写会影响推理的新句子。
- 美术参考：1920年代电报/电传发送联、薄碳纸复写、机械打字与手填授权栏。

### 5151 舞台上的尸体与Emma / envir_stage_body_and_emma_record

- 类型：Envir（环境叙事，不收集、不进背包）
- 位置：SC5005舞台正面；以开篇现场记录回看，Emma当前不再躺在舞台。
- 推理用途：只固定Emma昏迷在尸旁、手握与伤口吻合的餐刀；不能排除有人更早离开。
- 美术需求：
  - 现场记录中老Charles位于舞台门槛外，Emma昏迷在附近并握刀，构图需与开篇演出站位完全一致。
  - 刀与伤口的对应可读，但不能通过握法、血迹或构图提前直接宣布“摆放”。
  - 不增加第二个人影、暗道开口、拖行全路线或凶手离场方向。
- 美术参考：案发后克制的现场全景记录；视觉重心是“最方便的嫌疑画面”，但保留可被后续推翻的空间。

### 5152 舞台麦克风 / envir_stage_microphone

- 类型：Envir（环境证物，不收集、不进背包）
- 位置：SC5005舞台正面，线缆沿舞台边缘通向后台录音室。
- 推理用途：建立舞台与后台录音室的物理线路关系，不证明麦克风是否启动，也不证明录到任何声音。
- 美术需求：
  - 一支符合晚宴舞台演讲用途的有线麦克风，线缆走向连续、最终消失在通往后台录音室的方向。
  - 不设置亮起的工作灯、通电指示、转动卷盘、录音波形或“REC”字样。
  - 型号、支架高度、线缆长度尚未锁定；与舞台正式场景比例统一即可。
- 美术参考：1920年代碳粒式/早期广播麦克风的厚重外观；舞台道具感强，但不做现代录音设备。

### 5153 绣有“E.F.”的白色医用手帕 / envir_ef_white_medical_handkerchief

- 类型：Envir（可选观察，不收集、不进背包、不计进度）
- 位置：SC5005舞台正面，Foster尚未完成的伤情记录旁。
- 推理用途：只建立“E.F.属于Foster”的视觉记忆，并决定终幕谜题A的关系提示资格；不说明日后用途。
- 美术需求：
  - 干净、白色、具有医用感的折叠手帕，一角绣有清楚但克制的“E.F.”。
  - 必须与Foster未完成的伤情记录同框或明确相邻，方便玩家先辨认归属再进入关系选择。
  - 本轮不能出现包扎痕、血迹、撕裂、钥石或未来使用状态。
  - 尺寸、织法与绣线颜色未锁定；首要保证白色基底与缩写可辨。
- 美术参考：素色棉/麻医用手帕，整洁、实用，不做华丽蕾丝私人饰品。

### 5154 可旋转的镜子 / envir_corridor_pivot_mirror · L2

- 类型：Envir（可操作环境证物，不收集、不进背包；L1指证R2关键）
- 位置：SC5009礼堂入口走廊正中央。
- 推理用途：玩家旋转镜面后验证：正常角度照礼堂门，偏转后会照见衣帽间门和继续离开的巡逻警员方向。
- 美术需求：
  - 镜体必须有明确转轴结构，并至少支持正常角度与偏转角度两种场景状态。
  - 两种反射构图要保持空间几何可信：偏转后能把衣帽间门误读为礼堂门，并把离去警员的右手动作镜像成左手。
  - 不在镜后增加暗格、脚印、凶手倒影或转镜者痕迹。
  - 镜体尺寸、转轴形式和偏转角度需结合最终走廊白模确定，目前不锁具体数值。
- 美术参考：庄园公共走廊中的大型落地/壁装转轴镜，深色木框或金属轴与整体装修统一。

### 5155 礼堂正门 / envir_auditorium_main_door · L2

- 类型：Envir（环境观察，不收集、不进背包）
- 位置：SC5009礼堂入口走廊。
- 推理用途：固定正常入口发现时从内部上闩，以及供镜面误认的真实参照。
- 美术需求：
  - 深色木门、黄铜把手，门槛有清楚的横向铜条；内部门闩状态需在调查特写中可读。
  - 门的整体轮廓要与衣帽间门在远距观察时足够相似，但门脚不能有衣帽间的浅色补漆。
  - 不加入第二出口标识、钥石孔或暗道结构。
- 美术参考：1920年代庄园礼堂双扇或单扇门的具体形式尚未锁定；以当前场景白模和入口宽度为准。

### 5156 衣帽间门 / envir_cloakroom_door · L2

- 类型：Envir（环境观察，不收集、不进背包）
- 位置：SC5009礼堂入口走廊，同一巡逻路径上的远端。
- 推理用途：作为镜面偏转后的误认对象；门脚浅色补漆是区别礼堂正门的唯一已锁定视觉点。
- 美术需求：
  - 远距轮廓、深浅关系与礼堂正门相近，使低照明和镜中观察下可能被误认。
  - 门脚必须保留一块浅色补漆，近看可区别；补漆形状和面积未锁定，不能扩大成醒目标记。
  - 不写“衣帽间”大字，不用独特色彩或玻璃窗提前消除误认可能。
- 美术参考：与5155共用同一庄园木作语言，差异集中在门脚修补痕迹。

## Loop1信息节奏与制作边界

- 本轮可读：镜面会改变观察方向；巡警惯用右手；Pierce低头打点十四秒；正常入口从内部上闩；21:38有人提前登记死讯。
- 本轮只留疑问：5101血迹来源、5105监印用途、5106的M-7身份，以及舞台麦克风线路为何通向录音室。
- 必须隐藏：夹层和暗门、钥石、楼梯A/B回转的实施者、E-12投药、录音内容、继承安排、刺刀者与离场路线。
- 5105只制作“照片中的监印”，不得把原物当作玩家背包资产；5151—5156均为环境观察，不制作普通背包Icon。
- 5154需制作可旋转/切换的场景状态；5155与5156必须在同一走廊透视和低照明条件下联合校验。
