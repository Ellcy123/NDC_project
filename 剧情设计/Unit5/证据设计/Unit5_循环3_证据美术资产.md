## 证据详细卡片

### 5301 舞台玻璃实测页 / item_stage_glass_height_measurement

- **类型**：Item（调查实测记录，L3 剖面玩法输入）
- **位置**：SC5005 舞台正面，对舞台通高玻璃完成测量后形成。
- **推理用途**：锁定建筑内部完整高度为 9 米；单独不证明夹层。
- **美术需求**：
  - 表现一张当场测绘页，包含通高玻璃的简化纵向轮廓、上下测点和明确的“9 米”总高记录。
  - 数值是唯一必须精确可读的内容；不画夹层、暗门或墙后结构。
  - 与 5302—5304 使用同一套实测记录视觉模板，但轮廓图不得混用。
- **美术参考**：1920 年代现场测绘纸；铅笔线、尺规辅助线与少量手写数值，干净可读而非现代 CAD 图。

### 5302 舞台楼梯高度实测页 / item_stage_stair_height_measurement

- **类型**：Item（调查实测记录，L3 剖面玩法第二阶段输入）
- **位置**：SC5005 舞台正面，测量 A 位楼梯与平台。
- **推理用途**：记录 A 位顶端平台距舞台地面 3 米，并标出其正对木合地布景板；只证明它与未登记空间下沿同标高。
- **美术需求**：
  - 侧视简图中表现舞台地面基准线、A 位楼梯、顶端平台和正对的木合地布景板。
  - 清晰标注平台高度“3 米”；木板仅画成用途不明的平面，不画门缝、钥石或开启结构。
  - 在玩法界面中可作为可拖动记录页，轮廓必须能与舞台侧 0 米基准线对齐。
- **美术参考**：剧院舞台测绘草图；用铅笔加重 A 位记号，保持其他设备低信息密度。

### 5303 Vivian 房间层高实测页 / item_vivian_room_height_measurement

- **类型**：Item（调查实测记录，L3 剖面玩法输入）
- **位置**：SC5015 Vivian 房间，对地面至天花板净高实测后形成。
- **推理用途**：锁定下部房间净高约 2.7 米；还需 5305 的对应楼板厚度才能得出整体 3 米。
- **美术需求**：
  - 简化房间横截面上标出地面、天花板测点和“约 2.7 米净高”。
  - 不将天花板画成可打开的结构，不因上方声音增加脚印、震动线或人影。
  - 本页不预填楼板厚度，防止它单独完成计算。
- **美术参考**：建筑勘查草图；测量箭头和端点清晰，私人房间陈设仅用少量轮廓指示场所。

### 5304 Lawson 办公区层高实测页 / item_lawson_office_height_measurement

- **类型**：Item（调查实测记录，L3 剖面玩法输入）
- **位置**：SC5016 Lawson 办公室外层办公区，对净高实测后形成。
- **推理用途**：锁定上部办公区净高约 3.6 米；还需 5305 的对应楼板厚度才能得出整体 4 米。
- **美术需求**：

  - 纸面样式与 5303 同系，但必须用 Lawson 办公区的高窗、工作台等简化轮廓区分。
  - 本页不预填楼板厚度，不表现地板下的夹层。
- **美术参考**：同一调查者的成套测绘笔迹；可用页角场所简称防止玩家拿错。

### 5305 建筑材料登记册附图：庄园公开剖面 / item_manor_public_section_foldout

- **类型**：Item（历史建筑档案，L3 两阶段剖面玩法底图）
- **位置**：SC5016 Lawson 办公室外层办公区，建筑材料登记册的封底夹层内。
- **推理用途**：为 5301、5303、5304 提供可归位的公开剖面，并以背面测绘网格锁定一层楼板 0.3 米、二层楼板 0.4 米。
- **美术需求**：
  - 制作一张可翻面的旧式大开折页，正面是 Vivian 房间、Lawson 办公区及建筑外壳的公开剖面。
  - 正面不按本轮实测比例标高，且完全没有夹层登记；不能在初始画面中自动留出一条显眼的“两米空白”。
  - 背面是测绘网格和材料记录，清楚标出对应楼板厚度 0.3 米、0.4 米；不增加未锁定的建筑尺寸。
  - 第一阶段先看背面网格并归位实测数据，完成后再翻回正面，才显出约 2 米未登记阴影带。
  - 档案的年代、机构印记和正文尚未锁定；美术不得自行填写 Miller 家私密用途或 Lawson 签名。
- **美术参考**：20 世纪初保险／估值档案的工程折图；亚麻布纸、蓝黑墨线、反复折叠痕和边缘磨损。

### 5306 Lawson 房间的蓝色水痕 / clue_lawson_room_blue_water_traces · L5

- **类型**：Clue（现场拍照；L5 Expose R1 回查材料）
- **位置**：SC5016 Lawson 办公区，矿物工作台与洗手区之间。
- **推理用途**：L3 只建立“Lawson 鞋底卡有硫酸铜晶屑，沾水后会留蓝痕”；L5 再与 5311 夹层湿地毯回查，反驳 Lawson 穿当时鞋子走过湿夹层的说法。
- **美术需求**：
  - 矿物工作台与洗手区之间留有一组可读的蓝色湿鞋印，颜色从鞋底沾水后向外晕开。
  - 画面同时能看到鞋底纹路中残留少量蓝色晶屑，让“晶屑遇水溶出蓝色”的视觉关系成立。
  - 该蓝色必须与普通清水湿印明显可区分，但不增加现代化学发光效果。
  - 不绘制白板旧候选中的蓝铜矿丢失、通风口或四十厘米宝石夹。
- **美术参考**：湿润皮鞋印上的稀薄蓝绿色无机盐溶液；晶屑颗粒细小，藏在鞋底槽纹里。

  - 公文夹本体不画血迹、湿鞋印或夹层粉尘的额外定案信息。
- **美术参考**：1920 年代皮革或压纹硬纸公文夹；黄铜件有旧氧化层，新断面相对明亮。具体材质尚未由真源锁定，建模前需美术与策划确认。

### 5311 夹层湿地毯上的凌乱鞋印 / clue_mezzanine_wet_carpet_footprints · L5

- **类型**：Clue（现场拍照；L5 Expose R1 回查材料）
- **位置**：SC5018 夹层第一岔口，翻倒清水壶浸湿的整段狭窄通道。
- **推理用途**：L3 只能稳定分出四组鞋印，证明至少四人经过，不对应身份、方向或先后；L5 再回查“所有可见湿迹都没有蓝色反应”。
- **美术需求**：
  - 狭窄夹层的地毯被普通清水大面积浸湿，附近有一只翻倒的水壶；湿区覆盖玩家能看到的整段通道。
  - 大量脚印可依大小、鞋底纹路与踩压深浅稳定归为四组，但要保持重叠、乱向与难以还原顺序的状态。
  - 不把任一组画成可一眼匹配 Moore、老 Charles、Lawson 或其他人的特征鞋印。
  - 地毯湿迹保持普通水的灰暗色差，所有可见鞋印都不得出现蓝色晶屑溶出效果；L3 的文字描述不主动强调这个“没有”。
- **美术参考**：吸水后变深的老式窄幅地毯；用不同鞋底纹、印面尺寸和压痕深浅区分四组，不使用现代鉴识标尺作为场景原物。

### 5312 文件柜背后异常隔音材质勘验照片 / clue_abnormal_soundproofing_photo · L4 / 终幕 A

- **类型**：Clue（现场拍照；后续空间推理的早期观察）

  - 差异应够玩家记住，但不得用完整轮廓提前画出“墙后有一间房”。
  - 隔音材质的具体构造尚未锁定；正式设计应优先满足 1928 年可行性，不使用现代金字塔泡棉。
- **美术参考**：20 世纪初录音室可见的厚毛毡、软木纤维板、多层毡料或木骨空腔等时代可行方向；最终构造待统一场景美术确认。
