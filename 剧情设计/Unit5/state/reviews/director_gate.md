## 裁决：疑点方案

争议点：多轮复用物证是否需要首获轮先造碎片、后轮再造同证据疑点，以及 L3/L5 小游戏是否替代常规疑点。

判断依据：原则二与疑点系统的一对一、最早指证时序硬约束；主纲没有授权把 L3/L5 整轮改成免疑点，也禁止为便利配置增加组合结论页。

裁决结果：采用 `puzzle_preflight.md` 的最小方案，每轮 3 疑点、0 碎片，分母各为 3。每项 1—2 件条件；旧物保持原 ID，仅有一个疑点归属，不为首获轮强造碎片。单件疑点只承载该轮局部矛盾，不据此单件定杀人罪。

| Loop | 采用疑点 ID | 挂载方向 |
|---|---|---|
| L1 | 5101—5103 | 取烟手与谎言锚；镜面可变方向；巡逻证言与打点纸带 |
| L2 | 5201—5203 | 预备底片与谎言锚；当日批准联；叠压血滴与死亡顺序证言 |
| L3 | 5301—5303 | 公文夹与铆圈；催收急件；止付密电与 M-7 |
| L4 | 5401—5403 | 常规药盒与紫片；缺页与档案缺口；来信与护照 |
| L5 | 5501—5503 | 湿脚印与蓝色水痕；破门照片组与 C-3 证言；照片墙还原记录 |

下一步：State 架构负责人按登记表锁定证言 ID，生成后验证每件正式提交材料唯一挂载且归属不晚于首次使用。小游戏、公共推理、原文证言前提与新增 R1 问话仍须独立前置，不能因为疑点 100% 就跳过。L4 洗清 Emma 的三材料事件不是三件 condition 的疑点。

## 裁决：R1 前置与信息边界

争议点：新增普通问话如何避免把公共推理或后续承认提前。

判断依据：用户新增批准优先；原则一要求当前仅取得待反驳主张，原则二要求提问有已知来源且无循环依赖。

裁决结果：L3 完成夹层开启后，在第一岔口第二阶段普通 Talk 取得原 R1。L5 两次公共推理完成后、正式指证前设置独立可点击问话取得原 R1；不得把此锚作为公共推理的解锁条件。嫌疑选择仍区分可回退的 Lawson 误选与后续不可逆最终投票。R2/R3 动态退守及有限承认不能由新增 Talk 提前发放。

下一步：主代理在覆盖矩阵单列批准记录，生成者用明确阶段 flags 和 required_talks/testimony 约束入口。若需另行改变原嫌疑选择的事件顺序，不能冒称总监已批准。

## 覆盖计划机械修正门禁

当前 `outline_coverage_plan.json` 明确为 `planned_not_generation_pass`，段落索引不能替代逐事件落点验收。以下是原文已有约束的修复，不是剧情新增：

1. `S1-0019` 是色标定义表，不能因表内出现“角色｜NPC（可对话）”就算自由 NPC 事件；取消这一说明性假 marker。
2. `S1-0169/0171/0173` 目前被计划为 opening，但主纲明示“庄园内的幕后事实｜不单独演出”。改为幕后约束/知识边界映射；不得把 Emma 与小 Charles 私谈、彩排准备或远端刻录准备演给 L1 玩家。
3. `S1-0396` 等一段含多 NPC/多证言的来源必须细分每一项；一个段落一个勾不能代替逐 NPC、逐证言映射。L5 公共推理与嫌疑选择也不能因大标题“指证”而误生为额外 Expose 轮。
4. 所有自由搜证、对白交付、非收集口头记录、幕后解释和固定演出都按原文语义分类。计划里的 exact 只是候选，不能当无遗漏证明。

复核结果：主代理已将 S1-0019 的 dialogue_required 改为 false，将 S1-0169/0171/0173 改为 source_constraints.backstage_truth_not_performed。本节第 1、2 项已关闭；第 3、4 项作为生成期细分和独立验收要求，不是未批准偏差。新建 state_contract.yaml 已核对：五轮、15 疑点、零碎片、已批准问话与互动终幕、累计知识及适配状态均与上述边界一致。准予生成者按共同覆盖计划与原文进一步细分具体字段，由主代理最终独立验证。最终仍须达到漏项 0、无来源新增 0、重复主映射 0；批准的两处新增单独计数，不隐入 exact。
