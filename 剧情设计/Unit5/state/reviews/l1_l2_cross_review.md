## 通过项

- L1 七段根 Opening 完整承接医院决裂、Watts 留守、车内广播、短序幕、楼上背影误认、两次曝光与圆桌规则；圆桌之后才恢复控制。幕后补材料与录音准备没有演给玩家。
- L1 Foster、巡警、Lawson 的 ⚪ 内联正文保留原文限定。Lawson 口头记录不作为正式可收集证言，并保留给 L3 的同 ID 回查。巡警右袋、右手、全程二十秒、中段十秒和打点十四秒一致。
- Pierce 的普通 R1 为真实取得的可收集锚；动态两轮退守不提前放入普通证词。三轮只拆身份、镜面方向、剩余路程，指证后没有指认具体进入者或刺刀者。
- C-3 偶遇与后台私谈由场景事件承载，没有伪装成新增自由 NPC 问话；偶遇只保存空间记忆，不被写成时间不在场证明。
- E.F. 手帕保持可跳过，不进入强制证据或疑点门槛；两条关系选择均先建立同一归属记忆。选错或不查看不阻止 L2 完成医学顺序。
- L1 监印实体始终由 Lawson 保管，玩家只取得照片；M-7 首轮身份未知，只归 L3 疑点。舞台照片与暗角的后轮观察层没有提前解读。
- L2 Emma 苏醒、承诺与消防卡观察是强制开场；走廊 Pierce／Vivian 的问话仍为两个独立普通入口，没有被 Opening 吞掉。
- L2 Foster 完整证词逐字保留，明确先取得 5201 才可取得；不提前说出三米高度。R3 仅提交血滴，Foster 伤序是明确前提。
- 公开批准联为 Zack 固定行为，没有可丢弃分支；Vivian 指证后的克制／越界才是真实关系选择。两者没有混写。
- L2 三轮材料分别为底片、当天批准联、叠压血滴；不重复挂载跨轮照片组。两轮各三疑点零碎片，条件均不超过两件。
- 已知事实按统一合同累积；L1→L2→L3 的 next_talk 与下轮根入口一致。消防卡不入包、无终局拉杆编号；机关、投药、继承仍留在合法后轮。
