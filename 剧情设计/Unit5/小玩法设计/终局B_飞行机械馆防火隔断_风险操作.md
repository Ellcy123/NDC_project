# Unit5 终局 B：飞行机械馆防火隔断风险操作

> 状态：玩法拆分稿，不自动晋升为 Canon。
>
> 固定口径：三格`Lawson 暴露风险`；左上`R-42`是唯一正确拉杆；玩家通过排烟图标和不对称卡扣确认整体旋转 180°。

---

## 一、职责与非职责

### 职责

- 让 Emma 通过对话、站位和空间换算持续误导小 Charles；
- 回收 L2 见过的消防维护卡，但终局只能使用脑内残像；
- 让玩家在风险满格前拉下正确实体拉杆，使防火隔断形成有效阻挡；
- 以 B 成功／失败决定 Emma、Lawson 与 Vivian 是否获得安全空间。

### 非职责

- 不让玩家选择是否把 Lawson 藏进校准舱；该动作属于固定剧情；
- 不开放消防维护卡原件、背包或 Caseboard；
- 不把拉杆操作写成推理证据；
- 不证明小 Charles 的罪行；
- 不把 A 的结果用于改变 B 的答案、风险上限或成功权限；
- 拉对后不再要求玩家持续按住、再次确认或选择是否升降隔断。

卡片前期不出现 `R-42／R-17／R-28`编号，也不直接标出终局答案。

## 四、逐步操作

### R1：对话判断

玩家从短对白选项中选择一句能够刺激小 Charles 的控制欲或胜负欲、迫使他继续直视 Emma 为自己辩解的话。

- 选对：维持注意力，直接进入 R2；
- 选错：Emma 先按错误回答行动，小 Charles 的视线转向主控台与校准舱；Emma 立即以固定动作把注意力拉回，风险增加一格；
- 本轮是一次性判断，选错后不能回头重选，但自动补救保证流程仍进入 R2。

具体对白由终局台本负责，本玩法文档只规定功能条件。

正式台本必须提供三个功能互斥的候选槽：

| 候选槽 | 功能判定 | 必须产生的即时表现 |
|---|---|---|
| 挑战其掌控力／胜负欲 | 正确 | 小 Charles 留在 Emma 正面，继续盯着她辩解 |
| 直接提及 Lawson 或校准舱方向 | 错误 | 小 Charles 转头看向主控台，Emma 固定补救，风险 +1 |
| 服软并主动让路 | 错误 | 小 Charles 试图越过 Emma 搜查，Emma 固定补救，风险 +1 |

具体句子可以随声纹调整，但不得把正确槽写成直接提示消防墙、隔断或拉杆答案。

### R2：诱导站位判断

玩家选择 Emma 的移动位置。正确站位必须同时满足：

1. 位于飞行模拟主厅一侧、隔断轨道之外；
2. Emma 的身体能够遮住`EXIT`／消防逃生门标志；
3. 距消防机械墙只有一步；
4. 不把小 Charles 的视线引向校准舱。

界面固定给出三个可读站位缩略图，不用抽象文字代替空间判断：

| 站位缩略图 | 判定 | 画面硬条件 |
|---|---|---|
| 消防机械墙前、主厅侧 | 正确 | 同时遮住`EXIT`、距拉杆一步、校准舱不进入小 Charles 视线 |
| 主控台与校准舱之间 | 错误 | Emma 的移动反而把小 Charles 视线带向校准舱 |
| 隔断轨道内／检修前室侧 | 错误 | Emma 自己落入隔断作用区，且无法保持一步触及机械墙 |

美术可微调人物姿态和镜头，但三个缩略图必须保留上述判定差异，不能只靠选项文字说明对错。

- 选对：进入固定诱导演出；
- 选错：Emma 先移向错误位置，小 Charles 开始绕行或看向校准舱；Emma 自行察觉并修正到正确位置，风险增加一格；
- 本轮同样不能回头重选，但一定能够进入 R3。

Emma 正确落位后，小 Charles 推开她，看见突然显露的`EXIT`标志，被误导进入隔断与逃生门之间的消防检修前室。该段为固定演出，不追加姿态选择或 QTE。

### R3：记忆换算与实体拉杆

1. Emma 看见倒三角分布的三根拉杆，界面叠出 L2 消防卡的模糊脑内残像；
2. 玩家认出卡片上方的完整排烟图标，对应面板下中的残缺倒置排烟图标；
3. 卡片卡扣在右、面板卡扣在左，证明不是简单上下镜像，而是整体旋转 180°；
4. 旋转 180°后：
   - 卡片左下校准舱对应面板右上 `R-17`；
   - 卡片右下`EXIT`／防火隔断对应面板左上 `R-42`；
   - 卡片上方排烟对应面板下中 `R-28`；
5. 玩家拉下左上`R-42`，这是唯一正确提交。

玩家可以在提交前观察图标、切换残像透明度或进行脑内旋转；这些操作不增加风险，系统也不提前显示“对位正确”。

## 五、正确／错误反馈与容错

### 正确拉杆

拉下`R-42`后：

- 机械配重脱开；
- 防火隔断开始下降，并在小 Charles 返回主厅前形成有效阻挡；
- B 成功立即锁定；
- 风险条停止结算并退出操作态。

### 错误拉杆

- 拉下`R-17`：校准舱换气百叶弹开，产生暴露危险；
- 拉下`R-28`：屋顶排烟风门打开，发出明显机械声；
- 每次错误均增加一格风险；
- 风险未满时，错误拉杆自动复位，允许重新观察和选择；
- 风险达到 `3／3`时，小 Charles 识破误导，在隔断形成阻挡前返回主厅，B 失败。

### 三格容错表

| R1 错误 | R2 错误 | 进入 R3 时风险 | 可恢复的错误拉杆次数 |
|---|---|---:|---:|
| 否 | 否 | 0／3 | 2 次；第 3 次错误失败 |
| 是 | 否，或反之 | 1／3 | 1 次；第 2 次错误失败 |
| 是 | 是 | 2／3 | 0 次；第 1 次错误失败 |

R1、R2 的自动纠正保证玩家总能进入 R3，但前置错误会压缩拉杆容错。

## 七、产出与信息边界

### B 成功

- 建议 flag：`终局B_防火隔断成功`（工作名）；
- 成功条件唯一：风险满格前拉对`R-42`，使隔断形成有效阻挡；
- 小 Charles 用枪托卡住隔断、射伤 Emma／Vivian／Lawson、Emma 拒绝复位和门口来人均为成功后的固定演出；
- 这些演出不得重新读取玩家输入，也不得把已锁定成功翻回失败。

### B 失败

- 建议 flag：`终局B_防火隔断失败`（工作名）；
- 风险达到 `3／3`时，小 Charles 返回主厅，枪口对准 Emma 后切黑；
- 黑屏期间的具体枪击与死亡顺序不由本玩法定义；
- B 不生成证物或新的推理结论。

### 信息边界

- B 是求生操作，不是案件证据；
- A 成功时角色可以使用完整继承条款对白，A 失败时只能依据小 Charles 的追杀行为试探；
- A 的对白差异不能改变 B 的答案、风险值或基础成功权限；
- 门口最终出现 Zack 或 Pierce 只结算 A，不再判断 B。
