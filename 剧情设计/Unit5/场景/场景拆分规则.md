# Unit5 场景拆分规则

## 核心口径

- 以独立美术底图、可独立加载的玩家空间或必须冻结构图的剧情画面为拆分单位，不机械复制 State 的每一个 `scene_id`。
- 探索场景命名为 `EXP_SC{sceneId}_{地点}_{状态}.md`；纯剧情画面命名为 `AVG_L{loop/FIN}_{位置}_{用途}.md`。
- 同一地点可跨 Loop 复用底图，但证物、NPC、门锁、机关与光照状态必须分层挂载；构图或空间关系发生显著变化时另建 AVG 构图。
- 突发事件、指证和小游戏不冒充新探索地点：能在原底图上完成的，写入该场景的状态段；确需新镜头的，另建 AVG 档案。
- State 已分配的 ID 只表示逻辑地点。一个 ID 需要 A/B 构图时仍保留该 ID，并明确构图差异；State 没有分配而美术确需独立构图时标记“美术构图编号待定”，不私造正式 ID。

## 庄园空间口径

- `5005 舞台正面`、`5014 舞台背面`与`5011 舞台后台`是三个可辨认空间：正面承载尸体、楼梯和暗角；背面承载底片、批准联与 C-3 后方作业区；后台是通往录音室及舞台侧通道的交通空间。
- `5022 后台录音室`是 Emma 失能起点，不能画成舞台侧翼，也不能与 `5029 文件柜后隐藏试听室`混用。
- `5018 夹层第一岔口`是 Moore 被击破的通行节点；`5019 夹层文件柜区域`是旧档案与隔音异常所在；文件柜移开后才显露 `5029`。
- `5030 旧档案区封闭试听室`是终局追逐中的普通封闭空间，用于 Zack 换装误导 Pierce；它不是隐藏室，也不保存继承唱片。
- `5032 飞行机械馆主厅`、小游戏操作所在的校准舱、`5033 消防检修前室`为三层空间关系。校准舱尚无正式 State scene ID，按“美术构图编号待定”管理。

## 状态拆分

- 舞台正面至少有案发后初始、L2 血滴可查、L5 钥石已取/暗角放大三层交互状态，底图可复用，特写和热点分层。
- 舞台侧暗门至少有关闭、断齿取出后自动闭合、钥石拼合失败、三指握姿开启四种机关状态。
- 门厅照片墙有“开篇路过无热点”与“L5 解锁年份还原”两种权限状态，不能靠换底图提前提示调换。
- 飞行机械馆主厅需准备正常陈列、断电持枪对峙、隔断落下后三态；是否拆成完整底图由美术按机关覆盖面积决定。
- 法庭与结局蒙太奇全部是 AVG，不提供自由探索或交互热点。

## 证物与人物

- 所有证物必须绑定可见载体：底片在摄影工作台，批准联在舞台调度夹，药剂在护士站药柜，档案在书房废纸篓或夹层文件柜，钥石在暗角/工作匣，照片在照片墙。
- 环境证物只记录观察，不进入背包。舞台麦克风明确连向录音室，但场景不说明是否启动或是否完成录音。
- NPC 的可点击 Talk 与强制演出分开挂载；被指证者的 R1 必须先在普通 Talk 取得。L3 Moore 和 L5 小 Charles 采用已批准的前置问话。
