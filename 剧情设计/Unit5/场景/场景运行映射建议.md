# Unit5 场景运行映射建议

> 本文是 State 到场景制作/落表的运行建议；尚未实现的条件事件、环境证物与四个小游戏继续标为适配需求。

## L1 初始封锁与自由调查

```text
5001医院→5002办公室→5003车内→5004二楼走廊
→5005舞台曝光→5006圆桌规则
→开放5005、5009、5010、5011、5012、5013、5006
→5006 Pierce指证→Loop结束
```

5005 初次曝光不发照片组、不放大暗角；恢复探索后才开放 5101、5151—5153。5010/5011 的首次进入事件只种人物关系，不产出站位证据。环境镜 5154 需观察状态持久化后方能进入疑点及指证候选。

## L2 舞台前后

5008 苏醒演出观察消防卡后自动到 5009；Pierce、Vivian分别保留普通 Talk。5005与5014双向开放。取得批准联触发 Zack 单人念头并强制回5006公开，不能设置隐瞒分支。Vivian指证在5006完成，结束后进入关系选择并结算。

## L3 两阶段剖面与夹层

```text
5005开篇提测高
→5005/5015/5016/5017自由测量
→当前场景启动剖面阶段一并原地返回
→5006圆桌阶段二
→5020舞台端暗门AVG
→5018夹层调查、Moore普通问话与指证
→连续AVG走向5021并打开书房端入口
```

阶段一不得切到固定“小游戏房间”；完成后保持玩家原场景。5020 与5018是两个加载节点。Moore R1 在5018普通问话获得，三轮指证结束前不提前给退守句。

## L4 录音室—书房—文件柜

开篇先在东侧走廊交代 Moore 押入5026及 Emma 的远端安排，再到5022。自由调查开放5022、5023、5024；因L3书房端已开，5021与5019同时开放。Mary 在5023普通问话取得 R1，正式指证在5024。指证后争执与 Pierce 两次指控续接到5011洗清Emma，中途不恢复探索。Moore此后不离开看守房。

## L5 钥石、照片墙与指证

开篇按5007东侧走廊（送Lula隔离、释放Emma）→5011舞台后台（Vivian两段有限记录）→5021→5025→5016→5005巡回，均为强制演出；5025此时没有热点。恢复探索后，5005取得暗角材料，5020取断齿导致门闭合，强制转5016取残缺钥石，再回5020完成普通旋转失败与Emma三指握姿开门。`u5_door_reopened` 后才开放5025小游戏。

照片墙完成、四处复核条件满足后回5006：公共推理一→公共推理二→钥石用途判断→恢复控制，玩家点击小Charles取得R1→嫌疑选择→三轮指证。错误选择Lawson只进入5005/5016/5020复核，不形成永久结局。

## 终幕（仍属于 L5）

最终票选 Lula/Moore 直接进入固定蒙太奇。选择小Charles后，公开定罪失败、Lawson交实体监印，随后：

```text
5019文件柜区→A五步推理→5029隐藏试听室（可能在Q4后开启）
→A成功完整播放或失败不播放
→5028酒局袭击→5019追逐并换装→5030将Pierce引入普通封闭试听室/枪响→5031逃亡连廊
→5032机械馆主厅/校准舱B→5033隔断状态→揭晓来人
→按A/B组合进入5034法庭或5035—5041结局蒙太奇
```

A 与 B 均为受控互动界面，不开放普通探索。B成功时枪托脱落后配重自动落下隔断，无需Emma追加最后输入。只有双成功进入5034；法庭全段无玩家控制。
