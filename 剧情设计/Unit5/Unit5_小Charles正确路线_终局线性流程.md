# Unit5 小 Charles 正确路线：终局线性流程

> 状态：现行讨论方案，暂不自动晋升为 Canon。
> 使用边界：本文只维护“指证小 Charles”路线的演出顺序、双线解谜、角色生死与法庭后日谈。
> 文档分工：A、B、C 的界面、候选项、错误反馈与物件细节继续见[终局单场景搜证谜题设计](./Unit5_小Charles正确路线_终局单场景搜证谜题设计.md)。两文冲突时，以本文的演出顺序和结局条件为当前方向。

---

## 一、核心结构

小 Charles 正确路线不是“圆桌投票成功后当场抓住凶手”，而是：

1. Zack 在圆桌上正确指认小 Charles，却因证据不足而公开失败。
2. Lawson 私下给 Zack 最后一次查证机会。
3. 小 Charles 发现调查仍在继续，决定杀死 Lawson。
4. Lawson 陪小 Charles 喝酒争取时间；Zack、Emma、Vivian 与中立监督的 Foster 共同经历限时谜题 A。
5. 停电后，Pierce 追杀 Lawson 并把他逼进套间；Zack 与 Lawson 趁乱交换衣物，双线由此分开。
6. Zack 负责引走 Pierce；他的生死在一声枪响后暂时隐藏。Emma 则负责限时破解谜题 B。
7. A、B 分别决定 Zack 与 Emma 能否活下来，并共同决定 Lawson、Vivian 的命运。
8. 只有 A、B 都成功，才进入法庭后日谈 C。

### 三个谜题的职责

| 谜题 | 操作者 | 取得内容 | 剧情职责 |
|---|---|---|---|
| A | Zack | Webb 唱片另一半、继承变更录音、通用报音规则 | 决定广播站门口最终出现 Zack 还是 Pierce |
| B | Emma | 火灾隔断释放规则、Miller 旧设备参数 | 决定 Emma 能否把小 Charles 困在隔断后的旧安全区 |
| C | Zack＋Emma | 从密封母盘组中找出刺杀录音 | 法庭上的合作奖励与真相收束，不再制造失败结局 |

### 结局矩阵

| 谜题 A | 谜题 B | 结算 |
|---|---|---|
| 失败 | 成功 | 坏结局Ⅰ：Zack、Lawson 死亡；Vivian 反水，Emma 独活并被全城排斥 |
| 成功 | 失败 | 坏结局Ⅱ：Emma、Lawson、Vivian、小 Charles、Pierce 死亡；Zack 伪造现场后离开艾斯弗德 |
| 失败 | 失败 | 坏结局Ⅲ：Zack、Emma、Lawson、Vivian 均死亡，小 Charles 保住 Miller 家族 |
| 成功 | 成功 | 真结局：Zack、Emma、Lawson、Vivian 存活；进入法庭后日谈 C |

## 二、前置固定情节：嫌疑人走廊

1. L2 开篇，Emma 醒来，说明自己曾邀请老 Charles 提前彩排，并为彩排安排过保密录音。Pierce 随后将她关进庄园的临时看守走廊。
2. Emma 在被关押的房间里发现一张废弃广播站的旧维护卡。卡上标出了单人播音隔音间、火灾逃生门和火灾隔断释放器，但操作说明已有部分污损。
3. 隔音间只能容纳一名成年人，内部保留应急门闩；躲在里面的人可以自行开门，也能通过监听喇叭听见控制室的声音。
4. 维护卡在前期只像一件废弃设施信息；终局进入广播站后，空间标记成为 Emma 误导小 Charles 的基础，污损的释放说明则留给玩家补全。
5. L4 开篇，Moore 被关进 Emma 隔壁的房间，并与 Zack 争论走廊里还有其他人来过。
6. L5 开篇，Lula 也被关进同一条走廊，恳求 Zack 查出真相。Pierce 同时没收她随身携带的护士包，并把它留在拘禁区外；包内有一瓶密封、带医院标签的医用乙醚。
7. 小 Charles 正确路线的终局不让 Lula 与 Moore 离开拘禁区。Lula 只隔门告诉 Foster 护士包与乙醚的位置；二人的强演出仍保留给各自的坏结局。

### 终局枪械前提

1. Miller 庄园禁止宾客携带枪械。宾客进入庄园时必须接受检查并寄存武器，因此 Zack、Emma、Lawson、Foster、Moore 与 Lula 在终局都没有手枪。
2. Vivian 私下藏着 Unit1 曾经携带的 `Colt Vest Pocket Model 1908`（.25 ACP，象牙贴片枪柄）。她利用枪身小巧的特点把它偷偷带入庄园；这是宾客一侧唯一没有被收走的枪。
3. 小 Charles 作为 Miller 家族成员、Pierce 作为庄园警务与安保负责人，可以取得庄园内部枪械。

## 三、圆桌公开失败

1. Zack 在圆桌上公开宣布：小 Charles 是杀死老 Charles 的真凶。
2. Lawson 弃权。他已经开始怀疑哥哥，但不愿凭尚未闭合的推断公开裁决家人。
3. Vivian 弃权。她可以私下帮助 Zack，却不愿公开承担站队风险。
4. Foster 仍指向 Moore。她目前能用尸检支持的，仍只是 Moore 在死亡时间上撒谎。
5. Pierce 仍指向 Lula，并维护自己此前的拘禁与调查结论。
6. Emma、Moore、Lula 作为被看守的嫌疑人，不参与表决。
7. Zack 的指认正确，却因证据不足而公开失败。这不是众人提前设计的假戏。
8. 小 Charles 相信自己已经赢下圆桌，同意散场。

---

## 四、Lawson 私下给出最后机会

1. 圆桌散场后，Lawson 私下找到 Zack。
2. Lawson 不承认哥哥已经弑父，只承认 Zack 的怀疑值得最后查证一次。
3. Zack 要求 Lawson 释放 Emma、Lula 与 Moore，否则拒绝继续替 Miller 家族调查。
4. Lawson 拒绝全部释放：圆桌刚认定三人仍有嫌疑，他不能凭 Zack 的一句话公开推翻拘禁结果。
5. Zack 指出 Emma 是老 Charles 遇害前最后的约见者，也掌握彩排与录音信息；没有她，最后调查无法继续。
6. Lawson 同意暂时把 Emma 交由 Zack 负责，但坚持 Lula、Moore 留在原处，同时承诺不得转移二人，也不得让 Pierce 单独处置。
7. Lawson 让 Vivian 把 Miller 宝石钥片与私人档案套间入口交给 Zack。Vivian 只负责开门，不公开站队，也不替玩家完成唱片拼合。
8. Zack 前往嫌疑人走廊释放 Emma，把自己对小 Charles 的判断完整告诉她，并让她自行决定是否继续参与。
9. Emma 此时没有母盘，也不知道远端录音是否成功保存。
10. Lawson 要求 Foster 以中立监督者身份随 Zack、Emma 与 Vivian 进入私人套间。她仍不认同小 Charles 已经弑父，只负责观察调查是否被人为操纵。
11. Lawson 留下陪小 Charles 喝酒，为四人的调查争取时间；他不会主动离席，也不参与谜题 A。

## 五、套间阶段：谜题 A 与继承录音

### 1. 限时拼片

1. Zack 释放 Emma 后，与 Emma、Vivian、Foster 在老 Charles 的私人档案与刻录套间集合。
2. Lawson 仍在酒局中拖住小 Charles；Pierce 也不在套间。二人都没有听见接下来的录音内容。
3. A 的时间压力来自小 Charles 逐渐察觉 Lawson 正在替调查争取时间；玩家不在追杀过程中同时解谜。
4. Zack 使用从 Unit1 保留至背包的 Webb 唱片碎片，在套间内寻找另一半碎片。
5. 玩家亲手完成碎片拼合，并在接入庄园供电的 Miller 电动试听台上尝试播放。
6. A 同时让 Zack 从 Webb 唱片的开头报音中归纳出后日谈 C 所需的通用报音规则。
7. Foster 可以利用对断裂面的专业观察，提醒 Zack 根据碎片断口与沟槽延续方向进行拼合；她只降低辨认难度，不直接给出另一半碎片的位置。
8. Foster 把随身医疗包放在套间边桌上。玩家可以调查露在包外、绣有“E.F.”缩写的白色医用手帕；它只建立物件归属与视觉记忆，不进入背包。

### 2. A 成功：众人听见

1. Zack 在庄园断电前完成拼片。
2. Zack、Emma、Vivian 与 Foster 共同听见老 Charles 修改继承安排的完整录音；仍在酒局中的 Lawson 没有听见。
3. 录音明确说明：继承人已经从小 Charles 变更为 Lawson，并由家族外部律师负责后续执行与交割监督。
4. Lawson 若在交割前非正常死亡，外部律师将封存庄园安保记录并追查受益人；小 Charles 也不会因 Lawson 死亡自动取得全部遗产。
5. Foster 仍坚持这段录音只能证明继承安排与杀人动机，不能证明小 Charles 亲手弑父。
6. 该录音足以成为 Zack 随后拖延 Pierce 的真话筹码；本流程不再要求寻找遗嘱原件。

### 3. A 失败：无人听见完整内容

1. 小 Charles 在唱片完成拼合与播放前下令切断庄园电力，Miller 电动试听台随停电中断。
2. Zack、Emma、Vivian 与 Foster 只得到未完成的碎片，没有任何人听见完整继承内容。
3. Zack 因此无法在后续追杀中说出足够具体、可以迫使 Pierce 核实的条款。

## 六、Zack 线：交换外套与 Pierce 追杀

### 1. 小 Charles 的首要目标

小 Charles 的首要目标始终是 Lawson：

- Lawson 是老 Charles 的另一名继承人，也是能够合法接管 Tidewater、追查投毒命令的人。
- 一旦 Lawson 与 Zack 的怀疑结合，小 Charles 就可能同时失去 Miller 家族、Tidewater 与自由。
- Emma、Zack、Vivian 等人不是与 Lawson 并列的预定目标；小 Charles 只会在他们妨碍追杀或掌握真相时顺带灭口。

### 2. 追杀启动

1. Pierce 发现 Emma 已经脱离看守，同时发现私人档案套间有人进入，并把两件事报告给仍在酒局中的小 Charles。
2. 小 Charles 意识到 Lawson 一直在替 Zack 争取时间，当即切断庄园主要照明与普通电话线。
3. 停电强制结束谜题 A。酒局所在房间同时陷入黑暗，Pierce 拔枪准备射杀 Lawson。
4. Lawson 撞开酒局房门逃跑，被 Pierce 一路追进私人套间；他来不及询问唱片内容，只来得及告诉众人 Pierce 要杀他。
5. Foster 与 Vivian 利用套间门和书架暂时阻挡 Pierce。Zack 与 Lawson 趁黑交换外套、帽子和围巾。
6. Lawson 穿上 Zack 的衣物随 Emma、Vivian 撤离；Zack 则穿着 Lawson 的衣物从另一侧跑出，故意让 Pierce 看见自己的背影。
7. Pierce 追向 Zack；Emma、Vivian 护送真正的 Lawson 前往庄园另一端。Foster 让 Zack 把 Pierce 引进旧档案区附近的封闭试听室，自己转身赶往嫌疑人走廊。
8. 众人分散后，小 Charles 取出另一把警用手枪，从侧廊追向 Emma、Vivian 与 Lawson。
9. 追杀阶段不再进行拼片、找遗嘱或其他搜证操作，只保留逃亡、延迟结算与双线交叉剪辑。

### 3. 枪响后的延迟结算

1. Zack 按照 Foster 临走前的指示，把 Pierce 引入旧档案区附近的封闭试听室。
2. 若 A 成功，Zack 隔着障碍说出“Lawson 已被指定为继承人、异常死亡会触发外部追查、小 Charles 无法自动继承”等具体条款，使 Pierce 短暂停步核实。
3. 若 A 失败，Zack 只能用零散内容与猜测拖延，Pierce 继续逼近。
4. Pierce 靠近后识破 Zack 的伪装。
5. 黑暗中突然传出一声枪响。
6. 画面立刻切黑，不展示 Zack、Pierce 或 Foster 的状态。
7. 画面切回 Emma 线；A 的生死结果仍由广播站门口的人影揭晓。

## 七、Emma 线：进入废弃广播站

### 1. 两个出口

1. Emma 护送真正的 Lawson 与 Vivian 穿过停电后的庄园。
2. 暴风雪封死直接离开庄园的路线，三人只能进入废弃广播站寻找临时藏身处。
3. 广播站控制室里有两个显眼方向：只能容纳一人的播音隔音间，以及火灾隔断墙后方的火灾逃生门。
4. 火灾隔断平时收在天花板夹层内。隔断与逃生门之间留有一块旧安全区，控制室一侧设有机械释放器。
5. 火灾逃生门已经被冻胀的门框与门外积雪卡死，短时间内无法打开；它从控制室看去仍像一条可信的逃生路线，正适合被 Emma 用作诱饵。
6. 演出不立刻揭示 Emma 把 Lawson 推向哪一边。实际选择是让 Lawson 藏进单人隔音间，并保持监听喇叭开启；Lawson 可以从内部自行开门。
7. Emma 与 Vivian 留在控制室外侧。Emma 同时从旧设备铭牌记下 Miller 刻录设备的机型参数，供法庭后日谈 C 使用；这不是 B 的额外谜题。

### 2. 小 Charles 追到

1. 小 Charles 的脚步声从走廊逼近。他进入广播站后声称，自己已经知道 Pierce 追赶的人其实是 Zack。
2. 这句话不向玩家证明 Zack 的生死，只用于打击 Emma 与 Vivian，让她们相信门外不会有援手。
3. Emma 一边拖延，一边悄悄恢复火灾隔断释放器的机械连接。
4. Emma 抓住众人在断电前听到的遗嘱内容，指出老 Charles 已经把继承人改为 Lawson。若 A 失败，她便利用听到的零散片段虚张声势；若 A 成功，她可以说出明确的继承安排。
5. Emma 逼问小 Charles：既然杀死父亲也拿不回继承权，他接下来还准备杀多少人。
6. 小 Charles 终于亲口承认老 Charles 是他杀的，并声称只要 Lawson 死去，遗嘱与继承秩序仍能被他重新处理。
7. Emma、Vivian，以及藏在隔音间内的 Lawson，都听见这段承认。
8. Emma 故意用身体挡住火灾逃生门标志。小 Charles 推开她，看见标志后认定 Lawson 已从该处逃走，持枪走进隔断与逃生门之间的旧安全区。

## 八、谜题 B：火灾隔断释放器

### 1. 玩家操作

1. 小 Charles 进入旧安全区后，玩家视点正式切到 Emma。
2. 玩家根据污损的维护卡、释放器上的机械箭头与现场配重结构，自行判断解除保险、释放配重和锁定隔断的操作顺序。
3. Vivian 若在前期满足提示条件，会凭借对 Miller 庄园旧设施的熟悉，提醒 Emma 此类防火隔断必须先解除机械保险，不直接给出完整顺序。
4. 单次错误不会立即判负，但会消耗时间并发出声响；连续错误会使小 Charles 察觉 Emma 的动作。
5. B 的结算点是：隔断落下时，小 Charles 是否仍处在隔断与火灾逃生门之间。

### 2. B 成功：隔断形成

1. Emma 在小 Charles 退出旧安全区前完成操作，火灾隔断开始下落。
2. 小 Charles 来不及返回控制室，只能横起枪托卡住隔断下缘，在地面上方留下一道狭窄射击缝隙。
3. 他要求 Emma 升起隔断。Emma 拒绝后，他隔着缝隙射伤 Emma 的左腿，Emma 仍不操作。
4. 小 Charles 随即向 Vivian 开枪，试图迫使藏匿的 Lawson 自己现身。
5. Lawson 从隔音间的监听喇叭里听见枪声与 Vivian 的惨叫，自行打开门冲出来保护她。
6. 小 Charles 从缝隙中击伤 Lawson，但受隔断限制，无法立刻补枪。
7. 广播站门口随即出现一个持枪人影；来人是谁，负责揭晓此前被延迟的 A 结算。

### 3. B 失败：没有安全空间

1. 玩家未能及时完成正确顺序，或错误声响使小 Charles 提前察觉。
2. 小 Charles 在隔断落下前退出旧安全区，回到 Emma 与 Vivian 所在的控制室一侧。
3. Emma 的误导已经暴露，三人之间不再存在能够阻断枪线的物理屏障。
4. 小 Charles 先射杀 Emma，再向拔枪的 Vivian 开火。
5. Lawson 从监听喇叭里听见连续枪声，自行打开隔音间冲出，也被小 Charles 射杀。
6. 无论门口随后出现 Zack 还是 Pierce，Emma、Lawson 与 Vivian 的死亡都已经无法挽回。

## 九、门口来人：A 的延迟结算

### 1. 来人是 Zack

1. 门口人影显出 Zack 的脸；他拿着 Pierce 的手枪，口鼻仍系着自由探索中见过的“E.F.”白色医用手帕。该物件只暗示 Foster 曾经介入，不回放营救过程。
2. 若 B 成功，Zack 从控制室一侧压住小 Charles 的射击角度，并击落卡住隔断的枪托。
3. Emma 忍痛完成锁定操作，使隔断彻底落下。小 Charles 被困在旧安全区内，无法继续攻击 Lawson 与 Vivian。
4. Zack 只负责补上 Emma 计划所缺的最后一秒，不取代她完成误导、操作与封锁。
5. 若 B 失败，Zack 虽能在赶到后控制小 Charles，却只能面对 Emma、Lawson 与 Vivian 已经死亡的现场。

### 2. 来人是 Pierce

1. 门口人影显出持枪的 Pierce，证明 A 失败，也等于向 Emma 与 Vivian 确认 Zack 已经死亡。
2. 若 B 成功，Pierce 进入控制室一侧，持枪站到小 Charles 一方并封住广播站出口。
3. 隔断后的小 Charles 继续通过射击缝隙控制 Emma 与 Lawson；Pierce 则把枪口转向 Vivian。
4. Vivian 一人无法同时压住门口与隔断后的两处枪线。
5. 若 B 失败，Pierce 抵达时三人已经死亡；他直接协助小 Charles 收走现场枪械与材料并封锁广播站。

---

## 十、坏结局Ⅰ：A 失败、B 成功——两座家族重新分配城市

1. Pierce 在黑暗中杀死 Zack，持枪赶到广播站。
2. Emma 已经成功放下火灾隔断；她与受伤的 Vivian、Lawson 暂时位于隔断的安全一侧。
3. 门口的持枪人影显出 Pierce 的脸。Emma 与 Vivian 由此确认 Zack 已经死在旧档案区。
4. 镜头短暂切回封闭试听室：Foster 带着乙醚赶到，只看见 Zack 的尸体与已经离开的 Pierce。
5. Foster 判断继续追赶持枪的 Pierce 已经无法救回 Zack，只会让自己以及仍被拘禁的 Lula、Moore 一同陷入危险，因此带着乙醚撤回嫌疑人走廊。
6. 画面切回广播站。Pierce 持枪站到小 Charles 一方，封住广播站出口并把枪口转向 Vivian。
7. 隔断后的小 Charles 继续通过射击缝隙控制 Emma 与 Lawson。
8. Vivian 先看向门口，确认不会再有 Zack；再看向两处枪线，确认自己已经无法同时保住 Lawson、Emma 与自己。
9. Lawson 此时已经负伤挡在 Vivian 面前。Vivian 从身后拉住他；Lawson 回头后，她吻了他，随后用自己偷偷带入庄园的 `Colt Vest Pocket Model 1908` 开枪杀死他。
10. Vivian 放低枪口，主动提出由自己接管 Tidewater、处理投毒文件并维持官方叙事，以此向小 Charles 与 Pierce 投诚。
11. Vivian 同时要求留下 Emma 的性命：杀死记者只会制造烈士，摧毁她的信誉、让整座城市拒绝相信她，才是更安全的处理方式。
12. 小 Charles 接受这套方案，保住 Miller 家族；Pierce 继续控制广播站出口。
13. Emma 没有母盘，也没有能被城市权力结构采信的决定性证据。她被塑造成煽动枪击、害死 Lawson 的失控记者。
14. Vivian 与小 Charles 都向 Emma 提供过住所、工作或金钱。Emma 全部拒绝，独自承受整座城市的排斥。

## 十一、坏结局Ⅱ：A 成功、B 失败——堕落的侦探

1. Emma 未能及时完成释放器操作，小 Charles 在隔断落下前退出旧安全区。
2. 小 Charles 先射杀 Emma，再向拔枪的 Vivian 开火。
3. Lawson 听见枪声，自行打开隔音间冲出来保护 Vivian，也被小 Charles 杀死。
4. 门口随后出现持枪的 Zack。他口鼻仍系着“E.F.”白色医用手帕，并控制住小 Charles。
5. 小 Charles 指向已经失去继承人、记者与公司负责人的现场，声称 Miller 庄园如今只会服从他；这场枪击会被处理成家务事，自己不会入狱，第二天的报纸甚至不会刊登死者姓名。
6. Zack 看向 Emma，随后开枪杀死小 Charles。
7. Zack 放下枪，抱着 Emma 的尸体坐了一会儿。
8. 他返回封闭试听室。Pierce 仍因乙醚昏迷，Foster 守在附近；此前枪响后的结果至此得到完整交代。
9. Zack 向 Foster 借了一双医用手套。
10. Zack 戴上手套，把手枪放回 Pierce 手中，握着 Pierce 的手扣下扳机。
11. 他重新摆放 Pierce 的手与枪，伪造 Pierce 畏罪自杀的现场。
12. 第二天，报纸刊登简短消息：Miller 庄园内多人离奇死亡，私家侦探 Zack Brennan 下落不明。报道没有说明凶手，也没有还原庄园内发生的事情。
13. 画面切到一列驶离艾斯弗德的火车。Zack 独自坐在车厢里，膝上摊着那份报纸。
14. 火车驶过城市边界，Zack 没有回头。

达成坏结局Ⅱ：堕落的侦探。

## 十二、坏结局Ⅲ：A、B 均失败——来者不是援军

1. Pierce 在黑暗中杀死 Zack，继续持枪前往广播站。
2. Emma 未能及时完成释放器操作，小 Charles 在隔断落下前回到控制室一侧。
3. 小 Charles 先后杀死 Emma 与 Vivian；Lawson 听见枪声，从隔音间冲出后也被杀死。
4. 门口最后出现的是 Pierce。他与小 Charles 一同收走现场枪械与材料，并封锁广播站。
5. 四名关键角色全部死亡。Pierce 继续维护小 Charles 的对外口径，小 Charles 则保住 Miller 家族，并将枪击、投毒与庄园混乱推给 Zack 和其他嫌疑人。

---

## 十三、真结局：A、B 成功——两条线同时抵达

1. Emma 成功诱使小 Charles 进入旧安全区，并在他退出前放下火灾隔断。
2. 小 Charles 用枪托卡住隔断，先后射伤 Emma、Vivian 与冲出隔音间保护 Vivian 的 Lawson。
3. 广播站门口出现持枪人影。Emma 与 Vivian 看清来者是 Zack；他口鼻仍系着“E.F.”白色医用手帕，A 的成功至此得到确认。
4. Zack 从控制室一侧压住小 Charles 的射击角度，击落卡住隔断的枪托，挡住他的最后一次反击。
5. Emma 忍痛完成锁定操作，火灾隔断彻底落下；小 Charles 被困在旧安全区内。
6. Zack 避免了最后的死亡，却不取代 Emma 此前完成的藏人、误导与释放器操作。
7. Foster 稍后赶来，为 Zack 与广播站内的伤员做紧急处理。
8. Lawson 与 Vivian 接受救治并存活。庄园危机结束，但小 Charles 亲手弑父仍需要能够进入公开程序的决定性证据。

## 十四、法庭后日谈：谜题 C

### 1. Foster 的证言

1. 后日谈发生在小 Charles 的法庭审判中。
2. Foster 首先作为法医证人出庭，正式念出 Sean O'Malley 的姓名。
3. 她提交 1912 年的原始异常记录与自己当年签下的假尸检责任，证明 Sean 并非死于公开报告所称的意外，而是在事故前已遭到蓄意致命袭击。
4. 她由此纠正老 Charles 对 Sean 谋杀案的官方记录，也证明 Miller 体系曾迫使法医系统调换伤情顺序。
5. Foster 随后出示 L4 已经取得的 Tidewater 投毒文件，以及随文件完成的官方字迹鉴定报告；报告由专门鉴定人员签署，Foster 只负责在证言顺序中将其提交法庭。
6. 字迹鉴定确认：投毒命令上的“老 Charles”签名实际由小 Charles 仿写；传递记录显示命令经 Pierce 的执行渠道送入南区。
7. 该材料证明小 Charles 是投毒命令的真正签发者、Pierce 是知情执行者，但仍不能证明小 Charles 亲手杀死父亲。
8. Foster 最后确认：老 Charles 当晚的真正致命伤是刀伤，而不是坠落或其他伤势。
9. 法官指出：刀伤只能确定死因，不能单独确定持刀者就是小 Charles。
10. Foster 示意自己的证言已经完成，该换下一组证人和物证。

### 2. Watts 弄乱的母盘组

1. 法警把 Watts 保管并送交法庭的密封母盘组搬上证物桌。
2. Watts 不在证人台，也不参加 C 的现场解谜；他的保管记录与书面说明已经随证物提交。
3. 每张唱片仍保持独立密封，证据链没有被破坏，但 Watts 在送审前弄乱了自己使用的技术排序。
4. Zack 与 Emma 已经知道目标母盘确实存在，也知道其中记录了小 Charles 的刺杀过程；他们必须在当庭播放前重新找出正确原盘。

### 3. Zack 与 Emma 当庭合解 C

1. Zack 与 Emma 站到证物桌前，开始共同操作谜题 C。
2. Zack 提供 A 中从 Webb 唱片碎片归纳出的通用报音规则。
3. Emma 提供自己在废弃广播站恢复设备时记下的 Miller 刻录设备参数。
4. 玩家在手动拼接界面中组合出目标母盘应有的开头报音，再从密封唱片组中找出唯一匹配的原盘。
5. C 允许重听、重排与渐进提示，不设置新的失败结局。
6. 解谜过程中，Zack 与 Emma 一边压低声音吵嘴，一边纠正对方的排列与听音判断。
7. 两人共同抱怨真正应该解释技术排序的 Watts 没有站在台上。
8. 法官不断要求二人维持法庭秩序；这段轻微的荒诞感用于释放前段证言的压力。
9. Zack 与 Emma 最终同时停下争论，指向同一张唱片。

### 4. 法庭播放

1. 正确母盘被装上法庭留声机，并通过法庭内部扩音设备播放给法官、陪审团、记者与旁听者。
2. 录音先播放老 Charles 临死前与小 Charles 的谈话，并留下能够明确辨认父子身份的称呼与回应。
3. 随后响起小 Charles 实施致命刀刺以及仍留在现场的连续声音。
4. 方才因 Zack 与 Emma 吵嘴而稍显松动的法庭气氛立刻冷下来。
5. 记者席与旁听席一片哗然，法官敲槌也无法立刻恢复秩序。
6. 场景停在公众第一次共同听见完整弑父真相的时刻。

## 十六、与谜题文档的后续同步要求

1. 谜题 A 由 Zack 操作，地点是老 Charles 私人档案与刻录套间；在场者是 Zack、Emma、Vivian 与中立监督的 Foster，Lawson 仍在酒局中。
2. 谜题 B 由 Emma 操作，地点是废弃广播站；玩家通过维护卡、释放器标记和配重结构判断火灾隔断的正确操作顺序。
3. 单人隔音间只能容纳 Lawson 一人，但内部可以自行开门；Emma 把 Lawson 藏入其中属于固定演出，不另设玩家选择或结局门槛。
4. A、B 使用独立时钟：A 由小 Charles 察觉 Lawson 正在拖延并切断庄园电力表现，B 由小 Charles 逐步识破 Emma 的误导、即将退出旧安全区表现。
5. 谜题 C 移至法庭后日谈，由 Zack 与 Emma 共同完成。
6. A 提供通用报音规则；Emma 在启动广播站旧设备时固定记下 Miller 机型参数。
7. A、B 均成功后 C 一定可解；C 允许试错和渐进提示，不再制造新的坏结局。
8. 母盘始终由 Watts 在庄园外编号、密封和保管，Foster 不再移动或隐藏母盘。
9. Foster 利用对断裂面的专业观察降低 A 的拼片难度；Vivian 凭借对 Miller 庄园旧设施的熟悉降低 B 的操作难度。缺少提示不会隐藏谜题对象或封锁结局权限。
10. L4 已取得的 Tidewater 投毒文件只在法庭后日谈使用，由官方字迹鉴定确认小 Charles 的仿签，并由传递记录确认 Pierce 的执行位置。
11. A 成功时，完整继承条款为 Foster 取得并释放乙醚争取足够时间；A 失败时，Pierce 在 Foster 返回前杀死 Zack。
12. 绣有“E.F.”缩写的白色医用手帕作为套间自由探索中的环境证物，只建立 Foster 的物件归属，不进入背包；Zack 在广播站现身时用它暗示未展示的营救过程。

## 十七、一句话流程

> Zack 在圆桌上正确指认小 Charles 却公开失败，Lawson只同意释放Emma并留下陪小Charles喝酒争取时间；Zack、Emma、Vivian与Foster听见或错过继承录音后，停电迫使谜题A结算，遭Pierce追杀的Lawson逃入套间与Zack交换衣物；Zack把Pierce引入封闭试听室，一声枪响后生死暂时不明，Emma则把真正的Lawson藏入废弃广播站，并诱使小Charles走进火灾隔断后的旧安全区；B决定隔断能否及时落下，广播站门口最终出现的Zack或Pierce同时揭晓两线胜负，只有Zack抵达且隔断成功落下，众人才会存活并进入法庭后日谈C。
