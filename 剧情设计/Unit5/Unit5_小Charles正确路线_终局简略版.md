# Unit5 小 Charles 正确路线：终局简略版

> 用途：供其他策划快速了解本路线的玩家流程、操作节点、结局条件与情绪卖点。
> 状态：现行讨论方案，暂不自动晋升为 Canon。
> 阅读顺序：本文负责快速预览；完整演出与角色动作见[终局线性流程](./Unit5_小Charles正确路线_终局线性流程.md)。若其他文档与本文的分支条件冲突，以终局线性流程为准。

---

## 一、一句话概括

Zack 在圆桌上正确指认小 Charles，却因证据不足而无人公开支持。Lawson 私下给他最后一次调查机会。玩家先以 Zack 破解遗嘱唱片 A，随后在停电追杀中经历 Zack、Emma 两条线路：A 决定广播站门口最终出现 Zack 还是 Pierce，B 决定 Emma 能否用火灾隔断困住小 Charles。A、B 的组合产生三个坏结局和一个真结局。

---

## 二、整体流程

1. 玩家在圆桌上选择指认小 Charles，进入本路线。
2. Lawson、Vivian 弃票，Foster 指认 Moore，Pierce 指认 Lula；Zack 的正确指认公开失败。
3. 圆桌散场后，Zack 要求 Lawson 释放 Emma、Lula 与 Moore。Lawson 只同意释放 Emma，并开放老 Charles 的私人档案套间。
4. Zack、Emma、Vivian 与 Foster 进入套间。玩家操作 Zack，在限时状态下完成谜题 A。
5. 庄园突然停电。Pierce 追杀 Lawson，Lawson 逃入套间；Zack 与 Lawson 交换衣物。
6. Zack 假扮 Lawson 把 Pierce 引向封闭试听室；Emma、Vivian 护送真正的 Lawson 前往废弃广播站。
7. Zack 与 Pierce 在试听室内对峙。一声枪响后画面切黑，不展示 Zack、Pierce 或 Foster 的状态。
8. 玩家视点切换为 Emma。Emma 把 Lawson 藏进单人隔音间，并用火灾逃生门误导随后赶到的小 Charles。
9. Emma 借遗嘱内容逼小 Charles 亲口承认弑父，再诱使他进入火灾隔断后的旧安全区。
10. 玩家操作 Emma，在限时状态下完成谜题 B。
11. 广播站门口出现 Zack 或 Pierce，同时结算此前隐藏的 A；火灾隔断是否及时落下则结算 B。
12. A、B 均成功后，众人存活并进入法庭后日谈 C；C 是真结局的合作奖励，不再产生失败结局。

### 分支速览

```text
圆桌指认小 Charles
        ↓
公开失败 → Lawson 私下开放最后调查
        ↓
Zack 解 A → 停电、交换衣物 → 试听室枪响、暂不结算
        ↓
Emma 解 B → 广播站门口揭晓 A
        ↓
        ├─ A失败＋B成功 → 坏结局Ⅰ
        ├─ A成功＋B失败 → 坏结局Ⅱ
        ├─ A失败＋B失败 → 坏结局Ⅲ
        └─ A成功＋B成功 → 真结局 → 法庭谜题 C
```

## 三、玩家真正决定的内容

| 节点 | 玩家操作 | 可选帮助 | 实际后果 |
|---|---|---|---|
| 路线入口 | 圆桌指认小 Charles | 无 | 进入小 Charles 正确路线 |
| 谜题 A | 拼合 Webb 唱片碎片并在断电前听取完整遗嘱 | Foster 可提示断口与沟槽观察方向 | 决定 Zack 能否活着抵达广播站 |
| 谜题 B | 判断火灾隔断释放器的正确操作顺序 | Vivian 可提示先解除机械保险 | 决定 Emma 能否把小 Charles 困在隔断后的旧安全区 |
| 谜题 C | 组合 A 的报音规则与 Emma 取得的 Miller 参数，找出正确母盘 | 可重听、重排并获得渐进提示 | 播放弑父录音，完成真结局；不再制造失败结局 |

A、B 都采用“错误操作消耗时间”的限时压力。NPC 提示只降低理解与辨认难度，不代替玩家操作，也不直接改变结局权限。

### 固定演出，不是玩家选项

- Lawson 只同意释放 Emma，Lula 与 Moore 继续留在嫌疑人走廊。
- Miller 庄园禁止宾客携枪，Zack、Emma、Lawson、Foster、Moore 与 Lula 的武器均在入场时被收走；Vivian 偷偷带入了 Unit1 的 `Colt Vest Pocket Model 1908`，是宾客一侧唯一的例外。
- Zack 与 Lawson 交换衣物，由 Zack 引走 Pierce。
- Emma 把 Lawson 藏进单人隔音间，而不是火灾逃生门。
- Zack 线以枪响切黑，不在试听室现场公布生死。
- 套间内绣有“E.F.”缩写的白色医用手帕只作为环境证物建立归属，不进入背包。
- Zack 若出现在广播站，口鼻仍系着这条手帕，只暗示 Foster 曾经介入。
- 只有 A、B 均成功才进入 C；C 本身不会把真结局重新判成坏结局。

## 四、结局矩阵

| A | B | 结局 | 主要存亡与去向 |
|---|---|---|---|
| 失败 | 成功 | 坏结局Ⅰ：两座家族重新分配城市 | Zack、Lawson 死亡；Vivian 投诚；Emma 独活并被全城排斥 |
| 成功 | 失败 | 坏结局Ⅱ：堕落的侦探 | Emma、Vivian、Lawson、小 Charles、Pierce 死亡；Zack 伪造现场后离开艾斯弗德 |
| 失败 | 失败 | 坏结局Ⅲ：来者不是援军 | Zack、Emma、Vivian、Lawson 死亡；小 Charles 与 Pierce 控制现场 |
| 成功 | 成功 | 真结局：两条线同时抵达 | Zack、Emma、Vivian、Lawson 存活；小 Charles 被控制，进入法庭后日谈 C |

## 五、每个结局的魅力点

### 坏结局Ⅰ：两座家族重新分配城市

玩家成功完成 Emma 线，却没能救回 Zack。门口出现的不是援军，而是持枪的 Pierce；Foster 确认 Zack 已死后放弃追赶并撤回嫌疑人走廊。Vivian 被门口与隔断后的两道枪线夹住，从身后拉住挡在自己面前的 Lawson，吻别后用自己偷带的 Colt 小手枪亲手杀死他，以投诚换取 Emma 存活。

魅力点：

- “局部成功仍被另一条线反噬”，让双线结构真正具有相互影响。
- Foster 的撤退不是背叛，而是她的“中立→友善”最终没有越过自保边界；A 失败使她失去了值得冒险的救援窗口。
- Vivian 不是突然变坏，而是在 Zack 已死、Lawson无法保住的局面里做出最现实也最残酷的选择。
- Emma 虽然活下来，却拒绝 Vivian 与小 Charles 提供的住所、工作和金钱；她失去公共信誉，但没有接受他们替她安排的人生。

### 坏结局Ⅱ：堕落的侦探

Zack 成功完成 A 并活着抵达广播站，Emma 线却已经全灭。小 Charles 声称 Miller 体系会把庄园惨案处理成家务事；Zack 随即杀死他，又返回试听室杀死昏迷的 Pierce，伪造 Pierce 畏罪自杀的现场，最终乘火车离开艾斯弗德。

魅力点：

- 玩家救下了侦探，却失去了侦探之所以坚持调查的人。
- Zack 把调查所得、现场判断与伪装能力用于制造假现场，成为自己曾经反对的人。
- 次日报纸只把事件写成“庄园内多人离奇死亡、Zack失踪”；终幕以 Zack 独自乘火车离城完成黑色犯罪片式收束。

### 坏结局Ⅲ：来者不是援军

A、B 全部失败。小 Charles 在广播站杀死 Emma、Vivian 与 Lawson；最后出现在门口的是已经杀死 Zack 的 Pierce。二人收走材料、封锁现场，继续控制官方说法。

魅力点：

- 这是最短、最冷的系统胜利，不再给角色额外的英雄时刻。
- 玩家等待的门口人影不是迟来的援军，而是最后一个执行者。
- 两条线的失败不是抽象结算，而是在同一个门口意象中合并为完整覆灭。

### 真结局：两条线同时抵达

Zack 依靠 A 活着抵达广播站，Emma 依靠 B 把小 Charles 困在隔断后。Zack 击落卡住隔断的枪托，Emma 完成最后锁定；Foster、Vivian 与 Lawson 的行动共同让众人活下来。

后日谈转入法庭。Foster 先纠正 Sean O'Malley 旧案与投毒文件的官方记录；随后 Zack、Emma 把 A 的通用报音规则与 Miller 设备参数组合起来，在被 Watts 弄乱的唱片组中找出正确母盘。二人一边吵嘴一边完成 C，最终让法庭公众共同听见小 Charles 弑父的录音。

魅力点：

- Zack 与 Emma 分别完成自己的谜题，任何一人都没有成为算无遗策、独自反杀全场的英雄。
- A、B 的成果不只决定生死，还在 C 中重新组合，形成从危机求生到公开证明的机制回收。
- 法庭吵嘴提供轻微荒诞感，释放庄园追杀的高压，再由母盘播放瞬间把气氛压回真相。
- 真结局的奖励不是再考一次会失败的难题，而是让玩家亲手完成 Zack 与 Emma 的重新合作。

## 六、给后续策划的边界提醒

1. 本路线没有“圆桌多数票抓住凶手”；圆桌必须公开失败，才能进入私下调查与停电追杀。
2. A、B 是两条独立生死线。不得提前在试听室展示 Zack 死亡或 Foster 的完整营救过程。
3. Lawson 藏入单人隔音间是固定转折，不设置错误藏身选项。
4. 小 Charles 的首要目标始终是 Lawson；Emma、Vivian、Zack 是阻碍追杀或掌握真相后才成为攻击对象。
5. Pierce 在高潮中不会反水。他是主动执行追杀的共犯，不设置“发现自己会被栽赃后改投 Zack”的人物弧线。
6. 除 Vivian 偷带的 Unit1 Colt 小手枪外，宾客一侧不得临时出现其他枪械；小 Charles 与 Pierce 的武器来自庄园内部权限。
7. C 只存在于真结局后日谈，负责合作、机制回收与公开真相，不承担新的生死分支。

## 七、角色在不同结局中的魅力与发展

> 本节只概括小 Charles 正确路线内部的分支变化。坏结局中角色越过既有底线，属于玩家失败造成的路线断裂，不反向改写角色档案中的常态设定。

### Zack

共同发展线：从“正确指出凶手”走向“能否真正保护具体的人”。他主动替 Lawson 引走 Pierce，A 的结果决定这次自我牺牲究竟换来救援还是死亡。

- 坏结局Ⅰ／Ⅲ：Zack 死在封闭试听室。他查对了凶手，却没能把真相转化成保护他人的力量。
- 坏结局Ⅱ：Zack 活下来，却因 Emma 等人死亡而越过底线。他处决凶手、制造假现场，成为“赢了谜题却失去侦探身份”的人。
- 真结局：Zack 活着抵达广播站，但只补上 Emma 计划所缺的最后一秒；他没有取代 Emma 成为独自解决一切的英雄。

角色魅力：同一个“保护别人”的选择，可以通向牺牲、堕落或真正的合作。

### Emma

共同发展线：从被释放的嫌疑人变成独立行动者。她负责护送 Lawson、选择藏身位置、逼出小 Charles 的弑父承认并亲手操作 B；Zack 是否活着，不影响这些动作属于她自己。

- 坏结局Ⅰ：Emma 成功完成 B，却亲眼看见 Vivian 杀死 Lawson。她活下来并被整座城市排斥，仍拒绝 Vivian 与小 Charles 为她安排的住所、工作和金钱。
- 坏结局Ⅱ／Ⅲ：B 失败后，她没有交出 Lawson，而是死在自己尚未完成的隔断计划前。
- 真结局：她成功改变广播站空间、困住小 Charles，并在受伤后完成最后锁定；法庭上再与 Zack 共同破解 C。

角色魅力：Emma 的价值不由 Zack 是否及时赶到决定。B 让玩家亲手证明，她既能信任 Zack，也能独立完成自己的选择。

### Vivian

共同发展线：她始终先判断怎样活下来。她把 Unit1 使用过的 `Colt Vest Pocket Model 1908` 偷偷带进禁枪的 Miller 庄园，始终保留着宾客一侧唯一未被收走的反击手段。B 成功让她拥有短暂的安全空间，但 A 的结果决定她等来的究竟是援军还是新的持枪者。

- 坏结局Ⅰ：Zack 已死、Pierce 到场，她第一次越过“不主动杀人”的底线。负伤的 Lawson 已经挡在她面前；她从身后拉住他，吻别后用自己的 Colt 小手枪亲手杀死他，以投诚换取 Emma 与自己存活。
- 坏结局Ⅱ／Ⅲ：B 失败，她拔枪反抗小 Charles 并被杀死；最现实的生存者最终没有得到重新计算立场的时间。
- 真结局：她受伤却活下来，没有替 Emma 完成 B，也没有在最后一刻投敌；她第一次依靠别人共同撑过无法独自控制的局面。

角色魅力：她不是固定的叛徒或伙伴。门口出现的是谁，决定她的生存逻辑把她推向背叛、反抗还是合作。

### Lawson

共同发展线：他在圆桌上拒绝公开站队，却私下开放最后调查；随后从提供调查时间的人变成小 Charles 的首要追杀目标。他藏在隔音间内听见哥哥承认弑父，并在 Vivian 中枪后主动冲出。

- 坏结局Ⅰ：他没有死在小 Charles 枪下，而是在与 Vivian 的吻别后被她亲手杀死。两人之间既有真实亲密，也有无法跨越的生存计算。
- 坏结局Ⅱ／Ⅲ：他为了保护 Vivian 冲出隔音间，直接死在小 Charles 手中。
- 真结局：他以同样的动作冲出、受伤，却因 Zack 及时抵达而存活；他不得不带着亲耳听见的弑父承认面对后续家族与 Tidewater 清算。

角色魅力：最不想继承王冠的人，反而成为所有暴力围绕的中心；他第一次明确选择的不是权力，而是冲出去保护一个具体的人。

### Foster

共同发展线：她以中立监督者身份进入套间，只在专业范围内为 A 提供提示。玩家先通过“E.F.”手帕建立她的物件归属，她对 Zack 的营救则被隐藏在枪响之后。

- A 失败的结局：门口出现 Pierce 后，演出才补充她的选择。她确认 Zack 已死，判断追赶持枪的 Pierce 已经无法救人，于是带着乙醚撤回嫌疑人走廊，不再承担额外风险。坏结局Ⅲ默认发生同一动作，但不重复展示。
- 坏结局Ⅱ：她救下 Zack，却无法决定 Zack 被救之后会做什么。她借出的医用手套最终出现在 Zack 伪造的自杀现场中，但她不是知情共犯。
- 真结局：她的营救只通过 Zack 身上的手帕得到暗示；她随后处理伤员，并在法庭上纠正 Sean O'Malley 旧案与投毒文件的官方记录。

角色魅力：相同的专业援助既可能救回一名伙伴，也可能被获救者用于堕落；Foster 只对自己的专业选择负责，不能替 Zack 选择如何使用第二次生命。

### Pierce

共同发展线：他始终是主动执行追杀的程序性暴力，不设置临场醒悟或反水。玩家不会看见他的内心，只会通过试听室枪声与广播站门口的人影判断 A 的结果。

- 坏结局Ⅰ：他杀死 Zack 后赶到广播站，仅凭站位与枪口便彻底改变 Vivian 的选择。
- 坏结局Ⅲ：他成为门口最后一个执行者，与小 Charles 一同收走材料、封锁现场并维护官方口径。
- 坏结局Ⅱ：他被 Foster 的乙醚迷倒，随后遭堕落的 Zack 杀死，并被布置成畏罪自杀者。
- 真结局：他在听取具体遗嘱条款时停步核实，最终被乙醚制伏；这不是道德觉醒，只是 A 为营救争取到的时间。

角色魅力：Pierce 既是追杀者，也是 A 的人形计时器；门口出现的是他还是 Zack，能够在没有解释性对白的情况下完成整条支线结算。

### 小 Charles

共同发展线：他的目标始终是杀死 Lawson，重新控制 Miller 家族与继承秩序。他在广播站被 Emma 逼得亲口承认弑父，但这段现场承认能否转化为公开真相，取决于 Zack 与 Emma 是否都活下来。

- 坏结局Ⅰ：B 已经困住他，A 的失败却把 Pierce 送到门口。Vivian 杀死 Lawson 并投诚，小 Charles 重新掌握 Miller 家族。
- 坏结局Ⅱ：B 失败使他成功杀死 Emma、Vivian 与 Lawson，但活下来的 Zack 拒绝让他进入由 Miller 控制的司法程序，直接将他处决。
- 坏结局Ⅲ：A、B 同时失败，他与 Pierce 杀死或清除所有能够阻止他们的人，成为唯一完成原定目标的结局。
- 真结局：B 限制他的物理行动，A 把 Zack 送到广播站，两条线共同剥夺他的最后反击；法庭母盘再把私人承认变成公众共同听见的弑父事实。

角色魅力：同一个凶手不会因结局不同突然改变计划。变化的是主角们能否把他的暴力依次从“可以执行”“可以掩盖”推进到“可以公开证明”。

### Lula、Moore 与 Watts

- Lula：正确路线中不进入广播站抢戏。她被没收的护士包与医用乙醚在幕后参与 Zack 的生死线，使一个被拘禁角色仍能间接影响真结局。
- Moore：全程留在嫌疑人走廊，不参与本路线高潮。他的缺席控制群像规模，也把金融犯罪片式的强演出完整留给 Moore 坏结局。
- Watts：不进入庄园追杀。他对远端母盘的编号、密封与保管只在真结局发生作用；被他弄乱的技术排序又为 Zack、Emma 的法庭合作保留一层轻喜剧操作。

辅助角色魅力：三人不靠强行冲入广播站获取存在感，而是分别以物件、缺席和远端保全影响故事，让正确路线仍保持 Zack／Emma 双线为核心。
