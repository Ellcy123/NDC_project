# Unit5 结局方向脑暴备忘

> 状态：脑暴记录，非定稿，不直接覆盖现有大纲、人物设定或六循环案件结构。
>
> 用途：先保存终章的新方向与待解决问题，之后再逐项讨论、验证并决定是否写入正式大纲。

## 一、这次调整最重要的方向

当前结尾整体偏克制：Zack 与 Emma 只完成了关系修复的第一步，许多情绪被压进小动作、留白和“以后也许会继续同行”之中。

新的方向是不再把“克制”当作终章最主要的完成感。前四章积压下来的死亡、隐瞒、愧疚、理想破灭和关系裂痕，需要在 U5 得到一次真正的情感爆发。结局仍然可以保留现实的不彻底，但人物不能只留下余味；玩家需要明确感到，他们终于把一直没有说出口的话说了出来，也真正做出了选择。

情感爆发不等于所有人痛哭、所有关系立即复原。目标是让压抑已久的矛盾抵达顶点，再产生一个玩家能够清楚感受到的释放。

## 二、Emma 与 Zack：补完整双向救赎

现有“双向救赎”的基本逻辑可以保留：U4 中 Emma 曾把 Zack 从 Mickey 的算法里拉回来；U5 中，这套价值观反过来阻止 Emma 被复仇吞没，Zack 则接住她停手后的崩塌。

但现在的版本主要完成了 Emma 一侧的救赎，Zack 从 Emma 身上重新获得了什么，还不够有力。新方向需要补上以下内容：

### Emma 的道歉

- Emma 可以为 U5 开篇争吵时伤害 Zack 的表达方式、彻底把他推开，或者故意用最刺痛他的语言攻击他而道歉。
- 她不为自己的愤怒道歉，也不为要求知情权道歉。Zack 确实替她决定了什么可以知道，这个错误不能被反过来算到 Emma 身上。
- 这次道歉不是让 Emma 认错服软，而是她在愤怒之外仍愿意看见 Zack 的恐惧、失去与善意。

### Zack 的承认

- Zack 必须承认自己隐瞒 Sean 页面和水源风险的事实，也承认自己正在重复 Mickey“由最懂局势的人替别人管理真相”的做法。
- 他不能用“我是为了保护你”换取原谅，也不能因为最终救到人就抹掉自己的越界。
- 他可以解释自己为什么害怕，但解释不能代替承担。

### Emma 对 Zack 的反向救赎

- Zack 从 Emma 身上重新看见自己年轻时的理想主义：相信真相值得追、相信普通人的选择仍然有意义、相信失败过后仍可以再试一次。
- Emma 不是用一段励志演说把 Zack 劝好。更有力量的方式，是她已经知道报道可能失败、司法可能拖延、系统不会彻底倒下，却仍然决定把真相写出来。
- Zack 因此意识到，理想主义不是“不知道世界有多坏”，而是在已经知道以后仍决定再拼一次。
- 这一刻是 Zack 的真正救赎：他不再把自己当作唯一承担者，也不再因为害怕失去而替别人选择；他重新决定与别人一起寻找真相。

### 关系落点

- 两人不在 U5 结尾立刻恢复搭档关系，避免此前的裂痕被一次道歉轻易抹平。
- 但结尾不能只留下含糊的“也许”。玩家应当明确看到，两人重新相信了彼此，未来再次同行已经成为真实可能。
- 具体表现可以是一次坦白、一次失控后的拥抱、共同完成报道或交换调查材料；采用哪种动作以后再定。

## 三、结尾需要一份明确的慰藉

终章可以保留“城市仍会继续运转”的苦涩，但不能让玩家在经历五章后只得到系统仍然存在的结论。需要至少一个清晰、具体、属于人的好结果。

当前候选慰藉是：Mary 与 Helen 最终被放出来。

- 她们的获释可以证明前几章的调查、报道、Harrison 留下的材料以及众人的作证确实改变了一件具体的事。
- 这个结果不代表制度突然变好，而是代表足够多的人留下记录后，制度终于无法继续维持原判。
- 结尾可以让 Zack 与 Emma 亲眼看见她们走出法院或拘押处，使“真相改变现实”不只停留在报纸标题和程序文件上。
- 法律上如何成立需要以后单独解决。Mary 与 Helen 涉及预谋、合谋与正当防卫边界，不能一句“无罪”带过；可讨论改判、撤销死刑、刑期折抵、检方撤回部分指控或特别宽赦等路径。

虽然其他熟悉人物多数已经死亡或无法回来，但 Mary 与 Helen 活着离开，恰好能让结局告诉玩家：不是每一次努力都来得太晚。

## 四、多结局与假结局

U5 可以采用少量多结局，但不需要为了数量制造大量平行世界。初步方向是：一个主要真结局，加一至两个具有主题意义的假结局或偏离结局。

### Charles 的贿赂假结局

当 Charles 发现主角已经锁定他是凶手后，可以提出交易：金钱、身份、房产、报社资源或进入上流社会的通行证，换取证据消失和报道沉默。

如果玩家接受：

1. Zack 与同行者获得短暂的荣华富贵，生活看似立刻变好。
2. 画面快速展示两人逐渐替 Charles 处理麻烦、替自己解释第一次妥协，并越来越离不开这套利益。
3. 最后让玩家看见，他们没有战胜系统，而是成为了系统新的接口，最终被自己接受的黑暗吞没。
4. 假结局结束后回到接受贿赂之前的选择节点，不要求玩家重跑整个章节。

这个结局主要提供黑色幽默和“看看如果真收钱会怎样”的乐趣，同时把全系列主题变成一次可玩的反面证明。

待确认问题：最初脑暴中写的是“Charles 贿赂 Mary 和 Zack”。需要以后确认这里的 Mary 是确指 U3 的 Mary，还是 Emma 的口误。按照当前 U5 主角关系与案件位置，Emma 与 Zack 更自然；如果确实是 Mary，则必须补足她为何出现在终局并有资格共同决定证据去向。

### 真结局的数量

- 可以只有一个完整真结局，把选择重点放在玩家是否拒绝交易、是否公开全部真相。
- 也可以保留两种真结局余味，例如“司法公开”与“报道公开”，但二者不能让某一个明显成为内容缩水版。
- 假结局应该短、鲜明、可回退；真结局负责人物弧光和系列收束。

## 五、宝石收集与鉴赏玩法

U5 已经存在重要的宝石核心：真正锁住小 Charles 的不是他留下了宝石，而是他拿走了一颗只有知情者才会害怕的无编号宝石。新加入的收集玩法应服务这个“啊哈”时刻，而不是与案件平行存在的装饰系统。

可考虑：

- 庄园内分布少量可观察或登记的宝石、矿物与家族钥匙，每一件附带简短而有趣的现实知识，例如硬度、切割、包裹体、产地传说、仿制方法或当时的商业用途。
- Lawson 可以承担部分宝石知识与收藏背景，但不能直接替玩家解释终局答案。
- 玩家在前期通过收集自然熟悉“每颗登记宝石都有编号”“不同切面会留下什么轮廓”“家族钥匙与普通饰物如何区分”。
- 终局时，玩家利用自己建立的宝石认知，意识到血泊里的椭圆空白对应的不是一颗遗失首饰，而是一颗被刻意拿走的机关部件。
- 收集不宜过多，也不应要求查百科才能破案。即使没有全收集，核心推理材料仍必须完整；收集齐全可以提供更早的怀疑、额外对白或收藏页完成奖励。

需要避免的问题：

- 宝石介绍过早把“无编号宝石就是暗门钥匙”直接说破。
- 收集数量太多，冲淡终章紧迫感。
- 把唯一关键证据藏进可错过收集物，破坏公平推理。
- 宝石只负责科普，没有在最终推理中产生回收。

## 六、Loop 数量与推理篇幅

U4 之后，玩家已经进入等待总答案的状态。U5 不一定继续保持六个完整 Loop，可以考虑压缩到五个以下，把更多时间留给人物关系、终局选择和系列余波。

目前优先讨论的候选是“四个 Loop 加非 Loop 终局”，但这只是方向，不是已经决定的新结构。

压缩时必须守住以下底线：

- 推理篇幅可以减少，推理质量不能变成“很快找到一份文件，上面写着 Charles 是凶手”。
- 每个 Loop 仍要回答一个清楚的问题，并把玩家推向下一个问题。
- 当前六循环中 Pierce、Foster、Vivian、Moore、Lula 各自承担死亡链的一环；以后必须判断哪些可以合并，哪些一旦删掉就会破坏“所有人的小真话围住 Charles”的结构。
- 终局必须保留一个玩家亲自完成的“啊哈”时刻，而不是由 Zack 或 NPC 讲答案。

现阶段最适合作为核心“啊哈”的仍然是：

> 玩家一直在找凶手留下了什么，最后才意识到，真正暴露凶手的是他拿走了什么。

宝石收集玩法可以为这个翻转提供长期铺垫。玩家先把宝石当作收藏、家族趣闻与庄园规则，最终才发现这些知识其实一直在教自己如何识别凶手的清理行为。

## 七、终章情绪顺序的初步设想

为了避免推理高潮、假结局、人物爆发和温暖尾声互相抢戏，可以暂时按以下顺序理解：

1. 宝石推理完成，玩家获得最后一次明确的“啊哈”。
2. Charles 提出贿赂，出现可回退的假结局选择。
3. 玩家拒绝交易，进入真正的指证与公开。
4. Emma 与 Zack 的矛盾爆发并完成双向救赎，但不立刻恢复搭档身份。
5. Mary 与 Helen 获释，给玩家一个具体的好结果。
6. 最后再回到“城市仍在继续”的余味，使苦涩建立在已经赢下一件事之后。

这个顺序以后仍可调整。关键是不能让“系统不会消失”压过人物刚刚赢得的东西，也不能让温暖尾声冲淡 Charles 案件的代价。

## 八、后续逐项讨论清单

1. Emma 在开篇争吵中具体说了什么，她究竟为什么道歉。
2. Zack 通过 Emma 想起的“过去的理想主义”具体来自哪段经历，是否需要前章伏笔。
3. 情感爆发采用争吵、坦白、拥抱、共同写稿还是其他动作。
4. Mary 与 Helen 获释的法律路径和时间点。
5. “Mary 与 Zack 接受贿赂”是否为人名口误。
6. 假结局的长度、表现方式和回退规则。
7. 真结局保留一个还是两个，彼此差异是什么。
8. 宝石收藏数量、知识内容、奖励和终局回收方式。
9. 六 Loop 压缩为四或五 Loop 时，各 NPC 功能如何合并。
10. 最终核心推理怎样让玩家亲手完成，而不是由角色代替总结。

---

本备忘只锁定一个总方向：U5 的结局要比当前版本更热、更痛、更明确。它可以承认系统仍在，却必须先让玩家看见人物真正哭过、说过、选择过，也确实救下了某些人。
