## 一、整体变更概述

采用已整理的五轮案件，不导入历史六轮稿。主代理建立原文索引、覆盖计划、控制权流与统一ID；叙事、推理、系统三名独立工作者各审其维度，总监收束后由 State 架构工作者分工生成并交叉复核。没有虚构多个角色由同一人自我辩论；本轮没有需要两套盲产方案解决的未定剧情。

终局由最后一份 State 的 ending_sequence 承载：最终投票、两条误指固定坏结局及小 Charles 路线 A/B 互动、四种结算、双成功后的纯法庭。不是L6，不把已批准的玩家操作删除。

## 二、权威时间线

完整来源为主大纲第四节；生成的《案发时间线与动线》区分幕后事实和玩家获知时点。不把约数补为未经批准的精确分钟。

锁定14秒低头、20秒全程、10秒镜后路程；18:05团队未转楼梯，21:15仍B；坠落约21:25，致命刀刺约21:30，刀后唯一B→A；21:38 M-7止付；22:00破门、22:10/22:15固定曝光。取齿回查、人物自由流动不构成新的排他作案窗口。

## 四、各 Loop 详细设计

### Loop 1

医院到圆桌的全部章开场纳入同一个根Opening，多场景以change_scene+next续接；不演幕后补材料/预约录音。恢复控制后覆盖舞台、走廊、C-3背面、后台突发事件、安保室、圆桌Lawson和通讯台。Foster手帕可选调查后才触发关系选择，不成为证据完整度要求。三轮指证依次打身份、反射方向、时间距离；最后只有第二人可行路线，不锁定刺客。

### Loop 2

Emma苏醒及消防卡观察为开场，走廊Pierce/Vivian仍有普通问话。Foster只有取得导轨血滴后才完成伤序。批准联的“隐瞒念头”不是可丢弃证据的真实分支；Zack固定公开。三轮为停位、日期、血滴叠压。指证后Vivian关系选择只决定B提示。

### Loop 3

礼堂提出测高后开放三处测量和Moore房间。第一次剖面在当前场景自动弹出，9−3−4=2；第二次在圆桌定位A位楼梯，只给可能入口；AVG实地开门后开放第一岔口搜证。获批新增Moore普通问话取得R1。三轮用公文夹/铆圈、催签急件、M-7/发送联；post-expose同段打开书房端，不回礼堂重走。不生成合成复原页。

### Loop 4

押Moore进入看守房后主线不再让其离房。Emma披露远端刻录安排并引向录音室；Foster问话仍自由取得。护士站、书房、夹层柜、护工房分别承载药物、缺页与身份材料；乙醚仅护士站环境。R1复用Mary“亲送心脏病药”的原始语义锚，不改写普通原句；R2后Mickey中间选择再接身份轮。Pierce承担现场两次指控；末段三件材料小推理洗清Emma，不造三件condition疑点。

### Loop 5

释放Emma、隔离Lula后取得Vivian两段有限口头记录；公共流动不透露照片已调换。取齿关门→Lawson办公室取石比对→返回暗门→Emma特殊握姿实验→最后开放照片墙。旧照片组和湿痕保留原ID与分层观察。两次公共推理完成后，获批新增小Charles普通问话，才进入候选选择/正式指证；错误指Lawson可回查重选，不进入永久坏结局。三轮末仅有限认罪，唯一续接终幕投票。

### 疑点与材料合同

采用推理预检15项最小疑点，每轮3项、0碎片。具体condition见各State，理由与原文锚见[puzzle_preflight](./state/reviews/puzzle_preflight.md)。基本收集度100%不替代必要问话、公共推理和小游戏状态。

跨轮只定义一次原物：5106由L1取得、归L3疑点；5306/5311由L3取得、归L5疑点；5204由L2取得、L5才解读暗角变化。它们首获轮不被强行挂一次疑点，后续也不复制物证。5154镜子和5457档案缺口以环境观察适配保留，不入包。

## 五、关键设计问题与裁决

| 问题 | 依据 | 处理 |
|---|---|---|
| 通用终幕禁操作 | 用户明确批准本章互动 | 保留A/B，纯演出段不加自由探索 |
| Moore/小Charles R1缺普通入口 | 用户明确选择增加前置普通问话 | 原句、原场景、最晚合法阶段补入口；不提前R2+ |
| Emma投票身份残留 | 主纲与详案均明确已释放 | 保留协查与不投票，省略过期拘禁理由、不新增理由 |
| Mary普通口供不等于整句R1 | 原文亲送心脏药已为虚假语义锚 | 保存原文，现场R1重申加码；不扩写普通证言 |
| 旧人物档案冲突 | 现行大纲权威 | 保留背景，拒绝旧案情反向覆盖；档案同步另列风险 |
| 环境物证不在现有Expose池 | 当前Unity代码预检 | 设计期environment_observed，明确待适配，不改成可拾取物 |
| 1602跨章库存 | 当前切章重置ItemMgr | 记录合法外部导入依赖；不伪造初始库存、不把缺配置判为玩家错误 |

## 十一、连续性与 Unity 入口映射

每轮一个initTalk根；同场next、跨场change_scene+next，目标不重复firstEnterTalk。自由NPC用TalkInfo，突发事件用event_triggers。固定链包含Talk/flag条件时写special_adapter。L5末轮指证不提前loop_end；终幕分支各终点才loop_end+chapter_boundary，通关菜单映射留运行时验证。

四玩法、环境指证、跨章导入与终幕保存恢复仍是待实现接口。详见[运行时预检](./state/reviews/runtime_preflight.md)，不得把设计YAML可解析等同于Unity可运行。
