# Unit 5 大纲 v0.9 — 四 Loop 可玩化补全版

## 系统没有主人：拿走宝石的人

> 本稿以 `Unit5_大纲_0601.md` 的案件真相为基础，吸收 `Unit5_结局方向脑暴备忘.md` 的全部方向。
>
> 核心调整：删除原 L2 的 Foster 独立指证；原 Vivian、Moore、Lula 三轮依次前移；小 Charles 的指证改为非 Loop 终局。Foster 的关键戏放到终局前后，不占一个 Loop。
>
> 结构：四个调查 Loop + 非 Loop 终局 + 单一真结局 + 一个可回退的贿赂假结局。
>
> v0.9 补全范围：不改案件真相与四 Loop 结构，只把每轮补到“开篇认知—分场景探索—证词/道具—疑点—逐轮指证—指证后转向”的可玩大纲粒度。本稿不预填道具、证词与对话 ID；正文 SC 号只沿用 / 暂定为场景定位符，不表示已经占用 SceneConfig。

时间：1928 年 12 月 8–13 日  
地点：暴风雪封锁下的 Miller 私人庄园  
核心命题：系统让坏人也以为自己是好人；真正的理想主义，是知道世界有多坏以后仍愿意和别人再试一次。

## 图例

- 🟢 证据 / 道具：玩家可获得、拍照、分析或用于指证的物件与线索。
- ⚪ 证词：NPC 说出的有效信息，统一写成“人物：内容”。
- 🟡 谎言：NPC 在正式指证中主动说出、等待玩家击破的止损说法。
- 🟣 环境叙事：承担背景、情绪或世界信息，不进入正式指证。
- 🔵 跨 Loop 关联：当前获得、后续继续解释或使用的信息。
- ⚔️ 指证：玩家选择证词与道具击破谎言的环节。
- 🎮 小玩法：时间线、关系网、痕迹比对或物品分析等玩家操作。
- 🧪 派生证据：由分析、拼合或比对产生的二级证据。
- ❓ 疑点 / 碎片：装载指证材料、推动玩家进入下一步推理的问题。

落表边界：所有 🧪 结果最终均按 `Item · 派生`进入 ItemStaticData；Clue 照片只参加独立的视觉叠合 / 痕迹比对小玩法，真正进入 Expose 的是其派生 Item。普通疑点 condition 不超过 2，碎片只挂 1 件材料；逐轮退守产生的新证词用动态疑点承接，不计入当前 Loop 开场的 100% 指证门槛。

## 一、本版最重要的变化

1. 保留原案的凶手、坠落意外、嫁祸 Emma、夹层暗门和无编号宝石诡计。
2. 调查压缩为四个 Loop，每个 Loop 只正式指证一个人：Pierce、Vivian、Moore、Lula。
3. Foster 不再拥有独立 Loop。她前期继续提供指向 Emma 的删节版验尸结论，终局前才承认自己删掉了真话，并在庄园公开指证与后续法定程序中说出 1912 年 Sean 假尸检的事实。
4. 小 Charles 的指证放在非 Loop 终局，由玩家亲自完成“凶手拿走了什么”的宝石推理。
5. 结局不再只靠克制和留白。Emma 与 Zack 会正面承认错误、失控、拥抱，并明确选择重新相信彼此。
6. 真结局只有一个。玩家可以先进入一次短暂的贿赂假结局，随后回到选择点。
7. Mary 与 Helen 最终获释，成为玩家亲眼看到的具体胜利。
8. “城市继续”仍然保留，但放在人物已经赢下一件真实的事之后。
9. Vivian 的背叛与 Foster 的觉醒形成镜像：系统不要求她们亲手杀人，只要求专业记录里少掉或挪动一句足以改变结论的话；Vivian 为新的位置把时间写早，Foster 则在终局把自己曾删改的死因与限定交还出来。

## 二、不变的案件真相

老 Charles 并不是被人设计从夹层暗门坠落。坠落是一场由多个人分别造成的意外：

- Vivian 为晚会效果把旋转楼梯从 A 位移到 B 位，不知道 A 位原本承接舞台暗门。
- Lula 给老 Charles 的日常药里加入安眠药，想让他睡着后寻找旧案材料。老 Charles 察觉药粉气味和状态异常，假装服下、实际把药留在杯中；这份警觉使他避开公共走廊、改走私人夹层。
- Moore 为了逼老 Charles 处理账目，跟进夹层追问，使老 Charles 更急于从另一端离开。
- 老 Charles 推开舞台暗门时，以为脚下仍有 A 位楼梯，实际踩空坠落约四米，重伤但没有立即死亡。他本能抓住暗门卡座，使一枚带掌心尺寸、平底配重椭圆金属底托的无编号宝石机关嵌件脱落；锁扣已经变形松开，暗门仍可开合。
- 暗门失去受力后会依靠自重回弹重新贴平，坏的是锁扣而不是闭合能力；老 Charles 又落在门下偏侧。因此后来从礼堂侧门进入的人不会一眼看见敞开的暗门，也不能只凭落点判断坠落路线。

小 Charles 原本已经计划杀父并嫁祸 Emma。他不知道父亲刚刚经历了什么，到达舞台后只看到父亲倒地但仍活着，于是照原计划补刀：

- 他事先给 Emma 的安神酒加入镇静剂。
- Emma 到礼堂演讲台附近后药效发作，演讲被临时取消；她被留在后台帘后的休息位。小 Charles 借安保空窗从侧门进入后，能在同一封闭空间内把她拖扶到尸旁。
- 他刺死老 Charles，把半昏迷的 Emma 摆到尸体旁。
- 他把楼梯从 B 位调回 A 位，恢复成一个容易被理解的“楼梯事故现场”。
- 他在喷溅血迹区发现从机关卡座脱落的无编号宝石嵌件，认出它会暴露暗门，于是将它拿走。血滴已经绕过椭圆底托，在地面留下稳定的遮挡空白与浅色蜡面边缘。
- 他随后利用 A 位楼梯进入暗门，通过夹层离开反锁礼堂。

物理现场恢复之后，小 Charles 还需要恢复一份对外成立的时间线。破门后，他借 Miller 庄园事务室延续老 Charles 与 Vivian 之间的旧交换，送出一份看似合规的续约要约：蓝月亮的庇护继续有效，Vivian 也能重回南区娱乐项目的承包候选，但资格以“当晚舞台机械不存在重大未授权操作、承办方不承担独立过失”为前提。小 Charles 没有明文命令她改表；他知道如实记录晚间复位就会让利益条件失效，把选择留给 Vivian 自己完成。Vivian 明知团队 18:05 离场时楼梯仍在 B 位，仍在案后补写“18:05 已正常 B→A、此后始终为 A”。这份假记录抹去了命案时段的未知操作者，让 Emma 更像礼堂内唯一完成坠落、补刀与现场动作的人。

Vivian 不知道 Emma 是否无罪，也不知道暗门、四米落差、坠落真因或真正复位者。她的阴暗选择不在 17:00 那次正常工作，而在案后：她知道自己卖掉的是一条可能救 Emma 的时间矛盾，仍用它换取保护和向上爬的机会。

小 Charles 最终暴露，不是因为他留下了宝石，而是因为他拿走了宝石。

## 三、序幕：U4 后果与关系裂缝

### 医院走廊

Zack 与 Emma 进入 O'Hara 家，确认她出现疑似水源中毒症状。Emma 通知 Rosa 暂时不要把 Sarah 送回来，O'Hara 随后被紧急送医。本稿不额外锁定 O'Hara 的最终生死。

在医院走廊，Emma 得知 Zack 早已掌握部分水源风险和 Sean 页面，却替她决定了什么时候可以知道。

Zack承认自己隐瞒了材料，却仍本能地解释自己害怕 Emma 冲进危险。Emma最愤怒的不是他判断错了，而是他根本没有让她参与判断。

争吵最痛的一句暂定为：

> “你不是怕我受伤。你只是觉得自己比 Mickey 更有资格替别人决定。”

Emma 说完后也知道这句话是故意冲着 Zack 最深的伤口去的。她不收回自己的愤怒，但两人的关系彻底破裂。她拒绝继续与 Zack 共享调查计划。

### 真相被当成武器

晚宴前，小 Charles 单独找到 Emma，主动告诉她：

- 1912 年港口事故不是意外。
- Sean O'Malley 发现问题后被 Miller 系统杀害。
- Miller 与 Tidewater 借事故吞下南区土地。
- Emma 接受多年的资助，是杀父系统用来经营形象的赎罪外壳。

小 Charles 让 Emma 去晚宴上质问父亲。他不是良心发现，而是需要 Emma 带着最真实、最公开的杀人动机出现。

### Vivian 把席签往前挪

U1 结尾，Vivian 撕掉离开的船票，留下蓝月亮，也确实继续替厨房和后巷那些没有身份的人撑住一块地方。这部分没有作假。但此后酒吧的玻璃被砸、执照被卡、供应被断，她逐渐把“逃出系统”改成了另一个愿望：既然桌外的人永远等不到保护，她要坐进决定保护分给谁的那张桌子。

晚宴筹备时，事务员把她的席签放在演职人员一侧，仍称她“蓝月亮那位歌女”。Vivian 没有发火，只把席签换成“南区娱乐承包候选”，移到承办席。这个动作不承担谜题信息，只提前种下两种同时为真的动机：庇护是她能说服自己的生存需要，承包席位则是她主动想要的权力诱惑。

## 四、案发夜简要时间线

### 17:00 楼梯第一次移动

Vivian 为 Emma 的演讲入场效果，安排团队把旋转楼梯从 A 位移到 B 位。所有流程都有登记，她不知道这样会让舞台暗门外变成四米高的空洞。

### 20:30 Emma 与老 Charles 冲突

老 Charles 在书房继续羞辱 Emma，并炫耀 1912 年旧案。Emma 情绪失控推开他，但这一推不致命。她因此留下真实的自责：“我恨过他，我也确实动过手。”

### 20:50 两种药

小 Charles 亲手把掺有镇静剂的安神酒交给 Emma。与此同时，Lula 以 Mary Jones 身份在老 Charles 的日常药中加入少量安眠药。

Emma 意识逐渐模糊。老 Charles 闻出药物异常，假装服下、实际把近乎完整的药留在杯中；他因此怀疑公共动线不安全，决定通过私人夹层去赴儿子的约。

Emma 仍按流程抵达礼堂演讲台附近，随即因药效无法站稳。Vivian 取消演讲，让她暂时躺在后台帘后的休息位；此后她没有自行离开礼堂。

### 21:00 夹层追逼

Moore 看到老 Charles 进入书房暗门，跟进去逼谈账目。老 Charles 将他喝退，随后从夹层另一端推开舞台暗门。

### 21:25 意外坠落

楼梯仍在 B 位。老 Charles 一脚踩空，从暗门坠到舞台偏侧。坠落时他抓坏机关卡座，带椭圆金属底托的无编号宝石嵌件脱落到地面；卡座锁扣被扯松，暗门没有因此失效，门板随后依靠自重回弹重新贴平。

### 21:30–21:45 刺杀

小 Charles 借 Pierce 留出的空窗，从会自动回扣的礼堂侧门进入。暗门已经贴平、父亲落点又偏离门下，他并不知道坠落原因；他只发现父亲还活着，便继续执行原来的杀父计划。刺杀时新鲜滴溅绕过地上的宝石金属底托，在喷溅区留下带浅色蜡面边缘的椭圆遮挡空白。

### 21:45–22:00 恢复现场

小 Charles 随后从后台帘后拖扶 Emma、制造接触血迹，把主门从内侧上闩；侧门在他进入后已经自动回扣。他把楼梯从 B 位调回 A 位、拿走宝石嵌件，再利用已经松开的暗门经夹层离开，形成两个公共门都无法解释离场的反锁礼堂。

### 22:00–22:30 破门与第一现场

Pierce 召集在场者作证后，要求所有人退到门框外并倒数破门。晚宴新闻摄影师提前架好大画幅相机、装好镁粉盘，在门扇弹开的瞬间从门外拍下第一张玻璃底片；连续底片编号与多人证词共同固定了拍摄发生在任何人跨过门槛之前，也让掌心尺寸的金属底托轮廓足以在后续放大页中辨认。小 Charles 随后以悲痛继承人身份赶到，公开跪到尸体旁，使他能够用“破门后的接触”解释衣物沾血。

### 22:30 后 被买下的复位时间

在正式舞台记录提交前，Miller 庄园事务室向 Vivian 送来一份事故庇护与承包要约：继续保护蓝月亮，并恢复她在南区娱乐项目中的候选资格；风险条款只写“资格以当晚舞台机械不存在重大未授权操作、承办方不承担独立过失为前提”。文件没有要求她改表，不写凶手、暗门或具体操作，也没有小 Charles 的亲笔签名；此时只能证明 Miller 体系摆出了一项会奖励“干净记录”的利益条件。

Vivian 接受要约，案后补写“18:05 团队已经正常将楼梯 B→A，此后直到破门始终为 A”。真实时序却是 21:15 楼梯仍在 B，致命刀刺之后才有人将其调回 A。Vivian 知道自己的版本会把命案时段那次未解释的晚间操作从记录中删除，使 L1 的侧门来人更容易被说成无关者，继续强化 Emma 单独作案的解释；她不知道是谁复位，也不知道这次复位与暗门、坠落的真正关系。

## 六、宝石收集与鉴赏玩法

庄园内设置五个简短的宝石或矿物鉴赏条目，不做大规模收藏系统。

### 两个主线必看条目

1. Miller 家族宝石登记册摘页：每一颗正式登记的家族宝石都有编号、持有人和用途。小 Charles 在入庄园时亲自展示这一规则，玩家必得摘页。
2. Lawson 的镶嵌说明：宝石从卡座或机关中脱落时，会因切面和金属底托形状在灰尘、蜡或液体中留下稳定轮廓。Lawson只讲通用知识，不知道礼堂暗门使用了这种结构。

### 三个可选条目

1. 硬度与刮痕：用于增加世界细节。
2. 包裹体与仿制品：说明贵重与真假不能只看光泽。
3. 切割与商业用途：说明同一种矿物也可能是饰物、印章或机械装饰件。

### 玩法边界

- 玩家不会取得已经被小 Charles 拿走的无编号暗门宝石实物；主线必得的是公开编号规则、变形空卡座、椭圆遮挡空白和宝石消失时序。
- 即使玩家完全不收集三个可选条目，也能完成最终推理。
- 收集齐五个条目，只奖励一段 Lawson 的额外对白、一次提前怀疑小 Charles 的内心提示和收藏页完成标记。
- Lawson 只讲宝石常识，不能直接说出“血迹空白就是暗门宝石”。

## 七、四个调查 Loop

场景负载执行说明：每个地点实际只设置 1–3 个核心调查包；下列同一结论下的多件原始材料在场景中合并为一次热点调查，再在证据页拆成独立条目。例如礼堂的“破门现场封存包”、安保室的“巡查文书包”、Moore 客房的“不在场 / 鞋页 / 财务”三包、护工房的“冒名身份包”、酒水间的“E-12 连续保管包”。不得把每个子条目都做成一个新的主交互目标。

### 🔄 Loop 1：Pierce —— 守夜人的空窗 · 2 轮

**🎯 核心问题：礼堂真的没有人进出吗？**

#### 开篇与玩家初始认知

- Emma 半昏迷在尸体旁，手上有血，餐刀在身边；她刚刚公开质问过老 Charles，也承认在书房推过他。
- 门从内侧闩住，Pierce 声称 21:00–22:00 全程按标准路线巡查，没有任何人接近礼堂。
- 小 Charles 以“悲痛的儿子、仍愿保护 Emma 的赞助人”姿态出现，反对立刻把她交给警察。

#### ⚔️ 正式指证 @Mary Jones 的护工房

##### R1：击穿“Mary Jones 是合法派遣身份”

- **谎言：** “我是护理机构临时派来的 Mary Jones，与 Frank 和 Miller 旧案没有关系。”
- **需选证词：** 护理机构值班登记员的派遣证词。
- **需出示：** `Mary 冒名—Lula 身份对应页`。
- **击穿逻辑：** 登记证词证明派遣不存在，身份对应页再把换照持证人与 Frank 的伴侣 Lula 落成同一人；登记证词或人像材料任一单独都无法同时完成“假身份”和“真实身份”的闭环。
- **本轮承认：** 她就是 Lula。Mickey 帮她以护工身份进入庄园，她要找回 Frank 与 1912 年旧案的材料。
- **主动退守：** “冒名只为搜文件。我没有领取、拿走或加入任何药物，更没有碰 Emma 的酒。”

##### R2：击穿“只搜文件、没有碰药”

- **谎言：** “我没有领取任何安眠药，也没有动老 Charles 的药杯。”
- **需选证词：** 老管家关于 20:50 送药、收回近乎完整药杯的证词。
- **需出示：** `老 Charles 药杯添加物—护理包制剂相符报告`。
- **击穿逻辑：** 管家证词锁住她递送药杯的保管区间；护理包缺失剂量与杯底添加物的制剂比对锁住可检范围内的一致性。缺药只能说明药不见了，异常药杯只能说明被加过，二者与保管链合并才击穿她的否认。
- **指证后承认：** Lula 只想让老 Charles 睡着后搜查档案，加入了少量安眠药。老 Charles 闻出异常、假装服下并留下药杯，反而因警觉改走私人夹层。她没有给 Emma 下药——这句是真话。

#### 指证后分析与角色转向

1. 玩家先完成 `两种药制剂差异报告`，Lula 随后只解释药理差异；再与老 Charles 药杯、E-12 酒杯各自的保管链交叉，玩家才把它们拆成两个投放人，不能由 Lula 替玩家提前宣布结论。
2. 玩家再组合 Emma 的症状、礼服与接触血迹，确认她是被拖扶和摆放到尸体旁的人。她的书房推搡和杀父动机仍为真，但不足以支持舞台刺杀、楼梯复位和密室离场。
3. 侍酒人、Vivian、公共瓶和单杯样本共同形成唯一保管区间：镇静剂 B 只能在小 Charles 独占酒杯时加入。此时只把他提升为首要嫌疑，不由 Zack 直接宣布他就是凶手。
4. `同编号庇护与承包撤回通知`证明小 Charles 已经撕毁 L2 的交易，并准备把假记录归成 Vivian 的个人行为。她因此公开此前一直扣住的递杯证词，交出两份投毒材料；她仍保留 Webb 全部档案，准备在 Miller 倒下后继续谈条件。L2 是她为位置卖掉一段真相，L4 是她发现位置从未属于自己后，把另一段真相重新拿来出价。

#### 本轮答案

Lula 是造成老 Charles 警觉并改走夹层的一环，却不是刺杀者；老 Charles 没有真正服下她的药。Emma 所中的则是另一种单杯镇静剂，她被人拖扶、摆放并嫁祸，已无法作为刺杀、调梯和密室布置的执行者。

#### 进入终局

小 Charles 已被单杯保管链强烈指向，却仍可以把镇静解释成“保护 Emma”，也可以否认进入礼堂。玩家必须把 Foster 删去的活体反抗事实、完整夹层知识和喷溅区里消失的椭圆机件连成一条不可替代的现场链。

## 八、非 Loop 终局

### 终局第一段：Foster 终于说出真话

- **本层揭示边界：** 只锁定在场者中的完整能力，不证明实际进入，更不提前解释宝石。

##### R3：父亲仍活着时的舞台接触

- **主动谎言：** “破门前我没有在舞台碰过父亲。就算纤维来自我的衣服，也只能是更早的家庭接触，或我后来跪在尸体旁留下的。”
- **需选证词：** Foster：“卡座蜡尘先进入坠落新形成的甲缘裂口，深色纤维随后与致命刀刺活体出血压入同一处；这次抓袖发生在坠落后的舞台刀刺时。”
- **需出示：** `晚宴外套纤维排除与袖口缺丝报告`。
- **击穿逻辑：** Foster 用新伤与蜡尘层位锁定形成时机、地点和接触方式，衣物报告再从所有案发当夜封存的深色外套中把对应线束落到小 Charles 新破损的袖口。只说“深色西装”不能定人；只有时空层位、完整比对池与衣物缺丝交叉，才能证明他在破门前接触过仍能抓扯的父亲。
- **被迫承认：** 他承认自己借安保空窗从礼堂侧廊进入舞台，父亲倒在地上但仍活着，也抓过他的袖口。当时楼梯仍在 B 位，他不可能从四米高的夹层暗门进入。
- **主动退守：** “我从侧廊进去时，已经有另一个人刺伤了他。我只想扶他；看见场面失控，我又从礼堂内部绕回前厅。之后是那个人反锁并处理现场。我没有刺他、摆放 Emma、调楼梯，也没有拿走任何东西。”
- **本层揭示边界：** 已证明他在刺杀窗口接触活着的死者并隐瞒行踪，但“去扶父亲”的退守仍需由现场处理证据击穿。

##### R4：被拿走的无编号宝石机关嵌件

- **主动谎言：** “地面的椭圆空白可能是任何物体。即便真有宝石，也可能是 Pierce、Foster 或 Lawson 在破门后顺手拿走；我没有移动现场的任何东西。”
- **需选证词：** 晚宴新闻摄影师：“门被撞开的那一刻我从门外按下快门，镁光亮起时还没有人跨过门槛。底片编号与前后两张连续；Pierce 还握着破门器，Foster 和 Lawson 都在我的画面里。”
- **需出示：** `卡座缺口—椭圆遮挡轮廓比对报告` + `破门首张玻璃底片放大页` + `未登记宝石机关嵌件辨识页`。
- **玩家判断一——原物是什么：** 选择“从变形暗门卡座脱落、带椭圆金属底托的无编号宝石机关嵌件”。卡座尺寸、蜡面边缘与喷溅遮挡轮廓一致；普通饰物与杯底都不符合三处形状。
- **玩家判断二——何时、为何消失：** 选择“刀刺后、破门前被人取走，因为它会暴露舞台暗门”。血迹绕过底托说明刀刺时它仍在；首张底片证明任何公开进入前它已经消失，清点表只佐证后来登记中也没有该物。取走与摆放 Emma、调楼梯的具体先后留给自白，不由现有物证过推。
- **玩家判断三——谁能完成：** 选择“小 Charles”。调用 R2 的完整路线能力、R3 的舞台活体接触、礼堂双门闭锁与各替代者在场链：他既能认出秘密机件，又能在公共出口关闭后恢复楼梯、经夹层离开。
- **击穿逻辑：** 轮廓报告只锁定物体，首张底片只锁定消失时间，辨识页只锁定秘密用途；三者与前两层已经完成的路线、在场事实合并后，才形成唯一闭环。若小 Charles 只是无辜扶人者，就必须另有一名刺杀者在他之后上闩双门、取走只有夹层知情者才会害怕的机件并从密室离开；主门内闩、侧门外无返程湿印、人员名册、各自连续在场链和完整路线登记共同排除这个“另一人”。任何单件都不能定案。
- **替代者排除：**
  - Pierce：当晚制服不符合甲沟线束，公开进入前也没有完整夹层离场能力；破门底片再固定他未在门开后抢先取物。
  - Foster：首张底片后才进入，先前不知道密室入口；她的删改不能替代物理在场。
  - Lawson：`Lawson 21:20 至破门前连续在场报告`客观固定他不在舞台，底片又记录他警报后才到门外；无需依赖他自称不懂夹层来排除。
  - Moore：痕迹止于岔口，`Moore 坠落后至破门连续在场报告`又将他锁在东侧会客室；宝石在他折返后的刺杀时仍在地面。
  - Vivian：知道楼梯机构，却不知道书房—舞台夹层全线，也没有破门前舞台在场证明。
  - Lula 与 Emma：两种药、行动能力和摆放痕迹已经排除她们完成刺杀后清场。
- **本层结果：** 证据链在小 Charles 自白前已经闭合。他无法再把镇静、路线、活体接触和缺失机件拆给四个不同的人，只能请求先与 Zack、Emma 私下谈最后一笔交易。

玩家完成第三个判断并选择“小 Charles”后，Zack 才把玩家已经证成的结论说出口：

> “你不是因为留下宝石暴露。你是因为拿走了它。”

### 终局第三段：小 Charles 的贿赂假结局

四层证据已经闭合，但小 Charles 在作出完整自白前要求与 Zack、Emma 私下谈。他最后一次试图把“真相”重新变成少数人可以管理的资产。

交易对象明确为 Zack 与 Emma，不是 Lula / Mary。他承诺提供金钱、房产、报社资源、上流社会身份和 Tidewater 的调查权限，条件是验尸删改、宝石推理与完整报道永远消失。

这不是新的手法，而是他对 Vivian 所做之事的放大版：先给保护、资格和一个看似终于被系统接纳的位置，再要求对方替他删掉一条真相。L2 让玩家看见 Vivian 接受了这份诱惑；假结局则把同样的诱惑直接交到玩家手里。

玩家选择“接受”后进入约两至三分钟的可回退假结局：

1. Zack 获得豪宅和体面的顾问身份，Emma 得到一家不缺资金的报社。
2. 两人第一次替小 Charles 压下一条“不够重要”的消息，并告诉自己只是暂时妥协。
3. 之后每一次妥协都更容易，二人逐渐成为替 Tidewater 管理丑闻的新接口。
4. 最后，新的年轻记者拿着证据来找他们；Zack 关门，Emma 删掉报道。画面停在两人已经变成自己最厌恶的那类人。

假结局结束后，直接回到接受交易前，不要求玩家重跑章节。

### 终局第四段：拒绝交易与公开指证

真结局只有一个。玩家拒绝交易后，Zack 和 Emma 把已经完成的四层证明带回议事厅，让每个曾经说谎的人只为自己亲历的那一小段事实负责：

- Pierce 承认自己主动制造了 21:15–21:45 的安保空窗，并确认撤岗时楼梯仍在 B 位；他不知道谁从暗门离开。
- Vivian 承认自己完成了 17:00 的公开 A→B；案后她接受 Miller 体系的庇护与南区承包条件，把真实发生在命案时段的 B→A 倒填成“18:05 正常复位”，明知这会从正式记录中抹去一次可疑的晚间操作、让侧门来人更容易被判作无关，从而加重 Emma 嫌疑。她没有看见真正复位者，也不知道暗门与坠落真因；她另行证明小 Charles 独自保管并亲手递出 Emma 的酒杯，但没有看见投药动作。
- Moore 承认追入夹层并在岔口逼账；足迹与电话记录同时证明他没有到舞台完成刺杀。
- Lula 承认只动了老 Charles 的未服药杯；玩家把两种药制剂差异与各自保管链交叉，才证明 Emma 属于另一条投放链。
- Foster 只证明刀伤发生时死者仍活着、发生过短促防御抓握；衣物比对才把甲缝纤维落到小 Charles 的新破袖口。
- 晚宴摄影师证明宝石机件在任何公开进入前已经消失，并排除 Pierce、Foster 的“破门后顺手取走”说法；Lawson 则由独立清点在场链客观排除。
- Lawson 只说明自己的签收止于公开编号宝石，并读出维护簿的客观登记边界；他不替玩家解释暗门答案。
- Emma 明确区分“我确实恨他、也在书房推过他”与“我被镇静、拖扶并摆到尸旁”。她的模糊记忆只由物证校准，不反过来代替物证。

小 Charles 无法再逐个管理这些说过谎的人，因为每个人说出的有限真话恰好封住一条退路。庄园内完成的是公开指证与证据保全，不是法律裁决。

#### 小 Charles 的完整自白边界

他的自白必须保留两句核心内容：

> “我到的时候，他已经倒在那里。我不知道他是从哪里掉下来的。他还活着，我的剧本就还能继续。”

> “直到我看见那颗宝石，我才知道他从哪里出来。”

随后才按既定顺序补全动作：

1. 他先把 1912 年真相交给 Emma，让她带着真实、公开的杀父动机与老 Charles 冲突；对 Emma 的长期资助既有感情，也有把她经营成 Miller 赎罪形象的需要。
2. 他亲手递出掺镇静剂的安神酒，原计划在与父亲的密谈中杀人，再把失去行动能力的 Emma 布置成凶手；安保空窗是为这套计划准备的。
3. 他用 Miller 家内门钥匙借安保空窗从会自动回扣的侧门进入舞台。暗门已自重贴平，父亲又倒在门下偏侧；他只看见父亲重伤但仍活着，不知道楼梯第一次移动、Lula 的药、Moore 的追逼如何共同造成坠落，也没有事先设计父亲走暗门。
4. 他仍按自己的原计划刺下致命一刀。老 Charles 只来得及短促抓住他的袖口，留下新缺丝与甲缝纤维。
5. 他从后台帘后把半昏迷的 Emma 拖扶到尸旁，制造接触血迹，把刀留在她身边，将主门从内上闩；侧门早已自动回扣。随后他独自将楼梯从 B 位调回 A 位。
6. 他准备利用重新接通的暗门和夹层离场时，看见喷溅区里那枚从卡座脱落的无编号宝石机关嵌件，才明白父亲从哪里出来、坠落为何发生；他在血迹边缘已经形成后拿走嵌件，经已经松开但仍会贴平的暗门返回书房。
7. 他重新以悲痛继承人的身份出现在人群中，再借庄园事务室延续老 Charles 对 Vivian 的庇护逻辑：以蓝月亮保护和南区娱乐承包资格为诱饵，写下“舞台机械不存在重大未授权操作”这一看似正常的资格条件。他没有在要约里自曝真实时点，也没有明文叫 Vivian 说谎；他知道 Vivian 想保住庇护、更想坐进承包席，便让她自己把那次晚间复位倒填成 18:05，从纸面上进一步巩固 Emma 单独作案的版本。

坠落始终是多人各自行动叠加出的意外；小 Charles 的罪行是预谋投药、杀死仍活着的父亲、嫁祸 Emma、恢复物理现场、拿走会暴露暗门的机件，并在案后购买一份虚假的复位时间线。绝不能让自白把坠落也收编成他的预谋。

他最后承认，自己对 Emma 的帮助和利用都是真的。他想让 Emma 成为“Miller 仍然值得被原谅”的活证据，再把她放进一个只有他能宽恕的杀人叙事里。

### 终局第五段：Emma 停下来了

公开指证结束时暴雪仍封锁庄园，外部检方与有权辖区的警务人员尚未到场。小 Charles 立刻命令 Pierce 销毁宝石链和财务材料；Lawson 以尚未被撤销的信托权限反令保全。Pierce 转身控制证据柜，是服从眼前仍有效的权力，不是突然良心发现；正式看押尚未完成，小 Charles 趁这段争执混乱进入书房，试图处理最后一批文件。

Emma 跟进去，看见他伸手去够父亲的原始记录，便从书桌上拿起一把沉重的黄铜拆信刀。在父亲的记录和杀父仇人之间，她第一次真正产生可以立刻实行的杀意。

她最终不是被 Zack 劝停，而是想起自己曾对 Zack 说过的话：Mickey 把人算成代价，他们不能继承这套算法。

她最终把黄铜拆信刀放回桌面。Zack 赶到时只说：

> “你停下来了。”

Emma 的情绪彻底崩溃。她第一次允许 Zack 抱住自己。这不是和好捷径，而是她停止独自承担之后的释放。

两人随后完成一次明确的双向承认：

- Zack 承认自己扣住 Sean 页面和水源风险，也承认自己正在重复 Mickey“由最懂局势的人管理真相”的做法。他解释自己害怕失去 Emma，但明确说恐惧不能替他免责。
- Emma 不为愤怒和要求知情权道歉。她只为医院里故意把 Zack 说成 Mickey、故意让他也疼而道歉：“你做错了，但我知道你不是他。”

两人没有立刻宣布重新成为搭档。

Emma 回到打字机前，明知报道可能被删、诉讼可能拖延、Tidewater 也不会彻底消失，仍然开始写第一行。她把 Zack 带来的材料放到旁边，明确邀请他一起核对。

Zack 从她身上重新理解了自己最初相信的东西：真相不是由一个最聪明的人替所有人保管，而是让被忽视的人也有选择和说话的机会。他不再把自己当成唯一承担者，选择与 Emma 共同完成这份报道。

关系落点不是“已经恢复搭档”，而是“重新相信彼此，未来同行已经成为明确选择”。

### 终局第六段：Lawson、Foster 与公开后果

- `Lawson 身世—信托权限对应页`已在终局非指证节点坐实他的私生子身份与既有权限，不使用 DNA。小 Charles 的弑父动机因此增加一层：父亲把真正的权力和信任留给了并不渴望权力的 Lawson。
- Lawson 只能凭既有信托权限阻止 Pierce 销毁、要求保全，不能凭私生子身份直接完成法律逮捕。
- 道路恢复后，摄影底片、药物样本、衣物纤维、夹层维护记录、财务材料和现场证词分别交给有权辖区的警务与检方。小 Charles 随后被正式逮捕、起诉；庄园里的指证不替代法定程序。
- Foster 在庄园众人面前先念出 Sean O'Malley 的名字，承认 1912 年官方尸检删改；道路恢复后，她再以私存工作底稿和碳副本作正式宣誓与更正，使 Sean 第一次不再只是事故名单上的数字。
- Emma 完成报道，公开 Miller、湖滨信托银行、Lakeshore Investment、Tidewater、银月会、投毒和 1912 旧案之间的完整链条；银行与投资壳不混写成同一机构。

## 九、Mary 与 Helen 的明确慰藉

时间稍微向后推进。

Harrison 留下的三次改判往来信、法院夜间调阅记录、Miller 操纵司法的文件和 Emma 的公开报道共同证明：Mary / Helen 案存在证据压制、利益干预和程序污染。Foster 的 Sean 尸检只能证明 Miller 长期删改不利事实的模式，不被写成这个案件的直接翻案证据。

两人的法律姿态必须分开落地：

- Mary：U3 已取得的合法杀人 / 无罪结果，曾在 U4 开篇被法院强制改作过失杀人。后续复核先撤销这次受干预的强制改判，恢复此前无罪结果；Mary 因改判重新承受的羁押与限制随之解除。
- Helen：她从未拥有 Mary 的既有无罪结果，案件仍属待决。检方撤回死刑与蓄意谋杀主张，改按较轻罪名及受虐、求助失败、Thomas 骗保杀妻计划等情节处理；羁押期先行折抵。其余刑期由当时的州赦免委员会审查后提出建议，再由州长依法减免，使她最终获释。

这个结果不是宣布她们“什么都没有做”，也不把两人硬写成同一种无罪姿态；它承认原来的制度只截取了“她们布置陷阱”这一部分，却长期删除家暴、求助失败、骗保杀妻计划、银行压力与程序干预。

Zack 与 Emma 在法院外亲眼看见 Mary 与 Helen 走出来。她们没有发表胜利演说，只是在台阶下停了一下，确认自己真的可以往别处走。

这场获释证明：不是每一次努力都来得太晚。

## 十、最后的余味：城市继续

小 Charles 被捕，南区清退计划进入司法审查并暂时停止。部分家庭得以留下，但已经死去的人无法回来，已经转移的土地仍要经过漫长诉讼，世博会和城市开发也不会因为 Miller 家倒下而停止。

Lawson 卸任，Vivian 接手 Tidewater 残余开发接口。她得到的是一份既能救人、也能重新污染人的“脏礼物”。她曾为承包权卖掉一段真实时间，又在承诺被撤回后把另一段真相卖回来；这不是洗白，而是说明她已经学会给真相定价。她不再天然站在 Zack 与 Emma 一边。

最后一幕不直接停在悲观上：

1. 先让玩家看到 Mary 与 Helen 走出法院。
2. 再看到 Emma 与 Zack 坐在同一张桌子的两端核对报道，他们尚未重新自称搭档，却已经重新一起工作。
3. 最后切到 Lakeshore 大楼外，两个穿 Tidewater 西装的人继续谈论南区收购条款。

事情确实改变了。系统也确实没有完全消失。

最终落点：

> 事情结了，城市继续。但这一次，有人活着走了出来，也有人决定再试一次。

## 十一、脑暴备忘逐项落点

1. Emma 开篇伤人的话：明确为把 Zack 与 Mickey 相提并论，并承认自己当时故意让他疼。
2. Zack 的理想主义：不新增大段童年回忆，以 Emma 明知可能失败仍写报道的行动，唤回他“让被忽视者拥有选择”的初心。
3. 情感爆发形式：停手后的崩溃与拥抱 + 双方坦白 + 共同核对报道。
4. Mary 与 Helen：分开处理——Mary 撤销 U4 的强制过失杀人改判、恢复 U3 无罪结果；Helen 撤回死刑主张、按较轻罪名与羁押折抵处理，再经州赦免委员会建议、州长依法减免余刑后获释。
5. 贿赂对象：确认是 Emma 与 Zack，原备忘中的 Mary 视为口误。
6. 假结局长度：两至三分钟蒙太奇，结束后自动回到选择点。
7. 真结局数量：一个；拒绝交易、公开指证、报道与司法行动共同构成完整真结局。
8. 宝石收藏：五个条目，两个必看、三个可选；全收集只提供额外提示和对白。
9. Loop 压缩：删除原 Foster 独立 L2；Vivian、Moore、Lula 前移；小 Charles 改为非 Loop 终局。
10. 最终推理：玩家亲自判断血迹空白对应什么、为什么被拿走、谁理解它的意义；角色不替玩家先说答案。

## 十二、最终一句话总结

> 玩家用四个 Loop 依次拆掉安保空窗、被买走的复位时间、夹层追逼和药物嫁祸，发现每个人都只占死亡链的一环；Vivian 为位置把一个时间写早，Foster 则在终局交还曾被删改的死因与限定。玩家再利用一路建立的宝石知识，亲手判断真正暴露小 Charles 的不是他留下了什么，而是他拿走了一颗只有夹层知情者才会害怕的无编号宝石。拒绝他的贿赂后，所有人的小真话共同围住凶手；Emma 没有把复仇变成下一次谋杀，Zack 也不再替别人管理真相。Mary 与 Helen 最终活着走出法院，而城市仍在继续。
