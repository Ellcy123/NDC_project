## 一、已锁定结构

只有在圆桌上指证小 Charles，演出才以 Zack 的指认为钩子，回切至圆桌前发生的终局单场景搜证。自由探索阶段，Zack 没有向 Lawson 透露自己怀疑小 Charles；Lawson 仅因认可 Zack 的侦探能力而开放由老 Charles 控制的私人档案与刻录准备空间。他不支持任何凶手判断，也不提供搜索方向、谜题答案或额外证物。

谜题 A 与谜题 B 相互独立，可以按任意顺序完成。谜题 C 从进入场景起即可看见和调查，但只有同时取得 A、B 各自产出的信息，才能排除其他解释并得到唯一解。

| 谜题 | 目标材料 | 主要操作倾向 | 与后续的关系 |
|---|---|---|---|
| A：遗嘱与 Webb 唱片 | 遗嘱材料、完整 Webb 唱片 | 唱片听取机制学习、碎片辨认与拼接 | 提供谜题 C 所需的通用开头报音规则 |
| B：Tidewater 核心档案 | 1928 年世博完整计划档案 | 字迹特征提炼、样本识别与文件比对 | 提供谜题 C 所需的 Miller 庄园刻录设备特质参数 |
| C：Emma 保密试音母盘 | 直接记录致命刺杀过程的 Emma 母盘 | 组合 A 的规则与 B 的参数，拼出目标报音并试听候选 | 完成真结局所需的最后一层搜证 |

结局按玩家实际取得的材料分为三档：

- 仅取得 A 或仅取得 B：一般结局 I；共用主体演出，根据所得证物替换少量展开。
- 同时取得 A 与 B：一般结局 II。
- 取得 A、B，并解开 C：取得直接记录致命刺杀过程的 Emma 母盘，进入广播真结局。

谜题阶段只向玩家提供证物中的客观信息，不自动产出“小 Charles 因此有动机”“某人因此是凶手”等推理结论。取得哪些材料、材料之间能否形成完整叙事，只在结局阶段根据玩家的自由组合进行判断。

## 二、场景功能

圆桌前，Lawson 因职业信任向 Zack 开放一处由老 Charles 控制的私人档案与刻录准备空间。该场景同时容纳家族文件、Tidewater 原始档案、刻录设备和唱片档案，是正确路线唯一新增的自由探索场景；玩法上在 Zack 作出圆桌指认后以回忆形式进入。

场景必须支持三种信息层：

1. 表层可见：所有玩家都能发现三个谜题的相关对象、文件容器和刻录设备；缺少提示不会隐藏交互点。
2. 提示后更易处理：Vivian 与 Foster 的证言分别降低谜题 A、B 的搜索、辨认或比对难度。
3. 交叉后可确认：谜题 C 必须同时使用 A 的通用报音规则与 B 的 Miller 设备参数；缺少任意一项时都无法可靠推算目标报音。

A、B 的完成顺序保持自由。NPC 提示不改变证物是否存在，也不改变结局权限；真结局只取决于玩家是否实际取得 A、B，并在剩余时间内解开 C。

## 三、调查许可与可选提示

提示体系分为三步：

1. 前期埋种子：Vivian 与 Foster 的关系节点分别留下与 Webb 唱片、已知笔迹样本有关的信息，当时不说明其终局用途。
2. 圆桌再提醒：若关系节点达成，Vivian 或 Foster 可在演出切入搜证回忆前唤回玩家记忆并指出观察方向，不生成证物、公布答案或开放隐藏交互。
3. 终局亲手应用：玩家把提示或自己的观察用于碎片拼接、播放、特征提炼和文件比对，亲手取得材料。

| 提示状态 | 对谜题 A、B 的影响 | 对谜题 C 的影响 |
|---|---|---|
| 无额外提示 | A、B 难度较高，但均可独立解开 | 不提供 C 的任何答案或额外材料 |
| Vivian 或 Foster 提示 | Vivian 降低 A 的搜索、辨认难度；Foster 降低 B 的样本提炼、比对难度 | 通过更快取得 A 或 B，间接为 C 节省时间 |
| Vivian 与 Foster 均提示 | A、B 的调查路径都更明确 | 仍须亲手组合 A、B 产出的两项信息并完成 C |

Lawson 的固定作用只是开放场景，不属于提示状态，也不为“小 Charles 有罪”背书。Vivian 即使提供 A 的提示也始终弃票；Foster 是否提示 B 与她的投票分开计算，她在一般结局投 Moore，只有母盘得到验证后才改投小 Charles。NPC 提供的是可选观察方向，不是结局权限；好感度不开放隐藏答案，不增加搜证次数，也不能替代 A、B 的实际证物。

## 四、谜题 A：遗嘱与 Webb 唱片

### 目标材料

谜题 A 同时产出两组客观材料：

- 老 Charles 修改继承安排、将继承人从小 Charles 变更为 Lawson 的遗嘱与律师材料；
- Unit5 场景中找到的唱片碎片，可与 Unit1 的 Webb 唱片碎片拼合为完整唱片。

### 主要玩法

主要操作偏向唱片听取机制学习、碎片辨认与实际拼接：

1. 玩家在遗嘱材料与刻录设备附近找到 Unit5 唱片碎片。
2. 玩家把 Unit5 碎片与 Unit1 的 Webb 唱片碎片放入合成或拼接交互，完成至少一次由玩家亲手操作的碎片复原。
3. 拼合后的唱片既保留 Unit1 已经出现的南区录音内容，也恢复另一段可连续播放的唱纹；该段客观记录老 Charles 将继承人从小 Charles 变更为 Lawson 的过程。
4. Webb 唱片由 Webb 私人持有的便携式电气刻录设备录制，并非 Miller 庄园的产物；但两台设备属于 Tidewater 世博试录计划采用的同一设备体系，遵循相同的内部声音报码规程。
5. 拼合完成后，玩家可在 Webb 设备铭牌与盘心标记上读到两项已知参数：`刻录站号 W`、`有效拾音线路 II`。
6. Webb 唱片的开头依次播放：`持续校准长音／短—长—长／两次继电器短响／高—低结束音`。
7. 玩家在轻量匹配界面中，把设备上的校准回路、站号 W、两个线路插孔与切录开关，分别对应到四段声音，由此归纳通用报音规则。
8. 该规则作为谜题 C 的第一项输入收入玩家已知信息；A 不直接提供 Miller 设备参数，也不自动生成动机或凶手结论。

### 通用报音规则

Tidewater 同系设备的每张试录母盘都在正文前保留四段声音：

```text
持续校准长音
→ 刻录站字母的摩尔斯报码
→ 有效拾音线路数量的继电器短响
→ 高—低结束音
```

- 校准长音和高—低结束音是固定书挡，用来确认报音完整。
- 刻录站字母与线路数量是两个可变参数。
- 设备盒内附有一张短电报码条，只列本谜题需要的 W、M、L；玩家不需要预先掌握摩尔斯电码。
- 报音规程只适用于这一批同系实验设备，不设定为 1928 年唱片行业的统一标准。

### Vivian 的提示

- 自由探索前的关系信息：Vivian 记得 Webb 使用自己的便携设备制作过唱片，并注意到盘心上的 W、II 与开头报音之间存在固定对应。
- 圆桌提醒：只提示玩家重新关注 Webb 设备铭牌、唱片盘心与开头四段声音，不直接指出碎片位置、拼接方式或通用报音规则的答案。
- 没有 Vivian 提示时：玩家仍可通过唱片材质、断口、品牌压印和庄园设备自行完成辨认与拼接，但需要更多观察时间。

### Unit1 衔接备注

Unit1 的物品 1602 当前需要在后续落地时调整为可进入背包，并能保留到 Unit5 参与唱片拼接。本轮只在 Unit5 文档记录该需求，不修改 Unit1 现行大纲、`loop6_state.yaml` 或配置表。

### 仍待优化

- 遗嘱、律师材料和 Unit5 唱片碎片在场景中的具体空间关系；
- 碎片拼接的操作层级、容错反馈与播放界面；
- 完整唱片中继承变更录音的具体客观内容与声音顺序；
- Webb 设备、两个线路插孔、电报码条与报音匹配界面的具体视觉表现。

## 五、谜题 B：Tidewater 核心档案

### 目标材料

目标材料是 Tidewater 为 1928 年世博会计划准备的完整档案。档案中的核心文件客观记录：在正式截止日期尚未到达时，小 Charles 冒用老 Charles 的身份，要求银月帮向艾斯弗德南区居民投毒。

档案还包含世博广播设备附件，其中记录 Miller 庄园试音室的两项有效参数：`刻录站号 M`、`有效拾音线路 III`，作为谜题 C 的第二项输入。附件可以同时保留盘速、盘径和设备型号等时代包装信息，但这些内容不参与本轮解答，也不直接写出 Emma 母盘的报音答案。

### 主要玩法

主要操作偏向识别与比对，而不是单纯翻找文件或整理标签：

1. 场景中存在多份带有老 Charles 签名的 Tidewater 文件，其中只有目标文件实际由小 Charles 仿签。
2. 目标签名在整体外形上可以几乎与老 Charles 真迹一致；真正可供识别的是日期数字、连笔方式、停笔位置、转折或收笔等稳定书写习惯。
3. 玩家需要先从来源明确的样本中提炼小 Charles 的稳定特征，再使用灯箱叠放、局部放大或其他可视化比对方式，从多份候选文件中找出仿签材料。
4. 选中正确文件后，玩家取得完整世博计划档案、投毒命令及 Miller 庄园刻录设备参数。物品只记录签署内容、截止日期、执行对象、设备特质等客观信息，不自动生成犯罪链结论。

### Foster 的提示

- 场景中保留一份由小 Charles 以庄园代理人身份亲笔签署的尸检现场封存单或物品移交单，可作为来源明确的真迹样本。
- Foster 的证言帮助玩家确认该样本确由小 Charles 在没有刻意模仿他人时书写，并可提醒其中一项稳定笔迹特征。
- 没有 Foster 提示时：玩家仍可从此前搜证或场景内其他小 Charles 材料中自行提炼笔迹特征，但候选样本更多、比对步骤更长。

### 仍待优化

- Foster 样本的最终载体及其与尸检流程的自然关系；
- 比传统“找不同”更有可玩性的字迹或书写习惯比对机制；
- 候选文件数量、有效特征数量与错误反馈；
- Miller 庄园试音室设备附件的版式、型号与时代包装；
- `站号 M`与`三条有效拾音线路`怎样自然嵌入世博宣传广播的安装记录。

## 六、谜题 C：Emma 保密试音母盘

### 目标材料

Emma 在晚宴前秘密安排过一次庄园试音。对应母盘在庄园内完成刻录，之后被 Foster 在后台尸检与现场物品转移过程中拿走，最终留在 Lawson 开放的终局场景内。

母盘不是任何人的事后自白，而是一段没有中断的现场录音。录音直接保留老 Charles 临死前与小 Charles 的谈话，随后连续记录小 Charles 刺向老 Charles、老 Charles 死亡，以及小 Charles 仍留在现场的声音。

### 当前玩法方向

主要操作是迁移谜题 A 学会的通用报音规则，把谜题 B 取得的 Miller 设备参数代入规则，再用玩家自己拼出的报音辨认候选唱片：

1. 玩家打开四槽报音拼接界面。声音素材只包含少量校准音、W／M／L 三种摩尔斯报码、一至三次继电器短响，以及数种结束音。
2. 玩家查阅 A 中归纳出的通用规则与 B 中记录的`站号 M`、`有效拾音线路 III`，自行选择声音片段并排列顺序。系统不替玩家填空，也不自动计算正确答案。
3. 玩家应当拼出：`持续校准长音／长—长（M）／三次继电器短响／高—低结束音`。
4. 玩家点击试听，播放自己拼出的完整开头报音。拖动、调整和单独试听声音片段不消耗时间；只有正式试听一个错误的完整组合才计入错误操作。
5. 玩家随后免费试听四张候选唱片开头的短报音，找出与自己推算结果完全一致的一张。候选试听只播放用于辨认的报音，不能先听正文、再根据 Emma 的声音倒推答案。
6. 玩家正式确认正确唱片后播放正文，直接听见老 Charles 临死前与小 Charles 的谈话，以及紧接其后发生的致命刺杀过程。取得 Emma 母盘即完成谜题 C，不再追加寻找凶器或其他终局物证的步骤。

### 报音拼接素材

| 槽位 | 正确片段 | 主要干扰片段 |
|---|---|---|
| 校准 | 持续校准长音 | 两次短校准音 |
| 站号 | 长—长（M） | 短—长—长（W）、短—长—短—短（L） |
| 线路 | 三次继电器短响 | 一次短响、两次短响 |
| 结束 | 高—低结束音 | 单高音、带额外杂音的结束音 |

### 四张候选唱片

| 候选 | 开头报音 | 设计作用 |
|---|---|---|
| 1 | 校准长音／M／三次短响／高—低结束音 | Emma 母盘；完全符合推算结果 |
| 2 | 校准长音／M／两次短响／高—低结束音 | 站号正确，线路数量错误 |
| 3 | 校准长音／W／三次短响／高—低结束音 | 线路数量正确，刻录站错误 |
| 4 | 校准长音／M／三次短响／单高音 | 参数正确，但报音没有正常结束 |

### 信息依赖

| 已取得信息 | 玩家在 C 中能够完成的范围 |
|---|---|
| 仅 A | 知道设备特质与开头报音之间的通用规则，但缺少 Miller 设备参数 |
| 仅 B | 知道 Miller 设备的具体特质，但不知道这些特质怎样转换为报音 |
| A＋B | 能亲手拼出目标报音，并通过试听候选唱片辨认 Emma 母盘 |

### 设计边界

- C 从进入场景起即可看见和调查，但不能在缺少 A 或 B 时通过穷举候选直接取得正确母盘。
- A、B 提供的是两种不同维度的信息：通用报音规则与 Miller 设备参数；任何一项单独使用时都不足以推算目标报音。
- 报音拼接界面不逐格显示红绿对错。玩家只能试听自己的组合，再与候选唱片的开头进行整体比较。
- 如果理论报音拼错，玩家可能发现没有唱片完全吻合，也可能把对应某一错误组合的干扰盘当作答案；只有正式确认错误母盘时才给出整体不匹配反馈并扣时。
- 声音片段同步提供非答案式文字与波形辅助，例如`持续机械长音`、`长音—长音`、`三次继电器短响`、`高音降至低音`。判断不依赖玩家辨别绝对音高或颜色。
- 母盘入手后只登记实际听见的声音、顺序和物理特征，不在谜题阶段自动宣布小 Charles 是凶手。
- 场景内刻录设备、母盘材质与录音方式需要继续按 1928 年技术条件校准，避免把后期普及的录音技术当作普通家用设备。

### 时代包装边界

- 1925 年后电气录音已经进入商业应用，因此 1928 年由麦克风、线路与昂贵刻录设备组成的试录系统可以成立。
- 历史唱片常用带字母、数字、前缀或后缀的矩阵号区分盘面、母盘与录次，并将其刻印在唱片内缘；本谜题以此为依据，把相同信息冗余编码为声音报头。
- “声音报码规程”是 Tidewater 为多地世博试录自订的虚构内部规范，不宣称它是现实中的唱片行业标准。
- 1920 年代留存的完整广播录音十分稀少，因此 Miller 庄园设备必须表现为世博宣传所需的昂贵实验设施，而非普通家用唱片机。
- 时代考据参考：[Library of Congress Recorded Sound Timeline](https://www.loc.gov/static/managed-content/uploads/sites/6/2017/02/recorded_sound_timeline-2013.pdf)、[Columbia Records Paperwork Collection](https://findingaids.loc.gov/repositories/11/resources/795)、[Library of Congress 1920s Broadcast Recordings](https://www.loc.gov/item/prn-08-079/)。

### 仍待优化

- 四槽拼接界面的具体视觉布局、声音块尺寸和操作反馈；
- 四张候选唱片的具体外观、来源与报音音频制作；
- Foster 移动母盘后的物理位置闭环；
- 母盘中谈话、刺杀与死亡声音的客观顺序，以及怎样在不由系统代替玩家推理的前提下明确两名说话者身份；
- C 的操作时长、错误成本与限时公平性。

## 七、物品、信息与交互边界

- 可收集文件和实物使用 `item`；只能查看的环境提示使用 `envir`；机关、开关和不可收集的操作点使用 `interactive_item`。
- Unit1 Webb 唱片碎片与 Unit5 补片需要实际进入物品合成或专用拼接交互，不能只在剧情演出中自动恢复。
- 分析或合成仅在物件性质自然支持时使用；纸质文件不能为了增加操作量而强行送去化验。
- NPC 口述属于证词，不作为 `ItemStaticData` 物品处理。NPC 证言只能降低搜索或理解成本，不能替代场景中真实存在的物证。
- 每件道具只提供其自身能够承载的客观信息。结局根据玩家取得材料的自由组合推断不同结论，谜题阶段不替玩家完成推理。
- 若关键材料后续进入疑点系统，每份证据与疑点条件的对应关系须在 state 阶段另行设计；当前阶段不分配证据 ID、疑点 ID 或配置字段。

## 八、错误扣时与结局压力

终局不采用持续倒计时追赶玩家手速。时间压力来自小 Charles 正在重新控制庄园、销毁接口或组织反扑，并通过“正式提交错误会消耗时间”的半静态规则表现。

### 十格时间预算

- 以十格时间作为当前调参基准：完全正确地完成 A、B、C，基础流程约消耗七格；另外三格作为错误容错。
- 玩家累计错误提交不超过三格，即错误成本控制在总预算的 30% 以内时，应始终有足够时间完成真结局。
- 第四次错误提交开始超过 30% 容错，剩余时间通常只够取得 A 或 B，或停在 A＋B，进入对应的一般结局。
- 30% 是内部测试和调参指标，不直接向玩家显示“错误率”。游戏内只表现剩余时间格和小 Charles 的反扑进度。

### 计时边界

以下行为不消耗时间：

- 调查对象、阅读文件和查看已经取得的证物；
- 移动、试摆唱片碎片，但尚未正式确认拼接；
- 调整报音片段，但尚未点击试听；
- 重听已经成功取得的关键录音。

以下错误操作额外消耗一格时间：

- 谜题 A：正式确认错误的唱片拼接；
- 谜题 B：正式提交错误的仿签文件；
- 谜题 C：试听错误的报音组合，或正式确认错误的候选母盘。

### 体验目标

- A、B 的完成顺序自由，答案、位置与主要操作在重试时不随机变化。
- 约三分水平的玩家能够完成部分搜证，稳定进入一般结局；约七分水平的玩家允许犯少量错误，仍能完成 A＋B＋C 并进入真结局。
- 普通玩家第一次调查时可能只完成 A 或 B，也可能完成 A＋B 而来不及解开 C；足够敏锐的首次玩家可以一轮完成真结局。
- 一般结局结束后允许从终局搜证开始前直接重试，不要求重跑整章或重新经营 NPC 关系。
- 玩家重试时可以利用自己对 A、B 的记忆减少错误提交，自然为 C 留出更多时间。
- 若时间耗尽时 A、B 均未完成，则判定为搜证失败并返回终局检查点，不额外增加一个正式结局。
- 十格预算、单次扣时和各题基础成本仍须在 B、C 交互定稿后通过试玩校准。

## 九、结局交接

| 实际取得材料 | 进入结局 | 交接重点 |
|---|---|---|
| 仅 A 或仅 B | 一般结局 I | A-only 封存并暂缓遗产交割；B-only 暂停涉事项目并内部核查。两者都不默认公开，也不能证明弑父 |
| A＋B | 一般结局 II | Lawson 只开始怀疑哥哥，将继承变更、冒签和投毒关门作为家务与公司内务处理；仍缺少致命现场物证 |
| A＋B＋C（Emma 母盘） | 广播真结局 | Zack、Lawson 与 Foster 共同听完母盘；Lawson 首次确知哥哥弑父，Foster 确认录音与尸检吻合，随后母盘交给 Emma |

谜题 A、B 无论单独或合并，都不能让 Lawson 越过“怀疑哥哥”的知识边界。只有 C 的母盘正文直接记录致命刺杀过程，才能让他获得确定知识。结局演出、圆桌投票、一般结局的关门处理、母盘交接、广播危机及人物后果统一见 `Unit5_多结局分支方案_v2.md`，本文件只负责把玩家合法送到对应结局入口。

## 十、公平性与防穷举检查

后续每个谜题方案都必须回答：

1. 玩家进入场景前已经知道什么；
2. 场景中新获得什么客观信息；
3. A、B 单独成立时为何能够进入一般结局，同时又分别缺少什么；
4. A 的通用规则与 B 的设备参数如何在 C 中交叉形成唯一目标报音；
5. 缺少 NPC 提示时，玩家还能通过哪些公开线索自行抵达答案；
6. 为什么玩家不能靠遍历容器、声音片段、唱片或选项绕过；
7. 玩家怎样从环境反馈理解自己的操作方向是否正确；
8. 三个谜题是否各自使用不同的主要操作，避免连续翻文件或连续进行同类视觉比对。
