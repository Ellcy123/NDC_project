## 二、关系主轴

- Zack—Emma：冲突不是“是否相信她无罪”，而是 Zack 曾以保护为名替她删减真相。Emma 的自主行动不能被写成任性出走；Zack 的修复必须落实为完整告知、允许拒绝和共同承担。
- 老 Charles—小 Charles：长期压抑使儿子渴望证明自己；小 Charles 以 Miller 家族为优先，却不等于服从父亲。父亲传下的控制方式与儿子的野心共同构成冲突，不能只写成个人逃离父亲。
- 小 Charles—Lawson：作者层为同父异母兄弟；玩家层在 Unit1 只知道 Lawson 姓名与另一名同姓收件人，现行 U5 调查阶段仍只把他当受压的职业接口。隐藏继承只在终局 A 成功后揭晓，小 Charles 对 Lawson 的栽赃不能提前用遗嘱或血缘解释。
- Vivian—体系：Webb 的欺骗与酒吧生活让她学会生存规则。她努力向上主要为了守住在乎的同事，也有自己的愿望；计算代价更多来自系统下的无奈，不是天生冷酷逐利，也不是完全无私。她的楼梯谎言仍属自发自保，不是与小 Charles 共谋。
- Lawson—工作与人情：真正的投入在地质、宝石、绘画和感情；TideWater 事务常是别人交代后照办，而不是他的事业野心。外表叛逆与实际配合并存，不把他写成冷漠的程序管理者，也不把“两耳不闻窗外事”扩成毫无判断力或全然不知公司风险。
- Foster—Miller：她在 1912 年曾受体系压迫改写死因；本章的专业克制与法庭纠错是一条连续弧线。
- Pierce—秩序：他先把错误观察当成职责判断，后把暴力继续包装成安保与控制。
- Moore、Lula：二人都犯下真实罪行，但这些罪行不能自动等同于致命刀刺。

## 四、功能角色

以下人物只按现行剧情功能使用，不补私人背景、年龄、族裔或家庭史：

- 巡逻警员：L1 提供第十三圈、右袋取烟、惯用右手和巡逻用时；不知道转镜者身份。
- 摄影师：认证 22:10 与 22:15 为同一固定机位连续曝光；不替玩家判断取石者。
- 庄园管家：说明老 Charles 固定服用两片蓝色心脏病药。
- 法官：维持最终法庭程序；不额外承担真相解释。
- 书记员：负责封存、核对和播放程序中的记录动作。
- 无线电播报员：在章开场用维护 Miller 名望的口径先把 Emma 写成失控记者。
- 老年 Mary、老年 Helen：只出现在误指 Lula 的五十年后结局，负责把老年 Zack 带离监狱并送到 Emma 的汽车旅馆。
- 终局摄影、警务、法院辅助人员：若对白阶段需要新增，必须先明确其信息来源与程序职责，不由功能身份自动获得真相。

## 五、统一写作纪律

1. 人物没有掌握的事实，不因玩家已知而进入其台词。
2. R2 及后续退守只在对应指证中出现；L3 Moore、L5 小 Charles 的 R1 必须先经普通问话取得。
3. Emma 在录音室失去行动能力，医用乙醚只在护士站作为环境证物。
4. 同一份 1928 投毒安排在调查阶段保留老 Charles 签署的表象；双成功法庭才由 Foster 提交相关方字迹鉴定，证明为小 Charles 仿签。
5. A 成功与否决定谁听见继承录音；B 成功与否决定机械馆隔断是否形成。任何坏结局都不能倒推改写客观真相。
6. 外形资料以现行美术身份源及用户明确修订为准；本次用户确认 Lawson 的老钱风睡衣与叛逆穿着方向，具体颜色、材质、品牌仍待锁定，未改动现有美术资产。其他未确认年龄、身高、族裔、伤疤与服饰不自行补写。Lawson 的 ENFP 仅作作者侧性格辅助，不是时代内称呼；“宝石燃料”暂按绘画颜料理解，词义待用户核准，不新增制作方法或证物。
7. Lawson 的正式姓名、母姓与私生子身份由 Unit1 跨章作者层资料锁定；现行 U5 只落地继承录音，尚未给玩家层父子身世的独立证明。

## 六、性格与情感写作入口

每份核心档案第二节统一分为四部分：长期性格底色、情感需求与内在矛盾、已有经历及其影响、U5 当前情感状态；第六节补充平常、受压与面对不同人的表现。

| 人物档案 | 写作时不能丢掉的反差 |
|---|---|
| [Zack](./zack.md) | 对事实精确、对情感笨拙；真心保护人，却容易替人作决定 |
| [Emma](./emma.md) | 职业野心与人情关切并存；坚定自主，也会害怕、隐瞒和认错 |

| [老 Charles](./charles_sr.md) | 把安排他人理解成负责，难以接受被安排者拒绝自己 |
| [小 Charles](./charles_jr.md) | 亲和笑脸下的野心；以家族优先，仍被父亲的否定与自己的证明欲牵动 |

| [Lula／Mary](./lula_mary.md) | 追索死者真相的执拗，与冒名、换药的越界并存；揭面不等于换人格 |

- 性格底色不是每场都必须展示的动作或口头禅；不要让所有人物都只剩谨慎短句，也不要为了区别而机械加笑、怒或犹豫。
- “经历”只收录已载明的事件，并说明其可能影响；不补童年、婚恋、创伤事件、履历与私人关系。仅有本章材料的人物如实保持范围，不为凑完整传记编故事。
- U5 当夜新发生的事放在对应阶段，不当作开场以前的经历；终局和坏结局只能作为条件性走向，不能倒灌到平常性格或当前记忆。
- 作者层知道的身世、凶手行为、机关用途不自动进入人物对白；性格表现仍须遵守第五节知识边界与 State 的获取时序。
- 本次只更新人物文档；既有 L1—L3 草稿尚未按新性格逐段润色，L4 写作仍暂停，不能把档案完成等同于对白已经完成同步。
