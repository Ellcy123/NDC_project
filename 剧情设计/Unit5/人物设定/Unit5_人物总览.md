# Unit5 人物总览

> 适用范围：Unit5《系统没有主人》。
> 权威顺序：`canon_manifest.json` → `../Unit5_大纲.md` → `../state_source_contract.md` → `../state/loop1-5_state.yaml` → 终局与坏结局详案。旧人物文件只在不冲突时提供背景素材。

## 一、人物结构

| 人物 | 本章身份 | 戏剧功能 | 关键边界 |
|---|---|---|---|
| Zack Brennan | 私家侦探、玩家视角 | 在与 Emma 关系破裂后，以“把选择还给她”重新学习合作 | 不替 Emma 宣告无罪；不提前知道母盘是否录成 |
| Emma O'Malley | 记者、被栽赃者 | 以自主调查进入庄园，又被小 Charles 放进凶手叙事；L5 作为协查者回到行动中 | 不目击坠落或刀刺；只记得三指握姿，不认得操作者 |
| Charles Miller Sr. | Miller 家主、死者 | 系统建造者，也是被系统吞掉的受害者 | 坠落不致命；致命刀刺来自小 Charles |
| Charles Miller Jr. | 家族继承人表象、实际凶手 | 把众人的自保拼成密室，并把 Lawson 塑造成替罪者 | L5 只有限承认取石、闩门、暗门离场，不等于刀刺已定案 |
| Lawson Vanderbilt（劳森·范德比尔特） | TideWater 名义总裁；作者层为老 Charles 私生子，随母姓 | 最后一层假凶手；终局把实体监印交给 Zack 并拖住小 Charles | L1—L5 不知道监印用途；不参加 A，也不亲耳听见继承录音 |
| Vivian | 蓝月亮经营者、舞台承办方 | 因保护生计在 L2 撒谎，之后以有限合作加入终局 | 不知道楼梯暗锁；L5 只能证明小 Charles 经手 E-12 |
| Pierce | 庄园警务与安保负责人 | L1 的错误观察者；终局成为小 Charles 的暴力执行者 | L4 两次针对 Lula 的现场指控由他承担；Moore 被关押后不回自由场景 |
| Eleanor Foster | 法医 | 逐层建立死亡顺序，终局承担中立见证与历史纠错 | L1 不能提前完成完整伤序；不凭立场替 Zack 定罪 |
| Harold Moore | 湖滨信托行长 | 有真实恶行和强动机的假凶手 | 只追到第一岔口；不能因此排除其刀刺机会；L4 后只在看守房出现 |
| Lula Washington / “Mary Jones” | Frank 遗孀、冒名护工 | 换药与搜档者，保留至最终投票的落刀嫌疑 | 紫片在投票前未鉴定；不反咬 Moore，相关攻击交给 Pierce |
| Watts | Harrison 前书记员、程序协助者 | 庄园外的记录保全人；真结局带来唯一母盘 | 不到庄园、不参与现场调查、不具警员或司法权力 |

## 二、关系主轴

- Zack—Emma：冲突不是“是否相信她无罪”，而是 Zack 曾以保护为名替她删减真相。Emma 的自主行动不能被写成任性出走；Zack 的修复必须落实为完整告知、允许拒绝和共同承担。
- 老 Charles—小 Charles：父亲把控制术教给儿子，又试图收回继承；儿子用同一套风险管理逻辑杀死父亲。
- 小 Charles—Lawson：作者层为同父异母兄弟；玩家层在 Unit1 只知道 Lawson 姓名与另一名同姓收件人，现行 U5 调查阶段仍只把他当受压的职业接口。隐藏继承只在终局 A 成功后揭晓，小 Charles 对 Lawson 的栽赃不能提前用遗嘱或血缘解释。
- Vivian—体系：她的谎言来自生计与位置恐惧，不是与小 Charles 共谋。她可以帮忙，但始终会计算自保成本。
- Foster—Miller：她在 1912 年曾受体系压迫改写死因；本章的专业克制与法庭纠错是一条连续弧线。
- Pierce—秩序：他先把错误观察当成职责判断，后把暴力继续包装成安保与控制。
- Moore、Lula：二人都犯下真实罪行，但这些罪行不能自动等同于致命刀刺。

## 三、逐 Loop 群像

| 阶段 | 群像中心 |
|---|---|
| L1 | Zack 与 Emma 关系断裂；Pierce 的入口观察被击穿；Foster 坚持医学边界；小 Charles 扮演支持调查者 |
| L2 | Emma 苏醒但仍受隔离；Vivian 为保住舞台与员工而撒谎；Foster完成“坠落先、刀刺后”的伤序 |
| L3 | Vivian、Lawson 的上下层声音拼出夹层；Moore 先在普通问话中否认进入，再被逼出追签和提前止付 |
| L4 | Moore 被关进看守房；Emma 主动披露远端刻录安排；Lula 的换药、搜档与冒名逐层揭开；后台物证洗清 Emma 持刀嫌疑 |
| L5 | Emma 获释为受监督协查者；Vivian 给出 E-12 有限回忆；Lawson 被布置成假凶手；小 Charles 在前置普通问话后被逼出有限认罪 |
| 终幕 | 最终票决定是否进入正确路线；正确路线由 A/B 两个独立玩家操作分叉，双成功后才进入法庭纯演出 |

## 四、功能角色

以下人物只按现行剧情功能使用，不补私人背景、年龄、族裔或家庭史：

- 巡逻警员：L1 提供第十三圈、右袋取烟、惯用右手和巡逻用时；不知道转镜者身份。
- 摄影师：认证 22:10 与 22:15 为同一固定机位连续曝光；不替玩家判断取石者。
- 庄园管家：说明老 Charles 固定服用两片蓝色心脏病药。
- 法官：维持最终法庭程序；不额外承担真相解释。
- 书记员：负责封存、核对和播放程序中的记录动作。
- 无线电播报员：在章开场用维护 Miller 名望的口径先把 Emma 写成失控记者。
- 老年 Mary、老年 Helen：只出现在误指 Lula 的五十年后结局，负责把老年 Zack 带离监狱并送到 Emma 的汽车旅馆。
- 终局摄影、警务、法院辅助人员：若对白阶段需要新增，必须先明确其信息来源与程序职责，不由功能身份自动获得真相。

## 五、统一写作纪律

1. 人物没有掌握的事实，不因玩家已知而进入其台词。
2. R2 及后续退守只在对应指证中出现；L3 Moore、L5 小 Charles 的 R1 必须先经普通问话取得。
3. Emma 在录音室失去行动能力，医用乙醚只在护士站作为环境证物。
4. 同一份 1928 投毒安排在调查阶段保留老 Charles 签署的表象；双成功法庭才由 Foster 提交相关方字迹鉴定，证明为小 Charles 仿签。
5. A 成功与否决定谁听见继承录音；B 成功与否决定机械馆隔断是否形成。任何坏结局都不能倒推改写客观真相。
6. 外形资料以现行美术身份源为准；本组档案不新增年龄、身高、族裔、伤疤或固定服饰。未知项统一标为待美术锁定。
7. Lawson 的正式姓名、母姓与私生子身份由 Unit1 跨章作者层资料锁定；现行 U5 只落地继承录音，尚未给玩家层父子身世的独立证明。
