# Loop4 自由探索流程调整理念

> 本文只整理对白与自由探索流程的设计原则，不直接修改《Loop4_生成草稿.md》、State、场景配置或道具配置。

## 一、调整目标

Loop4 原流程把 O'Hara 家调查、电话求助、Sarah 转移、取得证词和前往 Margaret 家串成了一条固定顺序。玩家只有完整走完 O'Hara 家剧情，才会被自动送往 Margaret 家，因此探索更接近连续过场，而不是自由调查。

本次调整要把流程拆成两条可以并行推进的线：

1. 地点开放线：玩家在 O'Hara 家取得原道具 4413，从便条上的地址得知 Margaret 新家的位置，立即解锁 Margaret 家。
2. 证词调查线：玩家利用 O'Hara 家的电话赶走警员，随后从 O'Hara 处取得正式证词，再用证词解锁 Margaret 的谎言话题。

核心原则是：玩家可以提前到达一个地方，但不能因此提前得到尚未建立的信息结论。地点开放和推理推进彼此独立。

## 二、推荐流程

```text
进入 O'Hara 家
      │
      ├─ 调查 4413 ──→ 得知 Margaret 新家地址 ──→ 解锁 Margaret 家
      │                                             │
      │                                             └─ 可提前探索、自由交谈
      │                                                但暂时没有 O'Hara 谎言话题
      │
      └─ 调查清退文件 ──→ 使用墙边电话联系 Watts
                              │
                              └─ 警员撤离 ──→ O'Hara 给出正式证词
                                                   │
                                                   └─ Margaret 谎言话题解锁
                                                              │
                                                              └─ 取得 4104002，进入指证准备
```

两条线没有固定的先后顺序。玩家可以先去 Margaret 家，也可以先处理 O'Hara 家的电话事件。

## 三、三个阶段的信息边界

### 第一阶段：取得地址，开放新地点

- 4413 继续使用原有道具 ID，不新增地址道具。
- Margaret 新家的地址直接写在 4413 的便条末尾。
- 玩家调查 4413、关闭道具特写后，即可解锁 Margaret 家。
- 地址来自玩家亲手调查物证，不需要等 O'Hara 在后续对白中口头告知。
- 取得 4413 只负责开放地点，不直接解锁 Margaret 的谎言话题。

这一阶段的作用是给玩家选择权：发现地址后，可以立即换地点，也可以继续留在 O'Hara 家调查。

### 第二阶段：两处场景自由探索

#### O'Hara 家

- 玩家可以继续调查文件、与屋内人物交谈，或点击墙边电话处理门外警员。
- Sarah 的自由 Talk 不应成为电话事件的强制前置。
- 4413 和尚未取得的 O'Hara 证词不应成为电话事件的前置，避免循环门槛。
- 电话事件只使用申请停止执行所真正需要的材料，例如协警通知和 O'Hara 的书面拒售记录。
- 电话接通、进入 Watts 固定事件后可以暂时锁定操作；事件结束后恢复自由控制。

#### Margaret 家

- 玩家进入场景后立即拥有控制权，不需要等开场对话播完才开始探索。
- Margaret 不阻挡柜子、纸箱或其他调查点，场景保持纯自由探索。
- 玩家主动点击 Margaret 时，才进入她的自由 Talk。
- 搬家、新公寓、Patrick、Mickey 等普通话题可以提前交谈。
- 在 O'Hara 正式证词取得前，不出现关于“O'Hara 是否同意卖房”的谎言话题。

提前来到 Margaret 家应该有内容可看、有话可问，但不会跳过调查链直接进入指证。

### 第三阶段：证词解锁谎言话题

- 警员撤离后，O'Hara 才愿意完整说明 Margaret 曾经劝她接受报价，以及自己已经明确拒绝。
- O'Hara 的两条正式证词应在一段自然的事件对白中依次取得，两次证词获取之间留出足够的普通对白，避免连续弹出信息。
- Sarah 的转移安排可以放在这段事件中完成，但事件结束后不再自动把 Zack 送到 Margaret 家。
- 玩家重新点击 Margaret 时，新增与 O'Hara 有关的话题选项。
- Zack 只询问 Margaret 做过什么，不直接替玩家说出“你在撒谎”的结论。
- Margaret 必须主动、完整地说出第一轮指证所需的谎言：O'Hara 已经准备接受报价，她只是在帮忙安排搬家。
- 谎言说出后取得 4104002，为后续 Expose 建立合法入口。

这一阶段的重点是让证词产生实际作用：它不是单纯增加一条收藏信息，而是改变 Margaret 的可谈话题和玩家接下来的行动。

## 四、不同游玩顺序下的体验

### 顺序 A：先留在 O'Hara 家

玩家取得 4413 后暂不离开，继续调查文件并使用电话。警员撤离后取得 O'Hara 证词，再前往 Margaret 家。此时玩家首次与 Margaret 交谈，就可以看到已经解锁的 O'Hara 话题。

这是最接近原有顺序的走法，但不再由系统强制转场。

### 顺序 B：先去 Margaret 家

玩家取得 4413 后立即前往 Margaret 家，可以自由探索公寓并与搬家中的 Margaret 谈普通话题。因为尚未取得 O'Hara 证词，关于拒售事实的谎言话题不会出现。

玩家之后返回 O'Hara 家处理电话事件、取得证词，再次拜访或点击 Margaret 时，新的话题才出现。

这条顺序能让玩家产生“她可能隐瞒了什么”的感觉，但不会让 Zack 在证据不足时直接指控她。

### 顺序 C：取得地址后在两处来回调查

玩家可以先查看 Margaret 家的一部分物件，再回 O'Hara 家打电话，之后继续探索任一场景。流程不要求把某个场景彻底搜完才允许离开。

系统只在真正需要信息门槛的地方设门槛：Margaret 的谎言话题依赖 O'Hara 证词，地点移动和普通探索不依赖这条证词。

## 五、对白编写原则

### 1. 不让 Zack 替玩家完成推理

在谎言话题中，Zack 可以转述 O'Hara 的说法或询问 Margaret 的行为，但不能一开口就总结“你明知她不卖还替她做决定”。矛盾应由玩家把 O'Hara 证词与 Margaret 的回答放在一起后自行发现。

### 2. 谎言必须由 Margaret 主动说完整

第一轮 Expose 使用的 4104002 必须先在普通 Talk 中由 Margaret 明确说出。她的防御逻辑应是：自己只是出于安全考虑帮忙，O'Hara 原本已经准备接受报价。

这既符合她务实、保护欲强的声纹，也给后续指证留下清晰的事实矛盾。

### 3. 保留 Margaret 的关心，但不替她洗掉越界行为

Margaret 可以关心门锁、住处、食物和孩子今晚睡在哪里，也可以真心认为自己的安排更安全。但对白必须同时保留她替 O'Hara 作决定、切断 Zack 求助路径的问题。

她不是单纯恶意撒谎，而是在恐惧中把“替别人安排”合理化。

### 4. O'Hara 的证词要符合她的立场

O'Hara 可以承认 Margaret 是担心她们的安全，但必须清楚表达自己从未同意卖房。她反对的重点不是 Margaret 提供住处，而是 Margaret 越过她的意愿替她作决定。

### 5. 自由探索对白不承担强制转场

Talk 结束只负责结束本次交谈并恢复控制，不自动进入电话事件、不自动开始指证，也不自动切换到另一处场景。玩家下一步做什么，由地图和场景交互决定。

## 六、场景表现原则

- Margaret 家是正在搬入的小公寓，屋内有尚未归位的生活物品和折叠状态的折叠床。
- Margaret 可以一边整理衣服、床单、账单或餐具一边回答问题，以动作体现紧张和回避。
- 她不能用身体挡住调查点，也不能要求 Zack “站着别动”。
- 玩家从场景载入起即可移动和调查；与 Margaret 对话是玩家主动触发的交互。
- 若玩家提前来访，Emma 可以继续留在 O'Hara 家协助观察警员，避免人物同时出现在两个地点。

## 七、本次调整不处理的内容

- 不改变 4416 的用途、获取方式或解锁条件。4416 仍服务于 Mickey 相关回忆。
- 不重写 Margaret 指证的三轮核心逻辑和证据答案。
- 不新增证据或证词 ID。
- 不要求玩家彻底探索完 O'Hara 家或 Margaret 家才能离开。
- 不在本次理念文档中直接修改 State、场景配置、道具描述或正式对白。

## 八、后续落地时需要保持一致的项目

如果之后正式实施，需要让以下内容共同遵守同一流程，不能只改单份对白：

1. 4413 的文字与美术表现需要明确包含 Margaret 新家的地址。
2. Margaret 家的地图解锁条件需要绑定取得 4413。
3. O'Hara 家电话的触发条件需要去掉 Sarah Talk、4413和两条 O'Hara 证词等循环前置。
4. O'Hara 证词的取得位置需要移动到警员撤离后的事件对白。
5. Margaret Talk 需要根据 O'Hara 证词切换可用话题。
6. Sarah 转移结束后恢复玩家控制，不再自动转场。
7. Margaret 家的场景演出和指证入口描述需要去掉“阻挡柜子”的旧表现。

本文档只规定设计目标与信息时序。实际改稿时，应先以本流程为准检查对白，再同步核对 State 和运行配置。
