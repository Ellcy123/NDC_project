## 一、字段写作与美术总规则

### 1. 文本分工

- `Name`：中性、可辨认的正式名称，不在取得时点提前写出尚未证明的责任人或结论。
- `Describe`：物品详情面板正文。只写玩家在取得时点能够观察、读取或经合法分析得到的事实；可以说明直接物理关系，但不替玩家完成后续总推理。
- `ShortDescribe`：CASE BOARD、Tooltip 和选证界面的检索提示。用一句话保留该证据最值得回忆的事实，不得只重复名称，也不得写成答案。
- `ArtRequirement`：分为“重点（信息表达必不可少）”与“美术参考（不影响推理）”；另列剧透禁区和跨证据一致性。

### 2. 分析后证据

Unity 详情面板会对分析后物件同时显示原物 `Describe` 与分析结果 `Describe`；Tooltip 也会分别显示原物和分析结果的 `ShortDescribe`。因此：

- 分析结果只写新增事实，不重复抄写原物外观。
- 分析后详情图优先表现“原物的受控分析状态”，而不是凭空生成一份现代报告。
- 若小玩法明确要求世界内产物，则按玩法文档的产物形态制作。

### 3. 小玩法关系固定字段

每件证据必须写明以下一种情况：

- `无`：不参与任何分析、合成、门锁、记忆观察、容器交互或身份锁。
- `输入`：写清触发地点、其他输入、玩家操作、是否消耗。
- `输出`：写清来源玩法、生成条件、原物是否保留。
- `跨玩法输入`：本 Loop 取得，后续 Loop 才进入玩法。
- `玩法附属美术`：不进入物品栏，但需要为玩法制作页面、标尺、锁轮、节点卡等资源。

### 4. 悬疑与信息边界

- L1-L4 不得在画面或文本中直接写出 `Mickey = Whale`。
- 4315、4704 均不能单独锁定 Mickey；必须到 L5 用 4315 + 4512 完成复合比对。
- 4418 不能表现为 Patrick 对 Mickey 的继承授权。
- 4516 在 L5 办公室内只能显示外卷和未拆内封套；4517-4519 不得提前露出。
- 4705-4708 是推理结果卡，不是世界内纸质报告。

## 五、待策划 / 系统 / 美术确认的设计点

### 仍 open

1. 4412 的最终收购金额尚未锁定。需结合 O'Hara 房产正常价值确定具体美元数，不能只靠“看起来偏低”。
2. 4116 第三次提交、4313 提前签发、4319 晚报发行等精确日期/钟点需要与最终 Unit4 时间线校准后上画。
3. 4517 的原材料、替换材料、承重等级与工程术语需要年代/工程考据后定稿；当前只锁定“事故前主动降级”。
4. 4704-4709 的 CASE BOARD 结果卡尺寸、通用框架、来源回溯交互和是否需要独立 icon 尚需 UI 统一规范。
5. 4516 内封套的“底部暗夹”在终幕如何被发现需要与过场/交互实现对齐，避免美术把4519画得在L5初见就过分显眼。
6. 本文英文配置与上画文字为内容设计稿，正式进表前需要统一英文编辑校对，尤其是法律、银行、医院和工程术语。
