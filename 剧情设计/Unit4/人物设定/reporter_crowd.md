# 记者群像（记者 A / B / C）— Unit4 人物档案

> 权威依据：`剧情设计/Unit4/Unit4_大纲0723_逻辑重构版_v3.md`、`剧情设计/Unit4/state/loop2_state.yaml`、`AVG/对话配置工作及草稿/Unit4/Loop2_生成草稿_Mickey辩护开篇重写版.md`
> 适用边界：定义 Unit4 中记者 A、记者 B、记者 C 共用身体资产、分别使用独立头部设计的单一记者群像需求，不将 A / B / C 扩写成三名独立 NPC。

## 一、基本信息

- 角色名：记者群像（台本发言位：记者 A / 记者 B / 记者 C）
- 身份：被 Whitfield 邀请到法院、通过旁听席固定线路记录并传播预审的记者群体
- Unit4 用途：表现公开舆论从跟随 Whitfield 的“家属误用”口径，转向追问医院与追踪辩护方的整体变化
- 主要出场：Loop 2 的法院预审法庭与预审走廊

## 二、角色与美术需求

- 记者 A、记者 B、记者 C 在角色配置与资产统计中仍合并为一个“记者群像”角色需求，不制作三套独立身体资产。
- A / B / C 共用同一套身体、主体服装和基础姿势，但分别制作不同的五官与发型；三套头部必须具有脱离配饰仍可辨认的外貌差异，不能只靠帽子、相机或证章区别。
- 三套头部与同一身体资产组合，不因此拆分角色 ID、互动入口或三套完整基础立绘。
- 右侧黑色对话框使用头像构图，画面约从头顶裁切到衣领；每名记者只使用一件可替换配饰，不叠加第二识别物。

| 发言位 | 五官与发型 | 唯一配饰 | 头像表现 |
|---|---|---|---|
| 记者 A | 偏方的脸型、较宽下颌、浓直眉；深色短发严格侧分，帽檐下仍露出清楚的发际线与鬓角。 | 记者识别帽 | 深色窄檐羊毛 fedora，帽带固定一张小型 `PRESS` 采访卡；帽子与卡片作为一个完整配饰层。 |
| 记者 B | 窄长脸、高颧骨、较细眉眼；棕色微卷发向后梳理。 | 1928 年式折叠皮腔新闻相机 | 相机举在脸侧而不遮住五官，头像内需看到顶部提手、镜头板和少量皮腔；不加后世常见的大圆盘闪光灯。 |
| 记者 C | 偏圆脸、面颊较饱满、鼻梁稍宽；浅棕色短发侧分，发际线略高。 | 垂挂式采访证章 | 纵向布质 `PRESS` 证章别在靠近衣领的高位翻领上，确保头像裁切后文字仍然可辨。 |

- 三种配饰必须在头顶到衣领的裁切范围内完整可辨，不依赖胸口以下或画面外的道具。
- 三者不使用单耳监听耳机、现代手持麦克风、塑料证件套、挂绳工牌、现代单反相机或电子闪光灯。
- 台本中的“记者 A / B / C”用于指定当前发言者及其配饰变体，不对应三个独立基础立绘、角色 ID 或单人演出资产。

## 三、AVG 与自由探索演出规则

- 记者 A / B / C 只要在 AVG 或自由探索场景中出场，场景底图／场景演出层都必须保持“一群记者”的群像状态。
- 右侧黑色对话框内只显示当前发言记者的单人立绘。记者 A、B、C 共用同一套身体与主体服装，对话切换时同步切换当前发言者的头部设计及其对应配饰。
- 场景中的入场、转场和离场都按整个记者群像处理。自由探索场景可直接写成“记者群像立绘入场”或“记者群像立绘离场”，不分别播放 A / B / C 的个人进出。
- 群像可以整体围拢、后退、转向新的采访对象或涌入下一场景；黑色对话框内的单人发言者切换，不改变场景底图上的记者群像状态。

## 四、声音风格与交互姿态

- 群像整体追逐当下最有新闻价值的说法：开庭前追随 Whitfield 的引导，证据击穿后立即转向追问医院责任，裁定后追向 Mickey 与 Rosa。
- 台词可以密集、打断和相互接话，但不为 A / B / C 分别建立独立性格、私人背景或长期关系。
- 记者群像不是 Emma 的替身；Emma 仍使用自己的独立角色资产、记者身份与对话声纹。

## 五、设计边界

1. 不新建“记者 A”“记者 B”“记者 C”三份人物档案或三套完整身体立绘需求；三套独立头部设计属于记者群像资产内部变体。
2. 不在场景底图／场景演出层中让 A / B / C 以单人立绘独立入场或离场；右侧黑色对话框显示当前单人发言者不受此条限制。
3. 不因发言位变化拆分角色配置或互动入口；立绘仅切换头部设计与配饰变体，共用身体资产。
4. 不为记者群像补写与 Miller、Whitfield、法院或报社的私下合作关系；他们的立场变化只来自当庭可见的新闻价值。
