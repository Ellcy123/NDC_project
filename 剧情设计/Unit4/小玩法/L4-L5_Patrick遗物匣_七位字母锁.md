# 玩法设计文档：Patrick 遗物匣七位字母锁

**文档版本**：v1.0  
**隶属章节**：Unit 4 - Loop 4 至 Loop 5  
**玩法类型**：inscription_acrostic_letter_safe  
**设计目标**：让玩家先从 Patrick 遗物匣的完整刻句中亲手提取七个词的首字母，再跨 Loop 回收并使用这一结果，将它拨入 Mickey 私人办公室的机械字母锁，以一个短促的回收动作打开保险柜。  
**目标时长**：合计约 15—20 秒；L4 约 8—10 秒，L5 约 7—10 秒，不计场景移动与剧情对白。

---

## 0. 前因后果

### 前因——L4 取得 Patrick 遗物匣

Margaret 指证结束后，她在 `L4_post_expose_patrick_truth` 中主动交出：

- **4418「Patrick遗物匣」**

4418 是此前已经出现过的同一件橡木小匣，不得在本玩法中改变其既有物理属性：

- 约 25×18×10 cm 的深色橡木长方匣。
- 顶盖刻有 `P.B.`。
- 正面嵌有一枚氧化发暗的工人运动领袖徽章。
- 长侧面刻有完整句子：

> FOR THE MANY WE PAY THE FEW

- 匣内保存 Patrick 未使用的返程票。

4418 不参加 Margaret 指证，也不参加 L5 的身份锁或 Expose。它在本玩法中只承担家族遗物、未使用返程票与保险柜密码来源三项功能。

### 后果——L5 打开保险柜

玩家在场景 4042「Mickey 私人办公室」完成 `interaction_letter_safe`，打开七位字母锁保险柜后取得：

- **4513「1925年内部接口接管记录」**
- **4514「1919年的银行授权附页-Donnelly & Associates」**
- **4515「Mickey功业簿」**
- **4516「Miller保险外卷与内封套」**

本玩法只解锁容器，不生成新的证据卡、分析结果、合成结果或派生结论 ID。只有 4513—4515 会与前序 Loop 材料进入后续身份拼装；4516 随开柜结果原子取得并保持封存，不参加身份锁或 Expose。保险柜打开本身不能直接证明 `Mickey = Whale`。

## 1. 玩法概述

- **核心体验**：发现完整刻句 → 亲手选出七个首字母 → 跨 Loop 回收并使用结果 → 亲手拨动七位机械字母轮 → 打开保险柜。
- **结构**：L4 负责“读出密码”，L5 负责“使用密码”。
- **主要操作**：L4 一次旋转与七次首字母选择；L5 七次短拨与一次把手操作。
- **失败惩罚**：无；错误不消耗物品、不清空正确结果、不重置其他字位。
- **重复劳动控制**：L4 已经完成首字母提取后，L5 直接展示玩家留下的七枚黄铜字母作为参照，不要求再次寻找刻句或重新提取首字母。
- **玩家参与底线**：系统不得在选中第一个首字母后自动填满其余六位，也不得因玩家持有 4418 而自动打开保险柜。
- **完成反馈**：七个机械锁舌依次落下，玩家亲手扳动把手，保险柜门打开并显示内部文件架。
- **性能边界**：黄铜字片落槽不阻塞下一次点选；七个字母轮互相独立并允许连续输入；七锁舌完成动画总长约 0.8 秒；不增加确认按钮或长镜头。

玩法不设置倒计时、失败次数、生命值、材料消耗、随机密码或解错后从头重来的惩罚。

## 2. L4：遗物匣观察与首字母提取

### 2.1 触发条件

- 已完成对 Margaret 的 L4 指证。
- Margaret 已在指证后剧情中交出 4418。
- 4418 本轮只发放一次。

Margaret 交出 4418 后，系统立即将它一次性登记为章节级保留关键物，并进入遗物匣短观察。正常新流程必须在 L4 当场完成“旋转到刻句侧面 + 选出七个首字母”；完成前不得结束 `L4_post_expose_patrick_truth`，也不得把“稍后回看”作为普通推进路径。

### 2.2 遗物匣观察

遗物匣初始以正面朝向玩家，画面首先能看见顶盖的 `P.B.` 和正面的工人徽章。完整刻句位于长侧面，初始角度不能一次全部读出。

玩家水平拖动匣身，将它旋转到刻句所在侧面：

- 只需一次明确的水平拖动即可找到目标侧面，不设置多面盲搜。
- 匣身旋转采用固定角度吸附，防止玩家停在文字被透视压缩、无法阅读的位置。
- 到达目标侧面后，完整刻句保持在同一平面与同一阅读方向。
- 不把句子拆到两个侧面，也不缺字、不磨损到需要猜词。

此步让玩家主动找到刻句，但不把简单观察拖成长时间的 3D 物件搜寻。

### 2.3 选取七个首字母

完整刻句进入正视角后，七个单词形成七个独立的可选区域：

> FOR / THE / MANY / WE / PAY / THE / FEW

玩家逐词点选首字母：

1. 选中 `FOR` 的 `F`。
2. 选中第一个 `THE` 的 `T`。
3. 选中 `MANY` 的 `M`。
4. 选中 `WE` 的 `W`。
5. 选中 `PAY` 的 `P`。
6. 选中第二个 `THE` 的 `T`。
7. 选中 `FEW` 的 `F`。

每选对一个首字母，对应字符出现一圈薄黄铜描边，并复制为一枚黄铜字母片，落入画面下方的七格记录条。原有木刻文字仍留在匣身上，不能表现为玩家把字母从文物上拆走。字母片落槽动画不得锁住输入；前一枚仍在移动时，玩家可以继续点选下一词。

玩家可以按任意顺序选择七个词。系统按照单词在原句中的位置把字母放入对应格，而不是按照点击顺序重排。这样既要求玩家亲手识别每个首字母，也不会因为先点了后面的单词而形成无意义的顺序惩罚。

七格全部完成后，黄铜字母片由左至右显示：

> F T M W P T F

系统只记录这组字母，不弹出解释 Patrick 思想或 Mickey 身份的总结文本。

### 2.4 L4 完成条件

L4 部分必须同时满足：

- 玩家已经旋转到刻句所在侧面。
- 七个词的首字母均由玩家亲手选中。
- 黄铜记录条已经形成 `FTMWPTF`。

完成后保存密码发现状态，并以该状态作为 `L4_post_expose_patrick_truth` 的结束条件之一。该状态不是证据，不占 CASE BOARD 位置，不生成派生 ID，也不改变 4418 的证据属性。

## 3. 跨 Loop 状态保留

4418 与玩法进度均按章节范围保留，不随 L4 结束而清除：

- Margaret 交出后，4418 只进行一次章节级关键物登记，不在 L5 重复发放。
- 4418 可从专用的“Patrick遗物匣”关键物回看入口查看，不无条件写成普通物品栏道具。
- 已经发现刻句时，重新查看 4418 默认回到刻句正视角。
- 已经选中的首字母保持完成状态。
- 已完成 `FTMWPTF` 时，L5 字母锁界面显示七枚黄铜字母作为密码参照。
- L5 退出保险柜界面时，已经拨好的锁轮保持原位。

正常新流程必定在 L4 完成首字母提取。L5 补做只服务于旧存档、异常中断或状态迁移恢复，不能成为正常路径，也不能让新流程跳过 L4 完成门槛。

系统仅在检测到“已登记 4418，但缺少完整密码状态”的异常存档时开放恢复入口：

1. 保险柜当前字轮状态暂存。
2. 界面先提供通用“回看关键物”入口，不直接点名答案来源。
3. 玩家从关键物回看界面中自行选择 4418，完成尚缺的旋转与首字母提取。
4. 完成后返回保险柜，先前已经拨好的字轮不重置。
5. 只有三级提示可以进一步定位到 4418；一级、二级提示不得直接指出该物件。

这只是对不完整历史状态的恢复，不是让已经在 L4 完成的玩家重复提取。

### 3.1 4418 实现契约

本文将 4418 定义为“可回看的章节级保留关键物”。现行 state 存在实现契约歧义：L4 将 4418 写为 `type: key_item`、`pickup: false`，L5 的继承登记则写为 `type: item`。正式配置前必须裁定统一承载方式，但本次不修改 state。

- 推荐实现：使用专用关键物登记与“Patrick遗物匣”回看入口。
- 若最终必须复用 CASE BOARD，则落表时映射为可查看的 `itemType=3`，并保持章节级跨 Loop 保留。
- 两种实现都沿用 4418，不新增替代 ID，也不得在 L5 再次发放同一物件。

## 4. L5：七位机械字母轮输入

### 4.1 触发条件与场景

- 场景：**4042「Mickey 私人办公室」**。
- 交互：`interaction_letter_safe`。
- 输入来源：4418。
- 接受密码：`FTMWPTF`。

保险柜不是办公室入口门禁。Zack 进入办公室后才调查它，不增加破门、撬锁、潜入判定或额外钥匙步骤。

### 4.2 字母锁界面

保险柜面板包含：

- 七个并列的机械字母转轮。
- 每个转轮中央的一条对准刻线。
- 左至右七个机械锁舌状态点。
- 一个当前锁定的黄铜把手。
- 下方的 4418 黄铜记录条。

记录条只作为玩家已经亲手得到的参照，不会自动把字母填入锁盘。

### 4.3 拨入 FTMWPTF

玩家从左至右或按任意顺序拨动七个字母轮，将中央刻线分别对准：

> F / T / M / W / P / T / F

每一轮的操作方式固定为：

- 按住单个字母轮并上下拖动，使字母连续滚过中央刻线。
- 松手时吸附到距离最近的完整字母。
- 单次拖动允许越过多个字母，不要求玩家连续点击二十余次从 `A` 逐格转到目标字母。
- 每个字轮必须至少接收一次玩家输入；系统不能自动代填未操作的字位。
- 转轮之间互不联动，修改一位不会改变其他六位；一个转轮的吸附或回弹动画不阻塞玩家立即操作下一轮。

七位全部正确后，不再要求额外点击“确认密码”：

1. 七个锁舌由左至右依次落下，整段动画总长约 0.8 秒。
2. 黄铜把手从锁定状态转为可操作状态。
3. 玩家亲手向下扳动把手。
4. 保险柜门打开。

这一步只回收并使用 L4 得到的结果，不再次考玩家从句子中提取首字母。锁舌动画后不增加“确认密码”按钮，也不插入阻塞操作的长镜头。

### 4.4 开柜结果

保险柜打开后显示分层文件架，并以同一次开柜结果原子取得：

- 4513「1925年内部接口接管记录」
- 4514「1919年的银行授权附页-Donnelly & Associates」
- 4515「Mickey功业簿」
- 4516「Miller保险外卷与内封套」

其中只有 4513—4515 进入后续身份拼装。4516 在 L5 保持整袋封存，不参加身份锁或 Expose：外卷可以查看，内封套不得在办公室内拆开。开柜动画不展示 4517、4518、4519，也不提前泄露内封内容。

## 5. 容错与分层提示

### 5.1 错误处理

- **没有转到刻句侧面**：遗物匣停在当前角度，玩家可继续拖动，不判失败。
- **点到单词中的非首字母**：播放轻微木质敲击声，该词不计入结果，不清除其他正确选择。
- **重复点击已完成的首字母**：黄铜描边轻响一次，不重复生成字母片。
- **先点后面的单词**：字母进入它在原句中的固定位置，不要求从第一个词重新开始。
- **拨错字母轮**：转轮保持当前字母，其他字位与黄铜记录条不变。
- **七位尚未全部正确时拉动把手**：把手只表现短距离受阻与金属闷响，不触发警报或重置。
- **异常中断**：保存已经找到的刻句、已选首字母和已拨字轮；正常 L4 流程仍须补齐七个首字母后才能结束 post-expose。

### 5.2 分层提示

#### 一级提示

- L4 无操作时，刻句所在侧面的边缘出现一次自然擦光。
- 找到刻句后，七个单词之间的间距略微强化。
- L5 正常流程无操作时，当前选中的字母轮与下方黄铜记录条同时轻微提亮。
- 异常恢复流程无操作时，只提示存在通用“回看关键物”功能，不指出 4418。

一级提示只指出交互对象，不标出答案。

#### 二级提示

- L4 显示一次短促的水平旋转手势。
- 首字母阶段让下一处尚未选择的单词整体轻微浮起，但不单独高亮正确字母。
- L5 正常流程在黄铜记录条与七个字轮之间显示对应位置的细线。
- 异常恢复流程只强化通用“回看关键物”入口，仍不点名 4418。

二级提示说明对应关系，仍要求玩家亲手完成每个字母。

#### 三级提示

- L4 让下一处尚未选择的首字母轻微浮起，玩家必须点击后才计入。
- L5 扩大单个转轮在目标字母附近的吸附范围，但不自动转动该轮。
- 异常恢复流程到三级提示时，才允许在关键物回看列表中定位 4418。

三级提示降低观察与精细操作负担，不跳过七个首字母或七个密码位。

## 6. 叙事和证据边界

### 6.1 允许表达的关系

- Patrick 遗物匣上确实刻有 `FOR THE MANY WE PAY THE FEW`。
- Mickey 后来长期把这句话作为自己的私人信条使用。
- Mickey 因而把七词首字母 `FTMWPTF` 用作私人保险柜密码。
- 玩家必须亲手使用这句话，才能看见它实际保护着哪些文件。

### 6.2 禁止推出的结论

- 不把这句刻文写成 Patrick 全部思想的唯一答案。
- 不暗示 Patrick 授权 Mickey 继承使命。
- 不暗示 Patrick 折返前知道被困者是 Mickey。
- 不因 Mickey 使用 Patrick 的话，就证明 Patrick 会认可 Mickey 后来的行为。
- 不把保险柜写成 Mickey 专门留给 Zack 的邀请、考验或普通谜语。
- 不因密码正确就直接证明 Mickey 是 Whale。
- 不把 4418 放入 L5 三条身份锁的提交位。
- 不把 4418 用于任何一轮 Mickey Expose。
- 不为刻句、七位密码或开柜动作新增分析、合成或派生证据 ID。

### 6.3 后续推理分工

保险柜开启只解决“如何取得内部材料”，不解决“这些材料共同证明什么”。

```text
4418 Patrick遗物匣
        │ 玩家观察完整刻句并选取七个首字母
        ▼
FTMWPTF（跨 Loop 玩法状态，不是证据 ID）
        │ 玩家在 4042 亲手拨动七位机械字母轮
        ▼
打开字母锁保险柜
        │ 只取得容器内原始材料
        ▼
4513 + 4514 + 4515 + 4516（同次开柜原子取得）
        │ 仅 4513—4515 与前序 Loop 材料进入后续身份拼装
        ▼
玩家另行证明 Mickey = Whale
```

4516 不参加 L5 身份锁或 Expose；其外卷与内封套按照既定终幕时序处理。

## 7. 美术与音效需求

### 7.1 遗物匣美术

- 保持深色橡木、哑光木蜡油、圆润磨损边角与黄铜小搭扣的既有外观。
- `P.B.` 保持手工雕刻感，不能改为机刻铭牌。
- 工人徽章保持氧化后的深铜色或暗银色，并嵌在匣身正面。
- 完整刻句位于同一长侧面，字号略小于 `P.B.`，刻痕较浅但清晰可读。
- 首字母选中效果使用贴合刻痕的薄黄铜描边；不得使用现代霓虹发光、全屏粒子或把字母从木匣上拆下的表现。
- 七格记录条由旧皮革底座与薄黄铜字母片构成，完成态必须清楚显示 `FTMWPTF`。

### 7.2 保险柜美术

- 采用 1920 年代大型机械保险柜的厚重钢门、黄铜字母轮、实体锁舌与把手。
- 七个字母轮同时可见，中央刻线清晰，避免逐位切换造成额外操作时间。
- 字母轮通过字符、刻槽和机械停点共同表达当前位置，不只依靠颜色。
- 不出现现代数字键盘、电子屏幕、绿色确认灯、密码弹窗或自动开门电机。
- 保险柜内部使用分层文件架。4513、4514、4515 与整袋封存的 4516 在轮廓和封装上可区分，但开门瞬间不放大展示内容结论。

### 7.3 音效

- 遗物匣旋转：木面摩擦与黄铜搭扣的轻响。
- 首字母选中：短促、克制的黄铜落槽声；连续七次播放时避免高频刺耳。
- 七字完成：一次低沉的黄铜扣合声；表现不阻塞后续操作。
- 字母轮拨动：连续机械齿声；吸附到字母时出现一次清晰卡点。
- 字位正确不单独播放“答对”提示音，防止玩家只靠声音试出密码。
- 七位全部正确：七个锁舌在约 0.8 秒内依次落下，随后把手解锁。
- 拉开保险柜：沉重的金属把手转动与门轴低响。
- 所有错误操作均不播放失败警报。
