# L4—L5 Patrick 遗物匣与七位字母锁

**Loop**：L4 至 L5 · **场景**：Margaret 指证后 → 4042 Mickey 私人办公室

## 玩法简述

玩家在 L4 观察父亲留下的木匣，从刻句中选出七个首字母；L5 再亲手把这组字母拨入保险柜。它是一段简短的线索发现与回收，不需要另加题目或操作考验。

## L4：观察与提取

1. Margaret 在指证后交出 4418「Patrick遗物匣」。保留既有外观：深色橡木、顶盖 P.B.、正面工人徽章，匣内有未使用返程票；不新增夹层或隐藏机关。
2. 玩家水平拖动匣子，转到长侧面。完整刻句吸附到清楚可读的角度，不拆面、不缺字、不要求猜英文：
   > FOR THE MANY WE PAY THE FEW
3. 玩家点选七个词的首字母，记录条按原句位置形成 F / T / M / W / P / T / F。可以任意顺序点击，两个 THE 分别计入各自位置。
4. 七个字母全部记录后结束这一短互动；原刻字始终保留，选中效果只是记录，不表现为把字母从木匣拆走。

正常流程在 L4 完成提取。返程票信息按原剧情呈现，不添加“观察完所有装饰才可继续”的门槛。

接入待对齐：现有 L4 对白草稿只安排观察，并写明不强制提取首字母；上述短互动仍需与交匣演出对齐，不表示已接入 AVG。

## L5：拨锁与开柜

1. 玩家调查办公室内的七位字母锁保险柜，界面展示已记录的 FTMWPTF，供随时对照。
2. 玩家直接拨动七个独立字轮，每位允许一次拖过多个字母，松手吸附到完整字符；可任意顺序输入。
3. 单独一位正确不显示对错，也不发答对音。七位都由玩家输入且组合正确后，锁舌松开，玩家扳动把手开柜。
4. 同次开柜取得 4513—4516；没有额外确认题，也不再做一次首字母提取。

## 判定与容错

- 字母点击区清楚可辨，点错不清空其他位置；重复点选不重复记录。七个首字母和七位密码由玩家亲手操作，系统不代填。
- 拨错字轮保留当前位置，不影响其他六位；拉错把手只表现受阻，不报警、不限次数。
- 提示先指出刻句侧面或未记录的单词，再帮助定位首字母；L5 提醒对照已有记录，不新增密码线索。
- 4418 作为章节保留关键物只登记一次；刻句、已选字母、密码和字轮位置跨退出与 Loop 保留，能随时回看。
- 旧存档持有木匣却缺密码进度时，可回看补齐后返回锁盘，已拨字轮不重置；正常流程不要求重复完成 L4。
