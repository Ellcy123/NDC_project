# L5 Whale 身份开放推理面板

**Loop**：L5 · **场景**：4042 Mickey 私人办公室

**状态**：开放玩法设计稿；现行 State 仍采用固定三链，本文不直接替换运行合同。

## 玩法简述

玩家把已有的人物、案件、组织和证据摊在桌面上，尝试两两连线。成立的关系留下事实说明，必要时生成一张新的事实卡；新事实还可以继续连线，逐步积累当面对质的依据。

前台不显示三道题、指定材料数量或固定槽位。Whale 身份是主要推进目标，已调查案件的关系也可整理，不要求把所有支线连完才能对质。

## 操作方式

1. **进入**：在办公室开柜取得 4513—4516 后，可整理当前已获材料；缺少钢笔或雪茄时仍可返回调查，不提前完成对质条件。
2. **连线**：任意选择两个当前节点，不另猜关系类型或拖拽方向；反向连接视为同一次尝试。
3. **读结果**：有效线保留并说明两份材料具体对应之处。只有需要继续推理的认识才生成新事实卡，点击可回看原始来源。
4. **继续推理**：新事实可以与材料、人物或其他事实连接，同一证据可反复引用，不因使用而消失。
5. **开始对质**：必需依据完整后开放“开始对质”，玩家主动确认才触发 Mickey 返回；此前可以继续整理。

## 判定与容错

- 每条有效关系必须有已获材料支持。资金控制不等于法律所有，死前访客不等于已证明开枪，不能因为两个名字有关联就算证据成立。
- 例如电话记录直接连 Mickey，不能生成“他接了电话”；反馈说明“记录指向事务所，没有记下接听者”，保留其他进度。
- 同一对未变化的节点，判定始终一致。需要更多依据时生成新事实再连，不能让已经试错的旧配对暗中变为正确。
- 无效尝试不扣资源、不清进度；保留已试标记。提示只指出可核对的事实维度或材料范围，不直接画答案线。
- 可拖动、收起和重新展开节点；收起不删除关系，也不能藏掉必需材料。退出保留已发现关系、事实来源和桌面布局。
- 节点范围应有限、未尝试关系可查看；原型须验证从初始材料反复尝试节点对，能够生成全部必需事实，不依赖隐藏顺序或循环前置。关系表未验证前，不宣称玩法已经可通关。

## 完成与信息边界

- 对质仍需完整覆盖现行三链的证明要求：资金接口与职责沿革、书写者一致与参与者视角、Morrison 死前访客。上表示例不能替代全量关系表，也不能用一条弱联系跳过必需材料。
- 本稿产生的中间事实只作为面板记录，不擅自新增正式证据 ID；迁移时再对应现行 4705—4708 等结果。
- 完成只提示“已具备当面对质的依据”，不显示 Mickey＝Whale，也不让 Zack 提前总结最终身份；后续 Expose 负责逐轮击破狡辩。
- 4516 最多使用当前可读的公开外卷作背景，不增设主线条件；隐藏附件、4518—4519 及非 Loop 终幕新信息不得进入面板。
- 已知 Patrick 事实可作背景，不能生成“Patrick 授权 Mickey 继承使命”；其他案件关系须保留上层、接口与执行者的不同责任。
- 开放网与现行固定槽位、三链完成即触发返回的规则有差异。后续先验证小型原型，再同步 State、特殊机制规范和适配器；当前仅细化玩法文档。
