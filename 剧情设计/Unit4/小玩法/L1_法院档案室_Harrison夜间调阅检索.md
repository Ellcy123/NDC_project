# L1 Harrison 夜间调阅检索

**Loop**：L1 · **场景**：4003 法院档案室

## 玩法简述

玩家把 Harrison 的公开日程、闭馆后出入登记和调阅流水交叉核对，找出他在公开公务之外持续重查旧案的记录。三轮操作，每轮先选本人的访问时间窗，再选对应的调阅记录。

## 检索方式

1. **进入**：取得 4115「Harrison两个月调阅索引」后，点击档案室核对台。公开日程与出入登记作为桌面附属页面提供。
2. **找访问窗**：从当前目标日的多人登记中，选出 Harrison 在公开公务结束、档案室闭馆之后的进入—离开记录。
3. **找调阅记录**：保留已选姓名、日期和访问窗供对照；从流水中选出“同一日期、调出时间在访问窗内、签收人为 Harrison”的一行。
4. **记录结果**：正确匹配后才展开案卷类别。三轮分别核对下面三类，不展示裁定签署人。
5. **汇总**：三轮完成后，系统按相同规则快速核验剩余记录，生成十七次夜间调阅对照；玩家可回看明细，不再逐条提交。

| 轮次 | 案卷类别 | 干扰与判断 |
|---|---|---|
| 1 | 圣心医院项目争议案卷 | 同日有其他人进出，必须先核对姓名 |
| 2 | 南区地产裁定卷 | 同一时间窗内有他人调阅，必须核对签收人 |
| 3 | 法院旧赔偿裁定卷 | 一条记录仅归还时间在窗内，必须看调出栏 |

## 判定与容错

- 每轮只有一条流水满足全部条件；若有两条同样成立，应修正题面，不能让玩家猜系统预设答案。
- 流水明确区分“调出时间 / 归还时间 / 签收人”。签收人是调阅登记，不是裁定签署人，也不要求笔迹鉴定。
- 签收人可读栏及干扰行按现有登记逻辑补制；具体日期、时刻需与剧情统一，不临时编造新案情。十七次须有完整记录支撑，不能由三个样本推算。
- 选错只提示当前不符的字段，如“这行签收人不是 Harrison”或“窗内这一笔记在归还栏”；不清空正确步骤。
- 提示可缩小日期范围、指出要看哪一栏，不直接点选答案。退出保留当前轮次和已确认访问窗；完成奖励只发一次。
- 不限时，不考精细操作；玩法只统计“十七次”，不能由次数直接推出“连续十七晚”。

## 输入 → 产出

- 正式输入：4115「Harrison两个月调阅索引」。
- 附属页面：4122 公开日程、4123 闭馆后访问记录；两者不进入正式物品表或背包。
- 产出：4111「Harrison公开日程与夜间出入对照」。统计为医院七次、地产三次、旧赔偿七次。
- 4115 保留，后续与法院旧案号目录单独整理得到 4701；本玩法不提前显示旧裁定由 Harrison 签署。

## 指证用途

- L1 R1：4111 进入疑点 4101，支持反驳 Watts“只是处理日常工作”。
- L1 R2：另用 4701 反驳“查的都是别人”；不把这层结论合并到夜间检索结果。
