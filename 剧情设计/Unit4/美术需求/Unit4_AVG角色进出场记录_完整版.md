# Unit4 AVG 角色进出场记录

## 记录说明

本文档统计 Unit4 对话中对话进行过程中中途进出的角色，统计范围为 `Loop1_生成草稿.md` 至 `Loop5_生成草稿.md`。

统计口径沿用 Unit3 文档：

- 进场：对话进行中，角色从场景外进入，或从画面外、遮挡处明确现身。
- 离场：对话中途，角色主动离开当前空间，且台词或舞台指示明确表现了离场动作。
- 不计入：场景开始时已经在场的角色、电话或画外音角色、闪回人物、身份称谓变化，以及随普通场景切换完成的 Zack 视点移动。
- 群体角色：警员、记者等没有独立姓名、但需要整体画面表现的角色，以角色群记录。

## 美术需求关键点

### 需要立绘、动作或环境配合的进出场

1. L1 法院门口
   - Mickey 与 Pierce 从法院内并肩走出，仍处于低声交谈状态。
   - Zack 与 Emma 藏到石柱后，需保证两组角色的视线遮挡关系成立。

2. L2 圣心医院社会服务部
   - 调档员暂时离开柜台，等待段只保留 Zack 与 Emma。
   - 调档员推木质档案车返回，车上需要能表现七份病历。

3. L2 预审法庭与走廊
   - 记者群从法庭双开门涌向走廊。
   - Mickey 护住 Rosa，被人群一路挤向电梯口并逐渐消失。
   - 人群散去后，Harold 从粗大圆柱或走廊阴影处现身；谈完后从另一侧楼梯离开。

4. L3 Morrison 宅邸
   - 宅邸大门突然从内侧打开，Doris 苍白、惊恐地出现在门口。
   - 爆炸撤离时，Mickey 扛起 Doris 越过安全边界；落地后将她放下并护住。
   - Pierce 从外围警戒区大步跨入临时询问区；结案后转身走向警车。

5. L4 Zack 侦探事务所
   - Mickey 提起公文包摔门离开，门的闭合需要成为情绪断点。
   - 稍后门外急促敲门，Doris 猛然推门出现；需保留棕色大衣袖口的烟熏痕迹和喘息状态。

6. L4 O'Hara 家
   - 法院书记员与 Lakeshore 专员同时抵达门前，角色立场需要通过站位区分。
   - 警员群签署回执后撤离，Lakeshore 专员失去依仗、脸色铁青地跟随离开。
   - Emma 帮 Sarah 整理围巾后牵手离开；Sarah 走到门外回头呼喊，O'Hara 留在昏暗门厅挥手。
   - 送达与离场角色应统一画成法院书记员，不要依据尾注误画成 Watts。

7. L5 Donnelly & Associates 办公室
   - Mickey 从 Zack 身后开门走入，先表现疲倦和熟悉的温和姿态。
   - Emma 从办公室门口高速冲入，从后方抱住即将失衡的 Zack。
   - Mickey 咬手、主动松开墙沿并坠落；只展示坠落身影、Zack 抓空的手与袖料，不展示落地。

8. L5 服务出口
   - 空荡停车区先制造 Watts 爽约的错觉。
   - 法院档案车从街角拐入并无声停靠；Watts 从驾驶座侧面推开后门，以车门作为掩护接应两人。
