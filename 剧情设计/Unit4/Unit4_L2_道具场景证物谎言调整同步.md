# Unit4 L2 道具／场景／证物／谎言调整同步

## 一、道具／证物调整

| 调整前 | 调整后 | 为什么调整 |
|---|---|---|
| Harrison 处直接留下“圣心医院儿童死亡对照表” | Harrison 只留下编号纸，固定写有 `SH-24-071`、`SH-24-118`、`SH-25-044`、`SH-26-093`、`SH-27-031`、`SH-27-126`、`SH-28-052`；纸面可见 1924—1928 年份段，但不解释死亡属性。完成医院调档后，编号纸更新为“五年七例儿童死亡病例对照表” | 避免 L1 提前揭露死亡儿童和 Miller 项目，同时让 Foster 对话和后续调档能够逐项核对真实编号。 |
| Harrison 留下来源不明确的问题药剂样本 | 改为“医院冷藏库留样试剂”：由 Harrison 通过正式手续从医院冷藏库提取，封签及交接记录完整 | 建立可靠来源，使 Foster 的化验可以排除 Rosa 家庭或废弃样本库保存不当造成异常的可能。 |
| “经化验的问题批次药剂” | 改为“经化验的医院冷藏库留样试剂” | 除了证明连续使用风险，还能证明异常在药剂进入受助家庭前已经存在。 |
| 没有独立的 Isabel 病历证物 | 新增“Isabel 的病历本”，用于核对给药记录、药剂发放号和制剂信息 | 让 Isabel 的给药记录、Rosa 回收药瓶和项目采购、发放记录能够准确对应。 |
| “另外两名死亡儿童的同批次空药瓶” | 改为“两名死者的旧药样本”：Giuseppe、Bridget 使用过的旧药与 Harrison 样本含有相似的稳定特征成分，但无法确认完整配方、生产批次及当年的成分状态 | 五年前的废弃样本无法可靠检测原始异常，也不能与 Harrison 留样强行设为同一批次；它们的主要作用是让两个编号获得死亡意义并启动调档。 |
| 旧药样本与死亡对照表同时作为第二轮玩家选项 | 第二轮只选择“五年七例儿童死亡病例对照表”；击破后由 Zack 自动出示两瓶旧药样本 | 保留旧药样本的剧情价值，同时避免它与对照表争夺同一轮的决定性证物功能。 |
| 采购记录只证明某一批药进入医院项目 | 调整为“圣心医院慈善项目采购与发放记录”：精确连接 Isabel 病历发放号、Rosa 回收药瓶和 Harrison 官方冷藏留样，确认三者属于同一采购记录下的同一生产批次和同一配方，并经过正式采购、入库和项目发放 | 让医院冷藏留样成为 Isabel 药剂的同批保存条件对照；不把另外六名儿童强行锁成同一配方或同一批次。 |
| 没有进入医院病历的正式凭证 | 新增“验尸官办公室有限调档许可” | 两个编号被确认属于死者后，玩家能够立即取得继续调查另外五个编号的合法路径。 |

## 二、场景调整

| 调整前 | 调整后 | 为什么调整 |
|---|---|---|
| 取得 Foster 许可后才解锁整个医院调查地点 | 圣心医院社会服务部始终可以自由进入；许可只解锁调档员的“提交七个编号”特殊对话 | 不封锁环境探索，让玩家可以提前认识社会服务部和 Miller 项目的公开形象。 |
| Miller 基金病房同时承担慈善成果展示和死亡档案调查 | 调整为“圣心医院社会服务部／Miller 项目登记区”，保留基金铭牌、康复名册、救助统计与感谢信 | 让慈善成果展示和行政登记自然共存，完整病历仍由中央病案室管理。 |
| 调档员只在档案演出开始时出现 | 调档员始终在场，基础对话说明社会服务部职能和病历权限；取得许可后新增特殊调档对话 | 同一 NPC 自然承担场景介绍、权限限制和后续调档功能。 |
| 玩家进入后必须等待调档，并调查指定数量的环境点才能推进 | 环境调查始终自由且不设置数量门槛；玩家取得许可后可自行决定何时找调档员启动演出 | 避免把环境调查变成强制等待任务，让探索顺序由玩家决定。 |
| 玩家自行完成档案检索和排列玩法 | 中央病案室调档员推来档案车，按照 Harrison 纸条顺序依次展开七份病例 | 避免与其他档案玩法重复，同时保留儿童身份、项目关联和重复症状逐层出现的节奏。 |
| 调档员或其他 NPC 直接概括七份病例的共同点 | 调档员只核对编号、翻页和摆放；Emma 在最后只读出 Isabel 的名字 | 不让 NPC 替玩家完成推理，保留最后一份病例的情感击中。 |
| 七例儿童死亡对照表在医院调查前已经存在 | 七份病例展示完成后，Harrison 编号纸才更新为“五年七例儿童死亡病例对照表” | 明确对照表是玩家完成调档后的成果，不是医院或 Harrison 预先交出的答案。 |
| Whitfield 的自由探索对话包含 Rosa 在场 | 普通对话只有 Zack、Emma 与 Whitfield 在场；Rosa 在正式听证／指证阶段才回到现场 | 避免自由探索提前演完签字冲突，也让 Whitfield 的院方口径先成为可调查的陈述。 |

## 三、谎言与指证调整

| 轮次 | 调整前 | 调整后 | 为什么调整 |
|---|---|---|---|
| 第一轮 | 主要用红线注射器和十三日药盒反驳 Rosa 加量 | 谎言保持“Rosa 擅自增加药量”；玩家出示经容量分析的回收药瓶，注射器和药盒作为剧情辅助证物 | 注射器只能证明规定操作方式，实际药量消耗才足以证明不存在第十四针。 |
| 第二轮 | “Isabel 只是孤立事故”，以七例死亡和同批次药瓶共同击破 | 玩家只出示“五年七例儿童死亡病例对照表”；击破后 Zack 自动展示两名死者的旧药样本，引导药剂相似性话题 | 修正跨越五年却属于同一批次的问题，并让决定性证物与辅助证物各自承担清晰功能。 |
| 第三轮 | 药剂可能由护士私领或家庭转手，未进入正式项目 | 改为药剂离院后由贫困家庭自行保存，相似异常可能由院外变质造成；院方可借家庭环境材料影响法庭和舆论 | 七名死者已确定由 Miller 项目经手，继续否认正式关系过于勉强；保存不当是更合理、也更能体现制度性偏见的退守。 |
| 第三轮证物 | 问题药剂加普通采购记录 | 改为医院官方冷藏留样加慈善项目采购与发放记录 | 记录将 Isabel 药瓶与医院留样锁定为同一采购记录、同一生产批次和同一配方；同批留样在医院规范冷藏下仍有风险，直接排除 Rosa 家庭保存造成异常。 |

## 四、调整后的三轮证明边界

| 轮次 | 决定性证物 | 剧情辅助证物 | 本轮只证明 |
|---|---|---|---|
| 第一轮 | 经容量分析的 Rosa 回收药瓶 | 红线注射器、十三日药盒 | Rosa 没有使用第十四次完整剂量。 |
| 第二轮 | 五年七例儿童死亡病例对照表 | Giuseppe、Bridget 的两瓶旧药样本 | Isabel 不是 Whitfield 慈善项目中的孤立死亡。 |
| 第三轮 | 医院官方冷藏留样、慈善项目采购与发放记录 | Isabel 病历、Rosa 回收药瓶的发放号与批次对应 | 家庭保存不能解释同批官方留样中的风险；该批药由项目正式发给 Isabel。 |

## 五、调整后仍需保留的悬念

- 不确认问题配方的最终批准人。
- 不确认另外六名死亡儿童是否使用了与 Isabel 完全相同的配方或生产批次。
- 不确认 Whitfield 从何时开始知道药剂具有致死风险。
- 不确认七名儿童的死亡是否出于故意。
- 不确认 Miller 上层是否直接下达继续发放或掩盖事故的命令。
- 不确认 Harrison 的死亡是否由这项调查直接引发。
