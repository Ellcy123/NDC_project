# SC4014 法院预审走廊 · 下午

## 场景信息
- 类型：对话 + Whitfield 指证
- 内部英文名：`u4_exp_pretrial_hall_afternoon`
- 所属 Loop：L2

## 画面与交互

庭审前的拥挤走廊。法庭门、记者区和医院人员区形成公开压力。

| 交互点 | 内容 |
|---|---|
| Whitfield 手中的签字夹板 | 预留 Rosa 签名位的「家属误用说明」；演出物，不进入背包 |
| 法庭固定线路区 | 有线麦克风、录音设备与电讯接线；支撑记者传播 |
| 法庭门口 | 指证入口与书记员送达回执位置 |

## 人物与状态
- 自由探索状态：只摆放 Zack、Emma 与 Whitfield；Whitfield 在签字夹板旁保持制度化平静，Rosa 与 Mickey 均不入场。
- 正式听证／指证状态：Rosa 与 Mickey 加入，Rosa 面向法庭门，签字夹板转为指证演出物。
- 记者、医院人员和书记员分层站位，Emma 能联系并调动其中一部分记者。

## 运行阶段与衔接
1. 自由探索：Zack 与 Emma 单独询问 Whitfield 的院方口径，不提前演出要求 Rosa 签字的正面冲突。
2. 指证前：进入正式听证演出后，Rosa 与 Mickey 入场；Whitfield 持签字夹板施压，Rosa 在法庭门外等待。
3. 三轮指证：场面保持公开，记者与书记员在场，防止Whitfield把结果改写成私下误会。
4. 指证后：书记员送达暂停追究结果，Mickey托住Rosa递来的Isabel相框；这份帮助必须真实落地。
5. 散庭转弯：人群逐渐散去，Morrison带着密封通知袋在走廊拐角出现，留下“以后私下谈”的口子；此时才把L2交给L3。

玩家控制只在指证及结果演出完成后恢复；不得把Morrison提前放入指证画面。
