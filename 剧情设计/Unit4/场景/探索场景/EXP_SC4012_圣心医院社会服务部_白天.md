# SC4012 圣心医院社会服务部／Miller 项目登记区 · 白天

## 场景信息
- 类型：环境调查 + NPC 对话 + 条件演出
- 内部英文名：`u4_exp_hospital_social_service_day`
- 所属 Loop：L2
- 开放规则：场景、环境调查和调档员基础对话始终开放；4218 只解锁“提交七个编号”特殊对话。

## 画面与交互

圣心医院社会服务部兼 Miller 慈善项目登记区。这里负责救助登记、家庭联络和项目资料管理，完整病历仍由中央病案室保管。空间应同时呈现真实慈善成果与严格的行政权限，不能画成秘密档案室。

| 交互点 | 内容 |
|---|---|
| 社会服务登记柜台 | 调档员常驻；基础对话说明部门职能和病历权限，不要求玩家先取得许可 |
| Miller 项目展示墙 | 构成 4216「Miller事故基金项目铭牌与康复名册」；包含基金铭牌、康复名册、历年救助统计与家属感谢信 |
| 中央病案室传递门 | 只表现文件由其他部门送达，不允许玩家直接进入或自行翻找完整病历 |
| 七份病例档案车 | 取得 4218 后，由玩家选择“提交七个编号”才出现；调档员按 4117 顺序逐份摆放，完成后生成 4219 |

## 常态画面
- 白天始终开放，调档员、办事家属和医院文员正常活动。
- 调档员基础对话与全部环境调查点无门槛，不设置强制等待或调查数量要求。
- 基础画面不得提前出现七份死亡病例、儿童死亡名单、问题药剂或暗示医院故意藏匿的机关。

## 调档演出层
- 玩家持有 4218 并主动提交 4117 后，中央病案室传递门打开，文员推入一辆木质档案车。
- 七份病例按 Harrison 编号纸原顺序依次展开；调档员只核对编号、翻页和摆放，不做共同点总结。
- 七份档案严格依次对应：`SH-24-071 / Giuseppe Rosselli`、`SH-24-118 / Bridget O'Shea`、`SH-25-044 / Michael Donovan`、`SH-26-093 / Robert Carter`、`SH-27-031 / Stanley Nowak`、`SH-27-126 / Concetta Morelli`、`SH-28-052 / Isabel Martinez`。前两份确认儿童身份，第三至第六份逐步形成项目、症状和家属归责的重复，最后一份才揭示 Isabel。
- 最后一份摆定后留出情绪停顿，Emma 只读出 Isabel 的名字，画面再进入 4219 完成态。

## 美术重点
- 深色木质登记柜台、纸质表格架、传递窗口、分类抽屉和带轮木质档案车，符合 1928 年医院行政空间。
- 展示墙中的康复记录数量要明显多于七例死亡病例，强调项目真实帮助过许多人。
- 档案车是条件演出资产，不得常驻基础背景；七份病例必须在画面中清楚可数。
- 病例姓名、症状、项目经手和院方归责只在 4219 证物特写中可读；场景底图不表现药剂名称、配方、剂量或生产批次。
- 场景气氛克制明亮，不做恐怖医院、阴谋密室或刻意反派化处理。
