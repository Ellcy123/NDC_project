# SC4012 圣心医院社会服务部／Miller 项目登记区 · 白天

## 场景信息
- 类型：环境调查 + NPC 对话 + 条件演出
- 内部英文名：`u4_exp_hospital_social_service_day`
- 所属 Loop：L2
- 开放规则：场景、环境调查和调档员基础对话始终开放；4218 只解锁“提交七个编号”特殊对话。

## 画面与交互

圣心医院社会服务部兼 Miller 慈善项目登记区。这里负责救助登记、家庭联络和项目资料管理，完整病历仍由中央病案室保管。空间应同时呈现真实慈善成果与严格的行政权限，不能画成秘密档案室。

| 交互点 | 内容 |
|---|---|
| 社会服务登记柜台 | 调档员常驻；基础对话说明部门职能和病历权限，不要求玩家先取得许可 |
| Miller 项目展示墙 | 构成 4216「Miller事故基金项目铭牌与康复名册」；包含基金铭牌、康复名册、历年救助统计与家属感谢信 |
| 等候区域 | Zack 与 Emma 等候调档员返回；是否配置座椅可按最终场景空间决定，不强制站姿或坐姿 |
| 七份病例档案车 | 取得 4218 后，由玩家选择“提交七个编号”才出现；调档员离开柜台查找慈善项目归档，随后亲自推回档案车 |

## 常态画面
- 白天始终开放，调档员、办事家属和医院文员正常活动。
- 调档员基础对话与全部环境调查点无门槛；提交七个编号后进入约十分钟的等候过场，不要求玩家完成额外调查。
- 基础画面不得提前出现七份死亡病例、儿童死亡名单、问题药剂或暗示医院故意藏匿的机关。

## 调档演出层
- 玩家持有 4218 并主动提交 4117 后，调档员离开柜台查找慈善项目归档；约十分钟后，他亲自推着木质档案车返回。
- 调档员先依次翻开前两份和第三份档案。察觉异常后，他试图撤回档案，Zack抢先拿到剩余材料并直接翻到 Isabel 的记录。
- 七份档案仍按 Harrison 编号纸原顺序放在档案车上并清楚可数，但只要求第一、第二、第三份与 Isabel 页面进入文书特写，不逐份展示第四至第六份。
- 演出顺序为“前两份 → 第三份 → 调档员撤回 → Zack取得剩余档案 → Isabel”；随后生成 4219。

## 美术重点
- 深色木质登记柜台、纸质表格架、分类抽屉、可灵活配置的等候区域和带轮木质档案车，符合 1928 年医院行政空间。
- 展示墙中的康复记录数量要明显多于七例死亡病例，强调项目真实帮助过许多人。
- 档案车是条件演出资产，不得常驻基础背景；七份病例必须在画面中清楚可数。
- 病例姓名、症状、项目经手和院方归责只在 4219 证物特写中可读；场景底图不表现药剂名称、配方、剂量或生产批次。
- 场景气氛克制明亮，不做恐怖医院、阴谋密室或刻意反派化处理。
