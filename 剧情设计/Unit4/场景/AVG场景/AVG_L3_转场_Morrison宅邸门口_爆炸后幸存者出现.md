# AVG L3 转场 · Morrison 宅邸门口爆炸后幸存者出现

## 场景信息
- 对应台本：`L3_event_mansion_exterior_escape`
- 对应地点：Morrison 宅邸门口，爆炸刚刚发生
- 时段：深夜
- 内部英文名：`u4_l3_bridge_morrison_survivors_after_blast`
- 资源形态：固定 AVG 演出
- 后续衔接：SC4023 爆炸后回收区／幸存者问询

## 演出顺序

1. 镜头从宅邸厨房检修区切到暂时无人的宅邸门口。
2. Zack 在室内喊 Emma 趴下；悬浮动态漫画格表现火光随即从宅邸门窗内迸出。
3. 爆炸稍歇后，Zack 与 Emma 从门内跌撞冲出；两人衣服沾灰，被浓烟呛得不断咳嗽。
4. 两人在门口呼喊 Mickey 与 Doris，短时间内没有得到回应。
5. Zack 准备返回火场，Emma发现烟尘中出现人影并阻止他。
6. Mickey 扶着几乎无法独自行走的 Doris 从火光与浓烟中出现。
7. 本段 AVG 结束，随后进入 SC4023 爆炸后回收区的幸存者问询。

## 人物与画面状态

- Zack、Emma 先进入画面；二人均有烟灰、咳嗽和短暂失衡状态。
- Mickey、Doris 后进入画面。Mickey 扶住 Doris，Doris 此时无法独立稳定行走。
- Mickey 与 Doris 使用常规 AVG 立绘进场，不追加动态漫画格。
- 宅邸内部仍有火光与浓烟，主体画面保持在门口与残存门廊区域。

## 画面边界

- 本段使用爆炸后宅邸门口的即时灾难状态，但不承担后续自由探索。
- 本段不出现 Pierce 拔枪、防风帘落下、夺枪或 Mickey 枪位翻供；这些属于 Doris 指证后的后续 AVG。
- 正式警戒线和临时询问区在下一阶段 SC4023 建立，不要求在爆炸瞬间完整出现；后续不设置折叠椅，Doris 保持站立。
- 不展示宅邸内部尸体，也不恢复可供复核的右手枪位现场。

## 美术重点

- 提供爆炸火光、门窗涌烟、门口灰尘和人物沾灰状态。
- 门廊防风帘在本段保持爆炸后的静止状态，不播放快速落下或侧拉演出。
- Mickey 扶持 Doris 的双人站位必须清楚，保证后续幸存者问询能够自然承接。
- 本段只表现刚刚逃出火场的即时状态。进入下一阶段 SC4023 前经过短暂安置：Mickey 将自己的外套披到 Doris 肩上，Doris 已能站立，Mickey 站在她身旁。
