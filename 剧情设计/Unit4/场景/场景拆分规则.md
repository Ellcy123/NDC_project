# Unit4 场景拆分规则

## 核心口径

- 以实际美术底图和玩家交互空间为拆分单位，不照抄 state 的粗粒度地点名。
- 同一地点出现白天、夜晚且光照、人物、权限或证据状态有实质变化时，分别建立场景文件。
- 探索场景使用 `EXP_SC{sceneId}_{地点}_{时段}.md`；纯剧情画面使用 `AVG_L{loop}_{位置}_{用途}.md`。
- AVG 人物、构图和背景为一体；探索场景的 NPC、证据和可点击物件独立挂载。
- 突发事件不单独冒充探索场景；在承载场景中写清触发前后状态和所需演出。

## 空间拆分

- Morrison 宅邸在运行层正式拆为 `SC4027` 门厅客厅枢纽、`SC4022` 书房与 `SC4028` 厨房检修区三张底图。
- `SC4033 O'Hara 家` 的后巷井检口在院墙外，无法与室内共用底图，单独拆为 `SC4035` 短 AVG 建立镜头。
- `SC4027`、`SC4028`、`SC4029`、`SC4035` 已写回 state；落表时必须保持《场景运行映射建议》中的入口、返回与门控，不得再压回单一 `SC4022`。

## 昼夜状态

- 白天：清晨后至下午；以自然光、正常营业和公开访问为主。
- 夜晚：傍晚后至黎明前；以低瓦数灯、封闭权限和夜班状态为主。
- 黎明危机是独立画面，不复用白天平静状态：`SC4045` 与 L4 的 O'Hara 家门口分开。
- Zack 事务所白天与深夜来电分开：L2/L4 使用白天状态，L3 使用夜晚 AVG 状态。

## 关键物证载体

每件场景调查物必须写出可见载体，例如：

- 档案 → 档案柜、调阅格、台账架。
- 私人凭据 → 费用抽屉、写字台暗格。
- 废稿 → 打字机旁废纸篮。
- 封存样本 → 带编号的证物架或留存柜。
- 寄存材料 → 有号码的寄存柜与钥匙孔。

证据不得无载体悬浮在画面中；对话交付的物件也要有可见摆放位置。
