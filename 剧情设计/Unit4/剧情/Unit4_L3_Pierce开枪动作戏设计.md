# Unit4 L3 Pierce开枪动作戏设计

## 一、文档目的

本文用于确定 Unit4 Loop3 指证 Doris 后，Pierce 试图向 Zack 开枪、Zack 与 Emma 通过物理行动阻止射击，随后冲突被迫回到左手／右手枪位证词与事实判断的剧情设计。

动作戏不用于证明 Zack 或 Emma 武力更强，而是完成一次冲突换轨：Pierce 先用暴力解决问题；暴力路径被封死后，他把尚未处理的枪位问题抛给 Mickey，借此考验 Mickey，并要求他迅速提供一个能够维持现有结案口径的答案。

## 二、为什么这里需要动作戏

### 0. 评审结论：保留短促的物理冲突

本提案已确认保留“Pierce 拔枪—Zack 与 Emma 物理阻止—Pierce 转向 Mickey”的核心结构，但不扩张为大型动作场面。它先让玩家亲手阻止不公正的暴力，以为事情已回到公平讨论；再由 Mickey 利用证词冲突推翻这次胜利。若删去物理冲突，Mickey 的选择容易退化成普通串供，背叛感会明显减弱。

### 1. 剧情需要：Pierce 会先选择暴力手段解决问题

Pierce 既与 TideWater 有关，又掌握正式执法权。当 Zack 拒绝把记录和证物交给他无记录扣押时，他会先以“接管证物、制止妨碍执法”为名拔枪，试图迅速消除继续追查 Harold 死亡的阻力。这不是受辱后的街头暴怒，而是一次主动选择的最短路径；Pierce 最危险的地方，正是能够把灭口意图包装成合法执法处置。

### 2. 氛围需要：与 U1、U2、U3 的警察指证区分

前几个 Unit 已多次使用警察询问、身份施压、封锁现场和证物争论。本场若仍停留在站立交谈，体验上会重复。L3 应让制度威胁短暂转化为直接的身体危险，再回到证词与结案程序。动作与讨论形成的反差，既能区分此前的警察指证，也让玩家明白后续并非文明协商，而是 Pierce 在暴力失败后更换的第二种控制手段。

### 3. 刺激性需要：让玩家感受到 Pierce／TideWater 的威胁

实际拔枪使 TideWater 的威胁第一次通过高阶警察直接落到 Zack 与 Emma 身上，也为 L5 铺垫情感：L3 中，Mickey 主动站到这套暴力与程序结合的体系一边；L5 时，他才发现自己长期维护的体系同样能清理失去价值的人。该铺垫用于帮助玩家理解其坠楼时的绝望，但不为既往行为开脱，也不改变他主动松手的结局。

## 三、动作戏及动作戏后的剧情效果

动作戏首先要让玩家获得真实胜利感：Zack 与 Emma 阻止射击、卸下武器，迫使冲突回到证词与事实。短暂停顿应让玩家相信公平已经恢复。随后 Pierce 转向看似能提供第三方核验的 Mickey；Mickey 却回答“左手”，并利用现场已毁与陈述冲突削弱 Zack 的记录。玩家这才发现 Mickey 站在 Pierce 一边，刚建立的安全感被第二次击穿。

情绪顺序固定为：Pierce 拔枪制造生命威胁 → Zack 与 Emma 协作取胜 → 玩家相信正规讨论恢复 → Pierce 转向 Mickey → Mickey 给出“左手”陈述 → 天平重新倒向 Pierce，Harold 仍按自杀处理。

## 四、完整动作节拍

### 1. Pierce 试图接管材料

Doris 指证结束后，Zack 要求将自己看见的“尸体右手位置存在枪支”写入记录，并拒绝把现场笔记或证物交给 Pierce 无记录扣押。Pierce 不讨论内容真假，抓住 Zack 的肩包背带或记录本，将他逼退到门柱附近；Zack 扣住不放，只接受正式登记与交接。短暂拉扯既把绳扣带入 Zack 的可触范围，也为 Pierce 制造“拒绝移交、妨碍接管”的表面口径。

### 2. Pierce 拔枪

夺取失败后，Pierce 后退半步拔出左轮，以“妨碍现场接管、拒绝移交证物”为行动口径。枪口从 Zack 腰腹位置升向胸线，手指进入扳机护圈。他不咆哮，也不发表反派宣言，仍用警察命令要求 Zack 松手。这一动作必须明确越过普通警告，使玩家看出 Pierce 正准备把主动杀伤包装成执法处置。

### 3. Zack 释放防风帘，Emma 延续效果

Pierce 抬枪时，镜头保持 Zack 的行动视角并聚焦身旁绳扣。玩家控制 Zack 拉开绳扣，释放门廊上方的卷轴；配重下沿撞偏 Pierce 的前臂，将枪口带向石阶。Emma 随即抓住垂落的厚质防风帘向侧面拉紧，防止回弹并妨碍其肘部伸展。

### 4. 枪声响起

Pierce 在枪线被撞偏的瞬间扣动扳机，子弹打进门廊石阶或台阶前的泥地，没有命中人物。这一枪证明他不只是在威吓，也使外围人员因枪声转向现场，封死继续秘密使用暴力的空间。演出不强调弹道细节，只保留枪声、弹着点与人物一瞬间的失衡；玩家应明确意识到，若 Emma 慢一步，Zack 已经中枪。

### 5. Zack 近身控枪并卸弹

Zack 趁枪口偏离贴近，用肩膀压住 Pierce 的肘部，将其持枪手腕抵在石柱或扶栏边缘。Emma 继续拉紧垂落布面，妨碍 Pierce 的上臂活动。Zack 夺下左轮、打开转轮，将枪与子弹分开放在石阶上，但绝不把枪口反转指向 Pierce。他可以擦伤手掌、撞伤肩膀或短暂失衡，避免动作显得轻松和英雄化。

### 6. Zack 与 Emma 主动停止冲突

枪弹分离后，Zack 立即放开 Pierce，与 Emma 一同后退并亮出空手。两人不逃跑、不继续压制，也不以夺来的枪反向威胁。现场必须留出一拍安静，让玩家确认自己已经阻止暴力。外围警员、Doris 和 Mickey 此时都注意到枪声；Pierce 仍握有职位和命令权，却暂时失去再次开枪的物理条件与即时自卫口径。

## 五、从动作戏转入 Mickey 的证词处理

### 1. Pierce 把问题交给 Mickey

Pierce 熟悉命令、封锁、扣押和结案，却不擅长迅速处理证词冲突与证据资格。枪被卸下后，Zack 提出的右手枪位仍未解决，继续拖延还会放大刚才开枪的风险。因此 Pierce 不亲自展开证据辩论，而把问题直接抛给 Mickey，要求他用最快速度提供可执行的出口。这不是恢复理性，而是在第一种手段失败后立即调用更合适的人。

### 2. Pierce 对 Mickey 的考验

Pierce 只问：“你也进过书房。你第一次看到尸体时，枪在哪只手？”他不暗示完整答案，而是同时考验 Mickey 的能力与站位：Mickey 是否能立刻理解权力需要什么说法，又是否愿意当着 Zack、Emma 和 Doris 承担它。这个提问表面上像接受第三方核验，因此也暂时稳住玩家的公平预期；回答“左手”，才证明 Mickey 主动替现有结论制造支点。

### 3. Mickey 提供最快的解决方案

Mickey 回答枪在 Harold 左手，并迅速指出：Zack 记录的是右手，自己的陈述是左手，而原始书房已被爆炸摧毁，无法复核。两份现场陈述相互冲突，不能仅凭 Zack 的私人记录改变死亡定性。Mickey 不展开长篇法庭辩论，也不直接承认自己在帮 Pierce；他只提供一个足够让 Pierce 继续执行、同时听起来符合正规核验程序的处理口径。

### 4. Pierce 采纳并执行

Pierce 无需复述全部逻辑，只将 Mickey 的说法转换成行政命令：现场记录冲突、原现场无法复核，不启动他杀调查，继续按自杀处理。由此形成分工——Pierce 负责暴力、权力和最终命令；Mickey 负责识别证词弱点并生成最快方案。玩家虽然赢下动作冲突，却在刚恢复的正规渠道里再次失败，Mickey 的真实站位也由此完成第一次明确揭示。

## 六、动作戏的核心原则

- Pierce 必须真正准备杀伤 Zack，不能只作空洞威吓。
- 建议实际击发一枪，但枪口被带向石阶或泥地，不命中人物。
- QTE 的关键观察与输入属于 Zack；Emma 只在成功后拉紧防风帘扩大优势，不使用记者身份，也不突然成为格斗专家。
- Zack 的控腕、夺枪与卸弹必须短促、狼狈，并付出轻微身体代价。
- 两人只阻止本次射击，不持枪反威胁，也不继续殴打 Pierce。
- 动作戏只赢下生存；Pierce 仍借 Mickey 的说法维持自杀结案。

## 七、场景物件、道具与前置铺垫

### 1. 门廊物件关系

正式新增不可收集的环境互动“门廊卷收式厚质防风帘”。它安装在 Morrison 宅门廊外沿：卷轴固定于横梁，带配重的下沿连接控制绳，绳索收在门柱铜质绳扣上。防风帘在爆炸前已经出现，爆炸后虽有烟尘和轻度破损仍可使用；门廊石柱、扶栏和石阶为 Zack 控腕提供借力点。Pierce 的配枪为可侧开转轮的警用左轮，人物站位必须让配重下沿能够撞到其持枪前臂。

材质不锁死为帆布。剧情与 QTE 只要求：

- 布面厚实，能够卷收；
- 下沿带木杆或金属配重；
- Emma 拉紧后能够妨碍 Pierce 伸展手臂；
- 爆炸后没有完全撕裂。

可选材质范例：厚帆布、厚棉布或其他适合户外卷收的厚质织物。

### 2. 防风帘的环境交互铺垫

4029 宅邸门口开篇偶遇 Mickey 时，镜头展示卷收状态，并让控制绳与外侧门柱绳扣清楚入画，但不提供调查交互，也不提前提示动作解法。爆炸后 Doris 指证与 Pierce 冲突仍发生在同一门口；动作发生时，玩家与 Zack 同时认出开篇见过的绳扣，产生回收感。绳扣不放入 4027 室内门厅，也不进入 CASE BOARD。

### 3. 防风帘 QTE 正式要求

Pierce 抬枪时，玩家继续代入 Zack，以一次短促的持续按住输入拉开身旁绳扣、释放卷帘；Emma 在成功后抓紧垂落的防风帘，随后转入 Zack 控腕卸弹的固定演出。第一次未及时输入时短暂放缓并扩大提示窗口；再次未完成则辅助完成，不设置 Zack 死亡分支。提供自动完成动作输入的无障碍选项。

### 4. 道具与场景美术需求

- 防风帘提供卷收固定、快速落下、Emma 侧拉绷紧三个状态。
- 爆炸前后复用同一门廊结构；爆炸后布面可有烟尘和轻度破损，但卷轴、绳索与配重仍能工作。
- 提供 Pierce 左轮、枪弹分离状态与石阶弹着痕；均为演出物，不进入正式证物栏。
- 门柱、扶栏或石阶需要支持 Zack 短暂控腕的动作构图。

## 八、演出与信息边界

- 动作段控制在二十至三十秒，不抢走 Doris 指证的重心。
- 枪声后短暂停顿，让玩家看清枪弹分离、双方退开和目击者靠近。
- 本场只确认 Pierce 愿意开枪，不确认他参与 Harold 枪杀或安装爆炸装置。
- Mickey 的“左手”必须表面可信，不能像收到 Pierce 明示后的机械撒谎。
- Pierce 不长篇分析证据；复杂逻辑由 Mickey 提供，他只负责采纳执行。
- 防风帘的配重下沿只撞偏手臂，布面只妨碍动作，不能表现为防弹。

## 九、证物与后续使用建议

本场不新增正式证物。防风帘、泥地弹坑、石阶崩痕和左轮中的击发弹壳均作为环境或演出事实保留；若后续 Loop 不使用，就不为本段增加游离证据。
