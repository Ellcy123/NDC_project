# 最终凶手选择｜简版

2026-09-18 · 策划初稿，待制作。[详细版](最终凶手选择.md)

适用于 U1—U5 各章最后一轮。玩家完成搜证和疑点后，选择自己认定的凶手。选对后逐轮出示证物、击破谎言，再进入真相与结尾；选错后只推进对抗对白，结束后返回选人。前面各轮继续使用现有证物指证玩法。

## 玩家怎么玩

**完成调查 → 选择凶手 → 确认指认 → 播放对应剧情。**

候选人以姓名和头像展示。点击人物卡选中，再点击“确认指认”提交；提交前可以更换人选。

选对后，嫌疑人辩护、退守，玩家逐轮选择并提交证物，Zack 随之追问，故事走向真相和结尾。

选对和选错都进入现有指证的上下分屏界面，沿用人物展示和对白推进交互。错误路线全程只有对白推进。选错时也先正常展开对抗，随着嫌疑人的回答和 Zack 的追问，玩家逐渐发现自己指错了人。对白收住后，再显示结果提示。

## 选错怎么回来

U1 采用以下流程，其他章节的错误剧情与返回安排在各章方案中确定。

**错误路线对白结束 → 画面淡出 → 显示结果与返回按钮 → 玩家点击 → 重新选人。**

| 界面内容 | 文案 |
|---|---|
| 结果提示 | 这次指控未能成立 |
| 按钮 | 返回指认前 |
| 辅助说明 | 保留调查成果，无需重新搜证 |

提示和按钮放在同一个界面。返回后，材料与疑点进度保留，场景和剧情恢复到指认前，人物选择清空，由玩家重新决定。

![错误返回四分示意](最终凶手选择_交互示意.png)

## 程序需要做什么

- 选人界面：展示候选人、选中状态和确认按钮。
- 剧情分流：根据所选人物进入对应对白。
- 对抗表现：两类路线都使用现有指证上下分屏界面；正确路线保留道具指证，错误路线只推进对白。
- 失败返回：显示反馈，恢复指认前状态，保留调查成果。
- 存读档：继续上次的选人或剧情进度；错误路线读档后仍能返回。
- 章节配置：各章分别填写候选人、正确答案、剧情入口和结束去向。

## 内容怎么配合

选人前，玩家应已拿到足够的判断依据。选人后，对白负责展现嫌疑人的反应、犯罪经过和动机。可选线索按玩家实际取得情况补充对应内容。

U1 先做 Tommy、James 两条路线；U2—U5 的人物和剧情后续分别设计。关闭选人界面后能否返回调查，留界面方案确定。
