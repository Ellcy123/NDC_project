# NDC 五章节外围玩法详细规则

> 文档状态：当前系统规则；待逐章绑定主线谜题  
> 适用范围：Unit1—Unit5 章节外围玩法的策划、叙事、谜题和程序前期对齐  
> 本文定义共通规则，不分配 ID，不编写配置字段，也不将未通过现行大纲审查的候选写成 Canon。  
> 章节案件事实以 `canon_manifest.json` 指向的现行大纲为准；案件物品与证词仍遵守现有搜证、物品、对话和证词系统。

## 一、设计目标

章节外围玩法的首要目标，是让玩家通过动作进入 1928 年的生活，而不是把案件调查换一层小游戏皮肤。

玩家应当因为以下原因主动靠近玩法：

- 想试一杯酒会调成什么样。
- 想看看下一局赌博会不会失控。
- 想观察降神会里的人会作出什么反应。
- 想赌一件看不清来路的拍品。
- 想知道一批矿物颜料干燥后会变成什么颜色。

案件意义只在玩家已经接受这项活动之后出现。理想体验是：

> 玩家先把它当成生活，随后才发现生活中的某个异常属于案件。

因此，外围玩法不是案件的附庸，也不是完全与案件无关的休息区。它统一采用“一个确定的主线接触层 + 大量自由的支线深入层”结构。

## 二、系统核心结构

每个章节只能建立一份“外围玩法主线谜题合同”。

```text
章节场景探索
└─ 发现外围玩法入口
   ├─ 主线接触层
   │  ├─ 短
   │  ├─ 规则清楚
   │  ├─ 确定出现一个主线异常
   │  └─ 不受随机、技巧或失败阻断
   │
   └─ 支线深入层
      ├─ 材料与做法变化
      ├─ 有边界的不确定结果
      ├─ 人物支线与后续回响
      └─ 收藏、陈设、配方和纪念结果
```

两层的关系不是“先做任务，再解锁小游戏”。

主线接触层应尽量使用深入层本来就会使用的动作。玩家完成一次自然的调配、下注、仪式、竞拍或作画，在这个过程中碰到异常；主线接触结束后，玩家可以立刻离开，也可以沿用刚学会的动作继续深入。

### 2.1 主线层的确定性

“确定性”指：

- 相关异常由设计预先指定，不从随机结果池抽取。
- 玩家操作好坏可以改变过程反馈，但不能改变异常是否出现。
- 玩家不会因为材料用错、赌博连败、竞价失败或作画效果不好而丢失主线。
- 如果玩家可以拒绝首次邀请，相关主线检查点之前必须再次提供同一语境内的进入或兜底。
- 兜底只保证同一个谜题出现，不能另造一个完全不同的替代谜题。
- 主线异常只出现一次；重复玩法不会反复生成案件材料。

### 2.2 支线层的自由度

除主线合同明确指定的异常及必要案件材料外，以下内容统一视为支线：

- 配方和材料组合。
- 赌博输赢与额外收益。
- 降神会中不同参与者的反应。
- 拍品收藏、错失和价格结果。
- 画作颜色、纹理、命名和陈列。
- NPC 的即时评价。
- 人物小故事。
- 后续 Loop 的回忆和重新理解。
- 章节纪念物、收藏与陈设变化。

这些内容可以错过、变化或不触发，但不能改变案件结论，也不能成为第二条隐蔽的主线取证路线。

## 三、完整玩家流程

### 3.1 发现入口

玩家在正常场景探索中看见一个符合场所逻辑的玩法设施，例如吧台、赌桌、仪式桌、当铺后场入口或研磨台。

入口不以系统弹窗直接发布“完成小游戏”的任务。NPC 可以介绍、示范或提供服务，但不应像功能菜单管理员一样把玩法解释成奖励任务。

### 3.2 获取基础供给

承载场景必须提供完成第一次体验所需的基础工具和基础材料。

玩家还可以在其他可探索区域找到外围材料，用于扩大结果范围。例如：

- 蓝月亮的储藏区提供不同酒材或装饰。
- 教堂或附属空间提供公开允许使用的仪式物件。
- 当铺前台或周边场所提供可参与夜场的凭证或旁支拍品信息。
- Miller 庄园走廊提供松散、废弃或经允许取样的矿物性材料。

探索材料应增加玩法可能性，不能成为主线入口的隐蔽硬门槛。

### 3.3 进入短层体验

第一次进入时，只教玩家完成该玩法最核心的一到两个动作，不要求先掌握完整规则。

主线异常在正常动作或正常结算中出现。它不能被放在高分评价、隐藏配方、罕见随机结果或连续胜利之后。

### 3.4 主线意义浮现

异常第一次出现时，应当仍有完整的日常用途。

随后通过 Zack 的观察、与另一件证据的并置、案件分析或后续证词，它才转化成一个明确的主线问题。

这里需要区分：

- 玩法产物：在活动中合理取得的物件或现象。
- 主线谜题：玩家意识到该物件或现象存在异常后产生的问题。
- 必要证据：用于解释、验证或击穿该问题的案件材料。

三者可以有关联，但不能直接写成“小游戏通关奖励一个已经解释完的结论”。

### 3.5 选择离开或继续

主线接触完成后，系统明确给玩家离开的机会。

愿意继续的玩家进入支线深入层，使用更多材料、规则和人物组合。深入层结果不再承担主线职责。

## 四、承载场景规则

### 4.1 场景必须解释玩法为什么存在

玩法必须从本章的地点和人群中生长出来：

- 蓝月亮本来就有吧台、酒材和夜间客人。
- Silver Moon 本来就有赌桌、现金和结算关系。
- Unit3 的教堂语境天然容纳信仰、哀悼、欺骗与“人是否愿意相信”的冲突。
- 当铺或夜场天然容纳匿名交易、看不清来路的物品和竞价欲望。
- Miller 庄园的私人收藏、矿物资源、画廊与服务人员，可以承载上流社会艺术生活及其背后的劳动。

如果一个玩法只能靠外部任务说明为什么出现在这里，说明承载场景尚未成立。

### 4.2 场景可以复用，也可以新增

外围玩法不强制拥有独立房间，可以采用：

- 现有场景内的独立设施。
- 同一背景中的玩法模式。
- 现有场所的附属房间。
- 新增的小型专用空间。

但调查模式与外围玩法模式必须有明确入口和退出反馈，避免玩家误以为外围材料是案件证据。

### 4.3 新增空间的 Canon 边界

以下空间目前属于玩法提案，不自动成为现行案件事实：

- Unit3 降神会使用的具体教堂附属房间。
- Unit4 当铺后场或黑市夜场。
- Unit5 私人画廊与老管家研磨台的具体布局。

这些空间落地前，需要逐章确认开放 Loop、人物在场情况和是否影响现有场景动线。

## 五、场景供给与三类物件

现有物品系统中，可收集物通常会进入 CASE BOARD，而可交互设施不能作为普通库存材料使用。因此外围玩法需要独立的外围库存或等价的独立记录，不能把外围材料硬塞进案件背包。

### 5.1 三类物件

| 类型 | 主要来源 | 保存位置 | 是否可消耗 | 作用 |
|---|---|---|---|---|
| 玩法入口工具 | 承载场景或明确可见的探索点 | 外围玩法记录 | 默认不可消耗 | 开启或维持玩法，例如调酒工具、入场凭证、研磨工具 |
| 玩法扩展材料 | 场景探索、支线结果、深入玩法 | 外围库存 | 可以消耗 | 扩大配方、拍品、仪式或画作结果，不影响主线 |
| 主线桥梁物件／信息 | 主线合同指定的固定时刻 | CASE BOARD 或证词系统 | 不可被外围玩法消耗 | 进入唯一的主线谜题 |

### 5.2 入口工具规则

- 入口工具优先使用软前置。
- 玩家第一次看见玩法时，应当同时知道如何获得基础工具。
- 如果工具属于剧情必需，必须保证取得，不得因早期遗漏而永久关闭玩法。
- 入口工具默认跨本章 Loop 保留。
- 入口工具不能作为失败惩罚被夺走。

### 5.3 扩展材料规则

- 扩展材料只增加支线变化。
- 没找到某种材料，只意味着少一种结果，不影响主线谜题出现。
- 取消操作时不消耗材料。
- 一次性稀有材料不能因失败或界面误操作直接消失。
- 材料在正式提交一次创作、下注或交易后，才按玩法规则消耗。
- 场景关闭前，如果材料仍有后续用途，应迁移到合理位置或保留库存；若决定让其成为可错过支线，必须提前给出清楚提示。

### 5.4 主线桥梁物件规则

- 一旦被识别为案件材料，立刻脱离外围库存。
- 不得继续作为酒材、赌资、仪式物、拍品或颜料使用。
- 不能在重复玩法中再次生成。
- 不能被出售、丢弃或覆盖。
- 如果主线桥梁只是一个观察结果或人物陈述，则应进入对应的案件信息系统，而不是伪装成外围收藏。

### 5.5 视觉与反馈区分

外围材料与案件证据必须使用不同的获取提示、音效和查看入口。

玩家应当立刻明白：

- “获得玩法材料”意味着可以在外围玩法中使用。
- “发现案件材料”意味着它已经进入调查。

## 六、每章唯一的主线谜题合同

每个章节在详细设计前，必须先填写一份主线谜题合同。没有完成合同的玩法，只能继续做支线原型，不能声称已经接入主线。

合同至少回答以下问题：

1. 主线问题是什么？  
   玩家最终会对什么异常产生疑问？

2. 物件或现象原本在玩法里是什么？  
   它在改变意义之前，必须有完整、合理的日常用途。

3. 固定出现时刻是什么？  
   它是在调配、下注、仪式、竞拍、加工还是结算时出现？

4. 玩家如何注意到异常？  
   是编号、材质、来源、人物反应、状态变化还是与另一信息不符？

5. 它如何进入案件系统？  
   需要明确它成为物证、观察线索还是证词。

6. 还需要哪些外部证据才能解释？  
   外围玩法产物不必单独定案，但组合关系必须清楚。

7. 为什么玩家一定能遇到？  
   说明随机保护、失败重试、资金兜底、材料保证和拒绝后的重新进入方式。

8. 安全出现阶段是什么？  
   不能提前泄露后续 Loop 的案件结论。

9. 主线职责在哪里停止？  
   明确取得该异常后，哪些玩法内容全部回归支线。

10. 是否只有这一份合同？  
    同一章不得在深入玩法里再藏第二个必须取得的案件谜题。

### 6.1 自然变义检验

合格的桥梁应满足：

> 第一次看，它在玩法中完全合理；第二次看，它在案件中意义改变。

不合格的情况包括：

- 达到分数后直接弹出“获得证据”。
- NPC 因玩家完成小游戏而无理由交出秘密文件。
- 随机抽到罕见物品才可以继续主线。
- 先写好案件证据，再强行为它补一个小游戏来源。
- 玩家尚未比较或分析，Zack 就直接说出完整结论。

### 6.2 一个谜题不等于一件证据

“每章一个主线谜题”约束的是主线问题和桥梁职责，不强制整条推理只能使用一件证据。

Unit2 的三张中间号钞票、两张端点钞票和 Tony 证词可以共同服务于一个资金流谜题，但不能借此再拆出多个外围玩法主线任务。

## 七、支线叙事规则

外围玩法的主要内容量应当落在支线，而不是主线。

### 7.1 支线层级

| 层级 | 形式 | 作用 | 是否进入案件系统 |
|---|---|---|---|
| 即时反馈 | NPC 对结果的一两句评价、表情或动作 | 让操作有人的回应 | 否 |
| 人物小支线 | 因材料、选择或做法触发的短对话 | 展示生活、边界和关系 | 否 |
| 后续回响 | 后续 Loop 对先前行为的记忆或重新理解 | 形成角色连续性 | 否 |
| 收藏与陈设 | 配方、画作、拍品、纪念物、空间变化 | 记录玩家经历 | 否 |

### 7.2 支线对话边界

- 默认作为普通对话，不自动提取为证词。
- 不解锁主线疑点、指证材料或关键地点。
- 不允许角色提前说出尚未到揭示阶段的事实。
- 不把酒、礼物或高分表现写成“让角色说真话”的按钮。
- 不使用通用好感度替代具体人物反应。
- 同一种操作面对不同角色，应当产生符合其处境的不同反应。

### 7.3 后续回响

回响可以让玩家重新理解角色，但不能在没有主线证据的情况下替玩家下结论。

好的回响是：“原来他当时一直很清醒。”

不好的回响是：“所以他当时就是凶手。”

## 八、有边界的“不受控”

玩家想要的“不受控感”，不是系统真的失控，而是玩家不能精确计算每次结果。

设计上采用“输入可控、结果区间不完全可控、内容池受设计控制”的方式：

- 玩家选择材料、投入、对象和时机。
- 这些选择改变结果倾向，但不保证唯一结果。
- 系统从经过审核的结果池中产生变化。
- 结果可以令人意外，但不能破坏人物事实和案件时序。
- 主线异常完全不进入随机池。

### 8.1 五章的不受控来源

| 章节 | 不受控感来源 | 设计护栏 |
|---|---|---|
| Unit1 调酒 | 比例、酒材状态、客人口味与现场情绪共同改变反馈 | 不以醉酒强迫人物泄密 |
| Unit2 赌博 | 骰子或牌面、对手选择、资金压力 | 主线结算受保护，不能因连败阻断 |
| Unit3 降神会 | 参与者期待、含混动作、互相暗示与临场反应 | 不确认鬼魂真实存在，不用超自然力量提供法证 |
| Unit4 盲拍／当铺夜场 | 看不清拍品全貌、竞争者出价、来路信息不完整 | 主线桥梁不藏在罕见随机拍品中 |
| Unit5 矿物绘画 | 研磨粗细、媒介、颜料混合与隔夜变化 | 主线证据和家族重要藏品不得被研磨或作画 |

### 8.2 不受控不能变成惩罚

- 不确定结果用于制造趣味和人物反馈。
- 它不能永久销毁唯一材料。
- 它不能扣除主线资金或调查权限。
- 它不能要求玩家反复刷到某个随机主线结果。
- 它不能让一次“坏画”或“坏酒”被判定为玩法失败，只能产生不同支线结果。

## 九、进入、退出、失败与存续规则

| 环节 | 共通规则 |
|---|---|
| 进入 | 场景中存在清楚可见的入口；第一次进入提供最短教学 |
| 基础材料 | 承载场景保证一套可完成首次体验的基础供给 |
| 退出 | 教学后和每个完整小段结束后都可离开 |
| 取消 | 提交前退出不消耗材料，也不改变主线状态 |
| 主线失败 | 不存在永久失败；立即重试、动态降低门槛或由同一场景内的合理行为完成兜底 |
| 支线失败 | 只改变评价、反馈或结果，不扣除主线资源 |
| 重试 | 主线短层低成本重试；深入层重复依靠材料、人物和规则变化产生价值 |
| 跨 Loop | 外围工具、库存、收藏和已完成结果默认在本章内保留 |
| 场景关闭 | 主线入口和必要材料必须迁移或提供明确兜底；纯支线内容可在有提示的前提下成为阶段限定 |
| 重复游玩 | 不重复产生主线证据，不建立第二个主线谜题 |
| 跨章节 | 默认不继承；如个别玩法需要回访，必须单独设计，不作为共通规则 |

### 9.1 拒绝与跳过

每章主线谜题必须保证出现，但不要求把完整外围玩法强制完成。

推荐处理：

- 玩家至少完成一段很短的主线接触。
- 主线接触结束后，明确允许退出。
- 如果保留“暂时不玩”选项，应允许稍后返回。
- 如果保留“完全不玩”选项，则同一承载场景必须有符合情境的桥梁兜底；不能从菜单直接发证据。
- 兜底体验仍要保留“物件先合理、之后变义”的过程。

## 十、奖励与资源隔离

### 10.1 主线产出

每章仅允许主线谜题合同指定的异常及其必要案件条目进入主线。

它们不是“小游戏奖励”，而是调查对象。

### 10.2 支线奖励

推荐使用：

- 配方和技法。
- 画作、拍品和纪念物。
- 独立收藏图鉴。
- 承载空间的陈设变化。
- 人物短对话和后续回响。
- 不影响案件的熟客、称呼或气氛变化。
- 独立成就。

### 10.3 禁止交叉

- 外围赌资不得影响案件主钱包。
- 主线证据不得用作赌资、拍品、仪式耗材或颜料。
- 外围材料不得进入 CASE BOARD 分析或合成。
- 深入玩法奖励不得提升指证成功率。
- 支线人物反应不得替代正式证词。
- 收藏完成度不得成为主线通关条件。

## 十一、五章一页式概览

| 章节 | 核心体验 | 承载场景 | 场景供给 | 支线深入 | 主线合同 |
|---|---|---|---|---|---|
| Unit1 | 蓝月亮调酒 | 吧台、储藏区域 | 基础酒材由吧台提供，探索增加酒材与装饰 | 配方、客人反应、人物回响 | 待绑定一个与现行证据链相容的固定异常 |
| Unit2 | 银月赌博 | 赌桌、结算台 | 基础赌资或短局由场景保证 | 额外输赢、Tony 闲聊、熟客反馈 | 已确认：902B—904B 连号钞票资金流 |
| Unit3 | 灵媒降神会 | St.Patrick 教堂语境内或相邻附属空间 | 基础仪式物由主持空间提供，探索增加允许使用的物件 | 信仰、哀悼、怀疑和骗局相关的人物反应 | 待绑定；只能来自人物与物理行为，不能来自真实超自然 |
| Unit4 | 黑市盲拍／当铺夜场 | 当铺后场或夜间拍卖空间，属新增提案 | 入场方式与基础竞拍资源由场景保证 | 拍品收藏、竞价人物、物件来历小故事 | 待绑定；可从来源、交割或支付异常中选择一个方向 |
| Unit5 | 《第五幅画》矿物绘画 | Miller 庄园私人画廊、走廊、老管家研磨台，属新增提案 | 基础粉料由工作台保证，探索矿物增加色彩与质感 | 前四章意象回声、画作变化、命名与陈列 | 待绑定；不得加工现行主线宝石或其他案件证据 |

### 11.1 Unit1 候选约束

可以从配方、容器、酒液状态、结算物或人物对酒的反应中寻找一个自然变义点，但必须经过 Unit1 现行证据链审查后才能确定。

不得默认把“给某人一杯酒”写成换取口供的机制。

### 11.2 Unit3 候选约束

降神会可以利用人的期待、主持人的技巧、桌面物件、座位关系、声音来源或含混表达制造异常。

任何主线落点都必须有现实层面的可解释来源。游戏可以保留人物是否相信的模糊性，但不能确认亡灵替玩家提供了真实案件答案。

正式仪式是否直接发生在教堂内部，仍需逐章确认。可以先使用教堂语境建立哀悼与信仰冲突，再把操作放在相邻附属空间，避免让现行神职角色无理由主持降神会。

### 11.3 Unit4 候选约束

主线候选可以从某件固定拍品的来源、寄押记录、付款方式、竞拍者反应或交割过程寻找。

不能把主线证据放进随机拍品池，也不能要求玩家竞价胜出才有资格继续主线。

### 11.4 Unit5 候选约束

玩家可以在庄园走廊发现松散修缮废料、允许取样的矿物或普通粉料，由老管家协助研磨，再选择颗粒粗细、媒介和画法。

基础材料由研磨台保证；探索材料只扩展画作。

前四幅画可以用色彩、空间和纹理隐约对应前四章，玩家完成《第五幅画》。这些画作、命名、隔夜龟裂或晕染及其人物评价默认全部属于支线，不能直接画出前四章案件答案。

以下物品禁止进入研磨或作画：

- 现行案件中的编号或无编号宝石。
- 武器、药物、血迹和衣物。
- 文件、照片和账目。
- 任何需要进入 CASE BOARD 的物件。
- 不可替代的家族藏品。

老管家的姓名尚未确定。用户方向已确认罗森是画家，可作为画室玩法的主持或创作来源；但该人物尚未进入现行角色档案与 Unit5 大纲，因此先记录为待补录事实，不让主线入口依赖其尚未校验的行动时序。

## 十二、完整例子：Unit2 赌博与连号钞票

### 12.1 玩法中的普通意义

玩家来到 Silver Moon，参与一段有输赢压力的赌博。

目标体验是玩家赢下赌局。Tony 在结算时没有从普通钱箱中找钱，而是拿出 Vinnie 之前消费留下的零钱，交给 Zack 三张钞票：

- 902B
- 903B
- 904B

此时这些钞票首先是赌场里的正常结算物。Tony 不知道它们是案件线索，也不是为了帮 Zack 查案才交出。

### 12.2 异常出现

Zack 在接过钞票后注意到编号连续。

这一刻只产生问题，不立即给出结论：

> 为什么 Vinnie 留下的三张新钞会恰好连续？

三张钞票转入案件系统，之后不再作为赌资使用。

### 12.3 与外部证据组合

玩家此前或随后取得：

- O'Hara 手中的 901B。
- O'Hara 手中的 905B。
- Tony 关于 Vinnie 曾用崭新钞票消费的证词。

五张钞票重新组成 901B—905B 的完整连续编号。

三张中间号证明它们与 O'Hara 的两张端点钞票来自同一批；Tony 证词则把 Vinnie 与中间三张钞票的消费行为连接起来。结合案件中的贷款与催债关系，玩家才能逐步建立 Leonard → O'Hara → Vinnie → Tony 的资金流。

外围玩法只负责让 902B—904B 以赌场结算物的身份自然出现，不替玩家解释整条资金链。

### 12.4 确定性保护

赌博保留随机过程，但主线桥梁不进入随机结果池。

推荐的保证顺序为：

1. 主线短局采用受保护的胜利或结算条件，让目标体验仍然是“获胜后拿到钱”。
2. 玩家失败时可以立即、低成本重试。
3. 连败或资金不足时，由 Tony 在同一赌博和结算语境内提供合理帮助。
4. 如果设计仍保留拒绝选项，玩家在相关主线检查点前可以返回；最终兜底也必须发生在 Tony 的结算语境内。
5. 无论走哪种保护路径，最终出现的都是同一组三张钞票和同一个资金流谜题。

### 12.5 主线职责终止

第一次取得三张钞票后：

- 后续赌博不再产出连号钞票。
- 输赢不改变案件证据。
- 赢钱、亏损、Tony 的评价和熟客状态全部属于支线。
- 不再通过赌博增加第二条银行、催债或凶手相关的主线谜题。

## 十三、支线短例

以下例子只说明“同一玩法如何落到人物”，不建立主线证据；实际对白仍需按角色所在 Loop 的知识边界另行设计。

### 13.1 Morrison

玩家把一杯调得偏淡或味道失衡的酒交给 Morrison。

Morrison 可以一边抱怨酒淡，一边准确指出比例或酒味的问题。玩家当下只把它当成一个老警察的挑剔；后续回看时，可能意识到他看似微醺，却始终在观察和计算。

这段只增加人物理解：

- 不让他提前承认腐败。
- 不让他因酒精说出 Whale、债务或枪械信息。
- 不产生证词。
- 不改变正式指证。

### 13.2 Rosa

玩家向 Rosa 提供烈酒时，她可以礼貌拒绝；提供温和或不含酒精的饮品时，她可以接受，并在安全时序内短暂谈到工作、女儿或自己必须保持清醒。

玩法揭示的是她的边界和处境，不是“把她灌醉后得到真话”。

她受到胁迫、保存弹壳及女儿相关的信息，仍应按照现行调查时序揭示。

### 13.3 《第五幅画》

玩家在庄园走廊发现允许取样的普通矿物或修缮废料，请老管家研磨成粗粉或细粉，再选择媒介进行作画。

颜色可能隔夜晕开、变暗、开裂或留下颗粒。玩家可以覆盖、刮除、接受结果，并为画作命名。

作品中的色彩和构图可以隐约回响前四章，但不直接复述案件结论。画作的完成状态、命名、陈列位置和人物评价全部属于支线。

在 Unit5 主线谜题合同正式绑定前，任何作画结果都不得被写成案件证据。

## 十四、设计验收清单

每章外围玩法进入制作前，应逐项通过：

- [ ] 玩法本身在没有案件奖励时仍然值得尝试。
- [ ] 承载场景能够解释玩法为什么存在。
- [ ] 玩家通过场景探索发现入口，而不是只靠任务弹窗。
- [ ] 第一次体验所需的基础工具和材料有保证。
- [ ] 探索材料只扩展支线，不暗中卡主线。
- [ ] 外围工具和材料使用独立记录，不进入 CASE BOARD。
- [ ] 本章只有一份外围玩法主线谜题合同。
- [ ] 主线异常在玩法中先有合理的日常意义。
- [ ] 异常是在动作或结算中自然出现，不是通关奖励。
- [ ] 随机、技巧和失败都不能阻断主线异常。
- [ ] 拒绝、退出、资金不足和场景关闭均有明确处理。
- [ ] 主线异常的安全出现 Loop 已确认。
- [ ] 主线证据一旦进入案件系统就不可消耗。
- [ ] 深入层重复玩法不再产出主线材料。
- [ ] 支线对话默认不转化为证词。
- [ ] 支线结果不改变案件结论或指证成功率。
- [ ] 不受控结果来自审核过的结果池。
- [ ] 稀有外围材料不会因失败或误操作永久丢失。
- [ ] Unit3 没有确认真实超自然提供案件答案。
- [ ] Unit5 没有加工任何主线证据或不可替代藏品。
- [ ] 尚未经过 Canon 审查的内容已明确标注为“待绑定”或“提案”。

如果“主线异常自然出现”和“无失败阻断”两项无法同时成立，应先退回修改主线接触层，不得依靠深入层或随机兜底补救。

## 十五、与现有文档的关系

### 15.1 与核心系统文档

案件物品、分析、合成、证词、疑点和指证继续遵守现有核心玩法规则。

本系统只新增一个独立的外围体验层，并规定何时把唯一的桥梁物件或信息移交给案件系统。它不改变 CASE BOARD 的证据定义，也不允许外围材料冒充案件物品。

### 15.2 与《NDC 五章节“章节外围玩法方向”提案》

旧方向提案继续承担：

- 历史和时代研究。
- 玩法候选池。
- 场景、职业和操作方向参考。
- A 类、B 类结构讨论的背景资料。

本详细规则承担：

- 五章外围玩法的统一系统定位。
- “每章一个确定主线谜题，其余全部支线”的当前规则。
- 场景供给、库存隔离和失败保护。
- 后续逐章详案的验收标准。

如果旧提案中的某个方案要求多个主线桥梁、将唯一证据放入随机深入层、让支线对话替代证词，或允许主线证据被玩法消耗，应以本规则为准重新设计。

### 15.3 尚待逐章确认

目前只有 Unit2 连号钞票完成了主线谜题落点确认。

Unit1、Unit3、Unit4、Unit5 下一步应分别完成：

1. 对照 `canon_manifest.json` 指向的现行大纲。
2. 从现有证据链中寻找一个适合在玩法里先合理出现、随后变义的对象。
3. 填写唯一的主线谜题合同。
4. 审查出现 Loop、失败兜底和案件系统转移。
5. 用户确认后，才进入具体玩法详案和数据实现。

在这四章完成上述步骤之前，调酒、降神会、盲拍和绘画均可继续进行支线层原型，但不得声称已经承担主线证据职责。
