# U4L5 Miller 当夜专线联络人设计

## 目标

为 U4L5 市政厅专线来电补齐 speaking character 的最小人物档案，使 `team-dialogue` 可以依据明确声纹撰写电话段，同时不把 Miller 上层过早具象化。

## 设计选择

新增一名匿名、仅声音、只服务本场的功能型角色“Miller 当夜专线联络人”。角色不露脸、不配置立绘、不设定姓名、性别、年龄和私人经历，也不预设在 Unit5 再次出现。

不采用以下方案：

- 不让 Mickey 复述全部条件。电话另一端直接说出条件，才能保留系统仍在现场施压的感觉。
- 不把来电者升级为具名反派。U4 此处需要呈现的是 Miller 系统的非人格化运转，而不是揭晓新的幕后人物。

## 叙事功能

来电者只负责交付一条真实可执行的生路：Mickey 交出保险档案、独自上车，便可暂时保留律师身份；Zack 可以离开，但不能带走档案。

来电者不关心 Mickey 是否受伤，不询问 Zack 查到了多少，也不参与价值辩论。Mickey 拒绝并拔掉电话线后，来电者没有追加反应。

## 声音约束

- 平稳、简短、程序化，像在确认一项已经批准的文件交接。
- 每句话只交代一个条件，不解释命令来源。
- 不威胁、不劝说、不争论，不使用黑帮式恐吓或现代客服话术。
- 称呼使用“Donnelly 先生”和“Brennan 先生”。

声音样张：

> “楼下的车已经到了。把保险档案交给司机，您一个人上车。”
>
> “Brennan 先生可以离开。档案不能带走。您的律师身份暂时保留。”

## 知识边界

- 只知道车辆、档案交接与撤离条件已经准备完成。
- 不透露 Miller 上层成员、命令来源或后续安排。
- 不评价 Mickey、Zack、Harrison 或 Morrison。
- 不补充 Sean、水源污染、小 Charles 或 Unit5 相关信息。

## 落地范围

新增 `剧情设计/Unit4/人物设定/miller_line_liaison.md`，格式参考同目录的功能型人物档案。此次不修改 active outline、Loop5 State、场景文档或 AVG 对白草稿。

## 验收标准

- `team-dialogue` 能从档案中取得该 speaking character 的身份、声纹、知识边界和禁忌。
- 电话条件与 active outline、Loop5 State 完全一致。
- 角色不会提前具象化 Miller 上层，也不会制造 Unit5 出场承诺。
- 档案不包含与本场无关的私人背景或美术需求。
