# Zack 内心 OS 撰写规则

> 用途：规范玩家点击道具、环境物、场景细节后触发的 Zack 单人内心 OS。
>
> 适用范围：所有 Unit。本文只规定写作结构、信息边界和常见错误，不限制具体情绪风格。猎奇、悲伤、厌恶、冷幽默、警觉、疲惫、同情等语气，都由当时道具和剧情情境决定。

---

## 一、核心功能

Zack 内心 OS 通常承担两步：

1. 描述：Zack 看见了什么。
2. 评论：Zack 基于当下所见产生一句主观判断、情绪反应或有限推测。

它不是完整推理链，不负责替玩家总结案件结论，也不强制推进疑点。玩家点击道具时，OS 的作用是让这个物件“被 Zack 看见”，并让玩家知道这个物件在当前场景中的气味、重量和方向。

---

## 二、基本结构

推荐结构：

```markdown
**扎克·布伦南（内心）** [一个很短的观察动作]
> 描述可见细节。

**扎克·布伦南（内心）** [一个很短的反应动作]
> Zack 的评论、情绪反应或有限推测。
```

也可以压缩成一句：

```markdown
**扎克·布伦南（内心）**
> 描述可见细节 + 一句评论。
```

使用一段还是两段，取决于道具重要性：

- 普通环境物：1 句即可。
- 有明显情绪或氛围重量的道具：2 句更稳。
- 关键证物或触发玩法的道具：可以 2 句以上，但不要变成完整案情复盘。

---

## 三、写作要求

### 1. 至少落在一个可见细节上

Zack 的评论必须先有抓手：血迹、折痕、刮痕、字迹、灰尘、酒渍、摆放位置、缺失痕迹、过度清理痕迹等。

不要直接空降结论。

```markdown
不推荐：
> Webb 这里一定藏着很多见不得人的生意。

推荐：
> 这些是……擦过，但没擦干净的血迹。
> 看样子，蓝月亮的生意，只靠酒、音乐和员工们的笑脸，可撑不起来。
```

第一句给玩家一个具体可见物，第二句才允许 Zack 做主观评论。

### 2. 评论必须来自当下情境

Zack 可以刻薄、厌恶、猎奇、难过，也可以短促地判断危险。但这句评论要能从“他现在看见的东西 + 他当前已知的信息”里长出来。

例如在勒索包厢里看到歌舞服、猎犬面具和短裤，评论可以带猎奇感，因为道具本身就在承担“堕落、羞辱、色情化权力游戏”的场景功能。

```markdown
可用：
> 女士的歌舞服，男款的猎犬面具和短裤……看来这包厢里曾经上演过一些相当狂野的戏码。
> 这上面留下的痕迹可不是谈正事弄出来的。那位记者小姐还是太年轻了，根本没看懂这背后暗示着什么……
```

这里的重点不是“避免猎奇”，而是“猎奇必须服务道具和场景”。

### 3. 不提前揭示后续真相

OS 可以给方向，但不能把后续 Loop 才揭示的结论提前说死。

可以写：

```markdown
> 休息的时候都在给城市分区、估价，然后挑下一个能下手的目标。
```

不要写：

```markdown
> 这说明 Webb 已经和 Whale 的南区计划连在一起。
```

除非当前 Loop 的玩家已经通过其他信息明确知道这件事。

### 4. 不把环境物强行写成证物

环境道具可以有信息量，但不等于玩家获得了可出示证物。写作时不要用“证据已经足够”“可以用这个反驳某人”这类出示导向的句子，除非配置上它确实是证物。

环境物更适合写：

```markdown
> 这里留下的不是答案，是一种习惯。
```

而不是：

```markdown
> 这就是证明 Webb 勒索他人的关键证据。
```

### 5. 不强制 Emma 参与

点击环境物的 Zack 内心 OS 默认是单人观察。除非该道具明确设计成二人互动、突发事件或剧情对话，否则不要额外加入 Emma 评论。

### 6. 不替玩家完成完整推理链

Zack 可以说“看起来不对”“这不像普通娱乐”“有人试图擦掉痕迹”。但不要从一个环境物一路推出完整犯罪流程。

OS 的理想状态是：玩家读完以后更想继续查，而不是觉得 Zack 已经替自己想完了。

---

## 四、情绪语气由场景决定

Zack 内心 OS 不要求统一成一种“克制侦探腔”。不同道具可以有不同语气。

常见语气：

- 冷静观察：用于血迹、文件、账本、工具痕迹。
- 厌恶或反胃：用于暴力、羞辱、堕落、操控感强的道具。
- 猎奇或尖锐讽刺：用于荒诞、色情化权力游戏、上流社会腐烂表演。
- 悲伤或柔软：用于遗物、家庭照片、绝笔信、病历、儿童相关物件。
- 警觉或压迫感：用于武器、监视痕迹、威胁纸条、地图、名单。
- 疲惫或冷幽默：用于轻量补充环境物，但不要破坏当前场景的主情绪。

规则不是“只能写克制”，而是“语气必须服务当下道具和剧情气氛”。

## 五、不同道具类型的写法

### 1. 血迹、破损、擦拭痕迹

写法重点：

- 先描述物理状态：新旧、颜色、位置、是否被擦过。
- 再写 Zack 对暴力、遮掩或反复发生的判断。

示例：

```markdown
> 这些是……擦过，但没擦干净的血迹。
> 看样子，蓝月亮的生意，只靠酒、音乐和员工们的笑脸，可撑不起来。
```

### 2. 地图、名单、标记类环境物

写法重点：

- 先描述标记方式：飞镖、圈画、折角、删改、价格、代号。
- 再写 Zack 对“操控”“猎物化”“分区估价”等行为方式的评价。

示例：

```markdown
> 看来，这张写满了政敌和竞争对手的飞镖地图，就是 Webb 平日里消遣游乐的对象。
> 休息的时候都在给城市分区、估价，然后挑下一个能下手的目标。难怪他死的这么不明不白。
```

### 3. 衣物、面具、舞台道具、情色化环境物

写法重点：

- 可以猎奇，但要落在道具本身：衣物、面具、短裤、抓痕、酒渍、摆放状态。
- 可以写不适、荒唐、堕落、权力游戏。
- 不要写成旁白式色情描写，不要脱离 Zack 的侦探视角。

示例：

```markdown
> 女士的歌舞服，男款的猎犬面具和短裤……看来这包厢里曾经上演过一些相当狂野的戏码。
> 这上面留下的痕迹可不是谈正事弄出来的。那位记者小姐还是太年轻了，根本没看懂这背后暗示着什么……
```

### 4. 情感类遗物

写法重点：

- 少解释，多停顿。
- 让物件自己承载悲伤：折痕、磨损、反复翻看、藏起的位置。
- Zack 可以有温柔或沉默，但不要替角色念悼词。

示例模板：

```markdown
> 这张照片的边角被摸得发白。不是随手放在这里的东西。
> 有些人把想说的话写进信里，有些人只敢把它压在抽屉最底下。
```

### 5. 可分析或派生证据

写法重点：

- 可以提示“这东西还没说完”，但不要直接告诉玩家操作答案。
- 如果后续要进分析玩法，OS 可以引导玩家注意材质、痕迹、背面、气味、重量。

示例模板：

```markdown
> 背面这些淡黄的污渍不像普通水痕。
> 先收起来。纸有时候比人更诚实，只是需要一点耐心。
```

## 六、常见错误

### 1. 只有评论，没有描述

```markdown
不推荐：
> Webb 真是个恶心的混蛋。
```

问题：玩家不知道 Zack 是从哪个物件细节得出这个反应的。

### 2. 描述太长，像美术需求

```markdown
不推荐：
> 桌面是一张深胡桃木圆桌，左侧有三处黑红色血迹，边缘呈放射状，右侧还有擦拭留下的细小布纹。
```

问题：OS 不是资源说明。细节要够玩家理解，不要像交付清单。

### 3. 直接剧透后续 Loop

```markdown
不推荐：
> 这张地图说明 Webb 已经发现了 Whale 的城市清退计划。
```

问题：如果当前 Loop 玩家还不知道 Whale 或清退计划，这就是提前破梗。

### 4. 把所有情绪都写成同一种克制

```markdown
不推荐：
> 这件东西有异常，需要记录。
```

问题：如果道具本身是强情绪物件，过度中性会削弱场景。该猎奇时可以猎奇，该难过时可以难过。

### 5. Zack 说得比玩家能看到的多

```markdown
不推荐：
> 这说明有人在 23:10 到 23:20 之间进过房间。
```

问题：如果道具没有时间信息，这句话就是凭空推理。

## 七、快速检查清单

写完一段 Zack 内心 OS 后，检查这几件事：

1. 有没有至少一个可见物件细节？
2. Zack 的评论是否来自当前看见的东西？
3. 有没有提前说出后续 Loop 才该揭示的真相？
4. 这件道具是环境还是证物，措辞有没有混淆？
5. 是否不必要地加入了 Emma 或其他 NPC？
6. 情绪是否服务当前场景，而不是被规则硬拧成单一风格？
7. 字数是否适合点击反馈，不像长篇旁白？
