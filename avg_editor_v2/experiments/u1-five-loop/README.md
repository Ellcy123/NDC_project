# U1·五 Loop 试验版：L2

独立试验单元，身份为 `u1-five-loop-test`。不占用正式章节编号，不覆盖原 U1；当前只开放 L2。

## 打开

运行 `avg_editor_v2/server.py`，访问 http://localhost:9529/experiments/u1-five-loop/index.html 。也可在编辑器章节下拉框选择“试验 U - U1 五 Loop 版（L2 可玩）”。

六处调查地点、六名可交谈 NPC、十三个主题、两轮指证。各 NPC 最多三个主题，另加退出；Emma 第三个主题在取得照片后开放。照片可从随身记录带回小包厢分析。

两轮指证始终显示全部已取得材料。错件可以重试；正确答案混入无关材料时，单独说明已经包含有效反驳，请玩家整理材料，不播放否定推理的 NPC 台词。可选理由只记入本地试玩记录，不作自动语义判分。

存档仅使用 `ndc:experiment:u1-five-loop-test:l2:v1`。选项可重新试玩或导出调查顺序、台词、取得材料和提交记录。当前没有 L3—L5、语音和 Unity 配表回写。

## 对白与构建

中文来源：`剧情设计/试验单元/U1_五Loop试验版/L2_完整对白.md`。

运行本目录 `build_dialogue.py` 生成局部 `dialogue.json`；不运行正式 U1 台本同步脚本。当前为 43 段、239 个发言节点、13 个主题。

`manifest.json` 持有本试验的场景、材料和题目合同；`engine.js` 实现流程；`app.js` 展示界面。场景图复制自现有工程资产，没有修改源图。

## 验收

- `node test.mjs`：前置门槛、条件主题、分析替换、重复调查、完整候选池、错件／子集／超集、两轮正确推进和存档恢复。
- `node ui-test.mjs`：实际浏览器完整点击通关、错选重试、对白中刷新、导出、移动端和编辑器入口。该脚本的 Playwright 路径对应本机 Codex 运行时。
- `qa/ui-report.json`、`qa/playthrough.json` 和截图保留浏览器结果。
- `qa/preservation-report.json`：148 个原 U1／正式配置／Manifest 文件与动工前 SHA256 一致。

原编辑器仅增加试验入口；试验内容、生成数据及存档独立。内容审查已闭合照片数量、证词密度、物件位置和超集反馈问题；实际玩家是否能自然推到答案，仍需试玩反馈，自动通关不代替体验判断。
